(x)1 mark

Why are the rows and columns of a Karnaugh map labelled in the order 00, 01, 11, 10 and not 00, 01, 10, 11? (Understanding)

Answer

The order 00, 01, 11, 10 is the Gray code: neighbouring cells (including the two end cells) differ in only one variable, so adjacent 1s (or 0s) can be grouped and that variable eliminated. In 01 → 10 two bits change, so the cells would not be logically adjacent.

Gray code in a K-map: B26 1x. Rank 28.

A Dudeney number is a positive integer that is a perfect cube such that the sum of its digits is equal to the cube root of the number.

Example: 5832 = 183 and 5 + 8 + 3 + 2 = 18; 4913 = 173 and 4 + 9 + 1 + 3 = 17. 1000 = 103 is not a Dudeney number, as 1 + 0 + 0 + 0 = 1.

A class Dudeney has been defined to check whether a number is a Dudeney number. Some of the members of the class are given below:

Class name:Dudeney
Data members/instance variables:
num:to store a positive integer
Methods/Member functions:
Dudeney( ):default constructor to initialise the data member with a legal initial value
void input( ):to accept the number num
int sumDigits(int x):returns the sum of the digits of x using the recursive technique
int cubeRoot(int n):returns the cube root of n if n is a perfect cube, otherwise returns −1
void isDude( ):checks whether num is a Dudeney number by invoking the functions cubeRoot( ) and sumDigits( ), and displays an appropriate message

Specify the class Dudeney giving details of the constructor( ), void input( ), int sumDigits(int), int cubeRoot(int) and void isDude( ). Define a main( ) function to create an object and call the functions accordingly to enable the task.

(Create)
Answer
import java.util.*;

class Dudeney
{
    int num;                                 // the number to be checked

    Dudeney()                                // default constructor
    {
        num = 0;
    }

    void input()                             // accepts the number
    {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter a positive number : ");
        num = sc.nextInt();
    }

    int sumDigits(int x)                     // sum of the digits, recursively
    {
        if (x == 0)                          // no digits left
            return 0;
        return x % 10 + sumDigits(x / 10);   // last digit + sum of the rest
    }

    int cubeRoot(int n)                      // cube root if n is a perfect cube, else -1
    {
        int r = 1;
        while (r * r * r < n)
            r++;
        if (r * r * r == n)
            return r;
        return -1;
    }

    void isDude()
    {
        int cr = cubeRoot(num);
        if (cr != -1 && sumDigits(num) == cr)
            System.out.println(num + " IS A DUDENEY NUMBER");
        else
            System.out.println(num + " IS NOT A DUDENEY NUMBER");
    }

    public static void main()
    {
        Dudeney ob = new Dudeney();
        ob.input();
        ob.isDude();
    }
}

Output for 5832: 5832 IS A DUDENEY NUMBER; for 1000: 1000 IS NOT A DUDENEY NUMBER.

Answer
import java.util.*;

class MatRev
{
    int arr[][];                             // the matrix
    int m, n;                                // number of rows and columns

    static Scanner sc = new Scanner(System.in);

    MatRev(int mm, int nn)                   // parameterised constructor
    {
        m = mm;
        n = nn;
        arr = new int[m][n];
    }

    void fillarray()                         // accepts the elements
    {
        System.out.println("Enter " + (m * n) + " positive integers :");
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
                arr[i][j] = sc.nextInt();
    }

    int reverse(int x)                       // returns the reverse of x
    {
        int rev = 0;
        while (x > 0)
        {
            rev = rev * 10 + x % 10;
            x = x / 10;
        }
        return rev;
    }

    void revMat(MatRev P)                    // current object = P with every element reversed
    {
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
                arr[i][j] = reverse(P.arr[i][j]);
    }

    void show()                              // displays the matrix row by row
    {
        for (int i = 0; i < m; i++)
        {
            for (int j = 0; j < n; j++)
                System.out.print(arr[i][j] + "\t");
            System.out.println();
        }
    }

    public static void main()
    {
        System.out.print("Enter the number of rows and columns : ");
        int r = sc.nextInt();
        int c = sc.nextInt();
        MatRev A = new MatRev(r, c);
        MatRev B = new MatRev(r, c);
        A.fillarray();
        B.revMat(A);
        System.out.println("ORIGINAL MATRIX");
        A.show();
        System.out.println("REVERSED MATRIX");
        B.show();
    }
}

void addRear(int v):to add a book at the rear end if possible, otherwise display the message “RACK FULL AT REAR”
int removeFront( ):to remove and return the accession number at the front end; if the rack is empty, return −9999
int removeRear( ):to remove and return the accession number at the rear end; if the rack is empty, return −9999

Specify the class BookRack giving details of the functions void addRear(int) and int removeFront( ). Assume that the other functions have been defined.
The main( ) function and algorithm need NOT be written.

(Create)
Answer
class BookRack
{
    int bk[];                                // accession numbers of the books
    int cap;                                 // capacity of the rack
    int front, rear;                         // indices of the two ends

    BookRack(int max)
    {
        cap = max;
        bk = new int[cap];
        front = rear = -1;                   // the rack is empty
    }

    void addRear(int v)                      // add a book at the rear end
    {
        if (rear == cap - 1)                 // no room left at the rear
            System.out.println("RACK FULL AT REAR");
        else
        {
            if (front == -1)                 // first book on an empty rack
                front = 0;
            bk[++rear] = v;
        }
    }

    int removeFront()                        // remove the book at the front end
    {
        if (front == -1)                     // the rack is empty
            return -9999;
        int v = bk[front];
        if (front == rear)                   // the only book has been removed
            front = rear = -1;
        else
            front++;
        return v;
    }
}

Answer
ALGORITHM:
Step 1. Start.
Step 2. Set pos = 1 and ptr = start.
Step 3. Repeat Steps 4 and 5 while ptr ≠ null.
Step 4. If ptr.data = v then return pos.
Step 5. Set ptr = ptr.next and pos = pos + 1.

int position(Node start, int v)
{
    int pos = 1;
    Node ptr = start;
    while (ptr != null)                      // examine every node, the last one included
    {
        if (ptr.data == v)
            return pos;                      // first node holding v
        ptr = ptr.next;
        pos++;
    }
    return -1;                               // v is not in the list
}
