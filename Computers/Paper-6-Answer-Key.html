Question 610 marks

A Happy number is one which eventually reaches 1 when it is replaced, again and again, by the sum of the squares of its digits. If the process reaches 4 instead, it then repeats the cycle 4, 16, 37, 58, 89, 145, 42, 20, 4 for ever and the number is not happy.

Example 1: 28 -> 4 + 64 = 68 -> 36 + 64 = 100 -> 1 + 0 + 0 = 1 so 28 is a HAPPY number Example 2: 20 -> 4 + 0 = 4, so 20 is NOT a happy number

Design a class Happy to check whether a given positive number is a happy number. Some of the members of the class are given below:

Class name:Happy
Data members/instance variables:
n:to store the number
Methods/Member functions:
Happy( ):default constructor to initialise the data member with a legal initial value
void getnum(int nn):to assign the parameter value nn to the number n
int sum_sq_digits(int x):returns the sum of the squares of the digits of x using the recursive technique
void ishappy( ):checks whether n is a happy number by invoking sum_sq_digits( ) repeatedly, and displays an appropriate message

Specify the class Happy giving details of the constructor( ), void getnum(int), int sum_sq_digits(int) and void ishappy( ). Define a main( ) function to create an object and call the functions accordingly to enable the task.

(Create)
Answer
import java.util.*;

class Happy
{
    int n;                                   // the number

    Happy()                                  // default constructor
    {
        n = 0;
    }

    void getnum(int nn)                      // assigns the number
    {
        n = nn;
    }

    int sum_sq_digits(int x)                 // sum of the squares of the digits, recursively
    {
        if (x == 0)
            return 0;
        int d = x % 10;
        return d * d + sum_sq_digits(x / 10);
    }

    void ishappy()
    {
        int s = n;
        while (s != 1 && s != 4)             // every unhappy number falls into the cycle through 4
            s = sum_sq_digits(s);
        if (s == 1)
            System.out.println(n + " IS A HAPPY NUMBER");
        else
            System.out.println(n + " IS NOT A HAPPY NUMBER");
    }

    public static void main()
    {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter a positive number : ");
        Happy ob = new Happy();
        ob.getnum(sc.nextInt());
        ob.ishappy();
    }
}

Checked on 28, 7, 19, 1 (happy) and 4, 20, 2, 89 (not happy). 7 is happy: 7 → 49 → 97 → 130 → 10 → 1.

Trap Stopping as soon as the value has one digit (a common textbook shortcut) wrongly calls 7 unhappy. Stop at 1 or 4.

A class Angle stores an angle in degrees, minutes and seconds in an array of three integers (60 seconds = 1 minute, 60 minutes = 1 degree). Two angles are added and their sum is returned as an object.

Example: First angle : 45 deg 50 min 40 sec Second angle : 30 deg 25 min 35 sec Sum : 76 deg 16 min 15 sec

Methods/Member functions:

void dispAngle( ):to display the angle in degrees, minutes and seconds

Specify the class Angle giving details of the constructor( ), void readAngle( ), Angle addAngle(Angle) and void dispAngle( ). Define a main( ) function to create objects and call the functions accordingly to enable the task.

(Create)
Answer
import java.util.*;

class Angle
{
    int arr[] = new int[3];                  // degrees, minutes and seconds

    static Scanner sc = new Scanner(System.in);

    Angle()                                  // default constructor
    {
        arr[0] = arr[1] = arr[2] = 0;
    }

    void readAngle()                         // accepts degrees, minutes, seconds
    {
        System.out.print("Enter degrees, minutes and seconds : ");
        for (int i = 0; i < 3; i++)
            arr[i] = sc.nextInt();
    }

    Angle addAngle(Angle t)                  // current angle + t, returned in a new object
    {
        Angle s = new Angle();
        int sec = arr[2] + t.arr[2];
        int min = arr[1] + t.arr[1] + sec / 60;          // carry the whole minutes
        s.arr[2] = sec % 60;
        s.arr[1] = min % 60;
        s.arr[0] = arr[0] + t.arr[0] + min / 60;         // carry the whole degrees
        return s;
    }

    void dispAngle()
    {
        System.out.println(arr[0] + " deg " + arr[1] + " min " + arr[2] + " sec");
    }

    public static void main()
    {
        Angle a = new Angle();
        Angle b = new Angle();
        a.readAngle();
        b.readAngle();
        Angle c = a.addAngle(b);
        System.out.print("FIRST ANGLE : ");
        a.dispAngle();
        System.out.print("SECOND ANGLE : ");
        b.dispAngle();
        System.out.print("SUM : ");
        c.dispAngle();
    }
}

Example: 40 + 35 = 75 s = 1 min 15 s; 50 + 25 + 1 = 76 min = 1° 16 min; 45 + 30 + 1 = 76°. Sum 76 deg 16 min 15 sec.

Trap Carry the whole minutes out of the seconds BEFORE reducing the minutes mod 60, and the whole degrees out of the minutes after that; reducing the minutes first loses the carry when 59 min 59 s + 1 s ripples through both places (120° 59′ 59″ + 1″ must give 121° 0′ 0″).

A network card stores incoming data packets (integers) in a buffer. Packets are added at the rear and removed from the front, and the positions freed at the front are reused, the rear end being connected to the front end in a circular arrangement.

Define a class Buffer with the following details:

Class name:Buffer

pkt[ ]:array to hold the integer packets
cap:stores the maximum capacity of the array
front:to point to the index of the front
rear:to point to the index of the rear
Methods/Member functions:

void insert(int v):to add a packet at the rear if possible, otherwise display the message “BUFFER FULL”
int delete( ):to remove and return the packet from the front; if the buffer is empty, return −9999
void show( ):to display the packets from front to rear

Specify the class Buffer giving details of the functions void insert(int) and int delete( ). Assume that the other functions have been defined.
The main( ) function and algorithm need NOT be written.

(Create)
Answer
class Buffer
{
    int pkt[];                               // the data packets
    int cap;                                 // capacity of the array
    int front, rear;                         // front and rear indices

    Buffer(int max)
    {
        cap = max;
        pkt = new int[cap];
        front = rear = 0;
    }

    void insert(int v)                       // add a packet at the rear
    {
        if ((rear + 1) % cap == front)       // next rear position is the front: full
            System.out.println("BUFFER FULL");
        else
        {
            rear = (rear + 1) % cap;         // move rear round the circle
            pkt[rear] = v;
        }
    }

    int delete()                             // remove the packet at the front
    {
        if (front == rear)                   // empty
            return -9999;
        front = (front + 1) % cap;           // move front round the circle
        return pkt[front];
    }
}

Note Here front marks the slot just before the first packet, so one slot is always left empty: a buffer of cap 4 holds 3 packets, and front = rear means empty. Tested: after two deletions the freed slots are reused. Any consistent convention earns the marks — e.g. front = rear = −1 with front at the first packet, or a separate count of packets.

A linked list is formed from the objects of the class Node. The class structure of the Node is given below:

Write an Algorithm OR a Method to reverse an existing linked list (the last node becomes the first) and return the reference to the first node of the reversed list. The method declaration is as follows:

Node reverse(Node start)

(Analysis)
Answer
ALGORITHM:
Step 1. Start.
Step 2. Set prev = null and cur = start.
Step 3. Repeat Steps 4 to 7 while cur ≠ null.
Step 4. Set nxt = cur.next.
Step 5. Set cur.next = prev.
Step 6. Set prev = cur.
Step 7. Set cur = nxt.
Step 8. Return prev (the first node of the reversed list).
Step 9. End algorithm.

METHOD:

Node reverse(Node start)
{
    Node prev = null, cur = start, nxt;
    while (cur != null)
    {
        nxt = cur.next;                      // remember the rest of the list
        cur.next = prev;                     // turn this link round
        prev = cur;
        cur = nxt;
    }
    return prev;                             // the old last node is the new first node
}
