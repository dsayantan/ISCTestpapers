Study the given propositions and the statements marked Assertion and Reason that follow. Choose the correct option on the basis of your analysis.

P – It is raining.   Q – The road is wet.
S1 = P ⇒ Q   S2 = ~Q ⇒ ~P

Assertion: S2 is the converse of S1.
Reason: The converse of a conditional statement is formed by negating both its antecedent and its consequent.

(ix)1 mark

Differentiate between a tautology and a contradiction. (Understanding)

Answer

A tautology is a compound proposition (Boolean expression) whose value is always true (1) for every combination of the values of its variables; a contradiction is one whose value is always false (0) for every combination.

Tautology / contradiction in words: B25I 1ix (identical wording). Forecast tier A.
(x)1 mark

What is Gray code in a Karnaugh map? (Understanding)

Answer

A Gray code is a sequence of binary codes in which any two consecutive codes differ in exactly one bit (00, 01, 11, 10). The rows and columns of a K-map are labelled in this order so that adjacent cells differ in one variable and can be grouped.

Gray code: B26 1x (identical question). Forecast tier A.

Question 610 marks

A fraction is a combination of two positive integers, a numerator and a denominator. A fraction is in its lowest terms when its numerator and denominator have no common factor except 1. Design a class Fraction to reduce a fraction to its lowest terms, and to add two fractions.

Example 1: 35/77 in lowest terms is 5/11 Example 2: 1/6 + 3/10 = 28/60 = 7/15

The details of the members of the class are given below:

Class name:Fraction
Data members/instance variables:
n, d:integer variables to store the numerator and the denominator respectively
Methods/Member functions:
Fraction(int a, int b):parameterised constructor to initialise the data members
int fnHCF(int a, int b):to return the highest common factor of a and b using the recursive technique
Fraction fnReduce(Fraction f1):to reduce the fraction f1 to its lowest terms using fnHCF( ) and to return it as a new object
Fraction fnAdd(Fraction f1):to add the current fraction and f1 and to return the sum in its lowest terms, by calling fnReduce( )
void fnShow( ):to display the fraction in the form n/d

Specify the class Fraction giving details of the constructor( ), int fnHCF(int, int), Fraction fnReduce(Fraction), Fraction fnAdd(Fraction) and void fnShow( ). Define a main( ) function to create objects and call the functions accordingly to enable the task.

(Create)
Answer
import java.util.*;

class Fraction
{
    int n, d;                                // numerator and denominator

    Fraction(int a, int b)                   // parameterised constructor
    {
        n = a;
        d = b;
    }

    int fnHCF(int a, int b)                  // highest common factor, recursively (Euclid)
    {
        if (b == 0)
            return a;
        return fnHCF(b, a % b);
    }

    Fraction fnReduce(Fraction f1)           // f1 in its lowest terms, as a new object
    {
        int h = fnHCF(f1.n, f1.d);
        return new Fraction(f1.n / h, f1.d / h);
    }

    Fraction fnAdd(Fraction f1)              // current fraction + f1, in lowest terms
    {
        Fraction s = new Fraction(n * f1.d + f1.n * d, d * f1.d);
        return fnReduce(s);
    }

    void fnShow()
    {
        System.out.println(n + "/" + d);
    }

    public static void main()
    {
        Scanner sc = new Scanner(System.in);
        System.out.println("Enter numerator and denominator of two fractions :");
        Fraction f1 = new Fraction(sc.nextInt(), sc.nextInt());
        Fraction f2 = new Fraction(sc.nextInt(), sc.nextInt());
        System.out.print("First fraction   : ");
        f1.fnShow();
        System.out.print("After reduction  : ");
        f1.fnReduce(f1).fnShow();
        System.out.print("Second fraction  : ");
        f2.fnShow();
        System.out.print("Sum (lowest terms) : ");
        f1.fnAdd(f2).fnShow();
    }
}

import java.util.*;

class Anagram
{
    String s1, s2;                           // the two words
    int l1, l2;                              // their lengths

    Anagram(String a, String b)
    {
        s1 = a;
        s2 = b;
        l1 = s1.length();
        l2 = s2.length();
    }

    void sort(char c[])                      // bubble sort in ascending order
    {
        for (int i = 0; i < c.length - 1; i++)
            for (int j = 0; j < c.length - 1 - i; j++)
                if (c[j] > c[j + 1])
                {
                    char t = c[j];
                    c[j] = c[j + 1];
                    c[j + 1] = t;
                }
    }

    boolean areAnagram(char[] str1, char[] str2)
    {
        sort(str1);
        sort(str2);
        for (int i = 0; i < str1.length; i++)
            if (str1[i] != str2[i])          // the sorted words differ at i
                return false;
        return true;
    }

    void check()
    {
        if (l1 != l2)                        // different lengths cannot be anagrams
        {
            System.out.println(s1 + " and " + s2 + " are not anagram of each other");
            return;
        }
        char a[] = s1.toCharArray();
        char b[] = s2.toCharArray();
        if (areAnagram(a, b))
            System.out.println(s1 + " and " + s2 + " are anagram of each other");
        else
            System.out.println(s1 + " and " + s2 + " are not anagram of each other");
    }

    public static void main()
    {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter first word -> ");
        String w1 = sc.next().toLowerCase();
        System.out.print("Enter second word -> ");
        String w2 = sc.next().toLowerCase();
        Anagram ob = new Anagram(w1, w2);
        ob.check();
    }
}

class TokenLine
{
    int tk[];                                // the tokens (a maximum of 100)
    int cap;                                 // capacity of the array
    int f, r;                                // front and rear indices

    TokenLine(int m)
    {
        cap = m;
        f = 0;
        r = -1;
        tk = new int[cap];
    }

    void addToken(int v)                     // insert at the rear
    {
        if (r == cap - 1)
            System.out.println("Overflow! Insertion not possible.");
        else
        {
            r++;
            tk[r] = v;
        }
    }

    int serveToken()                         // remove from the front
    {
        if (f > r)
        {
            System.out.println("Underflow! Deletion not possible.");

        return v;
    }

    {
        for (int i = f; i <= r; i++)
            System.out.print(tk[i] + " ");
        System.out.println();
    }
}

(Analysis)
Answer
ALGORITHM:
Step 1. Start.
Step 2. If start = null or n < 1, return start (nothing to delete).
Step 3. If n = 1, return start.next (the second node becomes the first).
Step 4. Set cur = start and pos = 1.
Step 5. Repeat while cur.next ≠ null and pos < n − 1: set cur = cur.next and pos = pos + 1.
Step 6. If cur.next ≠ null, set cur.next = cur.next.next (the nth node is bypassed).
Step 7. Return start.
Step 8. End algorithm.

METHOD:

Node deleteNth(Node start, int n)
{
    if (start == null || n < 1)
        return start;                        // nothing to delete
    if (n == 1)
        return start.next;                   // the first node is removed
    Node cur = start;
    int pos = 1;
    while (cur.next != null && pos < n - 1)  // stop at the node just before position n
    {
        cur = cur.next;
        pos++;
    }
    if (cur.next != null)                    // position n exists
        cur.next = cur.next.next;            // bypass it
    return start;
}

Trap Deleting the first node needs the new start to be returned: a method that only changes links cannot remove the head. Stop at the node before position n, not at position n.
