Given below are two statements marked Assertion and Reason. Read the two statements carefully and choose the correct option.

Assertion: A class that implements an interface must implement all of its methods (unless the class is itself declared abstract).
Reason: If a class does not implement all the methods of an interface, it can still be instantiated.

(Analysis)
(a)Both Assertion and Reason are true and Reason is the correct explanation for Assertion.(b)Both Assertion and Reason are true but Reason is not the correct explanation for Assertion.(c)Assertion is true and Reason is false.(d)Both Assertion and Reason are false.
Answer

Question 610 marks

A fraction is a combination of two positive integers, a numerator and a denominator. A fraction is in its lowest terms when its numerator and denominator have no common factor except 1. Design a class Fraction to reduce a fraction to its lowest terms, and to add two fractions.

Example 1: 35/77 in lowest terms is 5/11 Example 2: 1/6 + 3/10 = 28/60 = 7/15

The details of the members of the class are given below:

Class name:Fraction
Data members/instance variables:
n, d:integer variables to store the numerator and the denominator respectively
Methods/Member functions:
Fraction(int a, int b):parameterised constructor to initialise the data members
int fnHCF(int a, int b):to return the highest common factor of a and b using the recursive technique
Fraction fnReduce(Fraction f1):to reduce the fraction f1 to its lowest terms using fnHCF( ) and to return it as a new object
Fraction fnAdd(Fraction f1):to add the current fraction and f1 and to return the sum in its lowest terms, by calling fnReduce( )
void fnShow( ):to display the fraction in the form n/d

Specify the class Fraction giving details of the constructor( ), int fnHCF(int, int), Fraction fnReduce(Fraction), Fraction fnAdd(Fraction) and void fnShow( ). Define a main( ) function to create objects and call the functions accordingly to enable the task.

(Create)
Answer
import java.util.*;

class Fraction
{
    int n, d;                                // numerator and denominator

    Fraction(int a, int b)                   // parameterised constructor
    {
        n = a;
        d = b;
    }

    int fnHCF(int a, int b)                  // highest common factor, recursively (Euclid)
    {
        if (b == 0)
            return a;
        return fnHCF(b, a % b);
    }

    Fraction fnReduce(Fraction f1)           // f1 in its lowest terms, as a new object
    {
        int h = fnHCF(f1.n, f1.d);
        return new Fraction(f1.n / h, f1.d / h);
    }

    Fraction fnAdd(Fraction f1)              // current fraction + f1, in lowest terms
    {
        Fraction s = new Fraction(n * f1.d + f1.n * d, d * f1.d);
        return fnReduce(s);
    }

    void fnShow()
    {
        System.out.println(n + "/" + d);
    }

    public static void main()
    {
        Scanner sc = new Scanner(System.in);
        System.out.println("Enter numerator and denominator of two fractions :");
        Fraction f1 = new Fraction(sc.nextInt(), sc.nextInt());
        Fraction f2 = new Fraction(sc.nextInt(), sc.nextInt());
        System.out.print("First fraction   : ");
        f1.fnShow();
        System.out.print("After reduction  : ");
        f1.fnReduce(f1).fnShow();
        System.out.print("Second fraction  : ");
        f2.fnShow();
        System.out.print("Sum (lowest terms) : ");
        f1.fnAdd(f2).fnShow();
    }
}

import java.util.*;

class PalPrime
{
    String line;                             // the sentence

    PalPrime()                               // default constructor
    {
        line = "";
    }

    void accept()
    {
        Scanner sc = new Scanner(System.in);
        System.out.println("Enter a sentence in UPPER CASE :");
        line = sc.nextLine().trim().toUpperCase();
    }

    boolean isPalin(String w)                // reads the same from both ends?
    {
        int i = 0, j = w.length() - 1;
        while (i < j)
        {
            if (w.charAt(i) != w.charAt(j))
                return false;
            i++;
            j--;
        }
        return true;
    }

    boolean isPrime(int n)
    {
        if (n < 2)
            return false;
        for (int i = 2; i * i <= n; i++)
            if (n % i == 0)
                return false;
        return true;
    }

    void display()
    {
        StringTokenizer st = new StringTokenizer(line);
        String res = "";
        int c = 0;
        while (st.hasMoreTokens())
        {
            String w = st.nextToken();
            if (isPalin(w) && isPrime(w.length()))     // palindrome of prime length
            {
                res = res + (c > 0 ? ", " : "") + w;
                c++;
            }
        }
        if (c == 0)
            System.out.println("NO PALPRIME WORDS");
        else
        {
            System.out.println(res);
            System.out.println("NUMBER OF PALPRIME WORDS = " + c);
        }
    }

    public static void main()
    {
        PalPrime ob = new PalPrime();
        ob.accept();
        ob.display();
    }
}

class RingQ
{
    int q[];                                 // the elements
    int cap;                                 // capacity of the array
    int f, r;                                // front and rear indices

    RingQ(int max)
    {
        cap = max;
        f = 0;
        r = 0;
        q = new int[cap];
    }

    void push(int n)                         // add at the rear
    {
        if ((r + 1) % cap == f)              // the next rear position is the front: full
            System.out.println("QUEUE FULL");
        else
        {
            r = (r + 1) % cap;               // move rear round the circle
            q[r] = n;
        }
    }

    int pop()                                // remove from the front
    {
        if (f == r)                          // empty
            return -999;
        f = (f + 1) % cap;                   // move front round the circle
        return q[f];
    }

    void display()
    {
        for (int i = f; i != r; )
        {
            i = (i + 1) % cap;
            System.out.print(q[i] + " ");
        }
        System.out.println();
    }
}

Write an Algorithm OR a Method to insert a new element x at the position pos (the first node is at position 1) of an existing linked list and return the reference to the first node of the list. A position one beyond the last node appends the element; if pos is larger than that, or less than 1, the list is left unchanged. The method declaration is as follows:

Node insertAt(Node start, int x, int pos)

(Analysis)
Answer
ALGORITHM:
Step 1. Start.
Step 2. If pos < 1, return start.
Step 3. Create a new node nw and set nw.n = x.
Step 4. If pos = 1, set nw.link = start and return nw (the new first node).
Step 5. Set cur = start and i = 1.
Step 6. Repeat while cur ≠ null and i < pos − 1: set cur = cur.link and i = i + 1.
Step 7. If cur = null, return start (pos is more than one beyond the last node).
Step 8. Set nw.link = cur.link and cur.link = nw.
Step 9. Return start.
Step 10. End algorithm.

METHOD:

Node insertAt(Node start, int x, int pos)
{
    if (pos < 1)
        return start;                        // no such position
    Node nw = new Node();
    nw.n = x;
    if (pos == 1)
    {
        nw.link = start;                     // the new node becomes the first node
        return nw;
    }
    Node cur = start;
    int i = 1;
    while (cur != null && i < pos - 1)       // stop at the node just before position pos
    {
        cur = cur.link;
        i++;
    }
    if (cur == null)
        return start;                        // the list is too short: unchanged
    nw.link = cur.link;                      // new node points to the old pos-th node
    cur.link = nw;                           // previous node points to the new node
    return start;
}

Trap Inserting at position 1 changes the first node, so the new node must be returned; and the new node must be linked to the old pos-th node before the previous node is pointed to it, or the rest of the list is lost.
