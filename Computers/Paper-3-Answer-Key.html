Question 610 marks

An Emirp number is a prime number which is also prime when its digits are reversed.

Example: 13 and 31 are both prime, so 13 is an Emirp number.
23 is prime but 32 is not, so 23 is not an Emirp number.

Design a class Emirp to check if a given number is an Emirp number. Some of the members of the class are given below:

Class name: Emirp
Data members/instance variables:
n: to store the number
rev: to store the reverse of n
Methods / Member functions:
Emirp(int nn): parameterised constructor to initialise n = nn and rev = 0
void reverse( ): to reverse the number n and store it in rev
boolean isPrime(int x, int d): returns true if x is a prime number, otherwise false, using the recursive technique, where d is the divisor being tried (initially 2)
void isEmirp( ): checks whether n is an Emirp number by invoking reverse( ) and isPrime( ), and displays an appropriate message

Specify the class Emirp giving details of the constructor(int), void reverse( ), boolean isPrime(int, int) and void isEmirp( ). Define the main( ) function to create an object and call the functions accordingly to enable the task.

(Create)
Answer
import java.util.*;
class Emirp
{
    int n;          // the number
    int rev;        // its reverse
    static Scanner sc = new Scanner(System.in);

    Emirp(int nn)
    {
        n = nn;
        rev = 0;
    }

    // stores the reverse of n in rev
    void reverse()
    {
        int t = n;
        rev = 0;
        while (t > 0)
        {
            rev = rev * 10 + t % 10;
            t = t / 10;
        }
    }

    // true if x is prime; d is the divisor being tried, starting at 2
    boolean isPrime(int x, int d)
    {
        if (x < 2)
            return false;
        if (d * d > x)                 // no divisor up to the square root
            return true;
        if (x % d == 0)
            return false;
        return isPrime(x, d + 1);      // try the next divisor
    }

    void isEmirp()
    {
        reverse();
        if (isPrime(n, 2) && isPrime(rev, 2))
            System.out.println(n + " is an Emirp number");
        else
            System.out.println(n + " is not an Emirp number");
    }

    public static void main()
    {
        System.out.print("Enter a number: ");
        Emirp ob = new Emirp(sc.nextInt());
        ob.isEmirp();
    }
}

A class ArrOp holds an array of integers. The array is to be sorted in ascending order using the selection sort technique, and then a new object is to be formed containing the elements of the sorted array with all repetitions removed.

Example: INPUT: { 7, 3, 9, 3, 7, 7, 1 }
Sorted array: { 1, 3, 3, 7, 7, 7, 9 }
Without repeats: { 1, 3, 7, 9 }

The details of the members of the class are given below:

Class name: ArrOp
Data members/instance variables:
arr[ ]: integer array
size: integer to store the number of elements
Member functions/methods:
ArrOp(int s): parameterised constructor to assign size = s and create the array
void input( ): to accept the elements of the array
void selSort( ): to sort the array in ascending order using the selection sort technique
ArrOp removeDup( ): returns an object whose array holds the elements of the sorted current array with all duplicates removed; its size equals the number of distinct elements
void display( ): to display the array

Specify the class ArrOp giving details of the constructor(int), void input( ), void selSort( ), ArrOp removeDup( ) and void display( ). Define a main( ) function to create an object and call the functions accordingly to enable the task.

(Create)
Answer
import java.util.*;
class ArrOp
{
    int arr[];      // the elements
    int size;       // number of elements
    static Scanner sc = new Scanner(System.in);

    ArrOp(int s)
    {
        size = s;
        arr = new int[size];
    }

    void input()
    {
        System.out.println("Enter " + size + " elements:");
        for (int i = 0; i < size; i++)
            arr[i] = sc.nextInt();
    }

    // sorts arr in ascending order using selection sort
    void selSort()
    {
        for (int i = 0; i < size - 1; i++)
        {
            int min = i;
            for (int j = i + 1; j < size; j++)
                if (arr[j] < arr[min])
                    min = j;
            int t = arr[i];             // bring the smallest to position i
            arr[i] = arr[min];
            arr[min] = t;
        }
    }

    // returns an object holding the elements of the sorted array
    // with every duplicate removed
    ArrOp removeDup()
    {
        int c = (size > 0) ? 1 : 0;     // count the distinct elements first
        for (int i = 1; i < size; i++)
            if (arr[i] != arr[i - 1])
                c++;
        ArrOp R = new ArrOp(c);
        int k = 0;
        for (int i = 0; i < size; i++)
            if (i == 0 || arr[i] != arr[i - 1])
                R.arr[k++] = arr[i];
        return R;
    }

    void display()
    {
        for (int i = 0; i < size; i++)
            System.out.print(arr[i] + " ");
        System.out.println();
    }

    public static void main()
    {
        System.out.print("Number of elements: ");
        ArrOp A = new ArrOp(sc.nextInt());
        A.input();
        A.selSort();
        System.out.print("Sorted array   : ");
        A.display();
        ArrOp U = A.removeDup();
        System.out.print("Without repeats: ");
        U.display();
    }
}

{

    Caesar()
    {

    void accept()

        if (ch >= 'A' && ch <= 'Z')
            return (char) ('A' + (ch - 'A' + s) % 26);
        if (ch >= 'a' && ch <= 'z')
            return (char) ('a' + (ch - 'a' + s) % 26);
        return ch;                          // not a letter: unchanged
    }

    void encode()
    {
        enc = "";
        for (int i = 0; i < txt.length(); i++)
            enc = enc + shift(txt.charAt(i), k);
    }

    // shifting forward by 26 - k undoes a shift of k
    String decode()
    {
        String d = "";
        for (int i = 0; i < enc.length(); i++)
            d = d + shift(enc.charAt(i), 26 - k);
        return d;
    }

    void display()
    {
        System.out.println("Original : " + txt);
        System.out.println("Encoded  : " + enc);
        System.out.println("Decoded  : " + decode());
    }

    public static void main()
    {
        Caesar ob = new Caesar();
        ob.accept();
        if (ob.k < 1 || ob.k > 25)
            System.out.println("INVALID KEY");
        else
        {
            ob.encode();
            ob.display();
        }
    }
}

Answer
class Undo
{
    String act[];   // the actions
    int size;       // maximum capacity
    int top;        // index of the last action

    Undo(int cap)                    // given in the question
    {
        size = cap;
        top = -1;
        act = new String[size];
    }

    // saves an action on top if there is room
    void push(String a)
    {
        if (top == size - 1)
            System.out.println("UNDO LIMIT REACHED");
        else
            act[++top] = a;
    }

    // removes and returns the most recent action
    String pop()
    {
        if (top == -1)
            return "NOTHING TO UNDO";
        return act[top--];
    }
}

A linked list is formed from the objects of the class Book. The class structure of the Book is given below:

(Analysis)
Answer

ALGORITHM:

Step 1. Start
Step 2. Set temp = first
Step 3. Repeat while link of temp is not null: temp = link of temp
Step 4. Create a new node nb; set title of nb = t and link of nb = null
Step 5. Set link of temp = nb
Step 6. End algorithm

OR METHOD:

void addBook(Book first, String t)
{
    Book temp = first;
    while (temp.link != null)        // move to the last node
        temp = temp.link;
    Book nb = new Book();            // create the new node
    nb.title = t;
    nb.link = null;
    temp.link = nb;                  // attach it after the last node
}

Note Here the loop condition is temp.link != null on purpose: the traversal must stop at the last node, not after it. The list is existing, so first is not null. Tested by adding two titles to a one-node list.
