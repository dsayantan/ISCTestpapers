According to the Principle of Duality, the Boolean equation A • (A′ + B) + B′ • 1 = A + B′ will be equivalent to: (Application)

(a)(A + (A′ • B)) • (B′ + 0) = A • B′(b)(A′ + (A • B′)) • (B + 0) = A′ • B(c)(A + (A′ • B)) • (B′ + 1) = A • B′(d)(A • (A′ + B)) + (B′ • 0) = A + B′

A class LCM has been defined to find the Lowest Common Multiple of two integers.

Example: INPUT : n1 = 12, n2 = 18 OUTPUT : LCM = 36

Some of the data members and member functions are given below:

Class name:LCM
Data members/instance variables:
n1:to store an integer number
n2:to store an integer number
large:integer to store the larger of n1 and n2
sm:integer to store the smaller of n1 and n2
l:to store the LCM of the two numbers
Methods/Member functions:
LCM( ):default constructor to initialise the data members with legal initial values
void accept( ):to accept n1 and n2, and to find large and sm
int getLCM( ):returns the LCM of n1 and n2 using the recursive technique
void display( ):to print the numbers n1, n2 and their LCM

Specify the class LCM giving details of the constructor( ), void accept( ), int getLCM( ) and void display( ). Define a main( ) function to create an object and call the member functions accordingly to enable the task.

(Create)
Answer
import java.util.*;

class LCM
{
    int n1, n2;                              // the two numbers
    int large, sm;                           // the larger and the smaller of them
    int l;                                   // the LCM

    LCM()                                    // default constructor
    {
        n1 = n2 = large = sm = l = 0;
    }

    void accept()                            // accepts n1 and n2
    {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter two positive integers : ");
        n1 = sc.nextInt();
        n2 = sc.nextInt();
        large = Math.max(n1, n2);
        sm = Math.min(n1, n2);
        l = large;                           // the first multiple of the larger number
    }

    int getLCM()                             // recursive: try the next multiple of large
    {
        if (l % sm == 0)                     // base case: the smaller number divides it
            return l;
        l = l + large;
        return getLCM();
    }

    void display()
    {
        System.out.println("n1 = " + n1 + ", n2 = " + n2);
        System.out.println("LCM = " + getLCM());
    }

    public static void main()
    {
        LCM ob = new LCM();
        ob.accept();
        ob.display();
    }
}

getLCM( ) for 12 and 18: l = 18 (18 % 12 ≠ 0) → l = 36, 36 % 12 = 0 → returns 36.

Note Any correct recursive method earns the marks: the recursion here walks the multiples of the larger number; LCM = n1 × n2 / HCF with a recursive HCF (gcd(a, b) = gcd(b, a % b)) is equally acceptable.

A class OddEven contains an array of integers. Using the details given below, form a new array from two such arrays which contains first all the odd numbers of the first array, then all the odd numbers of the second array, followed by all the even numbers of the first array and then all the even numbers of the second array, each in their original order.

Example: First array : { 12, 7, 9, 4, 15 } Second array : { 3, 10, 8, 21 } Resultant : { 7, 9, 15, 3, 21, 12, 4, 10, 8 }

Specify the class OddEven giving details of the constructor(int), void input( ), OddEven arrange(OddEven, OddEven) and void display( ). Define a main( ) function to create objects and call the functions accordingly to enable the task.

(Create)
Answer
import java.util.*;

class OddEven
{
    int arr[];                               // the array
    int size;                                // number of elements

    static Scanner sc = new Scanner(System.in);

    OddEven(int n)                           // parameterised constructor
    {
        size = n;
        arr = new int[size];
    }

    void input()                             // accepts the elements
    {
        System.out.println("Enter " + size + " integers :");
        for (int i = 0; i < size; i++)
            arr[i] = sc.nextInt();
    }

    OddEven arrange(OddEven P, OddEven Q)    // odds of P, odds of Q, evens of P, evens of Q
    {
        OddEven R = new OddEven(P.size + Q.size);
        int k = 0;
        for (int i = 0; i < P.size; i++)
            if (P.arr[i] % 2 != 0)
                R.arr[k++] = P.arr[i];
        for (int i = 0; i < Q.size; i++)
            if (Q.arr[i] % 2 != 0)
                R.arr[k++] = Q.arr[i];
        for (int i = 0; i < P.size; i++)
            if (P.arr[i] % 2 == 0)
                R.arr[k++] = P.arr[i];
        for (int i = 0; i < Q.size; i++)
            if (Q.arr[i] % 2 == 0)
                R.arr[k++] = Q.arr[i];
        return R;
    }

    void display()
    {
        for (int i = 0; i < size; i++)
            System.out.print(arr[i] + " ");
        System.out.println();
    }

    public static void main()
    {
        System.out.print("Number of elements in the first array : ");
        OddEven A = new OddEven(sc.nextInt());
        A.input();
        System.out.print("Number of elements in the second array : ");
        OddEven B = new OddEven(sc.nextInt());
        B.input();
        OddEven C = A.arrange(A, B);
        System.out.print("FIRST ARRAY : ");
        A.display();
        System.out.print("SECOND ARRAY : ");
        B.display();
        System.out.print("RESULTANT ARRAY : ");
        C.display();
    }
}

(NOON is a palindrome of length 4, and A has length 1; neither length is prime.)

Some of the members of the class are given below:

Class name:PalWord
Data members/instance variables:
sent:to store the sentence in UPPER CASE
Methods/Member functions:
PalWord(String s):parameterised constructor to assign s, converted to upper case, to sent
boolean isPalin(String w):returns true if the word w is a palindrome, otherwise false
boolean isPrime(int n):returns true if n is a prime number, otherwise false
void display( ):displays the palindromic words of prime length and their number, by invoking isPalin( ) and isPrime( ); displays “NO SUCH WORD” if there is none

Specify the class PalWord giving details of the constructor(String), boolean isPalin(String), boolean isPrime(int) and void display( ). Define a main( ) function to create an object and call the functions accordingly to enable the task.

(Create)
Answer
import java.util.*;

class PalWord
{
    String sent;                             // the sentence in upper case

    PalWord(String s)                        // parameterised constructor
    {
        sent = s.trim().toUpperCase();
    }

    boolean isPalin(String w)                // does w read the same both ways?
    {
        int i = 0, j = w.length() - 1;
        while (i < j)
        {
            if (w.charAt(i) != w.charAt(j))
                return false;
            i++;
            j--;
        }
        return true;
    }

    boolean isPrime(int n)                   // is n a prime number?
    {
        if (n < 2)
            return false;
        for (int k = 2; k * k <= n; k++)
            if (n % k == 0)
                return false;
        return true;
    }

    void display()                           // palindromic words of prime length
    {
        StringTokenizer st = new StringTokenizer(sent, " .,?!");
        int c = 0;
        String res = "";
        while (st.hasMoreTokens())
        {
            String w = st.nextToken();
            if (isPalin(w) && isPrime(w.length()))
            {
                res = res + w + " ";
                c++;
            }
        }
        if (c == 0)
            System.out.println("NO SUCH WORD");
        else
        {
            System.out.println(res.trim());
            System.out.println("NUMBER OF SUCH WORDS : " + c);
        }
    }

    public static void main()
    {
        Scanner sc = new Scanner(System.in);
        System.out.println("Enter a sentence :");
        PalWord ob = new PalWord(sc.nextLine());
        ob.display();
    }
}

Run on the examples: MOM DAD MADAM (3); for “NOON IS A GOOD TIME.” the output is NO SUCH WORD.

A railway reservation counter keeps a waiting line of at most 20 passengers. A passenger joins the line at the rear and the passenger at the front is served first.

Define a class Waitlist with the following details:

Class name:Waitlist
Data members/instance variables:
name[ ]:array to hold the names of the passengers
cap:stores the maximum capacity of the array
front:to point to the index of the front
rear:to point to the index of the rear
Methods/Member functions:
Waitlist(int max):constructor to initialise cap = max, front = rear = 0 and to create the array
void join(String n):adds the name n at the rear if possible, otherwise displays the message “COUNTER FULL”
String serve( ):removes and returns the name at the front; if the line is empty, returns “EMPTY”
void show( ):displays the names in the line

Specify the class Waitlist giving details of the functions void join(String) and String serve( ). Assume that the other functions have been defined.
The main( ) function and algorithm need NOT be written.

(Create)
Answer
class Waitlist
{
    String name[];                           // names of the waiting passengers
    int cap;                                 // capacity of the queue
    int front, rear;                         // front and rear indices

    Waitlist(int max)
    {
        cap = max;
        name = new String[cap];
        front = rear = 0;
    }

    void join(String n)                      // a passenger joins at the rear
    {
        if (rear == cap)
            System.out.println("COUNTER FULL");
        else
            name[rear++] = n;
    }

    String serve()                           // the passenger at the front is served
    {
        if (front == rear)                   // no one is waiting
            return "EMPTY";
        String n = name[front++];
        if (front == rear)                   // queue has emptied: start again at index 0
            front = rear = 0;
        return n;
    }
}

Note With front = rear = 0, rear is the next free slot, so the queue is full when rear = cap and empty when front = rear. Resetting both to 0 when the line empties lets the array be used again — a plain linear queue otherwise stays “full” for ever.

Class name:Deposit
Data members/instance variables:

(Create)
Answer
class Maturity extends Deposit
{
    int years;                               // period of the deposit
    double amount;                           // maturity amount
    double interest;                         // compound interest earned

    Maturity(String n, double p, double r, int y)
    {
        super(n, p, r);                      // initialise the super class members
        years = y;
        amount = interest = 0.0;
    }

    void compute()
    {
        amount = principal * Math.pow(1 + rate / 100, years);
        amount = Math.round(amount * 100) / 100.0;           // to two decimal places
        interest = Math.round((amount - principal) * 100) / 100.0;
    }

    void show()
    {
        super.show();
        System.out.println("Years : " + years);
        System.out.println("Interest : Rs " + interest);
        System.out.println("Maturity amount : Rs " + amount);
    }
}

Answer
ALGORITHM:
Step 1. Start.
Step 2. Set c = 0 and ptr = start.
Step 3. Repeat Steps 4 and 5 while ptr ≠ null.
Step 4. If ptr.price > p then c = c + 1.
Step 5. Set ptr = ptr.next.
Step 6. Return c.
Step 7. End algorithm.

METHOD:

int countCostly(Book start, int p)
{
    int c = 0;
    Book ptr = start;                        // start at the first node
    while (ptr != null)                      // visit every node, the last included
    {
        if (ptr.price > p)
            c++;
        ptr = ptr.next;
    }
    return c;
}
