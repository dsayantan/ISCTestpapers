Convert the following infix notation to prefix form.
(A + B * C) / (D − E) * F (Create)

Answer
  1. Fully bracketed, following precedence and left-to-right order: ((A + (B * C)) / (D − E)) * F
  2. Innermost first: B * C → *BC; A + *BC → +A*BC; D − E → −DE
  3. +A*BC / −DE → /+A*BC−DE
  4. /+A*BC−DE * F → */+A*BC−DEF

Answer Prefix: */+A*BC−DEF

Note / and * have equal precedence and associate left to right, so the division is done first and the * with F is the last operator: it heads the prefix string.

A Disarium number is a number in which the sum of its digits, each raised to the power of its position (counted from the left, starting at 1), is equal to the number itself.

Example: 135 = 11 + 32 + 53 = 1 + 9 + 125 = 135
175 = 11 + 72 + 53 = 1 + 49 + 125 = 175

Design a class Disarium to check if a given number is a Disarium number or not. Some of the members of the class are given below:

Class name: Disarium
Data members/instance variables:
num: to store the number
size: to store the number of digits of num
Methods / Member functions:
Disarium(int nn): parameterised constructor to initialise num = nn and size = 0
void countDigit( ): counts the number of digits of num and stores it in size
int sumofDigits(int n, int p): returns the sum of the digits of n, each raised to the power of its position, using the recursive technique, where p is the position of the last digit of n
void check( ): checks whether num is a Disarium number by invoking sumofDigits( ) and displays an appropriate message

Specify the class Disarium giving details of the constructor(int), void countDigit( ), int sumofDigits(int, int) and void check( ). Define the main( ) function to create an object and call the functions accordingly to enable the task.

(Create)
Answer
import java.util.*;
class Disarium
{
    int num;        // the number to be checked
    int size;       // number of digits in num
    static Scanner sc = new Scanner(System.in);

    Disarium(int nn)
    {
        num = nn;
        size = 0;
    }

    // counts the digits of num and stores the count in size
    void countDigit()
    {
        int t = num;
        size = 0;
        while (t > 0)
        {
            size++;
            t = t / 10;
        }
    }

    // returns the sum of the digits of n, each raised to the power of its
    // position; p is the position (from the left) of the last digit of n
    int sumofDigits(int n, int p)
    {
        if (n == 0)                                   // base case
            return 0;
        int d = n % 10;                               // last digit
        return (int) Math.pow(d, p) + sumofDigits(n / 10, p - 1);
    }

    // checks and displays whether num is a Disarium number
    void check()
    {
        countDigit();
        if (sumofDigits(num, size) == num)
            System.out.println(num + " is a Disarium number");
        else
            System.out.println(num + " is not a Disarium number");
    }

    public static void main()
    {
        System.out.print("Enter a number: ");
        int n = sc.nextInt();
        Disarium ob = new Disarium(n);
        ob.check();
    }
}

Sample run: 135 → 135 is a Disarium number; 80 → 80 is not a Disarium number (81 + 02 = 8).

A class Merge contains an array of integers arranged in ascending order. Two such arrays are to be merged into a third array which is also in ascending order. The merging must be done by comparing the elements of the two arrays, without sorting the resultant array afterwards.

Example: First array: { 3, 8, 15, 42 }
Second array: { 1, 8, 20 }
Merged array: { 1, 3, 8, 8, 15, 20, 42 }

The details of the members of the class are given below:

Class name: Merge
Data members/instance variables:
arr[ ]: integer array
size: integer to store the number of elements
Member functions/methods:
Merge(int s): parameterised constructor to assign size = s and create the array
void input( ): to accept the elements of the array in ascending order
Merge join(Merge P, Merge Q): returns an object whose array contains all the elements of the arrays of objects P and Q in ascending order, formed by merging them
void display( ): to display the array

Specify the class Merge giving details of the constructor(int), void input( ), Merge join(Merge, Merge) and void display( ). Define a main( ) function to create objects and call all the functions accordingly to enable the task.

(Create)
Answer
import java.util.*;
class Merge
{
    int arr[];      // the elements, in ascending order
    int size;       // number of elements
    static Scanner sc = new Scanner(System.in);

    Merge(int s)
    {
        size = s;
        arr = new int[size];
    }

    // accepts the elements, which are entered in ascending order
    void input()
    {
        System.out.println("Enter " + size + " elements in ascending order:");
        for (int i = 0; i < size; i++)
            arr[i] = sc.nextInt();
    }

    // merges the sorted arrays of P and Q into the array of a new object
    Merge join(Merge P, Merge Q)
    {
        Merge R = new Merge(P.size + Q.size);
        int i = 0, j = 0, k = 0;
        while (i < P.size && j < Q.size)       // take the smaller front element
        {
            if (P.arr[i] <= Q.arr[j])
                R.arr[k++] = P.arr[i++];
            else
                R.arr[k++] = Q.arr[j++];
        }
        while (i < P.size)                     // copy what is left of P
            R.arr[k++] = P.arr[i++];
        while (j < Q.size)                     // copy what is left of Q
            R.arr[k++] = Q.arr[j++];
        return R;
    }

    void display()
    {
        for (int i = 0; i < size; i++)
            System.out.print(arr[i] + " ");
        System.out.println();
    }

    public static void main()
    {
        System.out.print("Size of the first array: ");
        Merge P = new Merge(sc.nextInt());
        P.input();
        System.out.print("Size of the second array: ");
        Merge Q = new Merge(sc.nextInt());
        Q.input();
        Merge ob = new Merge(0);
        Merge R = ob.join(P, Q);
        System.out.print("First array : ");
        P.display();
        System.out.print("Second array: ");
        Q.display();
        System.out.print("Merged array: ");
        R.display();
    }
}

import java.util.*;
class SortLen
{
    String sent;        // the original sentence
    String newsent;     // the rearranged sentence
    static Scanner sc = new Scanner(System.in);

    SortLen()
    {
        sent = "";
        newsent = "";
    }

    // accepts the sentence in upper case
    void accept()
    {
        System.out.println("Enter a sentence in upper case:");
        sent = sc.nextLine().trim();
    }

    // true if the sentence ends with '.', '?' or '!'
    boolean isValid()
    {
        if (sent.length() == 0)
            return false;
        char ch = sent.charAt(sent.length() - 1);
        return ch == '.' || ch == '?' || ch == '!';
    }

    // arranges the words in ascending order of length; words of equal
    // length keep their original order
    void arrange()
    {
        char end = sent.charAt(sent.length() - 1);
        StringTokenizer st = new StringTokenizer(sent.substring(0, sent.length() - 1));
        int n = st.countTokens();
        String w[] = new String[n];
        for (int i = 0; i < n; i++)
            w[i] = st.nextToken();
        // bubble sort on length; swap only when strictly longer, which keeps
        // words of equal length in their original order
        for (int i = 0; i < n - 1; i++)
            for (int j = 0; j < n - 1 - i; j++)
                if (w[j].length() > w[j + 1].length())
                {
                    String t = w[j];
                    w[j] = w[j + 1];
                    w[j + 1] = t;
                }
        newsent = "";
        for (int i = 0; i < n; i++)
            newsent = newsent + w[i] + (i < n - 1 ? " " : "");
        newsent = newsent + end;
    }

    void display()
    {
        System.out.println("Original sentence : " + sent);
        System.out.println("Arranged sentence : " + newsent);
    }

    public static void main()
    {
        SortLen ob = new SortLen();
        ob.accept();
        if (ob.isValid())
        {
            ob.arrange();
            ob.display();
        }
        else
            System.out.println("INVALID INPUT");
    }
}

class Tunnel
{

    int cap;        // maximum capacity
    int front;      // index of the vehicle at the front end

    void addRear(int v)
    {

        else
        {
            if (front == -1)         // tunnel was empty

            front = rear = -1;
        else
            front++;
        return v;
    }
