A class BinDec has been defined to convert a binary number into its decimal equivalent using the recursive technique.

Example: INPUT: 101101
OUTPUT: Decimal equivalent = 45  (1×32 + 0×16 + 1×8 + 1×4 + 0×2 + 1×1)
INPUT: 1021   OUTPUT: NOT A BINARY NUMBER

Some of the members of the class are given below:

Class name: BinDec
Data members/instance variables:
bin: to store a binary number (long integer)
dec: to store its decimal equivalent
Methods / Member functions:
BinDec( ): default constructor to initialise the data members to 0
void readBin( ): to accept a binary number in bin
boolean isValid( ): returns true if every digit of bin is 0 or 1, otherwise returns false
int convert(long b): returns the decimal equivalent of the binary number b using the recursive technique
void show( ): invokes convert( ) to store the result in dec and displays bin and dec

Specify the class BinDec giving details of the constructor( ), void readBin( ), boolean isValid( ), int convert(long) and void show( ). Define the main( ) function to create an object and call the functions accordingly to enable the task.

(Create)
Answer
import java.util.*;
class BinDec
{
    long bin;       // the binary number
    int dec;        // its decimal equivalent
    static Scanner sc = new Scanner(System.in);

    BinDec()
    {
        bin = 0;
        dec = 0;
    }

    void readBin()
    {
        System.out.print("Enter a binary number: ");
        bin = sc.nextLong();
    }

    // true if every digit of bin is 0 or 1
    boolean isValid()
    {
        long t = bin;
        while (t > 0)
        {
            if (t % 10 > 1)
                return false;
            t = t / 10;
        }
        return true;
    }

    // returns the decimal equivalent of the binary number b, recursively
    int convert(long b)
    {
        if (b == 0)                                        // base case
            return 0;
        return (int) (b % 10) + 2 * convert(b / 10);       // last bit + 2 x rest
    }

    void show()
    {
        dec = convert(bin);
        System.out.println("Binary number      : " + bin);
        System.out.println("Decimal equivalent : " + dec);
    }

    public static void main()
    {
        BinDec ob = new BinDec();
        ob.readBin();
        if (ob.isValid())
            ob.show();
        else
            System.out.println("NOT A BINARY NUMBER");
    }
}

123

Member functions/methods:

boolean check(Frame P): returns true if the matrix of the current object and that of object P are of the same order and have the same elements, otherwise returns false
void print( ): to display the matrix

Specify the class Frame giving details of the constructor(int, int), void readArray( ), Frame rotate( ), boolean check(Frame) and void print( ). Define a main( ) function to create two objects A and B, obtain the rotation of A, display it, and print whether B is the rotation of A.

(Create)
Answer
import java.util.*;
class Frame
{
    int mat[][];    // the matrix
    int m, n;       // number of rows and columns
    static Scanner sc = new Scanner(System.in);

    Frame(int mm, int nn)
    {
        m = mm;
        n = nn;
        mat = new int[m][n];
    }

    void readArray()
    {
        System.out.println("Enter " + (m * n) + " elements row-wise:");
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
                mat[i][j] = sc.nextInt();
    }

    // returns a new object holding the matrix rotated 90 degrees clockwise
    Frame rotate()
    {
        Frame R = new Frame(n, m);             // an m x n matrix becomes n x m
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
                R.mat[j][m - 1 - i] = mat[i][j];
        return R;
    }

    // true if the current matrix and the matrix of P are identical
    boolean check(Frame P)
    {
        if (m != P.m || n != P.n)
            return false;
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
                if (mat[i][j] != P.mat[i][j])
                    return false;
        return true;
    }

    void print()
    {
        for (int i = 0; i < m; i++)
        {
            for (int j = 0; j < n; j++)
                System.out.print(mat[i][j] + "\t");
            System.out.println();
        }
    }

    public static void main()
    {
        System.out.print("Rows and columns of A: ");
        int r = sc.nextInt(), c = sc.nextInt();
        Frame A = new Frame(r, c);
        A.readArray();
        Frame B = new Frame(c, r);              // B must be c x r to be a rotation
        System.out.println("Matrix B (" + c + " x " + r + "):");
        B.readArray();
        Frame R = A.rotate();
        System.out.println("Matrix A:");
        A.print();
        System.out.println("A rotated 90 degrees clockwise:");
        R.print();
        if (R.check(B))
            System.out.println("B IS A ROTATION OF A");
        else
            System.out.println("B IS NOT A ROTATION OF A");
    }
}

import java.util.*;
class Encrypt
{
    String sent;        // original sentence
    String newsent;     // encoded sentence
    int vow, con;       // numbers of vowels and consonants
    static Scanner sc = new Scanner(System.in);

    Encrypt()
    {
        sent = "";
        newsent = "";
        vow = con = 0;
    }

    void accept()
    {
        System.out.println("Enter a sentence:");
        sent = sc.nextLine();
    }

    // returns the next vowel in the cycle a-e-i-o-u-a, keeping the case;
    // any other character is returned unchanged
    char nextVowel(char ch)
    {
        String low = "aeiou", up = "AEIOU";
        int p = low.indexOf(ch);
        if (p >= 0)
            return low.charAt((p + 1) % 5);
        p = up.indexOf(ch);
        if (p >= 0)
            return up.charAt((p + 1) % 5);
        return ch;
    }

    // forms newsent and counts the vowels and consonants of sent
    void encode()
    {
        newsent = "";
        vow = con = 0;
        for (int i = 0; i < sent.length(); i++)
        {
            char ch = sent.charAt(i);
            char nx = nextVowel(ch);
            if (nx != ch)
                vow++;                              // ch was a vowel
            else if (Character.isLetter(ch))
                con++;                              // a letter that is not a vowel
            newsent = newsent + nx;
        }
    }

    void display()
    {
        System.out.println("Original : " + sent);
        System.out.println("Encoded  : " + newsent);
        System.out.println("Vowels: " + vow + "  Consonants: " + con);
    }

    public static void main()
    {
        Encrypt ob = new Encrypt();
        ob.accept();
        ob.encode();
        ob.display();
    }
}

class Counter
{
    int tok[];      // token numbers
    int cap;        // capacity of the array
    int front;      // index before the first token
    int rear;       // index of the last token

    Counter(int max)                 // given in the question
    {
        cap = max;
        front = rear = 0;
        tok = new int[cap];
    }

    // adds a token at the rear, wrapping round the end of the array
    void push(int v)
    {
        if ((rear + 1) % cap == front)
            System.out.println("COUNTER IS FULL");
        else
        {
            rear = (rear + 1) % cap;
            tok[rear] = v;
        }
    }

    // removes and returns the token at the front
    int pop()
    {
        if (front == rear)
            return -999;
        front = (front + 1) % cap;
        return tok[front];
    }
}

A linked list is formed from the objects of the class Node. The class structure of the Node is given below:

class Node
{
    int data;
    Node next;
}

Write an Algorithm OR a Method to delete the first node whose data is k from an existing linked list and return the reference to the first node of the resulting list.
The method declaration is as follows:
Node delete(Node start, int k)

(Analysis)
Answer

ALGORITHM:

Step 1. Start
Step 2. If start is null, return null
Step 3. If data of start = k, return next of start (the second node becomes first)
Step 4. Set prev = start and temp = next of start
Step 5. Repeat while temp is not null and data of temp is not k:
            prev = temp, temp = next of temp
Step 6. If temp is not null, set next of prev = next of temp (bypass temp)
Step 7. Return start
Step 8. End algorithm

OR METHOD:

Node delete(Node start, int k)
{
    if (start == null)                      // empty list
        return null;
    if (start.data == k)                    // first node is to go
        return start.next;
    Node prev = start, temp = start.next;
    while (temp != null && temp.data != k)
    {
        prev = temp;
        temp = temp.next;
    }
    if (temp != null)                       // found: bypass it
        prev.next = temp.next;
    return start;
}

Note Tested on 12 → 25 → 7 → 25 → 40: deleting 25 removes only the first 25; deleting 12 (the first node), 40 (the last), a value not present, and deleting from an empty list all behave correctly.
