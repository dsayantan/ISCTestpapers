A relation R on the set of real numbers ℝ is defined as R = {(a, b) : a ≤ b3}. Then R is: (Analyse)

(a)reflexive only(b)symmetric only(c)transitive only(d)neither reflexive, nor symmetric, nor transitive
Answer

Note In answering Multiple Choice Questions, candidates have to write either the correct option number or the explanation against it. Please note that only ONE correct answer should be written.

(d) neither reflexive, nor symmetric, nor transitive

Reflexive? (½, ½) ∉ R, since ½ > (½)3 = 1/8. ∴ not reflexive.

Symmetric? (1, 2) ∈ R as 1 ≤ 8, but (2, 1) ∉ R as 2 > 1. ∴ not symmetric.

Transitive? (3, 3/2) ∈ R as 3 ≤ 27/8 and (3/2, 6/5) ∈ R as 3/2 ≤ 216/125, but (3, 6/5) ∉ R as 3 > 216/125. ∴ not transitive.

(v)1 mark

Let f(x) = x3 − 3x2 + 3x, x ∈ ℝ.
Statement I: f is strictly increasing on ℝ.
Statement II: Since f′(1) = 0, f has a local extremum at x = 1.
Which of the following is correct? (Understand)

(a)Statement I is true and Statement II is false.(b)Statement I is false and Statement II is true.(c)Both the statements are true.(d)Both the statements are false.
Answer

(a) Statement I is true and Statement II is false.

f′(x) = 3(x − 1)2 ≥ 0, and f′(x) = 0 only at the single point x = 1, so f is strictly increasing on ℝ. Statement I is true.

f′ does not change sign as x passes through 1, so x = 1 is not a point of local extremum (it is a point of inflection). Statement II is false.

(b) Statement I is false and Statement II is true.
