The relation R on the set of integers defined by a R b if and only if a2 − 5ab + 4b2 = 0 is: (Understand)

(a)an equivalence relation(b)symmetric and transitive but not reflexive(c)reflexive but neither symmetric nor transitive(d)reflexive and symmetric but not transitive
Answer

Note In answering Multiple Choice Questions, candidates have to write either the correct option number or the explanation against it. Please note that only ONE correct answer should be written.

(c) reflexive but neither symmetric nor transitive

a2 − 5ab + 4b2 = (a − b)(a − 4b), so a R b ⇔ a = b or a = 4b.

Reflexive: a = a, yes. Symmetric: (4, 1) is in R but (1, 4) is not, so no. Transitive: (16, 4) and (4, 1) are in R but (16, 1) is not, so no.

Question 32 marks

A die has the faces 1, 2, 3 coloured red and the faces 4, 5, 6 coloured green. It is thrown once. Let A be the event “the number is a multiple of 3” and B the event “the colour is green”. Show that A and B are independent events. (Evaluate)

Answer

Question 52 marks

The function f(x) = x2 + 3x + p for x ≤ 1 and f(x) = qx + 2 for x > 1 is differentiable at x = 1. Find p and q. (Understand)

Answer

Differentiable at 1 ⇒ continuous at 1: limx→1− f(x) = 1 + 3 + p = 4 + p and limx→1+ f(x) = q + 2, so 4 + p = q + 2.

Left derivative: f′(x) = 2x + 3 ⇒ Lf′(1) = 5. Right derivative: f′(x) = q ⇒ Rf′(1) = q.

Equal derivatives give q = 5, and then 4 + p = 7, p = 3. p = 3, q = 5.
