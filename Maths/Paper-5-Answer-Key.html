Answer

Note In answering Multiple Choice Questions, candidates have to write either the correct option number or the explanation against it. Please note that only ONE correct answer should be written.

Question 52 marks

Show that the function f(x) = |x − 3| is continuous but not differentiable at x = 3. (Understand)

Answer

Continuity: f(3) = 0; LHL = limx→3−(3 − x) = 0; RHL = limx→3+(x − 3) = 0. LHL = RHL = f(3), so f is continuous at 3.

Differentiability:

LHD = limh→0 f(3 − h) − f(3)−h = lim h−h = −1;   RHD = limh→0 f(3 + h) − f(3)h = lim hh = 1.

LHD ≠ RHD, so f is not differentiable at x = 3 (the graph has a corner there). Hence shown.

Question 133 marks

Using properties of determinants, prove that 1 + a1111 + b1111 + c = abc + ab + bc + ca. (Analyse)

Answer

For a, b, c ≠ 0 take a, b, c out of C1, C2, C3:

Δ = abc 1a + 11b1c1a1b + 11c1a1b1c + 1

C1 → C1 + C2 + C3: every entry of C1 becomes s = 1 + 1a + 1b + 1c, which is taken out:

Δ = abc · s 11b1c11b + 11c11b1c + 1

R2 → R2 − R1, R3 → R3 − R1:

Δ = abc · s 11b1c010001 = abc · s · 1 = abc(1 + 1a + 1b + 1c)
