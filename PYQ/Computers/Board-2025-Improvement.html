PART I – QUESTION 1 (10 marks)ISC 2025 Improvement Computer Science Paper 1 (868A), Q1(i)
Question 1(i)[1]
The complement of the Boolean expression (P + Q′) • (R′ + P) is:
(a)(P • Q′) + (R′ • P)
(b)(P′ • Q) + (R • P′)
(c)(P′ • Q) • (R • P′)
(d)(P + Q′) • (R′ + P)
  1. De Morgan’s law: (X • Y)′ = X′ + Y′, so the complement is (P + Q′)′ + (R′ + P)′.
    [½]
  2. (P + Q′)′ = P′ • Q and (R′ + P)′ = R • P′, giving P′•Q + R•P′.
    [½]
Answer
(b) (P′ • Q) + (R • P′)
Common slip Option (a) just swaps the operators and complements nothing; (d) is the original expression, not its complement.

Concepts to recall

  • De Morgan: (X + Y)′ = X′ • Y′ and (X • Y)′ = X′ + Y′. Complement every variable, swap + and •.
  • Complementing the whole expression is not the same as complementing each variable only (that gives the dual-with-complements, a different function).
PART I – QUESTION 1 (10 marks)ISC 2025 Improvement Computer Science Paper 1 (868A), Q1(ii)
Question 1(ii)[1]
Assertion: For overloaded method, signature matching happens at compile time.
Reason: The overloaded method must have a unique signature for its every prototype.
(a)Both Assertion and Reason are true and Reason is the correct explanation for Assertion.
(b)Both Assertion and Reason are true but Reason is not the correct explanation for Assertion.
(c)Assertion is true and Reason is false.
(d)Both Assertion and Reason are false.
  1. Assertion: the compiler picks the overloaded method by matching the number, types and order of the arguments with the declared signatures, all before the program runs (static / compile-time polymorphism). True.
    [½]
  2. Reason: overloaded methods share a name but must differ in signature, otherwise the compiler could not tell them apart and the matching would be ambiguous. True, and it is exactly why the signature can be matched at compile time.
    [½]
Answer
(a) Both Assertion and Reason are true and Reason is the correct explanation for Assertion.
Marking note A candidate who argues “(b)” because the Reason merely restates a rule is not credited: the unique signature is what makes compile-time matching possible.

Concepts to recall

  • Method overloading = same name, different signature (number, type or order of parameters); the return type alone does not distinguish methods.
  • Overloading is resolved at compile time (static binding); overriding is resolved at run time (dynamic binding).
PART I – QUESTION 1 (10 marks)ISC 2025 Improvement Computer Science Paper 1 (868A), Q1(iii)
Question 1(iii)[1]
According to the Principle of Duality, the Boolean equation (X′ + Y • 0) • X = 0 will be equivalent to:
(a)(X + Y′ • 1) • X′ = 1
(b)(X • Y′ + 1) + X′ = 1
(c)(X′ • Y + 1) + X = 1
(d)(X′ • Y + 0) + X = 0
  1. Dual: interchange + and •, and interchange 0 and 1; variables and their complements stay as they are.
    [½]
  2. (X′ + Y • 0) • X = 0 becomes (X′ • Y + 1) + X = 1.
    [½]
Answer
(c) (X′ • Y + 1) + X = 1
Marking note The option reads (X′•Y + 1); strictly the dual of X′ + (Y•0) is X′•(Y + 1). Option (c) is the only one with every constant and operator swapped and no variable complemented.

Concepts to recall

  • Principle of Duality: replace + by •, • by +, 0 by 1 and 1 by 0. Never complement a variable.
  • Options that change X to X′ (or Y to Y′) have confused duality with complementation; one that keeps a 0 has not swapped the constants.
PART I – QUESTION 1 (10 marks)ISC 2025 Improvement Computer Science Paper 1 (868A), Q1(iv)
Question 1(iv)[1]
Commutative law states that:
(a)A • (A + B) = A
(b)(A • B) • C = A • (B • C)
(c)A + (B + C) = (A + B) + C
(d)(A + B) = (B + A)
  1. The commutative law lets the order of the operands be changed: A + B = B + A and A • B = B • A. Option (d) states it.
    [1]
Answer
(d) (A + B) = (B + A)
Common slip (b) and (c) are the associative law, (a) is absorption.

Concepts to recall

  • Commutative: A + B = B + A, A•B = B•A. Associative: (A + B) + C = A + (B + C). Absorption: A•(A + B) = A. Distributive: A•(B + C) = A•B + A•C.
  • Quick test: the commutative law only swaps the two operands; the associative law moves brackets without changing the order of the letters.
PART I – QUESTION 1 (10 marks)ISC 2025 Improvement Computer Science Paper 1 (868A), Q1(v)
Question 1(v)[1]
The canonical expression for F(x, y, z) = Σ(1, 3, 6) is:
(a)(x • y • z′) + (x • y′ • z′) + (x′ • y′ • z)
(b)(x + y + z′) • (x + y′ + z′) • (x′ + y′ + z)
(c)(x′ + y′ + z) • (x′ + y + z) • (x + y + z′)
(d)(x′ • y′ • z) + (x′ • y • z) + (x • y • z′)
  1. Σ means sum of minterms; 1 = 001, 3 = 011, 6 = 110 (x y z).
    [½]
  2. m1 = x′ y′ z, m3 = x′ y z, m6 = x y z′; their sum is option (d).
    [½]
Answer
(d) (x′ • y′ • z) + (x′ • y • z) + (x • y • z′)
Common slip Options (b) and (c) are products of sums (POS) and so are maxterm forms; (a) has the wrong minterms.

Concepts to recall

  • Σm(...) is a canonical SOP: each listed number becomes a product of all variables, 1 = plain variable and 0 = complemented, read as binary.
  • ΠM(...) is a canonical POS: each maxterm is a sum with 0 = plain and 1 = complemented.

Question 1(vi)[1]
Assertion: An abstract class can contain abstract as well as non-abstract methods.
Reason: Abstract classes are meant to provide complete implementation of all types of methods in its sub class.
(a)Both Assertion and Reason are true and Reason is the correct explanation for Assertion.
(b)Both Assertion and Reason are true but Reason is not the correct explanation for Assertion.
(c)Assertion is true and Reason is false.
(d)Both Assertion and Reason are false.
  1. Assertion is true: an abstract class may have abstract methods (no body) and ordinary methods with a body.
    [½]
  2. Reason is false: an abstract class provides a partial implementation; its abstract methods have no body and the subclass must supply it.
    [½]
Answer
(c) Assertion is true and Reason is false.

Concepts to recall

  • abstract class: cannot be instantiated; may mix abstract and concrete methods; a subclass must override every abstract method or itself be abstract.
  • Interface (older Java): only abstract methods; abstract class: partial implementation.
PART I – QUESTION 1 (10 marks)ISC 2025 Improvement Computer Science Paper 1 (868A), Q1(vii)
Question 1(vii)[1]
X – Sujata is a topper; Y – Sujata is in the merit list.
Assertion: If Sujata is in the merit list, then she is a topper (Y ⇒ X).
Reason: Inverse is formed when both antecedent and consequent are negated.
(a)Both Assertion and Reason are true and Reason is the correct explanation for Assertion.
(b)Both Assertion and Reason are true but Reason is not the correct explanation for Assertion.
(c)Assertion is true and Reason is false.
(d)Both Assertion and Reason are false.
  1. Assertion: “If Y then X” is correctly written Y ⇒ X (antecedent Y, consequent X). The statement and its symbolic form agree: true.
    [½]
  2. Reason: the inverse of P ⇒ Q is P′ ⇒ Q′, both parts negated: true. It defines the inverse; it does not explain why Y ⇒ X is a correct symbolisation, so it is not the explanation.
    [½]
Answer
(b) Both Assertion and Reason are true but Reason is not the correct explanation for Assertion.
Marking note The Assertion is read as a statement about symbolisation, as the bracket (Y ⇒ X) shows; if a candidate treats it as a claim of fact about Sujata, it cannot be judged, so the symbolic reading is taken.

Concepts to recall

  • For P ⇒ Q: converse Q ⇒ P, inverse ¬P ⇒ ¬Q, contrapositive ¬Q ⇒ ¬P. The contrapositive is equivalent to the original; converse and inverse are equivalent to each other.
  • In an Assertion–Reason item first judge each statement alone, then ask whether the Reason explains the Assertion.

Question 1(viii)[1]
class Car extends Vehicle implements Fourwheeler { ... }
Which of the following statements are valid for the given code?
I  Vehicle is a super class and Fourwheeler is an interface.
II  Interface cannot have abstract methods.
III  Keyword extends applies to class and keyword implements applies to interface.
(a)Only I and II
(b)Only II and III
(c)Only I and III
(d)Only II
  1. I is true: the class after extends is the superclass, the name after implements is an interface.
    [½]
  2. II is false: an interface is a set of abstract methods. III is true: a class extends a class and implements an interface. So I and III.
    [½]
Answer
(c) Only I and III
Common slip III reads loosely (an interface can also extend another interface) but as stated for this code it is valid.

  • class … extends Superclass implements Interface1, Interface2: one superclass, many interfaces.
  • An interface declares abstract methods (and constants); the implementing class must define them all.
PART I – QUESTION 1 (10 marks)ISC 2025 Improvement Computer Science Paper 1 (868A), Q1(ix)
Question 1(ix)[1]
Differentiate between Tautology and Contradiction.
  1. Tautology: a compound proposition (or Boolean expression) whose value is true (1) for every combination of the values of its variables, e.g. A + A′ = 1.
    [½]
  2. Contradiction: a compound proposition whose value is false (0) for every combination, e.g. A • A′ = 0.
    [½]
Answer
Tautology is always true; contradiction is always false (the negation of one is the other).
Marking note An example of each is not demanded but may be credited with the definition.

Concepts to recall

  • A proposition that is true in some rows and false in others is a contingency.
  • ¬(tautology) is a contradiction and ¬(contradiction) is a tautology.
  • Test with a truth table: the output column is all 1s (tautology), all 0s (contradiction), or mixed.
PART I – QUESTION 1 (10 marks)ISC 2025 Improvement Computer Science Paper 1 (868A), Q1(x)
Question 1(x)[1]
For the given code segment, write Big O notation for worst case complexity.
int i=1, j=1, k=1, p;
while (i <= p)
{
    statements
}
while (j <= p)
{
    while (k <= p)
    {
        statements
    }
}
  1. The first loop runs about p times (i goes from 1 to p). The outer j loop runs about p times. The inner k loop is not reset: k is set to 1 once, before the loops, so it counts from 1 to p only once in all; after that k > p and the inner loop does nothing.
    [½]
  2. Total work ≈ p + p + p = 3p, so the worst case is O(p) (linear).
    [½]
Answer
O(p) (linear)
Common slip Reading the two while-loops as nested to the square, O(p²), without noticing that k is never set back to 1.
Marking note The statements inside are taken to update i, j and k as usual. Had k been reset to 1 inside the j loop the answer would be O(p²); the code as printed does not do that. Credit O(n) or O(p) for the linear answer.

Concepts to recall

  • Big O keeps the dominant term and drops constant factors: p + p + p = 3p → O(p).
  • Nested loops give O(p²) only when the inner counter restarts for every outer pass; check where k is initialised.
  • Sequential loops add (O(p) + O(p) = O(p)); nested loops multiply.

Question 2(i)[2]
Convert the following infix notation to postfix form.
(A*B^C) + (D*E)   where B^C = BC
  1. Priority: ^ (highest) > * > +. Scan left to right with a stack; operands go straight to the output, an operator is pushed after popping any operator of higher or equal priority (^ is right-associative and has nothing to pop here).
    [1]
  2. Working:
    SymbolStackOutput
    (( 
    A(A
    *(*A
    B(*AB
    ^(*^AB
    C(*^ABC
    ) ABC^*
    ++ABC^*
    (+(ABC^*
    D+(ABC^*D
    *+(*ABC^*D
    E+(*ABC^*DE
    )+ABC^*DE*
  3. Postfix = ABC^*DE*+
    [1]
Answer
A B C ^ * D E * + (ABC^*DE*+)
Common slip Writing AB*C^ (doing A*B first) ignores that ^ binds tighter than *.

Concepts to recall

  • Postfix (reverse Polish): operators come after their operands, no brackets needed.
  • Order of precedence ^ > * / > + −; ^ is evaluated right to left, + * − / left to right.
  • Shortcut check: B^C first, A*(B^C) next, D*E, then the sum → ABC^* DE* +.
PART I – QUESTION 2 (10 marks)ISC 2025 Improvement Computer Science Paper 1 (868A), Q2(ii)
Question 2(ii)[2]
A matrix P[−10…10, 1…10] is stored in the memory with each element requiring 2 bytes of storage. If the base address is 2000, find the address of P[5][6] when the matrix is stored Row Major wise.
  1. Rows = 10 − (−10) + 1 = 21, columns = 10 − 1 + 1 = 10, w = 2, lower bounds Lr = −10, Lc = 1, base B = 2000.
    [½]
  2. Row major: address of P[i][j] = B + w × [(i − Lr) × C + (j − Lc)], C = number of columns.
    [½]
  3. P[5][6] = 2000 + 2 × [(5 + 10) × 10 + (6 − 1)] = 2000 + 2 × 155
    [½]
  4. = 2000 + 310 = 2310
    [½]
Answer
Address of P[5][6] = 2310
Common slip Using (5 − 10) or taking 20 rows (10 + 10); the lower bound −10 gives 21 rows and an offset of 15 rows above P[5].

Concepts to recall

  • Row major: row by row, so row offset = (i − Lr) × (columns) and column offset = (j − Lc).
  • Column major: B + w[(j − Lc) × R + (i − Lr)], R = number of rows.
  • Number of rows/columns with bounds l..u is u − l + 1 (negative lower bound adds, it does not subtract).

Question 2(iii)[3]
The following function think() is part of some class. Assume f is the lower bound and l is the upper bound of arr[ ]. Answer the questions given below along with the dry run / working.
int think(int arr[], int f, int l)
{
    if (f > l)
        return 0;
    else
    {
        int current = (arr[f] % 2 == 0) ? arr[f] : 0;
        return current + think(arr, f + 1, l);
    }
}
(a) What will the function think() return, if arr[ ] = {9, 7, 12, 16, 19, 25}, f = 0 and l = 5? [2]
(b) What is the function think() performing apart from recursion? [1]
  1. (a) Dry run (current = the element if even, else 0):
    farr[f]currentreturns
    0900 + think(1)
    1700 + think(2)
    2121212 + think(3)
    3161616 + think(4)
    41900 + think(5)
    52500 + think(6)
    6––f > l, returns 0
    [1]
  2. Unwinding: 0 + 0 + 12 + 16 + 0 + 0 + 0 = 28.
    [1]
  3. (b) It finds and returns the sum of the even elements of the array between index f and l (odd elements add 0).
    [1]
Answer
(a) 28   (b) sum of the even elements of arr[f..l]
Marking note Marks: 1 for the dry run, 1 for the value, 1 for the purpose. Credit “adds only the even numbers”. Program checked by running it: it prints 28.

  • Recursive trace: write one row per call, then add the returns back up the chain once the base case (f > l) returns 0.

The following function getPart() is a part of some class which is used to extract h number of characters starting from index b of a string str. There are some places in the code marked by ?1?, ?2?, ?3? which must be replaced by an expression / statement so that the function works correctly.
String getPart(String str, int b, int h)
{
    int beg = ?1?;
    int end = b + h - 1;
    String g = "";
    while (beg <= ?2? && beg >= 0 && end < str.length())
    {
        g += str.charAt(beg);
        ?3?;
    }

(a) What is the expression or statement at ?1? [1]
(b) … at ?2? [1]
