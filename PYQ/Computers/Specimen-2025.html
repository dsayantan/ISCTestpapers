About this deck

The questions and CISCE's own marking scheme are from the Specimen Question Paper 2025 (Part I 20 marks, Part II 50 marks). The paper lets a candidate choose two of three questions in each section of Part II, so the deck solves all 25 questions: 95 marks on the slides, of which a candidate answers questions worth 70. PART I - Question 1 (10 marks; compulsory)ISC Specimen 2025 Computer Science Paper 1, Q1(i)
Question 1(i)[1]
The complement of the Boolean expression A′ · (B · C′ + B′ · C) is:
(a)A′ · (B + C + B′ + C)
(b)A + (B + C′) · (B + C′)
(c)A + (B′ + C) · (B + C′)
(d)A′ · (B′ + C′ + B′ · C)
  1. Apply De Morgan to the outer product: [A′ · (BC′ + B′C)]′ = A + (BC′ + B′C)′.
    [½]
  2. Complement the sum inside: (BC′ + B′C)′ = (BC′)′ · (B′C)′.
  3. (BC′)′ = B′ + C and (B′C)′ = B + C′, so the result is A + (B′ + C) · (B + C′).
    [½]
  4. This is option (c); the others keep the wrong signs (a keeps A′, b leaves B and C′ uncomplemented in the first bracket).
Answer
(c) A + (B′ + C) · (B + C′)
Common slip Complementing only the literals and leaving the operators alone (that gives the dual, not the complement).

Concepts to recall

  • De Morgan: (X + Y)′ = X′ · Y′ and (X · Y)′ = X′ + Y′. To complement a whole expression, swap every AND with OR and complement every literal.
  • Complementing twice cancels: (A′)′ = A, which is why the leading A′ becomes A.
PART I - Question 1 (10 marks; compulsory)ISC Specimen 2025 Computer Science Paper 1, Q1(ii)
Question 1(ii)[1]
Assertion: Recursion utilises more memory as compared to iteration.
Reason: Time complexity of recursion is higher due to the overhead of maintaining the function call stack.
(a)Both Assertion and Reason are true and Reason is the correct explanation for Assertion.
(b)Both Assertion and Reason are true but Reason is not the correct explanation for Assertion.
(c)Assertion is true and Reason is false.
(d)Assertion is false and Reason is true.
  1. Assertion: every recursive call pushes a new frame (parameters, locals, return address) on the call stack, so recursion needs extra memory; a loop reuses one set of variables. True.
    [½]
  2. Reason: maintaining the stack frames is a real overhead and it does add time per call. True as a statement.
    [½]
Answer
(b) Both Assertion and Reason are true but Reason is not the correct explanation for Assertion.
Marking note The Reason talks about time, while the Assertion is about memory; the memory comes from the stack frames themselves, so the Reason does not explain the Assertion. CISCE's key: (b).

Concepts to recall

  • Recursion uses the call stack: space O(depth) against O(1) for a loop; each call also costs time (push, pop).
  • Assertion-reason: first judge each statement alone, then ask whether the reason is why the assertion holds.

Question 1(iii)[1]
According to the Principle of duality, the Boolean equation (A′ + B) · (1 + B) = A′ + B will be equivalent to:
(a)(A + B′) · (0 + B) = A + B′
(b)(A′ · B) + (0 · B) = A′ · B
(c)(A′ · B) + (0 · B) = A′ + B
(d)(A′ + B) · (0 + B) = A′ + B
  1. The dual is formed by interchanging + and ·, and 0 and 1, on both sides. Literals (even complemented ones) are not changed.
    [½]
  2. LHS: (A′ + B)(1 + B) becomes (A′ · B) + (0 · B); RHS: A′ + B becomes A′ · B.
    [½]
Answer
(b) (A′ · B) + (0 · B) = A′ · B
Common slip Complementing A′ to A (option a) mixes up duality with complementation.

Concepts to recall

  • Principle of duality: replace AND by OR, OR by AND, 0 by 1, 1 by 0; do not complement the variables.
  • The dual of a true identity is also a true identity (here (A′B) + 0 = A′B).

Question 1(iv)[1]
Distributive law states that:
(a)A + B · C = (A + B) · (A + C)
(b)A + (A · B) = A
(c)A · (B + C) = (A · B) + (B · C)
(d)A + B · C = A · B + A · C
  1. The two distributive laws of Boolean algebra are A(B + C) = AB + AC and A + BC = (A + B)(A + C).
    [½]
  2. (b) is the absorption law; (c) has B · C where A · C is needed; (d) is false (A = 0, B = C = 1 gives 1 on the left and 0 on the right). So (a).
    [½]
Answer
(a) A + B · C = (A + B) · (A + C)

Concepts to recall

  • Boolean algebra has two distributive laws: AND over OR (as in ordinary algebra) and OR over AND (special to Boolean algebra).
  • Test a doubtful identity by substituting 0/1 values.

The complement of the reduced expression of F(A, B) = Σ(0, 1, 2, 3) is:
(a)1
(b)A · B
(c)0
(d)A′ + B′
  1. F contains all four minterms of two variables: A′B′ + A′B + AB′ + AB.

(c) 0

Question 1(vi)[1]
p = I am a triangle; q = I am a three-sided polygon; s1 = p → q; s2 = q → p.
Assertion: s2 is the converse of s1.
Reason: A three-sided polygon must be a triangle.
(a)Both Assertion and Reason are true and Reason is the correct explanation for Assertion.
(b)Both Assertion and Reason are true but Reason is not the correct explanation for Assertion.
(c)Assertion is true and Reason is false.
(d)Assertion is false and Reason is true.
  1. The converse of p → q is q → p, which is s2. Assertion is true.
    [½]
  2. The Reason says q → p is a true fact about polygons, which is also true; but it states that s2 is true, not why s2 is the converse of s1. So the Reason is true but does not explain the Assertion.
    [½]
Answer
(b) Both Assertion and Reason are true but Reason is not the correct explanation for Assertion.

Concepts to recall

  • For p → q: converse q → p; inverse ¬p → ¬q; contrapositive ¬q → ¬p (equivalent to the original).
  • Whether the converse is true is a separate question from whether it is the converse.

Question 1(vii)[1]
Assertion: In Java, the String class is used to create and manipulate strings, and it is immutable.
Reason: Immutability ensures that once a String object is created, its value cannot be changed.
(a)Both Assertion and Reason are true and Reason is the correct explanation for Assertion.
(b)Both Assertion and Reason are true but Reason is not the correct explanation for Assertion.
(c)Assertion is true and Reason is false.
(d)Assertion is false and Reason is true.
  1. Assertion: String objects cannot be altered after creation; methods such as toUpperCase() or concat() return a new String. True.
    [½]
  2. Reason: this is exactly what immutability means, and it explains the Assertion's claim. True and the correct explanation.
    [½]
Answer
(a) Both Assertion and Reason are true and Reason is the correct explanation for Assertion.

Concepts to recall

  • A String is immutable: s.concat("x") leaves s unchanged; the result must be assigned. StringBuffer/StringBuilder are the mutable alternatives.
  • When the Reason is simply the definition of the term in the Assertion, it is the explanation.

Question 1(viii)[1]
In class Circle, static final double pi = 3.142; Which of the following statements are valid for pi?
I. It contains a common value for all objects of class Circle.
II. Its value is non-changeable.
III. At a time two access modifiers, static and final, cannot be applied to a single data member pi.
(a)I and II
(b)II and III
(c)I and III
(d)Only III
  1. static makes one copy shared by every object of the class: I is true.
    [½]
  2. final forbids reassignment, so II is true. static and final are non-access modifiers and can be combined (public static final is the usual form), so III is false. Answer: I and II.
    [½]
Answer
(a) I and II

Concepts to recall

  • static: one copy per class; final: a constant (assigned once). static final together declare a class constant, e.g. Math.PI.
  • Only public, protected and private are access specifiers; a data member may carry one of them together with several modifiers.
PART I - Question 1 (10 marks; compulsory)ISC Specimen 2025 Computer Science Paper 1, Q1(ix)
Question 1(ix)[1]
For Big O notation, state the difference between O(n) and O(n2).
  1. O(n) is linear time: the running time grows in direct proportion to n; typical of a single loop (doubling n doubles the work).
    [½]
  2. O(n2) is quadratic time: the running time grows as the square of n; typical of nested loops (doubling n makes it four times as long).
    [½]
Answer
O(n): single loop, time proportional to n. O(n2): nested loops, time proportional to the square of n.

Concepts to recall

  • Big O gives the upper bound of growth of the running time with input size n, ignoring constants. Order: O(1) < O(log n) < O(n) < O(n log n) < O(n2).
  • Count loops: one loop over n → n; a loop inside a loop → n × n.
PART I - Question 1 (10 marks; compulsory)ISC Specimen 2025 Computer Science Paper 1, Q1(x)
Question 1(x)[1]
A full adder needs five gates: 3 AND, 1 OR and 1 XOR. When it is built from 2 half adders it also needs 5 gates. State the names, with the quantity, of those gates.
  1. A half adder is one XOR (sum) and one AND (carry). Two half adders give 2 XOR and 2 AND.
    [½]
  2. The two carries are combined by one OR gate. Total: 2 XOR + 2 AND + 1 OR = 5 gates.
    [½]
Answer
2 XOR gates, 2 AND gates and 1 OR gate.

Concepts to recall

  • Half adder: S = A ⊕ B, C = A · B. Full adder: S = A ⊕ B ⊕ Cin, Cout = AB + Cin(A ⊕ B).
  • Chaining: the sum of half adder 1 and Cin feed half adder 2; Cout = carry1 + carry2.
PART I - Question 2 (10 marks; compulsory)ISC Specimen 2025 Computer Science Paper 1, Q2(i)
Question 2(i)[2]
Convert the following infix notation to prefix form.
(A−B)/C*(D+E)
  1. Operators / and * have equal precedence and associate left to right, so the expression is ((A−B)/C) * (D+E).
    [½]
  2. Prefix, innermost first: (A−B) → −AB; (−AB)/C → /−ABC; (D+E) → +DE.
    [1]
  3. Join with the last operator *: * /−ABC +DE.
    [½]
Answer
* / − A B C + D E (written */−ABC+DE)
Common slip Treating / and * as if * came first, giving A−B / (C*(D+E)), which changes the answer.

Concepts to recall

  • Prefix (Polish) notation puts the operator before its operands; no brackets are needed.
  • Precedence: ^ > * and / (equal, left to right) > + and −. Brackets first.
  • Method: fully bracket the expression using precedence, then move every operator in front of its two operands. Check by evaluating with sample values.
PART I - Question 2 (10 marks; compulsory)ISC Specimen 2025 Computer Science Paper 1, Q2(ii)
Question 2(ii)[2]
A matrix M[−6 … 10, 4 … 15] is stored in the memory with each element requiring 4 bytes of storage. If the base address is 1025, find the address of M[4][8] when the matrix is stored column major wise.
  1. Column major: address of M[I][J] = B + W × [(J − LC) × R + (I − LR)], R = number of rows.
    [½]
  2. Rows = 10 − (−6) + 1 = 17; columns = 15 − 4 + 1 = 12. B = 1025, W = 4, LR = −6, LC = 4, I = 4, J = 8.
    [½]
  3. Address = 1025 + 4 × [(8 − 4) × 17 + (4 − (−6))] = 1025 + 4 × (68 + 10) = 1025 + 4 × 78 = 1025 + 312
    [½]
  4. = 1337
    [½]
Answer
Address of M[4][8] = 1337
Common slip Using columns (12) instead of rows (17) as the multiplier, which is the row-major formula.
Marking note The base address 1025 is taken as the address of M[−6][4], the first element.

Concepts to recall

  • Row major: B + W[(I − LR) × C + (J − LC)] (C = columns). Column major: B + W[(J − LC) × R + (I − LR)] (R = rows).
  • Number of elements in a dimension = upper − lower + 1; with a negative lower bound, I − LR adds.
  • Columns before column J are skipped whole (R elements each); then count the rows down inside the column.

Question 2(iii)[3]
The following function getIt() is a part of some class. Assume x is a positive integer, f is the lower bound of arr[ ] and l is the upper bound of arr[ ]. Answer the questions with dry run / working.
public int getIt(int x, int arr[], int f, int l)
{
    if (f > l)
        return -1;
    int m = (f + l) / 2;
    if (arr[m] < x)
        return getIt(x, arr, m + 1, l);
    else if (arr[m] > x)
        return getIt(x, arr, f, m - 1);
    else
        return m;
}
(a) What will the function getIt( ) return if arr[ ] = {10, 20, 30, 40, 50} and x = 40? [2]
(b) What is function getIt( ) performing apart from recursion? [1]
  1. (a) Dry run, x = 40, f = 0, l = 4:
  2. Call 1: f = 0, l = 4, m = (0 + 4)/2 = 2; arr[2] = 30 < 40, so call getIt(40, arr, 3, 4).
    [1]
  3. Call 2: f = 3, l = 4, m = (3 + 4)/2 = 3; arr[3] = 40 = x, so it returns m = 3. Value returned: 3.
    [1]
  4. (b) It performs a binary search on the sorted array arr[ ]: it halves the range each call and returns the index of x, or −1 when x is absent.
    [1]
Answer
(a) 3 (index of 40)   (b) binary search (recursive)
Marking note The paper prints the signature as intarr and the recursive calls as getIt(x,m+1,l) without arr (typing slips); the solution reads them as the signature with int arr[] and calls passing arr. The corrected method was compiled and run: it returns 3 for x = 40, −1 for 35 and 0 for 10.

Concepts to recall

  • Binary search needs a sorted array: compare with the middle element m = (f + l)/2; go right if arr[m] < x, left if arr[m] > x; stop when f > l (not found, returns −1).

  • Complexity O(log n) against O(n) for linear search.

Question 2(iv)[3]
The following is a function of class Armstrong. This recursive function calculates and returns the sum of the cubes of all the digits of num, where num is an integer data member of the class. [A number is Armstrong if the sum of the cubes of its digits equals the number.] Places marked ?1?, ?2?, ?3? may be replaced by a statement/expression so that the function works properly.
public int sumOfPowers(int num)
{
    if (num == 0)
        return ?1?;
    int digit = ?2?;
    return (int) Math.pow(digit, 3) + ?3?;
}
(a) ?1? [1]   (b) ?2? [1]   (c) ?3? [1]
  1. (a) Base case: when no digits are left the sum is 0, so ?1? is 0.
    [1]
  2. (b) The last digit of num is the remainder on division by 10: ?2? is num % 10.
    [1]
  3. (c) Add the cube sums of the remaining digits, i.e. of num with the last digit removed: ?3? is sumOfPowers(num / 10).
    [1]
public int sumOfPowers(int num)
{
    if (num == 0)
        return 0;
    int digit = num % 10;
    return (int) Math.pow(digit, 3) + sumOfPowers(num / 10);
}

Compiled and run: sumOfPowers(153) = 153, sumOfPowers(371) = 371, sumOfPowers(123) = 36.

Answer
?1? = 0; ?2? = num % 10; ?3? = sumOfPowers(num / 10)
Common slip Writing num / 10 for ?2? (that is the quotient, not the digit), or num for ?1? (infinite recursion).

Concepts to recall

  • Digit extraction: n % 10 gives the last digit, n / 10 (integer division) removes it. A digit recursion stops at n == 0.
  • Recursion has a base case that returns the identity of the operation (0 for a sum) and a recursive case that shrinks the problem.
  • Armstrong check: the number equals sumOfPowers(num); 153 = 1 + 125 + 27.

Reduce the above expression X(E, R, S, C) using a 4-variable Karnaugh map, showing the various groups (octal, quads and pairs). Draw the logic gate diagram for the reduced expression. Assume that the variables and their complements are available as inputs.
  1. Fill the map with 1 in cells 1, 3, 4, 6, 9, 10, 11, 14, 15 (rows ER in Gray order 00, 01, 11, 10; columns SC in Gray order).
    [1]
  2. Quad 1: m1 + m3 + m9 + m11 (top and bottom rows wrap round) = R′C.
    [1]
  3. Quad 2: m10 + m11 + m14 + m15 = E · S.
    [1]
  4. Pair: m4 + m6 (the end columns wrap round) = E′ R C′. No octet exists.
    [½]
  5. X(E, R, S, C) = R′C + E S + E′ R C′
    [½]
  6. Logic circuit: three AND gates (2, 2 and 3 inputs) feeding one OR gate, using the complemented inputs directly.
    [1]
Answer
X = R′C + ES + E′RC′

(b) Draw the logic gate diagram for the reduced expression. Assume that the variables and their complements are available as inputs. [1]
  1. (a) Each bracket is a maxterm: the nine brackets are M0, M1, M2, M4, M5, M6, M7, M8, M9 (a primed variable stands for bit 1). F = Π(0, 1, 2, 4, 5, 6, 7, 8, 9); enter 0 in those cells of the POS map.
    [1]
  2. Quad 1: M0 M1 M8 M9 = Q + R.
    [1]
  3. Quad 2: M4 M5 M6 M7 = P + Q′.
    [1]
  4. Quad 3: M0 M2 M4 M6 (the end columns wrap round) = P + S.
    [½]
