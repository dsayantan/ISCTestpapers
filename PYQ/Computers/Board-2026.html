PART I (20 marks)ISC 2026 Computer Science Paper 1 (868A), Q1(i)
Question 1(i)[1]
According to the Principle of Duality, the Boolean equation Q′·0 + P′·Q′ + P′·Q = P′ will be equivalent to:
(a)Q·0 + P·Q + P·Q′ = P
(b)Q′·1 + P′·Q′ + P·Q′ = P′
(c)(Q′+1)·(P′+Q′)·(P′+Q) = P′
(d)(Q′+0)·(P′+Q′)·(P′+Q) = P′
  1. Principle of Duality: interchange every + with · and every · with +, and every 0 with 1 and every 1 with 0. Variables and complements are not changed.
    [½]
  2. Q′·0 + P′·Q′ + P′·Q = P′ becomes (Q′+1)·(P′+Q′)·(P′+Q) = P′: the 0 became 1, the two + became · and the · became +. The right-hand side P′ is unchanged.
    [½]
Answer
(c) (Q′+1)·(P′+Q′)·(P′+Q) = P′
Common slip Complementing the variables as well (that gives the complement, not the dual).

Concepts to recall

  • Dual of an expression: swap + and ·, swap 0 and 1; leave the literals (including primes) alone. If an identity holds, so does its dual.
  • Option (a) and (b) change the literals or only part of the operators; (d) forgets to change 0 into 1.
PART I (20 marks)ISC 2026 Computer Science Paper 1 (868A), Q1(ii)
Question 1(ii)[1]
Consider the following statement written in class Student where school_Name is its data member.
static final String school_Name = "Co-Ed School";
Which of the following statements are valid for school_Name?
I. All objects of class Student share the same value of school_Name.
II. The value of school_Name cannot be changed during program execution.
III. The keywords static and final cannot be used together for a variable.
(a)Only I and II
(b)Only II and III
(c)Only I and III
(d)Only II
  1. static: one copy belongs to the class and is shared by every object, so I is true.
    [½]
  2. final: the value is assigned once and cannot be changed, so II is true. A variable may be declared static final (that is how constants are written), so III is false. Hence only I and II.
    [½]
Answer
(a) Only I and II

Concepts to recall

  • static = class-level, shared by all objects. final = constant, cannot be reassigned.
  • static final together is the standard way to declare a constant, e.g. static final double PI = 3.14;.
PART I (20 marks)ISC 2026 Computer Science Paper 1 (868A), Q1(iii)
Question 1(iii)[1]
P = You practise regularly; Q = You become skilled; S1 = P ⇒ Q; S2 = ~P ∨ Q.
Assertion: S1 and S2 are logically equivalent.
Reason: A conditional statement P ⇒ Q can be expressed as ~P ∨ Q.
(a)Both Assertion and Reason are true and Reason is the correct explanation for Assertion.
(b)Both Assertion and Reason are true but Reason is not the correct explanation for Assertion.
(c)Assertion is true and Reason is false.
(d)Both Assertion and Reason are false.
  1. The truth table of P ⇒ Q is false only when P = 1, Q = 0, and so is that of ~P ∨ Q; so the two are equivalent: the Assertion is true.
    [½]
  2. The Reason is exactly the law that makes them equivalent (implication elimination), so it is true and it explains the Assertion.
    [½]
Answer
(a) Both Assertion and Reason are true and Reason is the correct explanation for Assertion.

Concepts to recall

  • P ⇒ Q ≡ ~P ∨ Q (implication elimination). It is false only when P is true and Q is false.
  • Assertion–Reason: decide each statement separately, then ask whether the Reason explains the Assertion.
PART I (20 marks)ISC 2026 Computer Science Paper 1 (868A), Q1(iv)
Question 1(iv)[1]
The Boolean equations a + 1 = a and a · 0 = 0 correspond to:
(a)Involution Law
(b)Law of Identity
(c)Distributive Law
(d)Law of Complements
  1. The equations are of the type “a combined with a constant (1 or 0)”. They are not complements (a + a′, a·a′), not double negation, and not a distributive pattern.
    [½]
  2. Of the four laws offered, they belong with the Law of Identity (the laws of the constants 0 and 1), so (b).
    [½]
Answer
(b) Law of Identity
Marking note The paper prints “a + 1 = a”, which is a misprint of a + 1 = 1 (a + 1 = a is false for a = 0). Neither is in the Law of Complements, Involution or Distributive Law, so (b) is the only option that can be intended. Treated as a printing error; (b) is the answer.

Concepts to recall

  • Identity: a + 0 = a, a · 1 = a. Null/dominance: a + 1 = 1, a · 0 = 0. Complement: a + a′ = 1, a · a′ = 0. Involution: (a′)′ = a.
  • Eliminate the options that clearly do not fit; that is the examiner’s intention.
PART I (20 marks)ISC 2026 Computer Science Paper 1 (868A), Q1(v)
Question 1(v)[1]
The worst case complexity for the following code segment is:
for(int i=1; i<=n; i++)
{
    for(int j=1; j<=i; j++)
    {
        statement;
    }
}
(a)O(n+i)
(b)O(n×i)
(c)O(n)
(d)O(n2)
  1. The inner loop runs i times for each value of i: total = 1 + 2 + 3 + … + n = n(n+1)/2.
    [½]
  2. n(n+1)/2 = (n2 + n)/2; the dominant term gives O(n2).
    [½]
Answer
(d) O(n2)

Concepts to recall

  • Dependent nested loops: the inner count depends on the outer variable, so add up 1 + 2 + … + n = n(n+1)/2.
  • Big-O keeps only the highest power and drops constants: n(n+1)/2 is O(n2). O(n+i) and O(n×i) are not valid in terms of n alone.
PART I (20 marks)ISC 2026 Computer Science Paper 1 (868A), Q1(vi)
Question 1(vi)[1]
Assertion: An interface in Java contains abstract and non-abstract methods.
Reason: All methods in an interface must be implemented by any class that extends this interface.
(a)Both Assertion and Reason are true and Reason is the correct explanation for Assertion.
(b)Both Assertion and Reason are true but Reason is not the correct explanation for Assertion.
(c)Assertion is true and Reason is false.
(d)Both Assertion and Reason are false.
  1. Assertion: since Java 8 an interface may hold default and static methods with bodies besides abstract methods, so it can contain non-abstract methods: true.
    [½]
  2. Reason: a class implements (not “extends”) an interface, and it must define only the abstract methods; default methods need not be overridden (and an abstract class need not define any). So the Reason is false.
    [½]
Answer
(c) Assertion is true and Reason is false.
Marking note If a candidate argues from the older (pre-Java 8) rule that an interface has only abstract methods, the Assertion would be false and the answer (d). The ISC syllabus is Java 8 era (BlueJ), so (c) is taken. A further check: with the old rule the Assertion would be false and the Reason true, a combination the four options do not offer, so the Assertion must be meant as true and (c) is the only fit.

Concepts to recall

  • An interface has abstract methods; from Java 8 it may also have default and static methods with a body. A class uses implements; an interface uses extends for another interface.
  • A concrete class must implement every abstract method of its interface; default methods are inherited.
PART I (20 marks)ISC 2026 Computer Science Paper 1 (868A), Q1(vii)
Question 1(vii)[1]
The complement of the Boolean expression a·b′ + a′ + a′·b is:
(a)a + b′·a′·a′ + b
(b)(a′+b)·a·(a+b′)
(c)(a+b′)·a′·(a+b′)
(d)a′·b + a + a·b′
  1. Apply De Morgan’s theorem to the sum: complement of (X + Y + Z) = X′ · Y′ · Z′, with X = a·b′, Y = a′, Z = a′·b.
    [½]
  2. (a·b′)′ = a′+b, (a′)′ = a, (a′·b)′ = a+b′. So the complement is (a′+b)·a·(a+b′).
    [½]
Answer
(b) (a′+b)·a·(a+b′)

Concepts to recall

  • De Morgan: (X + Y)′ = X′·Y′ and (X·Y)′ = X′ + Y′. Complement each term, change every + to · and every · to +.
  • Check by taking a value: a = 0, b = 0 makes the given expression 1, so its complement is 0; option (b) gives (1)·0·(1) = 0.
PART I (20 marks)ISC 2026 Computer Science Paper 1 (868A), Q1(viii)
Question 1(viii)[1]
Assertion: The return statement enables the exit of the program control from the current method.
Reason: If a method’s return type is void, it can still contain return 0 statement to return nothing.
(a)Both Assertion and Reason are true and Reason is the correct explanation for Assertion.
(b)Both Assertion and Reason are true but Reason is not the correct explanation for Assertion.
(c)Assertion is true and Reason is false.
(d)Both Assertion and Reason are false.
  1. return transfers control back to the caller and ends the current method: the Assertion is true.
    [½]
  2. A void method may contain return; but never return 0;: returning a value from a void method is a compile-time error. The Reason is false.
    [½]
Answer
(c) Assertion is true and Reason is false.

Concepts to recall

  • return ends the method; in a void method write just return; (optional). A non-void method must return a value of its type.
  • return 0; in a void method: error “incompatible types: unexpected return value”.
PART I (20 marks)ISC 2026 Computer Science Paper 1 (868A), Q1(ix)
Question 1(ix)[1]
Consider the two propositions: A = You use ecofriendly methods; B = Pollution is reduced. If A implies B, then write its Contrapositive statement.
  1. A ⇒ B is “If you use ecofriendly methods, then pollution is reduced”. Its contrapositive is ~B ⇒ ~A: If pollution is not reduced, then you do not use ecofriendly methods.
    [1]
Answer
~B ⇒ ~A : If pollution is not reduced, then you do not use ecofriendly methods.
Common slip Writing the converse (“If pollution is reduced, you use ecofriendly methods”) or just negating both without swapping them.

Concepts to recall

  • Contrapositive of P ⇒ Q is ~Q ⇒ ~P and is always equivalent to P ⇒ Q.
  • Converse (Q ⇒ P) and inverse (~P ⇒ ~Q) are not equivalent to the original; they are contrapositives of each other.
PART I (20 marks)ISC 2026 Computer Science Paper 1 (868A), Q1(x)
Question 1(x)[1]
What is Gray code in Karnaugh map?
  1. Gray code is a binary code in which two successive values differ in exactly one bit. In a K-map the rows and columns are labelled 00, 01, 11, 10 (not 00, 01, 10, 11), so that neighbouring cells, including those at opposite edges, differ in only one variable and can be grouped to eliminate that variable.
    [1]
Answer
A code in which adjacent values differ in one bit (00, 01, 11, 10); it is the order used to label K-map rows and columns so that adjacent cells differ in a single variable.

Concepts to recall

  • Two-variable Gray sequence: 00, 01, 11, 10. A 4-variable K-map has Gray-coded rows and columns; cell numbers are not in natural order.
  • Because of Gray labelling, groups may wrap round the edges (top-bottom, left-right).

Question 3[10]
(i) (a) What is a decoder? [1] (b) Draw the logic gate diagram for decoding the binary numbers {0011, 0100, 0101, 0111, 1011, 1110} to hexadecimal numbers. [3] (c) State any one application of a multiplexer. [1]
(ii) The Chain rule states that [(a⇒b) · (b⇒c)] ⇒ (a⇒c). Prove this rule using Boolean laws. [3]
(iii) Given that P = 0, Q = 1, R = 0, S = 0, write its: (a) Maxterm [1] (b) Minterm [1]
  1. (i)(a) A decoder is a combinational circuit with n input lines and up to 2n output lines which activates exactly one output line, the one corresponding to the binary code applied at the inputs (it converts a binary code into a single active line).
    [1]
  2. (b) Hexadecimal digits: 0011 = 3, 0100 = 4, 0101 = 5, 0111 = 7, 1011 = B, 1110 = E. Four inputs A B C D (A the MSB) and their complements A′ B′ C′ D′ (through NOT gates) are available.
    [1]
  3. One 4-input AND gate per number; each takes the true line for a 1 bit and the complemented line for a 0 bit: 3 = A′B′CD, 4 = A′BC′D′, 5 = A′BC′D, 7 = A′BCD, B = AB′CD, E = ABCD′.
    [1]
  4. Each output is labelled with its hexadecimal digit (figure below).
    [1]
  5. (c) Applications of a multiplexer (any one): selecting one of many data sources onto a single line (data routing); parallel-to-serial conversion; implementing Boolean functions; communication systems (many signals sharing one channel).
    [1]
  6. (ii) Proof of [(a⇒b)·(b⇒c)] ⇒ (a⇒c)
  7. Remove each implication using x ⇒ y = x′ + y: LHS = [(a′+b)·(b′+c)]′ + (a′+c). De Morgan on the bracket: = (a′+b)′ + (b′+c)′ + a′ + c = ab′ + bc′ + a′ + c.
    [1]
  8. Absorption x + x′y = x + y, taking x = a′: a′ + ab′ = a′ + b′, so the expression is a′ + b′ + bc′ + c. Again b′ + bc′ = b′ + c′ and c′ + c = 1: = a′ + b′ + c′ + c
    [1]
  9. = a′ + b′ + 1 = 1 (null law). The expression is always 1, i.e. a tautology, so the Chain rule is proved.
    [1]
  10. (iii) With P = 0, Q = 1, R = 0, S = 0:
  11. (a) Maxterm (a sum in which each variable appears complemented if its value is 1): P + Q′ + R + S (= M4, the only row where this sum is 0)
    [1]
  12. (b) Minterm (a product in which each variable appears complemented if its value is 0): P′·Q·R′·S′ (= m4)
    [1]
Answer
(iii) Maxterm = P + Q′ + R + S; Minterm = P′·Q·R′·S′.  (ii) Expression reduces to 1, so the rule is proved.
Common slip Swapping the rule for maxterms and minterms (complementing the 0s in a maxterm).

Concepts to recall

  • Decoder: n inputs, 2n outputs, one active at a time; each output is an AND (minterm) of the true/complemented inputs. Encoder is the reverse.
  • Multiplexer: many inputs, one output, chosen by select lines (2n data lines need n select lines).
  • x ⇒ y = x′ + y; De Morgan; absorption x + x′y = x + y; x + x′ = 1; x + 1 = 1.
  • Minterm: value 1 → plain, 0 → complemented (product). Maxterm: value 0 → plain, 1 → complemented (sum). Minterm and maxterm of the same row are complements.

    import java.util.*;
class PendulumS
{
    String wrd, newwrd;

    PendulumS(String k)
    {
        wrd = k;
        newwrd = "";
    }

    int minCharIndex(String str)            // index of the smallest ASCII character
    {
        int idx = 0;
        for (int i = 1; i < str.length(); i++)
            if (str.charAt(i) < str.charAt(idx))
                idx = i;
        return idx;
    }

    void arrange()
    {
        int n = wrd.length();
        char res[] = new char[n];
        String rest = wrd;                  // letters not yet placed
        int c = (n - 1) / 2;                // centre position
        int l = c, r = c;                   // last position used on the left / right
        for (int k = 0; k < n; k++)
        {
            int i = minCharIndex(rest);
            char ch = rest.charAt(i);
            rest = rest.substring(0, i) + rest.substring(i + 1);   // remove it
            if (k == 0)
                res[c] = ch;                // lowest goes to the centre
            else if (k % 2 == 1)
                res[++r] = ch;              // 2nd, 4th, ... to the right
            else
                res[--l] = ch;              // 3rd, 5th, ... to the left
        }
        newwrd = new String(res);
    }

    void display()
    {
        System.out.println("Original word : " + wrd);
        System.out.println("Rearranged word : " + newwrd);
    }

    public static void main(String args[])
    {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter a word in upper case: ");
        PendulumS ob = new PendulumS(sc.next());
        ob.arrange();
        ob.display();
    }
}

Concepts to recall

  • Find the minimum: keep the index of the smallest so far; compare characters with < (their ASCII values are compared).
  • Remove the character at index i: s.substring(0,i) + s.substring(i+1). Strings are immutable, so build a new one.
  • Pendulum pattern: centre, then alternately right and left. Even length: centre = (n−1)/2 means the left half is one shorter than the right half.
  • Repeated letters (SCIENCE has two C and two E) cause no problem: the first occurrence is taken each time.
