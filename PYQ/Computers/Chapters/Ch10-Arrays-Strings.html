Question 1(vii) · Specimen 2025[1]
Assertion: In Java, the String class is used to create and manipulate strings, and it is immutable.
Reason: Immutability ensures that once a String object is created, its value cannot be changed.
(a)Both Assertion and Reason are true and Reason is the correct explanation for Assertion.
(b)Both Assertion and Reason are true but Reason is not the correct explanation for Assertion.
(c)Assertion is true and Reason is false.
(d)Assertion is false and Reason is true.
  1. Assertion: String objects cannot be altered after creation; methods such as toUpperCase() or concat() return a new String. True.
    [½]
  2. Reason: this is exactly what immutability means, and it explains the Assertion's claim. True and the correct explanation.
    [½]
Answer
(a) Both Assertion and Reason are true and Reason is the correct explanation for Assertion.

Concepts to recall

  • A String is immutable: s.concat("x") leaves s unchanged; the result must be assigned. StringBuffer/StringBuilder are the mutable alternatives.
  • When the Reason is simply the definition of the term in the Assertion, it is the explanation.

Question 2(ii) · Board 2025 Imp.[2]
A matrix P[−10…10, 1…10] is stored in the memory with each element requiring 2 bytes of storage. If the base address is 2000, find the address of P[5][6] when the matrix is stored Row Major wise.
  1. Rows = 10 − (−10) + 1 = 21, columns = 10 − 1 + 1 = 10, w = 2, lower bounds Lr = −10, Lc = 1, base B = 2000.
    [½]
  2. Row major: address of P[i][j] = B + w × [(i − Lr) × C + (j − Lc)], C = number of columns.
    [½]
  3. P[5][6] = 2000 + 2 × [(5 + 10) × 10 + (6 − 1)] = 2000 + 2 × 155
    [½]
  4. = 2000 + 310 = 2310
    [½]
Answer
Address of P[5][6] = 2310
Common slip Using (5 − 10) or taking 20 rows (10 + 10); the lower bound −10 gives 21 rows and an offset of 15 rows above P[5].

Concepts to recall

  • Row major: row by row, so row offset = (i − Lr) × (columns) and column offset = (j − Lc).
  • Column major: B + w[(j − Lc) × R + (i − Lr)], R = number of rows.
  • Number of rows/columns with bounds l..u is u − l + 1 (negative lower bound adds, it does not subtract).

Question 2(ii) · Board 2025[2]
A matrix M[−1 … 10, 4 … 13] is stored in the memory with each element requiring 2 bytes of storage. If the base address is 1200, find the address of M[2][7] when the matrix is stored Row Major Wise.
  1. Rows = 10 − (−1) + 1 = 12; columns = 13 − 4 + 1 = 10 (the number of columns is what a row-major address needs). Formula: Address = B + w[(i − Lr)×C + (j − Lc)].
    [1]
  2. Address of M[2][7] = 1200 + 2[(2 − (−1))×10 + (7 − 4)] = 1200 + 2[30 + 3] = 1200 + 66 = 1266.
    [1]
Answer
Address of M[2][7] = 1266
Common slip Using (i − 0) and (j − 0) because the matrix looks like a normal array; with negative and non-zero lower bounds the offsets must be measured from Lr and Lc.

Concepts to recall

  • Row major: elements of one row are consecutive; Addr(i,j) = B + w[(i − Lr)×C + (j − Lc)] where C = number of columns = Uc − Lc + 1.
  • Column major uses the number of rows: B + w[(j − Lc)×R + (i − Lr)].
  • The base address is that of the first element M[−1][4].

Question 2(ii) · Specimen 2025[2]
A matrix M[−6 … 10, 4 … 15] is stored in the memory with each element requiring 4 bytes of storage. If the base address is 1025, find the address of M[4][8] when the matrix is stored column major wise.
  1. Column major: address of M[I][J] = B + W × [(J − LC) × R + (I − LR)], R = number of rows.
    [½]
  2. Rows = 10 − (−6) + 1 = 17; columns = 15 − 4 + 1 = 12. B = 1025, W = 4, LR = −6, LC = 4, I = 4, J = 8.
    [½]
  3. Address = 1025 + 4 × [(8 − 4) × 17 + (4 − (−6))] = 1025 + 4 × (68 + 10) = 1025 + 4 × 78 = 1025 + 312
    [½]
  4. = 1337
    [½]
Answer
Address of M[4][8] = 1337
Common slip Using columns (12) instead of rows (17) as the multiplier, which is the row-major formula.
Marking note The base address 1025 is taken as the address of M[−6][4], the first element.

Concepts to recall

  • Row major: B + W[(I − LR) × C + (J − LC)] (C = columns). Column major: B + W[(J − LC) × R + (I − LR)] (R = rows).
  • Number of elements in a dimension = upper − lower + 1; with a negative lower bound, I − LR adds.
  • Columns before column J are skipped whole (R elements each); then count the rows down inside the column.

Question 2(ii) · Board 2024[2]
An array ARR [ −5 …… 15, 10 …… 20 ] stores elements in Row Major Wise with each element requiring 2 bytes of storage. Find the address of ARR [10] [15] when the base address is 2500.
  1. Rows = 15 − (−5) + 1 = 21; columns n = 20 − 10 + 1 = 11. Row major: Address of A[i][j] = B + w [ (i − Lr) × n + (j − Lc) ]
    [1]
  2. = 2500 + 2 [ (10 − (−5)) × 11 + (15 − 10) ]
    [½]
  3. = 2500 + 2 [ 15 × 11 + 5 ] = 2500 + 2 × 170 = 2840
    [½]
Answer
Address of ARR[10][15] = 2840
Common slip Using n = 20 − 10 = 10 columns (forgetting the +1), or taking 10 − 5 = 5 for the row offset.
Marking note The base address is that of the first element ARR[−5][10] (no other cell is quoted).

  • With a negative lower bound, i − Lr = 10 − (−5) = 15: subtracting a negative adds.

Question 8 · Board 2026[10]
Design a class PendulumS to perform an operation on a word containing alphabets in upper case only. Rearrange the word by putting the lowest ASCII value character at the centre and the second lowest ASCII value character to its right and the third to its left and so on. Example 1: Input COMPUTER, Output TPMCEORU. Example 2: Input SCIENCE, Output SIECCEN.
Class name: PendulumS
Data members
wrd: to store the original word
newwrd: to store the rearranged word
Methods
PendulumS(String k): parameterised constructor to initialise wrd = k and newwrd = ""
int minCharIndex(String str): to find the index of the minimum ASCII value character in str and return it
void arrange( ): to rearrange the characters of wrd as per the given instructions and store it in newwrd by invoking minCharIndex( )
void display( ): to display the original word and the rearranged word
Specify the class giving the details of the constructor( ), int minCharIndex(String), void arrange( ) and void display( ). Define the main( ) function to create an object and call the functions accordingly. [10]
  1. Class header, data members; constructor wrd = k; newwrd = "";
    [1]
  2. minCharIndex(str): assume index 0 is smallest, compare each character, return the index of the smallest
    [2]
  3. arrange(): repeat n times – find the smallest remaining letter with minCharIndex(), remove it from the remaining string
    [1½]
  4. Centre position c = (n − 1)/2; first (lowest) letter at c; 2nd, 4th, … at c+1, c+2, … (right); 3rd, 5th, … at c−1, c−2, … (left)
    [2]
  5. Build the rearranged String from the char array and store in newwrd
    [½]
  6. display(): print wrd and newwrd
    [1]
  7. main(): accept the word, create the object, call arrange() and display()
    [2]
  8. Working for COMPUTER: sorted order C, E, M, O, P, R, T, U; n = 8, centre index 3: positions 3 4 2 5 1 6 0 7 receive C E M O P R T U ⇒ T P M C E O R U.
  9. Program (run: COMPUTER gives TPMCEORU, SCIENCE gives SIECCEN, plus one-, two- and four-letter words):
    import java.util.*;
class PendulumS
{
    String wrd, newwrd;

    PendulumS(String k)
    {
        wrd = k;
        newwrd = "";
    }

    int minCharIndex(String str)            // index of the smallest ASCII character
    {
        int idx = 0;
        for (int i = 1; i < str.length(); i++)
            if (str.charAt(i) < str.charAt(idx))
                idx = i;
        return idx;
    }

    void arrange()
    {
        int n = wrd.length();
        char res[] = new char[n];
        String rest = wrd;                  // letters not yet placed
        int c = (n - 1) / 2;                // centre position
        int l = c, r = c;                   // last position used on the left / right
        for (int k = 0; k < n; k++)
        {
            int i = minCharIndex(rest);
            char ch = rest.charAt(i);
            rest = rest.substring(0, i) + rest.substring(i + 1);   // remove it
            if (k == 0)
                res[c] = ch;                // lowest goes to the centre
            else if (k % 2 == 1)
                res[++r] = ch;              // 2nd, 4th, ... to the right
            else
                res[--l] = ch;              // 3rd, 5th, ... to the left
        }
        newwrd = new String(res);
    }

    void display()
    {
        System.out.println("Original word : " + wrd);
        System.out.println("Rearranged word : " + newwrd);
    }

    public static void main(String args[])
    {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter a word in upper case: ");
        PendulumS ob = new PendulumS(sc.next());
        ob.arrange();
        ob.display();
    }
}
Answer
COMPUTER → TPMCEORU; SCIENCE → SIECCEN (program above).
Common slip Using the middle index n/2 for even length (gives UPMC… instead of TPMC…), or placing the second lowest on the left.

Concepts to recall

  • Find the minimum: keep the index of the smallest so far; compare characters with < (their ASCII values are compared).
  • Remove the character at index i: s.substring(0,i) + s.substring(i+1). Strings are immutable, so build a new one.
  • Pendulum pattern: centre, then alternately right and left. Even length: centre = (n−1)/2 means the left half is one shorter than the right half.
  • Repeated letters (SCIENCE has two C and two E) cause no problem: the first occurrence is taken each time.

Example: Array1 = {9, 7, 6, 4}, Array2 = {8, 3, 2, 1}; resultant array = {1, 2, 3, 8, 4, 6, 7, 9}.
Class name: JoinArray
Data members / instance variables
arr[ ]: integer array
size: integer to store the size of the array
Member functions / methods
JoinArray(int s): constructor to initialise size
void accept(): to input the elements of the array

void display(): to display the array elements
Specify the class JoinArray giving details of the constructor(int), void accept(), JoinArray attach(JoinArray, JoinArray) and void display(). Define the main() function to create objects and call the functions accordingly to enable the task.
  1. Class header, data members
    [1]
  2. Constructor JoinArray(int s): size = s and arr = new int[size]
    [1]
  3. accept(): loop to input the elements
    [1]
  4. attach(): new object of size P.size + Q.size
    [1]
  5. attach(): second array copied from last index to first
    [2]
  6. attach(): then first array copied from last index to first; result returned
    [2]
  7. display() and main(): objects created, accept, attach, display
    [2]
  8. import java.util.*;
class JoinArray
{
    static Scanner sc = new Scanner(System.in);   // one scanner shared by accept() and main()
    int arr[];                               // the elements
    int size;                                // number of elements

    JoinArray(int s)
    {
        size = s;
        arr = new int[size];
    }

    void accept()
    {
        System.out.println("Enter " + size + " elements : ");
        for (int i = 0; i < size; i++)
            arr[i] = sc.nextInt();
    }

    JoinArray attach(JoinArray P, JoinArray Q)
    {
        JoinArray R = new JoinArray(P.size + Q.size);
        int k = 0;
        for (int i = Q.size - 1; i >= 0; i--)    // second array, last index to first
            R.arr[k++] = Q.arr[i];
        for (int i = P.size - 1; i >= 0; i--)    // then the first array, last index to first
            R.arr[k++] = P.arr[i];
        return R;
    }

    void display()
    {
        for (int i = 0; i < size; i++)
            System.out.print(arr[i] + " ");
        System.out.println();
    }

    public static void main(String args[])
    {
        System.out.print("Size of first array : ");
        int n1 = sc.nextInt();
        System.out.print("Size of second array : ");
        int n2 = sc.nextInt();
        JoinArray a = new JoinArray(n1);
        JoinArray b = new JoinArray(n2);
        a.accept();
        b.accept();
        JoinArray r = new JoinArray(n1 + n2);
        r = r.attach(a, b);
        System.out.println("Resultant array : ");
        r.display();
    }
}
Answer
Program above; for {9, 7, 6, 4} and {8, 3, 2, 1} it prints 1 2 3 8 4 6 7 9
Common slip Sizing the result array with s from this object (which is unrelated to P and Q) instead of P.size + Q.size.
Marking note Compiled and run with the paper’s example and a second case of unequal sizes. attach() may be written so that it uses the current object as one of the arrays provided the described order is kept.

Concepts to recall

  • Reversing while copying: loop i from size − 1 down to 0 and write into the next free index k++.
  • A method may create and return an object of its own class; the new array must be as long as both arrays together.
  • Arrays of objects P and Q are reached through the dot operator: P.arr[i], Q.size.

A class Palprime has been defined to display Palprime words from a sentence. Palprime is a palindrome word and its length is a prime number.
Example: Input: MY MOM POSSESSES A GOOD LEVEL OF KNOWLEDGE IN MALAYALAM   Output: MOM, LEVEL

Methods / member functions
Palprime(): constructor to initialise data member
void input(): to accept the sentence in UPPER CASE
boolean isPalin(String n): to check whether the string n is a palindrome word and return true, otherwise return false
boolean primelen(String n): to find the length of the string and to check for prime and return true if the length is a prime number otherwise return false
void display(): to display the palprime word(s) from the sentence by invoking isPalin() and primelen()
Specify the class Palprime giving details of the constructor(), void input(), boolean isPalin(String), boolean primelen(String) and void display(). Define a main() function to create an object and call the member functions accordingly to enable the task.
  1. Class header, data member, constructor
    [1]
  2. input(): accept the sentence
    [1]
  3. isPalin(): compare characters from both ends
    [2]
  4. primelen(): length, prime test (length 1 is not prime)
    [2]
  5. display(): split into words (StringTokenizer or charAt scan)
    [2]
  6. display(): invoking isPalin() and primelen() and printing the qualifying words
    [1]
  7. main(): object created and methods called
    [1]
  8. import java.util.*;
class Palprime
{
    String line;

    Palprime()
    {
        line = "";
    }

    void input()
    {
        Scanner sc = new Scanner(System.in);
        System.out.println("Enter a sentence in UPPER CASE : ");
        line = sc.nextLine();
    }

    boolean isPalin(String n)                // palindrome word ?
    {
        int i = 0, j = n.length() - 1;
        while (i < j)
        {
            if (n.charAt(i) != n.charAt(j))
                return false;
            i++;
            j--;
        }
        return true;
    }

    boolean primelen(String n)               // is the length a prime number ?
    {
        int len = n.length();
        if (len < 2)
            return false;
        for (int d = 2; d * d <= len; d++)
            if (len % d == 0)
                return false;
        return true;
    }

    void display()
    {
        StringTokenizer st = new StringTokenizer(line);
        boolean first = true;
        while (st.hasMoreTokens())
        {
            String w = st.nextToken();
            if (isPalin(w) && primelen(w))
            {
                if (!first)
                    System.out.print(", ");
