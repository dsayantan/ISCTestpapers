Question 2(iv) · Board 2025[3]
The following function duck() checks whether a given number is a duck number (the digit zero is present in it). Places marked ?1?, ?2?, ?3? may be replaced by a statement / expression so that the function works properly.
boolean duck(int a)
{   int f = -1;
    if (a == 0)
        return true;
    for (int i = a; i != 0; ?1?)
    {   int c = i % 10;
        if (c == ?2?)
        {   f = 1; break; }
    }
    return (f == ?3?) ? false : true;
}
(a) ?1? [1]   (b) ?2? [1]   (c) ?3? [1]
  1. (a) The loop peels digits off the number: after a digit has been tested it is removed, so ?1? is i = i / 10 (i /= 10).
    [1]
  2. (b) The digit is a duck digit if it is zero, so ?2? is 0.
    [1]
  3. (c) f stays −1 when no zero was found, and then the function must return false: (f == -1) ? false : true. So ?3? is -1.
    [1]
boolean duck(int a)
{
    int f = -1;
    if (a == 0)
        return true;
    for (int i = a; i != 0; i = i / 10)
    {
        int c = i % 10;
        if (c == 0)
        {
            f = 1;
            break;
        }
    }
    return (f == -1) ? false : true;
}
Answer
?1? → i = i / 10   ?2? → 0   ?3? → -1
Marking note Completed function compiled and run: duck(1203), duck(100), duck(0) are true; duck(123), duck(5) are false.

Concepts to recall

  • Digit extraction: i % 10 gives the last digit, i / 10 removes it; the loop ends when i becomes 0.
  • A flag initialised to −1 and set to 1 when the condition is met; the final test must use the same initial value.
  • a == 0 is handled before the loop because the loop would not run for 0.

Question 2(iv) · Board 2024[3]
The following function is used to find the smallest digit present in a number. Replace ?1?, ?2?, ?3? by an expression / a statement so that the function works correctly.
int small_dig(int n)
{ int min = ?1?;
  while (n != 0)
  {
      int q = n / 10;
      int r = ?2? * 10;
      min = r > min ? ?3? : r;
      n = q;
  }
  return min;
}
(a) ?1? [1]   (b) ?2? [1]   (c) ?3? [1]
  1. (a) min must start higher than any digit, so that the first digit replaces it: ?1? = 9.
    [1]
  2. (b) q = n/10 is the number without its last digit, so the last digit is n − q×10. Substituted into int r = ?2? * 10; the text n - q gives int r = n - q * 10; and by operator precedence (* before −) this is n − (q × 10): ?2? = n - q.
    [1]
  3. (c) The statement min = r > min ? ?3? : r; must keep the smaller of r and min: if r > min keep min, else take r. ?3? = min.
    [1]
  4. Completed method (compiled and run: small_dig(5274) = 2, small_dig(3081) = 0):
    int small_dig(int n)
{ int min = 9;
  while (n != 0)
  {
      int q = n / 10;
      int r = n - q * 10;
      min = r > min ? min : r;
      n = q;
  }
  return min;
}
Answer
?1? = 9    ?2? = n − q    ?3? = min
Common slip Writing ?2? = n % 10 gives r = (n % 10) * 10 – a multiple of ten – and the function returns a wrong value.
Marking note The blank is part of the product r = ?2? * 10. The answer n − q is the one that makes the whole statement the last digit; n%10 is the digit itself, but is wrong in this position because of the trailing * 10.

Concepts to recall

  • Last digit of n: n % 10, or n − (n/10)×10 using integer division.
  • To find a minimum: start with a value larger than every possible digit (9) and replace it whenever a smaller one is met.
  • Textual substitution into ?2? * 10: the operator precedence of the pasted text matters, so n − q gives n − q*10.

Question 6 · Board 2025 Imp.[10]
A class Mighty has been defined to create m1 and m2 as mighty numbers from integers n1 and n2. m1 will become mighty by placing the eventual sum of digits of n2 at the end of n1. m2 will become mighty by placing the eventual sum of digits of n1 at the end of n2.
Example: n1 = 235, eventual sum of digits of n1 = 1; n2 = 106, eventual sum of digits of n2 = 7; then m1 = 2357, m2 = 1061.
Class name: Mighty
Data members / instance variables
n1: to store first integer
n2: to store second integer
m1: to store the first mighty number
m2: to store the second mighty number
Methods / member functions
Mighty(): constructor to initialise data members with legal initial values
void accept(): to accept values for n1 and n2
int sumofdigits(int x): to return the eventual sum of digits of x using recursive technique
void calMighty(): to calculate mighty numbers m1 and m2 by invoking sumofdigits()
void display(): to display mighty numbers m1 and m2
Specify the class Mighty giving details of the constructor(), void accept(), int sumofdigits(int), void calMighty() and void display(). Define the main() function to create an object and call the functions accordingly to enable the task.
  1. Class header, data members n1, n2, m1, m2
    [1]
  2. Constructor with legal initial values
    [1]
  3. accept(): input of n1 and n2
    [1]
  4. sumofdigits(): base case (x < 10), sum of digits, recursive call on the sum
    [3]
  5. calMighty(): m1 = n1×10 + sumofdigits(n2), m2 = n2×10 + sumofdigits(n1)
    [2]
  6. display() and main() creating the object and calling the methods
    [2]
  7. import java.util.*;
class Mighty
{
    int n1, n2, m1, m2;                      // m1, m2 : the mighty numbers

    Mighty()                                 // constructor : legal initial values
    {
        n1 = 0;  n2 = 0;  m1 = 0;  m2 = 0;
    }

    void accept()
    {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter n1 : ");
        n1 = sc.nextInt();
        System.out.print("Enter n2 : ");
        n2 = sc.nextInt();
    }

    int sumofdigits(int x)                   // eventual (single digit) sum of digits, recursive
    {
        if (x < 10)                          // already a single digit : stop
            return x;
        int s = 0;
        while (x > 0)                        // sum of the digits of x
        {
            s = s + x % 10;
            x = x / 10;
        }
        return sumofdigits(s);               // repeat on the sum
    }

    void calMighty()
    {
        m1 = n1 * 10 + sumofdigits(n2);      // place the eventual sum of n2 after n1
        m2 = n2 * 10 + sumofdigits(n1);      // place the eventual sum of n1 after n2
    }

    void display()
    {
        System.out.println("m1 = " + m1);
        System.out.println("m2 = " + m2);
    }

    public static void main(String args[])
    {
        Mighty ob = new Mighty();
        ob.accept();
        ob.calMighty();
        ob.display();
    }
}
  8. Sample run: n1 = 235, n2 = 106 gives m1 = 2357, m2 = 1061 (235 → 10 → 1; 106 → 7).
Answer
Program above; output for 235 and 106: m1 = 2357, m2 = 1061
Common slip Computing only one round of the digit sum (10 for 235) instead of repeating to a single digit.
Marking note Compiled and run with 235 & 106 (m1 2357, m2 1061), 99 & 18 and 0 & 7. Marks: 1 + 1 + 1 + 3 + 2 + 2. Any correct recursive digit-root method is accepted.

Concepts to recall

  • Eventual (digital-root) sum: keep adding the digits until one digit remains. 235 → 10 → 1.
  • Recursion = base case + a call on a smaller problem; here the base case is x < 10 and the call is on the digit sum.
  • Appending a single digit d to n: n × 10 + d.
