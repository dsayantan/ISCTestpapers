ONE-MARK QUESTIONS (1)ISC 2025 Computer Science Paper 1 (868A), Q1(v)
Question 1(v) · Board 2025[1]
Also draws on: constructor with the this keyword (Ch 9).
Consider the following code statement:
public class Person
{
    int age;
    public Person(int age)
    {
        this.age = age;
    }
}
Which of the following statements are valid for the given code?
I. The keyword this in the constructor refers to the current instance of the class.
II. The keyword this differentiates between the instance variable age and the parameter age.
III. The keyword this can be used only in constructors.
(a)Only I and II
(b)Only II and III
(c)Only I and III
(d)Only III
  1. I is true: this is a reference to the object on which the constructor is running.
    [½]
  2. II is true: this.age is the instance variable, plain age is the parameter. III is false: this may be used in any instance method, not only constructors. So only I and II.
    [½]
Answer
(a) Only I and II

Concepts to recall

  • this = reference to the current object; used to separate a field from a parameter of the same name, to call another constructor this(...) and to pass the current object.
  • It cannot be used in a static method, but it is certainly not restricted to constructors.
TEN-MARK QUESTIONS (1)ISC 2026 Computer Science Paper 1 (868A), Q6
Question 6 · Board 2026[10]
Also draws on: an object passed to and returned from a method (addTime(TimeOp)); the array holds h, m, s.
A class TimeOp adds any two accepted time periods. Example: Time A = 6 hours 35 minutes 40 seconds, Time B = 7 hours 45 minutes 30 seconds, Time A + Time B = 14 hours 21 minutes 10 seconds (60 minutes = 1 hour, 60 seconds = 1 minute).
Class name: TimeOp
Data member / instance variable
arr[ ]: integer array to hold three elements (hours, minutes and seconds)
Methods / member functions
TimeOp( ): default constructor
void readTime( ): to accept the elements of the array
TimeOp addTime(TimeOp tt): to add the time of the parameterised object tt and the current object, to store it in a local object and return it
void dispTime( ): to display the array elements in hours:minutes:seconds format
Specify the class TimeOp giving the details of the constructor( ), void readTime( ), TimeOp addTime(TimeOp) and void dispTime( ). Define the main( ) function to create objects and call the functions accordingly. [10]
  1. Class header, array declaration int arr[] (hours, minutes, seconds)
    [½]
  2. Default constructor: arr = new int[3];
    [1]
  3. readTime(): accept the three values into the array with a loop (or three statements)
    [1½]
  4. addTime(TimeOp tt): local object; seconds total arr[2]+tt.arr[2]; carry /60 into minutes; minutes carry /60 into hours; store %60 for seconds and minutes; return the object
    [3]
  5. dispTime(): print hours:minutes:seconds
    [1½]
  6. main(): create two objects, call readTime() on each, call addTime(), display the result
    [2½]
  7. Program (compiled and run: 6:35:40 + 7:45:30 gives 14:21:10; 1:59:59 + 0:0:1 gives 2:0:0):
    import java.util.*;
class TimeOp
{
    int arr[];                              // hours, minutes, seconds
    static Scanner sc = new Scanner(System.in);

    TimeOp()                                // default constructor
    {
        arr = new int[3];
    }

    void readTime()                         // accepts hours, minutes and seconds
    {
        System.out.println("Enter hours, minutes and seconds:");
        for (int i = 0; i < 3; i++)
            arr[i] = sc.nextInt();
    }

    TimeOp addTime(TimeOp tt)               // adds tt and the current object
    {
        TimeOp t = new TimeOp();            // local object to hold the sum
        int s = arr[2] + tt.arr[2];
        int m = arr[1] + tt.arr[1] + s / 60; // carry of seconds into minutes
        int h = arr[0] + tt.arr[0] + m / 60; // carry of minutes into hours
        t.arr[2] = s % 60;
        t.arr[1] = m % 60;
        t.arr[0] = h;
        return t;
    }

    void dispTime()
    {
        System.out.println(arr[0] + ":" + arr[1] + ":" + arr[2]);
    }

    public static void main(String args[])
    {
        TimeOp A = new TimeOp();
        TimeOp B = new TimeOp();
        System.out.println("Time A");
        A.readTime();
        System.out.println("Time B");
        B.readTime();
        TimeOp C = A.addTime(B);
        System.out.print("Time A + Time B = ");
        C.dispTime();
    }
}
Answer
Time A + Time B = 14:21:10 for the example (program above).
Common slip Adding without carrying (gives 13:80:70), or modifying the current object instead of storing the sum in a local object.

Concepts to recall

  • Object passed as a parameter: tt.arr is the argument object’s array, arr the current object’s; the method returns a new object.
  • Carry: total seconds / 60 goes to minutes; total seconds % 60 stays. Do the same for minutes to hours; hours need no limit (14 hours here).
  • Use a loop to read the array; give mnemonic names and comments, as the paper requires.
