TWO-MARK QUESTIONS (7)ISC 2025 Improvement Computer Science Paper 1 (868A), Q2(i)
Question 2(i) · Board 2025 Imp.[2]
Convert the following infix notation to postfix form.
(A*B^C) + (D*E)   where B^C = BC
  1. Priority: ^ (highest) > * > +. Scan left to right with a stack; operands go straight to the output, an operator is pushed after popping any operator of higher or equal priority (^ is right-associative and has nothing to pop here).
    [1]
  2. Working:
    SymbolStackOutput
    (( 
    A(A
    *(*A
    B(*AB
    ^(*^AB
    C(*^ABC
    ) ABC^*
    ++ABC^*
    (+(ABC^*
    D+(ABC^*D
    *+(*ABC^*D
    E+(*ABC^*DE
    )+ABC^*DE*
  3. Postfix = ABC^*DE*+
    [1]
Answer
A B C ^ * D E * + (ABC^*DE*+)
Common slip Writing AB*C^ (doing A*B first) ignores that ^ binds tighter than *.

Concepts to recall

  • Postfix (reverse Polish): operators come after their operands, no brackets needed.
  • Order of precedence ^ > * / > + −; ^ is evaluated right to left, + * − / left to right.
  • Shortcut check: B^C first, A*(B^C) next, D*E, then the sum → ABC^* DE* +.

Question 11(i) · Board 2025 Imp.[2]
A linked list is formed from the objects of class VotersList. The class structure is given below.
class VotersList
{
    int age;
    VotersList link;
}
Write an Algorithm OR a Method to count and return total number of nodes whose age ≥ 60. The method prototype is: int countNodes(VotersList start)
  1. Algorithm (accepted in place of the method):
    1. Set count = 0 and p = start.
    2. While p is not null: if age of p ≥ 60, increase count by 1; set p = link of p.
    3. Return count.
  2. Method (in Java):
  3. Counter initialised, traversal pointer started at start, loop until null
    [1]
  4. Condition age ≥ 60 counts the node, pointer advances, count returned
    [1]
  5. int countNodes(VotersList start)
{
    int count = 0;
    VotersList p = start;                    // temporary pointer, start is never moved
    while (p != null)                        // visit every node
    {
        if (p.age >= 60)
            count++;
        p = p.link;                          // go to the next node
    }
    return count;
}
Answer
countNodes() returns the number of nodes with age ≥ 60 by one traversal of the list
Common slip Moving start itself, or writing age > 60 (the condition includes 60).
Marking note Algorithm OR method: either earns the full 2 marks. Method run on lists of ages (72, 45, 61, 18) giving 2, an empty list giving 0 and (60, 59) giving 1.

Concepts to recall

  • Linked-list traversal: p = start; while (p != null) { ... p = p.link; }.
  • Use a temporary pointer so that start (the head) is not lost.
  • The case of an empty list: the loop does not run and 0 is returned.

Question 2(i) · Board 2025[2]
Convert the following infix notation to postfix form.
(A − B / C) + (D * E / F) * G
  1. Scan left to right with a stack. Operands go straight to the output; an operator pops operators of higher or equal precedence (× and / before + and −); a closing bracket pops to the opening bracket.
    [1]
  2. Trace:
    SymbolStackPostfix so far
    (( 
    A(A
    -(-A
    B(-AB
    /(-/AB
    C(-/ABC
    ) ABC/-
    ++ABC/-
    (+(ABC/-
    D+(ABC/-D
    *+(*ABC/-D
    E+(*ABC/-DE
    /+(/ABC/-DE*
    F+(/ABC/-DE*F
    )+ABC/-DE*F/
    *+*ABC/-DE*F/
    G+*ABC/-DE*F/G
    — ABC/-DE*F/G*+
  3. Postfix: A B C / - D E * F / G * +
    [1]
Answer
A B C / − D E * F / G * +
Common slip Writing D E F / * G * (treating E/F first) is wrong: * and / have the same precedence and associate from the left, so D*E is done before /F.
Marking note A correct postfix with the working (the stack trace) shown earns full marks; the answer alone, if correct, is also credited.

Concepts to recall

  • Precedence: ^ highest, then * / (left to right), then + −. Equal precedence operators of the left are popped first (left associativity).
  • Check by order of evaluation: B/C first, then A−(B/C); D*E, then /F, then *G; finally +.

Question 11(i) · Board 2025[2]
A linked list is formed from the objects of the class Cell. The class structure of the Cell is given below:
class Cell
{
    char m;
    Cell right;
}
Write an Algorithm OR a Method to print the sum of the ASCII values of the lower case alphabets present in the linked list. The method declaration is as follows: void lowercase(Cell str)
  1. Algorithm
  2. Step 1: Set sum = 0 and p = str (the first cell).
    [½]
  3. Step 2: Repeat steps 3 and 4 while p is not null.
    Step 3: If the character in p lies between ‘a’ and ‘z’, add its ASCII value to sum.
    Step 4: Move p to the next cell, p = p.right.
    [1]
  4. Step 5: Print sum. Stop.
    [½]
  5. Method (the alternative, full marks for either)
    void lowercase(Cell str)
{
    int sum = 0;
    Cell p = str;                      // start at the first cell
    while (p != null)                  // until the end of the list
    {
        if (p.m >= 'a' && p.m <= 'z')  // a lower case letter
            sum = sum + p.m;           // its ASCII value is added
        p = p.right;                   // move to the next cell
    }
    System.out.println("Sum of ASCII values = " + sum);
}
Answer
Sum of the ASCII values of the lower case letters in the list.
Marking note Either the algorithm or the method earns the 2 marks. Compiled and run on the list a, B, c, D (97 + 99 = 196) and on an empty list (0).

Concepts to recall

  • Traversal of a singly linked list: start at the first node and follow right until null.
  • A char can be added to an int directly, which adds its ASCII value (‘a’ = 97 … ‘z’ = 122).
  • Test c >= 'a' && c <= 'z' (or Character.isLowerCase(c)).
TWO-MARK QUESTIONS (7)ISC Specimen 2025 Computer Science Paper 1, Q2(i)
Question 2(i) · Specimen 2025[2]
Convert the following infix notation to prefix form.
(A−B)/C*(D+E)
  1. Operators / and * have equal precedence and associate left to right, so the expression is ((A−B)/C) * (D+E).
    [½]
  2. Prefix, innermost first: (A−B) → −AB; (−AB)/C → /−ABC; (D+E) → +DE.
    [1]
  3. Join with the last operator *: * /−ABC +DE.
    [½]
Answer
* / − A B C + D E (written */−ABC+DE)
Common slip Treating / and * as if * came first, giving A−B / (C*(D+E)), which changes the answer.

Concepts to recall

  • Prefix (Polish) notation puts the operator before its operands; no brackets are needed.
  • Precedence: ^ > * and / (equal, left to right) > + and −. Brackets first.
  • Method: fully bracket the expression using precedence, then move every operator in front of its two operands. Check by evaluating with sample values.
TWO-MARK QUESTIONS (7)ISC Specimen 2025 Computer Science Paper 1, Q11(i)
Question 11(i) · Specimen 2025[2]
A linked list is formed from objects of the class Node { int n; Node link; }. Write an Algorithm OR a Method to search for a number in an existing linked list. The method declaration is: void FindNode(Node str, int b)
  1. Algorithm (either the algorithm or the method earns the 2 marks):
    1. Start.
    2. Set temp = str (the first node).
    3. Repeat steps 4 and 5 while temp is not null.
    4. If n of temp equals b, display "found" and stop.
    5. Set temp = link of temp.
    6. If the loop ends (temp is null), display "not found". Stop.
    [1]
  3. Method:
    void FindNode(Node str, int b)
{
    Node temp = str;
    while (temp != null)              // visit every node, including the last
    {
        if (temp.n == b)
        {
            System.out.println(b + " is found");
            return;
        }
        temp = temp.link;
    }
    System.out.println(b + " is not found");
}
    [1]
Answer
Traverse from the first node, comparing n with b; report "found" on a match, "not found" when temp becomes null.
Common slip Looping while temp.link != null, which never inspects the last node.
Marking note CISCE's key loops while temp.link != null, so the last node is never compared (FindNode(str, 9) on 12, 7, 25, 9 would wrongly say "not found"); it also prints with prinln. The loop here tests temp != null. Compiled and run on the list 12, 7, 25, 9: 9 and 12 are found, 5 is not found, and an empty list gives "not found".

Concepts to recall

  • Linear traversal of a singly linked list: temp = temp.link until temp == null; test temp != null (not temp.link != null) so that the last node is also examined.
  • Search is O(n): a linked list gives no random access.
  • Handle the empty list: str == null makes the loop run zero times and "not found" is displayed.

Question 11(ii) · Specimen 2025[3]
Answer the following from the diagram of a binary tree: (a) Name the root of the left sub tree and its siblings. [1] (b) State the size and depth of the right sub tree. [1] (c) Write the in-order traversal of the tree. [1]
  1. (a) The root A has left child B and right child F. The left sub tree is rooted at B; its sibling (the other child of A) is F.
    [1]
  2. (b) The right sub tree is rooted at F with nodes F, C, G, H: size = 4 nodes. Longest path F → G → H has 2 edges: depth (height) = 2.
    [1]
  3. (c) In-order = Left, Root, Right. Left of A: (E, D, B); root A; right of A: C, F, then G with its right child H: G, H. Sequence: E D B A C F G H.
    [1]
Answer
(a) root B, sibling F   (b) size 4, depth 2   (c) E D B A C F G H
Common slip Reading the tree as a complete tree (C as B's child): C and G are the children of F, and H hangs from G on the right.
Marking note Depth of the right sub tree is counted in edges (F to H), giving 2, as in CISCE's key; counted in levels it would be 3.

Concepts to recall

  • Siblings are nodes with the same parent. A sub tree consists of a node and all its descendants.
  • Size = number of nodes; depth/height of a tree = number of edges on the longest root-to-leaf path (leaf-only tree = 0).
  • In-order: left → root → right; pre-order: root → left → right; post-order: left → right → root. In-order of a binary search tree is sorted.

FIVE-MARK QUESTIONS (6)ISC 2026 Computer Science Paper 1 (868A), Q9
Question 9 · Board 2026[5]
In any internet browser, a user can visit new webpages and go back to previously visited webpages. Each new webpage URL is stored in the browser’s memory such that when the user clicks ‘Back’, the previous webpage is displayed.
Class name: Browser
Data members
pages[ ]: an array to hold the URLs of visited webpages
max: to store the maximum capacity of the array
top: to point to the index of the last visited webpage
Methods
Browser(int cap): constructor to assign max = cap and top = −1
void visit(String url): to add the URL of a new webpage if possible, else display the message “Browser history full”
String back( ): to remove and return the last visited webpage URL, if present, else return the message “No previous browser history”
(i) Specify the class Browser giving details of the functions void visit(String) and String back( ). Assume that the other functions have been defined. [4] (ii) Name the entity described above and state its principle. [1]
  1. (i) visit(String url): test the overflow condition top == max-1 (history full)
    [1]
  2. otherwise increase top and store the URL: pages[++top] = url;
    [1]
  3. back(): test the underflow condition top == -1 and return the message “No previous browser history”
    [1]
  4. otherwise return the URL at top and reduce top: return pages[top--];
    [1]
  5. Program (run with capacity 2: third visit prints Browser history full; back() gives www.b.com, www.a.com, then the message):
    class Browser
{
    String pages[];                         // URLs of the visited webpages
    int max;                                // maximum capacity
    int top;                                // index of the last visited webpage

    Browser(int cap)                        // assumed already defined
    {
        max = cap;
        pages = new String[max];
        top = -1;
    }

    void visit(String url)
    {
        if (top == max - 1)                 // stack full
            System.out.println("Browser history full");
        else
            pages[++top] = url;             // push
    }

    String back()
    {
        if (top == -1)                      // stack empty
            return "No previous browser history";
        else
            return pages[top--];            // pop and return
    }
}
  6. (ii) The entity is a stack (array implementation); its principle is LIFO – Last In First Out: the most recently visited page is the first to be removed by Back.
    [1]
Answer
(ii) Stack; LIFO (Last In First Out). visit = push, back = pop.
Common slip Testing top == max (off by one) or storing the URL before incrementing top (the first URL would go to pages[−1] and throw ArrayIndexOutOfBoundsException).

Concepts to recall

  • Stack: insertion (push) and deletion (pop) at one end, the top. Overflow: top == max − 1; underflow: top == −1.
  • Push: ++top then store (top starts at −1). Pop: read pages[top] then top--.
  • Always test the full / empty condition before changing top; print or return the message the question specifies.

(ii) M N P Q T U O R S V W; level 2; sizes 5 and 5.

A circular queue is a linear data structure that allows data insertion at the rear and removal from the front, with the rear end connected to the front end forming a circular arrangement. Given below are the details of class MerryGoRound.

  4. remove(): test for empty (front == rear) and return −999
    [1]

    [1]
  6. class MerryGoRound
{
    int q[];                                 // array holding the integers
    int cap;                                 // maximum capacity of the array
    int front, rear;                         // front stays one place behind the first element

    MerryGoRound(int n)                      // already defined
    {
        cap = n;
        q = new int[cap];
        front = rear = 0;
    }

    void add(int val)
    {
        if ((rear + 1) % cap == front)       // next place of rear is front : no room
            System.out.println("QUEUE IS FULL");
        else
        {
            rear = (rear + 1) % cap;         // move rear round the circle
            q[rear] = val;
        }
    }

    int remove()
    {
        if (front == rear)                   // nothing in the queue
            return -999;
        front = (front + 1) % cap;           // move front round the circle
        return q[front];
    }

    void display()                           // already defined
    {
        int i = front;
        while (i != rear)
        {
            i = (i + 1) % cap;
            System.out.print(q[i] + " ");
        }
        System.out.println();
    }
}
  7. (ii) A queue works on the principle of FIFO – First In First Out: the element added first is removed first (insertion at the rear, deletion at the front).
    [1]
Answer
(i) add() and remove() as above, using % cap for the circular movement. (ii) FIFO (First In First Out)
Common slip Testing full as rear == cap − 1, which is the linear queue’s test and never reuses the freed cells.
Marking note Program tested by adding to capacity, removing and adding again across the wrap (display 20 30 40 50) and removing from an empty queue (−999). With this convention a queue of cap = 5 holds 4 items. An answer that keeps all cells usable by another consistent scheme is accepted.

Concepts to recall

  • Circular queue: after the last index the pointers wrap to index 0 using (index + 1) % cap, so freed cells at the front are reused.
  • With front = rear = 0 for empty, keep one cell free: full when (rear + 1) % cap == front, empty when front == rear.
  • Linear queue wastes the cells before front; the circular queue does not.
