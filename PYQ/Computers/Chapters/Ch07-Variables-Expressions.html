ONE-MARK QUESTIONS (2)ISC 2026 Computer Science Paper 1 (868A), Q1(ii)
Question 1(ii) · Board 2026[1]
Also draws on: static final: a named constant (Unit 7); static also belongs to Methods (Ch 9).
Consider the following statement written in class Student where school_Name is its data member.
static final String school_Name = "Co-Ed School";
Which of the following statements are valid for school_Name?
I. All objects of class Student share the same value of school_Name.
II. The value of school_Name cannot be changed during program execution.
III. The keywords static and final cannot be used together for a variable.
(a)Only I and II
(b)Only II and III
(c)Only I and III
(d)Only II
  1. static: one copy belongs to the class and is shared by every object, so I is true.
    [½]
  2. final: the value is assigned once and cannot be changed, so II is true. A variable may be declared static final (that is how constants are written), so III is false. Hence only I and II.
    [½]
Answer
(a) Only I and II

Concepts to recall

  • static = class-level, shared by all objects. final = constant, cannot be reassigned.
  • static final together is the standard way to declare a constant, e.g. static final double PI = 3.14;.

Question 1(viii) · Specimen 2025[1]
Also draws on: static final: a named constant (Unit 7); static also belongs to Methods (Ch 9).
In class Circle, static final double pi = 3.142; Which of the following statements are valid for pi?
I. It contains a common value for all objects of class Circle.
II. Its value is non-changeable.
III. At a time two access modifiers, static and final, cannot be applied to a single data member pi.
(a)I and II
(b)II and III
(c)I and III
(d)Only III
  1. static makes one copy shared by every object of the class: I is true.
    [½]
  2. final forbids reassignment, so II is true. static and final are non-access modifiers and can be combined (public static final is the usual form), so III is false. Answer: I and II.
    [½]
Answer
(a) I and II

Concepts to recall

  • static: one copy per class; final: a constant (assigned once). static final together declare a class constant, e.g. Math.PI.
  • Only public, protected and private are access specifiers; a data member may carry one of them together with several modifiers.
