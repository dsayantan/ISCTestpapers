What to revise

  • Question 5(i) is almost always a circuit: a decoder (3:8, or binary numbers to hexadecimal digits), an encoder (octal to binary) or a multiplexer derived from a decoder, for 5 marks with an application.
  • Gate diagrams: derive the expression at every labelled node, reduce it with Boolean laws, then name the gate it equals (2025 Q4(ii), 2025 Improvement Q4(ii) and Q5(ii), specimen 2025 Q4(ii)); a two-input gate image with a short output question recurs.
  • Universal gates: OR from NAND (board 2024), AND from NOR (board 2026) – show the expression at each step.
  • Adders: full adder from two half adders (board 2026), and the gate count of a full adder (specimen 2025 Q1(x)): sum = A XOR B XOR C, carry = AB + C(A XOR B).

ONE-MARK QUESTIONS (2)ISC Specimen 2025 Computer Science Paper 1, Q1(x)
Question 1(x) · Specimen 2025[1]
Topic: Half and full adders (Unit 2b)
A full adder needs five gates: 3 AND, 1 OR and 1 XOR. When it is built from 2 half adders it also needs 5 gates. State the names, with the quantity, of those gates.
  1. A half adder is one XOR (sum) and one AND (carry). Two half adders give 2 XOR and 2 AND.
    [½]
  2. The two carries are combined by one OR gate. Total: 2 XOR + 2 AND + 1 OR = 5 gates.
    [½]
Answer
2 XOR gates, 2 AND gates and 1 OR gate.

Concepts to recall

  • Half adder: S = A ⊕ B, C = A · B. Full adder: S = A ⊕ B ⊕ Cin, Cout = AB + Cin(A ⊕ B).
  • Chaining: the sum of half adder 1 and Cin feed half adder 2; Cout = carry1 + carry2.
ONE-MARK QUESTIONS (2)ISC 2024 Computer Science Paper 1 (868A), Q1(ii)
Question 1(ii) · Board 2024[1]
Topic: Logic gates and universal gates (Unit 2a-b)
When a sequence of OR, NOT, NOR are connected in series, the logic gate obtained is:
(a)AND
(b)NOT
(c)OR
(d)XOR
  1. Follow one signal down the chain: OR gives A + B; the NOT gives (A + B)′.
    [½]
  2. A NOR gate whose inputs are joined is an inverter, so it gives ((A + B)′)′ = A + B, which is an OR gate.
    [½]
Answer
(c) OR
Marking note The wording is loose; the reading used is a single signal passing through the three gates in order (the NOR acting as an inverter). Every other reading gives no better-defined gate, and OR is the only option the chain can produce.

Concepts to recall

  • NOR = OR followed by NOT; NOR with its inputs tied = NOT.
  • Two inversions in series cancel: NOT of NOT is the original signal.

Question 5(ii) · Board 2025 Imp.[3]
Topic: Logic gates and universal gates (Unit 2a-b)
Also draws on: the derived expression is reduced with Boolean laws (Ch 1).
From the logic gate diagram given below, derive the Boolean expression for X(A, B, C) and reduce it using Boolean laws.
  1. Output of the three OR gates: P = A•B + A,   Q = B + B•C,   R = C + A•B. X = P • Q • R = (A•B + A) • (B + B•C) • (C + A•B).
    [1½]
  2. P = A(B + 1) = A (absorption),   Q = B(1 + C) = B (absorption).
    [½]
  3. X = A • B • (C + A•B) = ABC + A•A•B•B = ABC + AB = AB(C + 1) = A•B.
    [1]
Answer
X = (A•B + A) • (B + B•C) • (C + A•B) = A • B
Marking note The gate connections were read at 250 dpi: first AND takes A, B; second takes B, C; third takes A, B. Any correct sequence of Boolean laws reaching AB earns the reduction mark. Truth-table check: X = 1 exactly when A = B = 1.

Concepts to recall

  • Absorption laws: A + A•B = A and A•(A + B) = A; also A + 1 = 1.
  • Idempotent law: A•A = A; B•B = B.
  • Read the diagram gate by gate; here every first-level OR takes an input straight from A, B or C and the other from an AND gate.

Draw the logic gate diagram for 2-input OR gate using NAND gates only. Show the expression at each step.
  1. A NAND gate with both inputs joined is a NOT gate: A NAND A = (A·A)′ = A′.
    [1]
  2. Likewise B NAND B = B′.
    [1]

Draw the logic gate diagram for an octal to binary encoder. State how multiplexer can be derived from a decoder. Mention one application of multiplexer.
  1. Octal to binary encoder (8 input lines D0…D7, one active at a time; 3 output lines Y2 Y1 Y0). Output = binary code of the active line:
    Active inputY2Y1Y0
    D0000
    D1001
    D2010
    D3011

    Y2 = D4 + D5 + D6 + D7;   Y1 = D2 + D3 + D6 + D7;   Y0 = D1 + D3 + D5 + D7.
    [1½]
  2. Diagram: three 4-input OR gates, one for each output (D0 is not wired because 000 is the output when no other line is active).
    [1½]
  3. Multiplexer from a decoder: connect the select lines to the inputs of an n to 2n decoder; each decoder output is 1 for exactly one select combination. AND each decoder output with its data line (Di • Ii) and OR all the products to get the single output Y. (A 2 to 4 decoder gives a 4 to 1 multiplexer.)
    [1½]
  4. Application of a multiplexer (any one): selecting one of many data lines on a single channel / data routing (e.g. time-division multiplexing in telephone networks), parallel-to-serial conversion, or implementing a Boolean function.
    [½]
Answer
Y2 = D4+D5+D6+D7, Y1 = D2+D3+D6+D7, Y0 = D1+D3+D5+D7 (three 4-input OR gates). A decoder + AND gates + one OR gate = multiplexer. Use: data selection / routing.
Marking note Marks: expressions/table 1½, diagram 1½, decoder-to-multiplexer explanation 1½, application ½. An 8-input priority encoder diagram is not asked for.

  • Encoder: 2n input lines → n output lines (binary code of the active line); decoder does the opposite.
  • Decoder output for select value i is the minterm mi of the select lines; Y = Σ mi•Ii is exactly the multiplexer equation.
  • Multiplexer: many inputs, one output, select lines choose which; demultiplexer is the reverse.

Question 5(i) · Board 2025[5]
Topic: Decoders, encoders, multiplexers (Unit 2b)
What is an encoder? Draw the logic gate diagram for an octal to binary encoder. State one application of a decoder.
  1. An encoder is a combinational circuit with 2n input lines and n output lines that converts the active input line into its n-bit binary code. (Octal-to-binary: 8 inputs D0–D7, 3 outputs A2 A1 A0; only one input is high at a time.)
    [1]
  2. Output equations: A2 = D4 + D5 + D6 + D7; A1 = D2 + D3 + D6 + D7; A0 = D1 + D3 + D5 + D7 (D0 needs no gate: all outputs 0).
    [1½]
  3. Logic diagram: three 4-input OR gates.
    [1½]
  4. Application of a decoder: memory address decoding (selecting one memory chip/location from its binary address); also driving a 7-segment display (BCD to seven-segment decoder).
    [1]
Answer
Encoder: 2n lines → n-bit code; octal-to-binary encoder = three 4-input OR gates (A2, A1, A0 as above). Decoder application: memory address decoding.
Marking note D0 is not connected to any OR gate; some keys show an extra OR input line for it with no effect.

Concepts to recall

  • Encoder: many inputs → binary code (n outputs for 2n inputs). Decoder: the reverse, an n-bit code selects one of 2n output lines (uses AND gates).
  • Each output bit is the OR of the inputs whose index has that bit set to 1.
  • Other decoder uses: demultiplexing, instruction decoding in a CPU, BCD-to-7-segment drivers.

FIVE-MARK QUESTIONS (7)ISC 2024 Computer Science Paper 1 (868A), Q5(i)
Question 5(i) · Board 2024[5]
Topic: Decoders, encoders, multiplexers (Unit 2b)
How is a decoder different from a multiplexer? Draw the logic circuit for 3:8 decoder (Octal decoder). Which multiplexer can be derived from the Octal decoder?
  1. Difference. A decoder has n input lines and 2n output lines and activates exactly one output for each input code (no select lines, no data inputs). A multiplexer has 2n data inputs, n select lines and a single output; it passes the selected data input to the output.
    [1]
  2. 3:8 decoder. Inputs A, B, C with their complements; eight 3-input AND gates, one per minterm: D0 = A′B′C′ … D7 = ABC (circuit shown).
    [3]
  3. Multiplexer derived: an 8:1 multiplexer: AND each decoder output (minterm mk) with its data input Dk and OR the eight results, Y = Σ Dk · mk; the decoder inputs serve as the select lines.
    [1]
Answer
Octal (3:8) decoder circuit as drawn; an 8:1 multiplexer can be derived from it.

Concepts to recall

  • Decoder: n inputs → 2n outputs, one-hot; built from AND gates (one per minterm) and NOT gates. Encoder is the reverse.
  • Multiplexer: many inputs → one output, chosen by select lines. A decoder + AND + OR = multiplexer.
  • Draw one NOT per input and a separate true/complement line for each input, so every AND gate is wired to exactly the right lines.

  2. (b) Hexadecimal digits: 0011 = 3, 0100 = 4, 0101 = 5, 0111 = 7, 1011 = B, 1110 = E. Four inputs A B C D (A the MSB) and their complements A′ B′ C′ D′ (through NOT gates) are available.

    [1]

    [1]
  6. (ii) Proof of [(a⇒b)·(b⇒c)] ⇒ (a⇒c)

    [1]

    [1]
  9. = a′ + b′ + 1 = 1 (null law). The expression is always 1, i.e. a tautology, so the Chain rule is proved.
    [1]
  10. (iii) With P = 0, Q = 1, R = 0, S = 0:
  11. (a) Maxterm (a sum in which each variable appears complemented if its value is 1): P + Q′ + R + S (= M4, the only row where this sum is 0)

    [1]

(iii) Maxterm = P + Q′ + R + S; Minterm = P′·Q·R′·S′.  (ii) Expression reduces to 1, so the rule is proved.

Concepts to recall

  • Decoder: n inputs, 2n outputs, one active at a time; each output is an AND (minterm) of the true/complemented inputs. Encoder is the reverse.
  • Multiplexer: many inputs, one output, chosen by select lines (2n data lines need n select lines).

Concepts to recall
