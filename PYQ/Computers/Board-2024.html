PART I (20 marks)ISC 2024 Computer Science Paper 1 (868A), Q1(i)
Question 1(i)[1]
According to the Principle of duality, the Boolean equation (A + B′) · (A + 1) = A + B′ will be equivalent to:
(a)(A′+B)·(A′+1)=A′+B
(b)(A·B′)+(A·0)=A·B′
(c)(A′·B)+(A′·1)=A′·B
(d)(A′·B)+(A′·0)=A′·B
  1. Duality: interchange every + with · and every 0 with 1; variables and their complements are left exactly as they are.
    [½]
  2. Dual of (A + B′) · (A + 1) = A + B′ is (A · B′) + (A · 0) = A · B′, which is option (b).
    [½]
Answer
(b) (A·B′)+(A·0)=A·B′
Common slip Complementing the variables as well as swapping the operators gives the complement of the equation, not its dual.

Concepts to recall

  • Principle of duality: replace + by ·, · by +, 0 by 1, 1 by 0. Do not complement the variables.
  • Options (a), (c), (d) all complement A or B: that is a different operation (complementing), the usual trap.
PART I (20 marks)ISC 2024 Computer Science Paper 1 (868A), Q1(ii)
Question 1(ii)[1]
When a sequence of OR, NOT, NOR are connected in series, the logic gate obtained is:
(a)AND
(b)NOT
(c)OR
(d)XOR
  1. Follow one signal down the chain: OR gives A + B; the NOT gives (A + B)′.
    [½]
  2. A NOR gate whose inputs are joined is an inverter, so it gives ((A + B)′)′ = A + B, which is an OR gate.
    [½]
Answer
(c) OR
Marking note The wording is loose; the reading used is a single signal passing through the three gates in order (the NOR acting as an inverter). Every other reading gives no better-defined gate, and OR is the only option the chain can produce.

Concepts to recall

  • NOR = OR followed by NOT; NOR with its inputs tied = NOT.
  • Two inversions in series cancel: NOT of NOT is the original signal.

PART I (20 marks)ISC 2024 Computer Science Paper 1 (868A), Q1(iv)
Question 1(iv)[1]
Assertion: For proposition ~A => B, its contrapositive is B => ~A.
Reason: Contrapositive is the converse of inverse for any proposition.
(a)Both Assertion and Reason are true, and Reason is the correct explanation for the Assertion.
(b)Both Assertion and Reason are true, but Reason is not the correct explanation for the Assertion.
(c)Assertion is true but Reason is false.
(d)Assertion is false but Reason is true.
  1. For p => q the contrapositive is ~q => ~p. Here p = ~A, q = B, so the contrapositive is ~B => A (since ~~A = A). B => ~A is the converse, so the Assertion is false.
    [½]
  2. Inverse of p => q is ~p => ~q; its converse is ~q => ~p, the contrapositive. So the Reason is true. Answer: Assertion false, Reason true.
    [½]
Answer
(d) Assertion is false but Reason is true.

Concepts to recall

  • For p => q: converse q => p; inverse ~p => ~q; contrapositive ~q => ~p (equivalent to the original).
  • Contrapositive = converse of the inverse = inverse of the converse.
  • Assertion–reason: judge each statement separately first.
PART I (20 marks)ISC 2024 Computer Science Paper 1 (868A), Q1(v)
Question 1(v)[1]
The complement of the Boolean expression (P′ · Q) + (R · S′) is:
(a)(P′+Q)·(R′+S)
(b)(P+Q′)·(R′+S)
(c)(P′+Q)·(R+S′)
(d)(P+Q′)·(R+S′)
  1. De Morgan: [(P′Q) + (RS′)]′ = (P′Q)′ · (RS′)′.
    [½]
  2. (P′Q)′ = P + Q′ and (RS′)′ = R′ + S, so the complement is (P + Q′) · (R′ + S).
    [½]
Answer
(b) (P+Q′)·(R′+S)

Concepts to recall

  • De Morgan: (X + Y)′ = X′Y′, (XY)′ = X′ + Y′. Complement every literal, swap + and ·.
  • Keep the grouping: the complement of a sum of products is a product of sums.
PART I (20 marks)ISC 2024 Computer Science Paper 1 (868A), Q1(vi)
Question 1(vi)[1]
Assertion: Recursive data structure follows the LIFO principle.
Reason: Execution of recursive code follows the concepts of data structure Queue.
(a)Both Assertion and Reason are true, and Reason is the correct explanation for the Assertion.
(b)Both Assertion and Reason are true, but Reason is not the correct explanation for the Assertion.
(c)Assertion is true but Reason is false.
(d)Assertion is false but Reason is true.
  1. Assertion: recursion unwinds in last-in-first-out order (the last call made returns first), so the Assertion is true.
    [½]
  2. Reason: the run-time stack of calls (a Stack, not a Queue) holds the pending calls, so the Reason is false. Answer (c).
    [½]
Answer
(c) Assertion is true but Reason is false.
Marking note “Recursive data structure” is loosely worded; it is read as the recursion/call-stack behaviour, which is what the Reason refers to.

Concepts to recall

  • Each recursive call is pushed on the call stack and popped when it returns: LIFO.
  • A Queue is FIFO, which is the opposite behaviour.

Write the cardinal form of the maxterm X + Y′ + Z.
  1. A maxterm is 0 for exactly one row: X + Y′ + Z = 0 when X = 0, Y = 1, Z = 0, i.e. 010 = 2.
    [½]
  2. Cardinal form: M2 (maxterm number 2).
    [½]

M2

State any one difference between instance variable and class variable.
  1. Instance variable: a separate copy for every object, created when an object is created. Class (static) variable: a single copy shared by all objects of the class, declared with static.
    [1]
Answer

Convert the following infix notation to postfix form.

  1. Scan left to right. Operands go straight to the output; an operator waits on the stack until an operator of lower or equal priority (or a closing bracket) arrives. * and / have the same priority and are taken left to right, so / is applied before the last *.
    [1]

PART I (20 marks)ISC 2024 Computer Science Paper 1 (868A), Q2(ii)
Question 2(ii)[2]
An array ARR [ −5 …… 15, 10 …… 20 ] stores elements in Row Major Wise with each element requiring 2 bytes of storage. Find the address of ARR [10] [15] when the base address is 2500.
  1. Rows = 15 − (−5) + 1 = 21; columns n = 20 − 10 + 1 = 11. Row major: Address of A[i][j] = B + w [ (i − Lr) × n + (j − Lc) ]
    [1]
  2. = 2500 + 2 [ (10 − (−5)) × 11 + (15 − 10) ]
    [½]
  3. = 2500 + 2 [ 15 × 11 + 5 ] = 2500 + 2 × 170 = 2840
    [½]
Answer
Address of ARR[10][15] = 2840
Common slip Using n = 20 − 10 = 10 columns (forgetting the +1), or taking 10 − 5 = 5 for the row offset.
Marking note The base address is that of the first element ARR[−5][10] (no other cell is quoted).

Concepts to recall

  • Row major: Address = B + w[(i − Lr) × Nc + (j − Lc)], where Nc = number of columns = Uc − Lc + 1.
  • Column major: B + w[(j − Lc) × Nr + (i − Lr)].
  • With a negative lower bound, i − Lr = 10 − (−5) = 15: subtracting a negative adds.

The following function is a part of some class:

{

Question 2(iv)[3]
The following function is used to find the smallest digit present in a number. Replace ?1?, ?2?, ?3? by an expression / a statement so that the function works correctly.
int small_dig(int n)
{ int min = ?1?;
  while (n != 0)
  {
      int q = n / 10;
      int r = ?2? * 10;
      min = r > min ? ?3? : r;
      n = q;
  }
  return min;
}
(a) ?1? [1]   (b) ?2? [1]   (c) ?3? [1]
  1. (a) min must start higher than any digit, so that the first digit replaces it: ?1? = 9.
    [1]
  2. (b) q = n/10 is the number without its last digit, so the last digit is n − q×10. Substituted into int r = ?2? * 10; the text n - q gives int r = n - q * 10; and by operator precedence (* before −) this is n − (q × 10): ?2? = n - q.
    [1]
  3. (c) The statement min = r > min ? ?3? : r; must keep the smaller of r and min: if r > min keep min, else take r. ?3? = min.
    [1]
  4. Completed method (compiled and run: small_dig(5274) = 2, small_dig(3081) = 0):
    int small_dig(int n)
{ int min = 9;
  while (n != 0)
  {
      int q = n / 10;
      int r = n - q * 10;
      min = r > min ? min : r;
      n = q;
  }
  return min;
}
Answer
?1? = 9    ?2? = n − q    ?3? = min
Common slip Writing ?2? = n % 10 gives r = (n % 10) * 10 – a multiple of ten – and the function returns a wrong value.
Marking note The blank is part of the product r = ?2? * 10. The answer n − q is the one that makes the whole statement the last digit; n%10 is the digit itself, but is wrong in this position because of the trailing * 10.

Concepts to recall

  • Last digit of n: n % 10, or n − (n/10)×10 using integer division.
  • To find a minimum: start with a value larger than every possible digit (9) and replace it whenever a smaller one is met.
  • Textual substitution into ?2? * 10: the operator precedence of the pasted text matters, so n − q gives n − q*10.

(a) Reduce the Boolean function F (A, B, C, D) = π (0, 2, 4, 6, 8, 9, 10, 11, 14) by using a 4-variable Karnaugh map, showing the various groups (i.e. octal, quads and pairs). [4]
(b) Draw the logic gate diagram for the reduced expression. Assume that the variables and their complements are available as inputs. [1]
  1. π means a product of maxterms: put 0 in cells 0, 2, 4, 6, 8, 9, 10, 11, 14 and 1 in the rest. Each 0-cell is a maxterm, so the heading of a cell uses sums.
    [1]
  2. Groups of 0s: no octet; three quads – M0,M2,M4,M6 = (A + D); M2,M6,M10,M14 = (C′ + D); M8,M9,M10,M11 = (A′ + B). In a POS group a variable that is 0 appears plain, 1 appears complemented.

    [1]
  4. (b) Three 2-input OR gates feeding one 3-input AND gate (diagram).
    [1]
Answer
F = (A + D)(C′ + D)(A′ + B)

SECTION A (any two of Q3–Q5, 10 marks each)ISC 2024 Computer Science Paper 1 (868A), Q4(iii)
Question 4(iii)[2]
Find the complement of the following expression and reduce it by using Boolean laws.
P · (P + Q) · Q · (Q + R′)
  1. Complement by De Morgan: [P(P + Q)Q(Q + R′)]′ = P′ + (P + Q)′ + Q′ + (Q + R′)′ = P′ + P′Q′ + Q′ + Q′R
    [1]
  2. Absorption: P′ + P′Q′ = P′ and Q′ + Q′R = Q′, so the result is P′ + Q′.
    [1]
Answer
P′ + Q′
Marking note Reducing first (P(P+Q) = P, Q(Q+R′) = Q, so the expression is PQ) and then complementing to P′ + Q′ is equally acceptable.

  • Absorption: X + XY = X and X(X + Y) = X.
  • Check: the original reduces to PQ by absorption, whose complement is P′ + Q′.
SECTION A (any two of Q3–Q5, 10 marks each)ISC 2024 Computer Science Paper 1 (868A), Q5(i)
Question 5(i)[5]
How is a decoder different from a multiplexer? Draw the logic circuit for 3:8 decoder (Octal decoder). Which multiplexer can be derived from the Octal decoder?
  1. Difference. A decoder has n input lines and 2n output lines and activates exactly one output for each input code (no select lines, no data inputs). A multiplexer has 2n data inputs, n select lines and a single output; it passes the selected data input to the output.
    [1]
  2. 3:8 decoder. Inputs A, B, C with their complements; eight 3-input AND gates, one per minterm: D0 = A′B′C′ … D7 = ABC (circuit shown).
    [3]
  3. Multiplexer derived: an 8:1 multiplexer: AND each decoder output (minterm mk) with its data input Dk and OR the eight results, Y = Σ Dk · mk; the decoder inputs serve as the select lines.
    [1]
Answer
Octal (3:8) decoder circuit as drawn; an 8:1 multiplexer can be derived from it.

Concepts to recall

  • Decoder: n inputs → 2n outputs, one-hot; built from AND gates (one per minterm) and NOT gates. Encoder is the reverse.
  • Multiplexer: many inputs → one output, chosen by select lines. A decoder + AND + OR = multiplexer.
  • Draw one NOT per input and a separate true/complement line for each input, so every AND gate is wired to exactly the right lines.

Draw the logic gate diagram for 2-input OR gate using NAND gates only. Show the expression at each step.
