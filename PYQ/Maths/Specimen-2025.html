About this deck

The paper is the CISCE Specimen Question Paper 2025 for ISC Mathematics (the old paper pattern, 80 marks), read from the page images, with CISCE’s own printed answer key. Every question is covered: Question 1 and the sub-parts of Questions 15 and 19 get a slide each, and an OR alternative sits on its own question’s slide. The paper is 80 marks: Section A (65) plus either Section B (Vectors and 3-D Geometry, 15) or Section C (Regression, applications of calculus in commerce, and Linear Programming, 15), so the slides here carry 95 marks in all and a candidate attempts 80 of them (the same convention as the 2024–2026 board decks). The solutions follow CISCE’s key and expand it into marked steps, but the key is thin and in places wrong: it never evaluates Q10(ii)(a) and (c), splits Q15 and Q17’s answer lines oddly, and the following are corrected on their slides: Q1(iv) (degree is 3, so the Assertion is true), Q1(ix) (the logically correct option is (b)), Q1(xi) (misprinted conditional), Q4 (the key answers a different question), Q9(i) (17/15 m/s, not 17/8), Q10(ii)(b) (0·195, not 0·39), Q15(iii) (the option “±3” should be ±√3) and Q21(ii) (the two regression coefficients are interchanged). This specimen has the old Section B / Section C choice and linear regression, which have since been dropped from the ISC 2027 syllabus; every question is solved as set.

SECTION A – 65 MARKSCISCE Specimen 2025 Mathematics, Q1(i)
Question 1(i)[1]
A matrix which is both symmetric and skew symmetric matrix is a / an:
(a)triangular matrix
(b)identity matrix
(c)diagonal matrix
(d)null matrix
  1. Symmetric: A′ = A. Skew symmetric: A′ = −A. Both together give A = −A, so 2A = O.
    [½]
  2. Hence A = O, every entry is zero: the matrix is a null (zero) matrix.
    [½]
Answer
(d) null matrix
Common slip Choosing “diagonal”: a diagonal matrix is symmetric, but diag(1, 2) is not skew symmetric.

Concepts to recall

  • Symmetric: aij = aji; skew symmetric: aij = −aji, so every diagonal entry of a skew matrix is 0.
  • A zero matrix is the only matrix that is both; the identity is symmetric but not skew.

Question 1(iii)[1]
The trigonometric equation tan−1 x = 3 tan−1 a has solution for
(a)|a| ≤ 1√3
(b)|a| > 1√3
(c)|a| < 1√3

SECTION A – 65 MARKSCISCE Specimen 2025 Mathematics, Q1(iv)
Question 1(iv)[1]
Assertion: Degree of the differential equation a(dy/dx)2 + b(dx/dy) = c is 3.
Reason: If each term involving derivatives of a differential equation is a polynomial (or can be expressed as a polynomial) then the highest exponent of the highest order derivative is called the degree of the differential equation.
(a)Both Assertion and Reason are true and Reason is the correct explanation for Assertion.
(b)Both Assertion and Reason are true but Reason is not the correct explanation for Assertion.
(c)Assertion is true and Reason is false.
(d)Assertion is false and Reason is true.
  1. dx/dy = 1/(dy/dx), so the equation can be expressed as a polynomial in y′ : multiply by y′ = dy/dx to get a(y′)3 + b = cy′.
    [½]
  2. Highest order derivative is y′ (order 1) with highest exponent 3: degree = 3, so the Assertion is true. The Reason is exactly the definition used to reach it: Reason true and explains the Assertion.
    [½]
Answer
(a) Both Assertion and Reason are true and Reason is the correct explanation for Assertion.
Common slip Saying the equation “has dx/dy so the degree is not defined”.
Marking note CISCE’s printed key gives (d) “Assertion false”. That cannot be right: after multiplying by dy/dx the equation is a(y′)3 + b = cy′, order 1 degree 3, exactly as the Assertion says. (a) is the answer worked out here; if the examiner’s key is followed, (d) is what it prints.

Concepts to recall

  • Degree = power of the highest order derivative once the equation is a polynomial in the derivatives (clear fractions and radicals first).
  • dx/dy = 1/(dy/dx): an inverse derivative is not an obstacle, it is cleared by multiplying through.

Question 1(v)[1]
Five numbers x1, x2, x3, x4, x5 are randomly selected from the numbers 1, 2, 3, …, 18 and are arranged in the increasing order such that x1 < x2 < x3 < x4 < x5. What is the probability that x2 = 7 and x4 = 11?
(a)2651
(b)3104
(c)168
(d)134
  1. Total ways to choose the 5 numbers: 18C5 = 8568.
    [½]
  2. Favourable: x1 from {1, …, 6} (6 ways), x3 from {8, 9, 10} (3 ways), x5 from {12, …, 18} (7 ways): 6 × 3 × 7 = 126. Probability = 126/8568 = 1/68.
    [½]
Answer
(c) 168

Concepts to recall

  • A random 5-subset in increasing order is just a combination: total = nCr.
  • Fixing x2 and x4 forces where the other three must lie: one below 7, one between 7 and 11, one above 11.

Question 1(vi)[1]
If abcmnpxyz = k, then what is the value of 6a2b2c3mnp3xyz ?
(a)k6
(b)2k
(c)3k
(d)6k
  1. Take the common factor 3 out of the first column (6a, 3m, 3x): the determinant becomes 3 × the one with first row (2a, 2b, 2c) and rows 2, 3 = (m, n, p), (x, y, z).
    [½]
  2. Take 2 out of the first row: 3 × 2 × |a b c; m n p; x y z| = 6k.

(d) 6k

Question 1(vii)[1]
Consider the graph y = x1/3.
Statement 1: The above graph is continuous at x = 0.
Statement 2: The above graph is differentiable at x = 0.
(a)Statement 1 is true, and Statement 2 is false.
(b)Statement 2 is true, and Statement 1 is false.
(c)Both the statements are true.
(d)Both the statements are false.
  1. Continuity: limx→0 x1/3 = 0 = f(0). The graph is unbroken at the origin: Statement 1 is true.
    [½]
  2. Derivative: [f(h) − f(0)]/h = h−2/3 → ∞ as h → 0. The tangent at O is vertical, so f is not differentiable: Statement 2 is false.
    [½]
Answer
(a) Statement 1 is true, and Statement 2 is false.

Concepts to recall

  • Differentiable ⇒ continuous, but not conversely. A vertical tangent (slope infinite) means no derivative.
  • Check the graph: it crosses the origin steeply, tangent along the y-axis.

SECTION A – 65 MARKSCISCE Specimen 2025 Mathematics, Q1(ix)
Question 1(ix)[1]
Statement 1: The intersection of two equivalence relations is always an equivalence relation.
Statement 2: The union of two equivalence relations is always an equivalence relation.
Which one of the following is correct?
(a)Statement 1 implies Statement 2.
(b)Statement 2 implies Statement 1.
(c)Statement 1 is true only if Statement 2 is true.
(d)Statement 1 and 2 are independent of each other.
  1. Statement 1 is true: R ∩ S is reflexive (it contains every (a, a)), symmetric and transitive because R and S both are.
    [½]
  2. Statement 2 is false: with R = {(1,1),(2,2),(3,3),(1,2),(2,1)} and S = {(1,1),(2,2),(3,3),(2,3),(3,2)}, R ∪ S has (1,2), (2,3) but not (1,3): not transitive. Statement 1 is true while Statement 2 is false, so “Statement 2 implies Statement 1” holds (a false statement implies anything) and the other implications fail.
    [½]
Answer
(b) Statement 2 implies Statement 1.
Common slip Choosing (c): “Statement 1 true only if Statement 2 true” would make Statement 1 depend on a false statement.
Marking note CISCE’s printed key is (c). By the logic above, Statement 1 is true while Statement 2 is false, so (c) (S1 ⇒ S2) is false; (b) is the logically correct option and is the answer worked here. The key’s (c) is flagged as an error in the specimen key. (Option (d), “independent”, is also arguable for two statements with fixed truth values, so the item is ambiguous; (b) is the one the logic of the options supports.)

Concepts to recall

  • Intersection of equivalence relations is an equivalence relation; the union need not be transitive.
  • p ⇒ q is false only when p is true and q is false: true ⇒ false (option a, c) fails; false ⇒ true (option b) holds.

SECTION A – 65 MARKSCISCE Specimen 2025 Mathematics, Q1(xi)
Question 1(xi)[1]
Given two events A and B such that (A/B) = 0·25 and P(A ∩ B) = 0·12. The value of P(A ∩ B′) is:
(a)0·36
(b)0·48
(c)0·88
(d)0·036
  1. P(A ∩ B′) = P(A) − P(A ∩ B). The conditional probability fixes P(A): P(B/A) = P(A ∩ B)/P(A) ⇒ P(A) = 0·12/0·25 = 0·48.
    [½]
  2. P(A ∩ B′) = 0·48 − 0·12 = 0·36.
    [½]
Answer
(a) 0·36
Marking note The paper prints the conditional as “(A/B)” with no P. Read as P(A/B) = 0·25 it gives P(B) = 0·48 but P(A ∩ B′) cannot be found, and no option matches. CISCE’s key is (a) 0·36, which follows from P(B/A) = 0·25 as worked here.

Concepts to recall

  • P(A ∩ B′) = P(A) − P(A ∩ B) (the part of A outside B).
  • P(B/A) = P(A ∩ B)/P(A); P(A/B) = P(A ∩ B)/P(B).

SECTION A – 65 MARKSCISCE Specimen 2025 Mathematics, Q1(xiii)
Question 1(xiii)[1]
If a relation R on the set {a, b, c} is defined by R = {(b, b)}, then classify the relation.
  1. Not reflexive: (a, a) and (c, c) ∉ R.
    [½]
  2. Symmetric: the only pair (b, b) is its own reverse. Transitive: no pair (x, y), (y, z) other than (b, b), (b, b) ⇒ (b, b) ∈ R.
    [½]
Answer
R is symmetric and transitive but not reflexive.

Concepts to recall

  • Reflexive: (x, x) ∈ R for every x in the set; symmetric: (x, y) ∈ R ⇒ (y, x) ∈ R; transitive: (x, y), (y, z) ∈ R ⇒ (x, z) ∈ R.
  • A relation with few pairs is often symmetric and transitive “vacuously”.

Question 1(xiv)[1]
The given function f: R → R is not ‘onto’ function. Give reason.
  1. A function is onto if every real number (every line y = k parallel to the x-axis) is the value of f for some x.
    [½]
  2. The graph has a lowest point (the minimum of the dip left of the origin); a horizontal line y = k drawn below it cuts the graph nowhere, so such a k has no pre-image: the range ≠ R.
    [½]
Answer
Range is not the whole of R: a horizontal line below the lowest point of the graph meets it nowhere, so f is not onto.

  • Onto (surjective): range = codomain. Graph test: every horizontal line must cut the graph at least once.

Question 1(xv)[1]
There are three machines and 2 of them are faulty. They are tested one by one in a random order till both the faulty machines are identified. What is the probability that only two tests are needed to identify the faulty machines?
  1. Two tests are needed exactly when the first machine tested is faulty: whatever the second result (good, or faulty), the faulty pair is then known (if the second is good, the third is faulty). If the first is good, one test is enough.
    [½]
  2. P = P(first faulty and second good) + P(first faulty and second faulty) = (2/3)(1/2) + (2/3)(1/2) = 2/3.
    [½]
Answer
2/3
Common slip Counting only “faulty, faulty” (1/3).

  • Multiplication rule: P(E1 ∩ E2) = P(E1)P(E2/E1); add the disjoint cases.
  • Identification stops when the remaining machine can be inferred.
SECTION A – 65 MARKSCISCE Specimen 2025 Mathematics, Q2
Question 2[2]
(i) If xy = yx, then find dy/dx.
OR
(ii) Find the interval in which the function f(x) = x2e−x is strictly increasing or decreasing.

Solution to the first alternative

  1. Take logs: y log x = x log y.
    [½]
  2. Differentiate both sides w.r.t. x: y·(1/x) + log x·(dy/dx) = x·(1/y)(dy/dx) + log y.
    [1]
  3. Collect: (log x − x/y) dy/dx = log y − y/x, so dy/dx = (log y − y/x)/(log x − x/y).
    [½]
Answer
dy/dx = (log y − y/x) / (log x − x/y)

Solution to the OR alternative

  1. f′(x) = 2xe−x − x2e−x = e−xx(2 − x). f′(x) = 0 at x = 0 and x = 2.
    [1]
  2. e−x > 0, so the sign is that of x(2 − x): positive for 0 < x < 2, negative for x < 0 and x > 2. Hence f is strictly increasing on (0, 2) and strictly decreasing on (−∞, 0) ∪ (2, ∞).
    [1]
Answer
Increasing on (0, 2); decreasing on (−∞, 0) ∪ (2, ∞)

Concepts to recall

  • If the variable is in both base and exponent (xy), take logarithms first: log uv = v log u.
  • Product rule on y log x and x log y; y depends on x, so d(log y)/dx = (1/y) dy/dx.
  • f′ > 0 on an interval ⇒ strictly increasing; f′ < 0 ⇒ strictly decreasing.
  • Factorise f′, mark the critical points on the number line and test the sign of each piece.
