Question 1(i)[1]
If A and B are square matrices of order 3, A is a non-singular matrix and AB = O, then the matrix B is:
(a)unit matrix
(b)scalar matrix
(c)non-singular matrix
(d)null matrix
  1. A is non-singular, so |A| ≠ 0 and A−1 exists.
    [½]
  2. Pre-multiply AB = O by A−1: A−1(AB) = A−1O ⇒ (A−1A)B = O ⇒ IB = O ⇒ B = O, the null matrix.
    [½]
Answer
(d) null matrix
Common slip Saying “AB = O means A = O or B = O”: that is false in general (two non-zero singular matrices can multiply to O).

Concepts to recall

  • A non-singular matrix has an inverse, so it can be cancelled from the left: AB = O ⇒ B = O.
  • For singular matrices AB = O does not force A = O or B = O; the non-singular hypothesis is what settles it.

Question 1(ii)[1]
If m and n are respectively the order and degree of the differential equation ddx(dydx)3 = 0, then the value of (m − n) is:
(a)0
(b)1
(c)2
(d)3
  1. Differentiate: 3(dy/dx)2·(d2y/dx2) = 0. The highest derivative is d2y/dx2, so the order m = 2.
    [½]
  2. Its power is 1 (the equation is a polynomial in the derivatives), so the degree n = 1. Hence m − n = 2 − 1 = 1.
    [½]
Answer
(b) 1
Common slip Reading the cube as the degree (n = 3) and the order as 1, which gives m − n = −2, not an option.

Concepts to recall

  • Order = order of the highest derivative; degree = power of that highest derivative once the equation is a polynomial in the derivatives.
  • The cube on (dy/dx) is a lower derivative: it does not make the degree 3. Expand the outer d/dx first.

The derivative of xy = c2 with respect to x is:

Question 1(iv)[1]
Consider Δ = |2a 2b 2c ; 2e f g ; 2i j k|.
Assertion: The value of Δ = 4 × |a b c ; e f g ; i j k|.
Reason: If all elements of one row or one column of a determinant are multiplied by a scalar k, then the value of the determinant is multiplied by k.
(a)Both Assertion and Reason are true, and Reason is the correct explanation for Assertion.
(b)Both Assertion and Reason are true, but Reason is not the correct explanation for Assertion.
(c)Assertion is true and Reason is false.
(d)Assertion is false and Reason is true.
  1. Reason: multiplying every element of one row (or one column) by k multiplies the determinant by k: a standard property, so the Reason is true.
    [½]
  2. In Δ only the first row (2a, 2b, 2c) carries the factor 2; the other rows are unchanged. So Δ = 2 × |a b c; e f g; i j k|, not 4 ×. The Assertion is false.
    [½]
Answer
(d) Assertion is false and Reason is true.
Common slip Counting a 2 against each of the three entries of the row and writing 22, 23 or 4.

Concepts to recall

  • Taking a factor out of one row gives one factor; the factor 23 = 8 arises only when every row is doubled, i.e. |2A| = 8|A| for order 3.
  • Assertion–Reason: test each statement separately first; only then ask whether the Reason explains the Assertion.

Question 1(v)[1]
Five numbers x1, x2, x3, x4, x5 are randomly selected from the numbers 1, 2, 3, …, 18 and arranged in increasing order such that x1 < x2 < x3 < x4 < x5. What is the probability that x2 = 7 and x4 = 11?
(a)26/51
(b)3/104
(c)1/68
(d)1/34
  1. Number of ways to choose 5 numbers from 18: 18C5 = 8568 (the increasing order is then forced).
    [½]
  2. x2 = 7 and x4 = 11: x1 from {1…6} (6 ways), x3 from {8, 9, 10} (3 ways), x5 from {12…18} (7 ways): 6 × 3 × 7 = 126. Probability = 126/8568 = 1/68.
    [½]
Answer
(c) 1/68

Concepts to recall

  • Choosing 5 numbers and sorting them: the sample space is a combination, 18C5, not a permutation.
  • Fixing the 2nd and 4th smallest splits the rest into three independent gaps: below 7, between 7 and 11, above 11.

Question 1(vii)[1]
Observe the following graphs (a), (b), (c) and (d), each representing a different type of function.
Statement 1: A function which is continuous at a point may not be differentiable at that point.
Statement 2: Graph (c) is an example of a function that is continuous but not differentiable at the origin.
(a)Statement 1 is true and Statement 2 is false.
(b)Statement 2 is true and Statement 1 is false.
(c)Both the statements are true.
(d)Both the statements are false.
  1. Statement 1 is true: continuity does not imply differentiability. Example: f(x) = |x| is continuous at 0, but Lf′(0) = −1 ≠ Rf′(0) = 1. Graph (a), with its sharp corner at the origin, shows exactly this.
    [½]
  2. Statement 2 is false: graph (c) is a smooth wave-like curve with no corner or break anywhere (it dips just below the origin and does not pass through it), so it is differentiable at x = 0 and cannot be an example of a function that is not differentiable there. (Graphs (b) and (d) have jumps, so they are not even continuous.)
    [½]
Answer
(a) Statement 1 is true and Statement 2 is false.
Marking note The graphs are redrawn from the question; (a) is the corner-at-the-origin graph.

Concepts to recall

  • Differentiable ⇒ continuous, but continuous ⇏ differentiable. The standard failure is a sharp corner (or cusp, or vertical tangent).
  • Reading a graph: a corner = unequal left and right slopes; a gap/jump = not continuous; a smooth unbroken curve = differentiable.

Question 1(ix)[1]
Statement 1: If a relation R on a set A satisfies R = R−1, then R is symmetric.
Statement 2: For a relation R to be symmetric, it is necessary that R = R−1.
(a)Statement 1 is true and Statement 2 is false.
(b)Statement 2 is true and Statement 1 is false.
(c)Both the statements are true.
(d)Both the statements are false.
  1. R−1 = {(b, a) : (a, b) ∈ R}. If R = R−1, then (a, b) ∈ R ⇒ (b, a) ∈ R−1 = R, which is exactly symmetry: Statement 1 is true.
    [½]
  2. Conversely, if R is symmetric then R−1 ⊆ R, and applying the same to R−1 gives R ⊆ R−1, so R = R−1 is necessary: Statement 2 is true. Both are true: R is symmetric ⇔ R = R−1.
    [½]
Answer
(c) Both the statements are true.

Concepts to recall

  • R is symmetric ⇔ R = R−1 (the inverse relation just reverses every pair).
  • “Necessary” means: symmetry cannot hold without it. “Sufficient” means: it is enough by itself. Here the condition is both.

Assertion: The equality tan(cot−1x) = cot(tan−1x) is true for all x ∈ ℝ.
Reason: The identity tan−1x + cot−1x = π/2 is true for all x ∈ ℝ.
(a)Both Assertion and Reason are true and Reason is the correct explanation for Assertion.
(b)Both Assertion and Reason are true but Reason is not the correct explanation for Assertion.
(c)Assertion is true and Reason is false.
(d)Assertion is false and Reason is true.
  1. The Reason is a standard identity valid on all of ℝ: cot−1x = π/2 − tan−1x. It is true.
    [½]
  2. Then tan(cot−1x) = tan(π/2 − tan−1x) = cot(tan−1x), using tan(π/2 − θ) = cot θ. So the Reason directly gives the Assertion: option (a).
    [½]

(a) Both Assertion and Reason are true and Reason is the correct explanation for Assertion.

Question 1(xi)[1]
Given two events A and B such that P(A | B) = 0·25 and P(A ∩ B) = 0·12. The value P(A′ ∩ B) is:
(a)0·36
(b)0·48
(c)0·88
(d)0·036
  1. P(A | B) = P(A ∩ B)/P(B) ⇒ P(B) = 0·12/0·25 = 0·48.
    [½]
  2. B splits into (A ∩ B) and (A′ ∩ B): P(A′ ∩ B) = P(B) − P(A ∩ B) = 0·48 − 0·12 = 0·36.
    [½]
Answer
(a) 0·36
Common slip Choosing 0·48, which is P(B) itself.

Concepts to recall

  • Conditional probability: P(A | B) = P(A ∩ B)/P(B).
  • P(A′ ∩ B) = P(B) − P(A ∩ B), because B = (A ∩ B) ∪ (A′ ∩ B), a disjoint union.

Question 1(xiii)[1]
If a relation R on the set {a, b, c} is defined by R = {(b, b)}, then classify the relation.
  1. Reflexive needs (a, a), (b, b) and (c, c) all in R; (a, a) and (c, c) are missing, so R is not reflexive.
    [½]
  2. (b, b) reversed is (b, b) ∈ R: symmetric. (b, b) and (b, b) give (b, b) ∈ R: transitive.
    [½]
Answer
R is symmetric and transitive but not reflexive (so it is not an equivalence relation).

Concepts to recall

  • Reflexive: (a, a) ∈ R for every element of the set. Symmetric: (a, b) ∈ R ⇒ (b, a) ∈ R. Transitive: (a, b), (b, c) ∈ R ⇒ (a, c) ∈ R.
  • Reflexivity is judged against the whole set, here three elements, not just against the pairs present in R.

Question 1(xiv)[1]
The given function f : ℝ → ℝ is many-one. Give reason.
  1. From the graph, the curve meets the x-axis at three different points, x1, x2 and the origin.
    [½]
  2. Three different inputs have the same image: f(x1) = f(x2) = f(0) = 0 with x1 ≠ x2 ≠ 0. A function is one-one only if different inputs give different outputs, so f is many-one.
    [½]
Answer
Many-one: the horizontal line y = 0 cuts the graph at three points, so one image (0) has three pre-images.

Concepts to recall

  • One-one ⇔ every horizontal line cuts the graph at most once (horizontal-line test). Many-one ⇔ some horizontal line cuts it at least twice.
  • Many-one has nothing to do with onto: the range may or may not be all of ℝ.

Question 1(xv)[1]
There are three machines and 2 of them are faulty. They are tested one by one in a random order till both the faulty machines are identified. What is the probability that only two tests are needed to identify the faulty machines?
  1. Two tests are needed when the first machine tested is faulty: whether the second is good (the third is then faulty) or faulty (both found), the pair is known after two tests. [If the first is good, the other two must both be faulty after a single test.]
    [½]
  2. P = (2/3)(1/2) + (2/3)(1/2) = 1/3 + 1/3 = 2/3.
    [½]
Answer
2/3
Marking note CISCE’s key adds the two branches “first faulty, second good” and “both faulty”, each with probability 1/3; the sum equals P(first machine faulty) = 2/3.

Concepts to recall

  • Multiply along a branch of the tree and add the branches that lead to the event.
  • Think about what the tests reveal: with 2 faulty out of 3, one good machine found means the other two are faulty without any further test.

Question 2[2]
(i) If x = exy, then prove that dydx = x − yx log x.
OR
(ii) Find the values of ‘a’ for which the function f(x) = b − ax + sin x is increasing on ℝ.

Solution to the first alternative

  1. Take logarithms: log x = (x/y) log e = x/y, so y log x = x.
    [½]
  2. Differentiate with respect to x (product rule): y·(1/x) + log x·(dy/dx) = 1.
    [1]
  3. log x·(dy/dx) = 1 − y/x = (x − y)/x ⇒ dy/dx = (x − y)/(x log x). Proved.
    [½]
Answer
dy/dx = (x − y)/(x log x)

Solution to the OR alternative

  1. f′(x) = −a + cos x. For f to be increasing on ℝ we need f′(x) ≥ 0 for every real x, i.e. cos x ≥ a for all x.
    [1]
  2. The smallest value of cos x is −1, so the condition holds for all x exactly when a ≤ −1 (at a = −1, f′ = 0 only at isolated points x = (2n+1)π, so f is still increasing).
    [1]
Answer
a ≤ −1, i.e. a ∈ (−∞, −1]

Concepts to recall

  • Logarithm trick: when the variable sits in an exponent, take logs first; log e = 1.
  • Product rule on y log x gives both a (1/x)y term and a log x (dy/dx) term.
  • f is increasing on an interval if f′(x) ≥ 0 there (strictly increasing if f′ > 0).
  • A condition required for all x must hold at the worst case: here the minimum of cos x, which is −1.

Find the point on the curve y = (x − 2)2 at which the tangent is parallel to the chord joining the end points (2, 0) and (4, 4).
  1. Slope of the chord = (4 − 0)/(4 − 2) = 2. Slope of the tangent at (x, y) is dy/dx = 2(x − 2).
    [1]
  2. Parallel: 2(x − 2) = 2 ⇒ x = 3, then y = (3 − 2)2 = 1. The point is (3, 1).
    [1]
Answer
The point is (3, 1)

Concepts to recall

  • Parallel lines have equal slopes. The slope of the tangent is the derivative; the slope of a chord is (y2 − y1)/(x2 − x1).
  • This is the Mean Value Theorem: some point c in (2, 4) has f′(c) = [f(4) − f(2)]/(4 − 2); here c = 3 lies in (2, 4) as required.

If y = (A + Bx)e−2x, prove that d2ydx2 + 4dydx + 4y = 0.

  1. (a) Draw x + y = 60 (intercepts (60, 0), (0, 60)) and 5x + y = 100 (intercepts (20, 0), (0, 100)). Both constraints are ≤ and contain the origin, so the feasible region lies on the origin’s side of each line in the first quadrant: the bounded polygon OCBA.

    [1]
  3. (b) Z has the same (maximum) value at A and B: Z(0, 60) = 60q and Z(10, 50) = 10p + 50q.
    [1]

    [1]

(a) O(0, 0), C(20, 0), B(10, 50), A(0, 60); (b) p = q, infinitely many optimal solutions

  1. (a) Line DA: x/25 + y/50 = 1 ⇒ 2x + y = 50. Line CE: x/40 + y/20 = 1 ⇒ x + 2y = 40. The origin is in the shaded region and satisfies 0 ≤ 50 and 0 ≤ 40, so the constraints are 2x + y ≤ 50, x + 2y ≤ 40, x ≥ 0, y ≥ 0.

    [1]

Concepts to recall

  • Corner-point method: the optimum of a linear objective over a bounded feasible region is at a corner point.
  • If the objective has the same maximum value at two adjacent corners, it has that value at every point of the edge joining them: infinitely many optimal solutions.
