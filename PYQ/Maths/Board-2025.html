About this deck

The paper is CISCE’s ISC 2025 Mathematics (860), 80 marks: Section A (65 marks, compulsory) and then Section B or Section C (15 marks). Both optional sections are solved here, so the slides add to 95. Questions were read from the page images (integrals, matrices and the four graphs in particular), and Question 1 is split into one slide per sub-part. CISCE publishes no marking scheme for board papers, so every answer is worked out here in the style of an ISC marking scheme (marks against each step) and every answer is re-checked symbolically (sympy) by the deck’s verifier. Graphs redrawn from the paper are labelled as such.

If A = 0a00, then A16 is:
(a)Unit matrix
(b)Null matrix
(c)Diagonal matrix

  1. A2 = 0a000a00 = 0000 = O

Question 1(ii)[1]
Which of the following is a homogenous differential equation?
(a)(4x2 + 6y + 5) dy − (3y2 + 2x + 4) dx = 0
(b)(xy) dx − (x3 + y3) dy = 0
(c)(x3 + 2y2) dx + 2xy dy = 0
(d)y2 dx + (x2 − xy − y2) dy = 0
  1. A first-order equation Mdx + Ndy = 0 is homogeneous when M and N are homogeneous functions of the same degree.
    [½]
  2. (a) mixes degrees 2, 1, 0; (b) has xy of degree 2 but x3 + y3 of degree 3; (c) has x3 (3) with 2y2 (2) in the same bracket. In (d) y2 and x2 − xy − y2 are both of degree 2: homogeneous.
    [½]
Answer
(d) y2 dx + (x2 − xy − y2) dy = 0

Concepts to recall

  • Homogeneous function of degree n: f(λx, λy) = λnf(x, y).
  • Such an equation is solved by y = vx, dy/dx = v + xdv/dx.

Question 1(iii)[1]
Consider the graph of the function f(x) shown (redrawn below). Statement 1: The function f(x) is increasing in (½, 2). Statement 2: The function f(x) is strictly increasing in (½, 1). Which is correct?
(a)Statement 1 is true and Statement 2 is false.
(b)Statement 2 is true and Statement 1 is false.
(c)Both the statements are true.
(d)Both the statements are false.
  1. From the graph, f rises from 0 at x = ½ to 1 at x = 1, and is constant (= 1) on [1, 2].
    [½]
  2. “Increasing” means x1 < x2 ⇒ f(x1) ≤ f(x2); a flat piece is allowed, so Statement 1 is true. On (½, 1) the values rise strictly, so Statement 2 is true. Both are true.
    [½]
Answer
(c) Both the statements are true.
Common slip Rejecting Statement 1 because of the flat part on (1, 2): in the ISC/NCERT definition a flat part does not stop a function being increasing.

Concepts to recall

  • Increasing (non-decreasing): x1 < x2 ⇒ f(x1) ≤ f(x2). Strictly increasing: f(x1) < f(x2).
  • A constant stretch is increasing but not strictly increasing.

Question 1(v)[1]
Assertion: Consider the two events A and B such that n(A) = n(B) and P(A|B) = P(B|A).
Reason: The events A and B are mutually exclusive.
(a)Both Assertion and Reason are true and Reason is the correct explanation for Assertion.
(b)Both Assertion and Reason are true but Reason is not the correct explanation for Assertion.
(c)Assertion is true and Reason is false.
(d)Assertion is false and Reason is true.
  1. P(A|B) = n(A∩B)/n(B) and P(B|A) = n(A∩B)/n(A). Since n(A) = n(B) the two are equal: the Assertion is true.
    [½]
  2. The Reason is a separate claim that nothing in the question guarantees (A and B may overlap), so it is false. Assertion true, Reason false.
    [½]
Answer
(c) Assertion is true and Reason is false.
Marking note In the (unlikely) case that A and B were exclusive both conditional probabilities would be 0 and the Assertion would still hold, but exclusivity is not the reason the two are equal; the equal sizes are. Option (c) is the intended key.

Concepts to recall

  • Conditional probability: P(A|B) = P(A∩B)/P(B).
  • Mutually exclusive events have P(A∩B) = 0; they need not be the ones given here.
  • Assertion–Reason: decide each statement on its own first, then ask whether the Reason is why the Assertion holds.

Question 1(vi)[1]
The existence of unique solution of the system of equations x + y = λ and 5x + ky = 2 depends on:
(a)λ only
(b)λ/k = 1
(c)both k and λ
(d)k only
  1. Coefficient determinant: |A| = 115k = k − 5.
    [½]
  2. A unique solution exists iff |A| ≠ 0, i.e. k ≠ 5. The constants λ and 2 do not enter this test: it depends on k only.
    [½]

(d) k only

  • For AX = B with a square A: |A| ≠ 0 ⇔ a unique solution; |A| = 0 ⇒ none or infinitely many (decided by (adj A)B).

A cylindrical popcorn tub of radius 10 cm is being filled with popcorns at the rate of 314 cm3 per minute. The level of the popcorns in the tub is increasing at the rate of:
(a)1 cm/minute
(b)0·1 cm/minute
(c)1·1 cm/minute
(d)0·5 cm/minute

Question 1(ix)[1]
Assertion: If Set A has m elements, Set B has n elements and n < m, then the number of one-one function(s) from A → B is zero.
Reason: A function f: A → B is defined only if all elements in Set A have an image in Set B.
(a)Both Assertion and Reason are true and Reason is the correct explanation for Assertion.
(b)Both Assertion and Reason are true but Reason is not the correct explanation for Assertion.
(c)Assertion is true and Reason is false.
(d)Assertion is false and Reason is true.
  1. One-one means different elements of A have different images, which needs at least m distinct elements in B. With n < m two elements of A must share an image, so no one-one function exists: Assertion true.
    [½]
  2. The Reason is a true statement about the definition of a function, but it says nothing about distinct images, so it does not explain the Assertion. (b).
    [½]
Answer
(b) Both Assertion and Reason are true but Reason is not the correct explanation for Assertion.

Concepts to recall

  • Number of one-one functions from A to B (m ≤ n): n!/(n − m)!; zero if m > n (pigeonhole principle).
  • Function: every element of the domain has exactly one image.
  • Assertion–Reason: decide each statement on its own first, then ask whether the Reason is why the Assertion holds.

Statement 1: If ‘A’ is an invertible matrix, then (A2)−1 = (A−1)2.

Question 1(xii)[1]
Write the smallest equivalence relation from the set A to A, where A = {1, 2, 3}.
  1. An equivalence relation must be reflexive, so it must contain (1, 1), (2, 2), (3, 3).
    [½]
  2. This set is already symmetric and transitive, so nothing more is needed: R = {(1, 1), (2, 2), (3, 3)}, the identity relation.
    [½]
Answer
R = {(1, 1), (2, 2), (3, 3)}

Concepts to recall

  • Equivalence relation = reflexive + symmetric + transitive.
  • The identity relation is the smallest equivalence relation on a set; the universal relation A × A is the largest.

Three critics review a book. Odds in favour of the book are 5:2, 4:3 and 3:4 respectively for the three critics. Find the probability that all critics are in favour of the book.

Question 2[2]
Find the point on the curve y = 2x2 − 6x − 4 at which the tangent is parallel to the x-axis.
  1. Slope of tangent = dy/dx = 4x − 6. Parallel to the x-axis means slope = 0: 4x − 6 = 0, x = 3/2.
    [1]
  2. y = 2(9/4) − 6(3/2) − 4 = 9/2 − 9 − 4 = −17/2.
    [1]
Answer
The point is (3/2, −17/2).

Question 3[2]
Find the value of tan−1x − cot−1x, if (tan−1x)2 − (cot−1x)2 = 5π/8.
  1. Put a = tan−1x, b = cot−1x. Then a2 − b2 = (a − b)(a + b) and a + b = π/2.
    [1]
  2. (π/2)(a − b) = 5π/8, so a − b = (5π/8) ÷ (π/2) = 5/4.
    [1]
Answer
tan−1x − cot−1x = 5/4
Marking note Taken as printed (5π/8, not 5π2/8). The answer 5/4 is attainable: a = (5/4 + π/2)/2 ≈ 1·41 lies in (−π/2, π/2), i.e. x = tan(1·41) ≈ 6·2. Had the right side been 5π2/8, a − b would be 5π/4 > π/2, which is impossible; the printed reading is the sensible one.

Concepts to recall

  • tan−1x + cot−1x = π/2 for every real x.
  • Difference of squares turns a square equation into a linear one in a − b.
SECTION A – 65 MARKS (compulsory)ISC 2025 Mathematics (860), Q4
Question 4[2]
(i) If xy = ex−y, prove that dy/dx = log x/(1 + log x)2.
OR
(ii) If f(x) = log(1 + x) + 1/(1 + x), show that f(x) attains its minimum value at x = 0.

Solution to the first alternative

  1. Take logarithms: y log x = x − y, so y(1 + log x) = x and y = x/(1 + log x).
    [1]
  2. dy/dx = [(1 + log x)(1) − x(1/x)]/(1 + log x)2 = log x/(1 + log x)2. Hence proved.
    [1]
Answer
dy/dx = log x/(1 + log x)2

Solution to the OR alternative

  1. f′(x) = 1/(1 + x) − 1/(1 + x)2 = x/(1 + x)2 (domain x > −1). f′(x) = 0 gives x = 0.
    [1]
  2. f″(x) = (1 − x)/(1 + x)3, so f″(0) = 1 > 0: a minimum at x = 0 (value f(0) = 1). (Also f′ < 0 for −1 < x < 0 and > 0 for x > 0.)
    [1]
Answer
f″(0) = 1 > 0, so f has its minimum at x = 0; fmin = 1.

Concepts to recall

  • Equation of the form xy = f: take logs, and if y can be isolated do so before differentiating.
  • Quotient rule: (u/v)′ = (vu′ − uv′)/v2.
  • Second-derivative test: f′(c) = 0 and f″(c) > 0 ⇒ local minimum at c.
  • First-derivative test: f′ changes from − to + at c ⇒ minimum.

Three shopkeepers Gaurav, Rizwan and Jacob use carry bags made of polythene, handmade paper and newspaper. Question 6[2]
(i) Differentiate sin−1( 2x+1 3x / (1 + (36)x) ) with respect to x.
OR
(ii) Show that tan−1x + tan−1y = C is the general solution of the differential equation (1 + x2) dy + (1 + y2) dx = 0.

Solution to the first alternative

  1. 2x+13x = 2(2x3x) = 2 · 6x, and 36x = (6x)2. Put 6x = tan θ: the argument is 2 tan θ/(1 + tan2θ) = sin 2θ, so y = 2θ = 2 tan−1(6x).
    [1]
  2. dy/dx = 2 · 1/(1 + 36x) · 6x log 6 = 2 · 6x log 6/(1 + 36x).
    [1]
Answer
dy/dx = 2 · 6x log 6 / (1 + 36x)
Marking note The substitution is exact for 6x ≤ 1, i.e. x ≤ 0 (then 2θ ≤ π/2). For x > 0 the expression equals π − 2tan−1(6x) and the derivative changes sign; the expected answer is the one above, and the restriction need not be stated.

Solution to the OR alternative

  1. Separate the variables: divide by (1 + x2)(1 + y2): dy/(1 + y2) + dx/(1 + x2) = 0.
    [1]
  2. Integrate: tan−1y + tan−1x = C. Hence shown.
    [1]
Answer
tan−1x + tan−1y = C is the general solution.

Concepts to recall

  • 2 tan θ/(1 + tan2θ) = sin 2θ; sin−1(sin 2θ) = 2θ for −π/2 ≤ 2θ ≤ π/2.
  • d/dx(ax) = ax log a; d/dx tan−1u = u′/(1 + u2).
  • Variables-separable equation: f(x)dx + g(y)dy = 0, integrate each side.
  • ∫dx/(1 + x2) = tan−1x + C. A first-order general solution carries one arbitrary constant.

Question 7[4]
If x + y + z = 0 then show that 111xyzx3y3z3 = 0, using properties of determinant.
  1. Let Δ be the determinant. Apply C2 → C2 − C1, C3 → C3 − C1:
    Δ = 100xy − xz − xx3y3 − x3z3 − x3
    [1]
  2. Take (y − x) out of C2 and (z − x) out of C3, using a3 − b3 = (a − b)(a2 + ab + b2):
    Δ = (y − x)(z − x) 100x11x3x2 + xy + y2x2 + xz + z2
    [1]
  3. Expand along R1: Δ = (y − x)(z − x)[(x2 + xz + z2) − (x2 + xy + y2)] = (y − x)(z − x)[(z − y)(z + y) + x(z − y)]
    [1]
  4. = (y − x)(z − x)(z − y)(x + y + z) = 0, because x + y + z = 0. Hence proved.
    [1]
Answer
Δ = (y − x)(z − x)(z − y)(x + y + z) = 0.
Common slip Expanding the original determinant and using x3 + y3 + z3 = 3xyz only: the expansion does not contain that sum, so that route is not a proof.

Concepts to recall

  • Column operation Cj → Cj − Ci leaves a determinant unchanged; a common factor of a column may be taken outside.
  • Expanding along a row that is (1, 0, 0) reduces a 3×3 determinant to one 2×2 minor.
  • The factor (x + y + z) appearing is what lets the given condition kill the whole determinant.
SECTION A – 65 MARKS (compulsory)ISC 2025 Mathematics (860), Q8
Question 8[4]
(i) Evaluate: ∫cos x3 cos x − 5 dx
OR
(ii) Evaluate: ∫(log x)2 dx

Solution to the first alternative

  1. Write cos x = (1/3)(3 cos x − 5) + 5/3, so the integrand is 1/3 + (5/3)/(3 cos x − 5).
    [1]
  2. Let t = tan(x/2): cos x = (1 − t2)/(1 + t2), dx = 2dt/(1 + t2), and 3 cos x − 5 = −(2 + 8t2)/(1 + t2).
    [1]
  3. ∫dx/(3 cos x − 5) = ∫−2dt/(2 + 8t2) = −∫dt/(1 + 4t2) = −½ tan−1(2t).
    [1]
  4. Hence the integral = x/3 − (5/6) tan−1(2 tan(x/2)) + C.
    [1]
Answer
x/3 − (5/6) tan−1(2 tan (x/2)) + C

Solution to the OR alternative

  1. Integrate by parts with u = (log x)2, dv = dx: ∫(log x)2dx = x(log x)2 − ∫x · 2 log x · (1/x) dx
    [1]
  2. = x(log x)2 − 2∫log x dx
    [1]
  3. ∫log x dx = x log x − x (by parts again, with u = log x)
    [1]
  4. Therefore the integral = x(log x)2 − 2x log x + 2x + C.
    [1]
Answer
x(log x)2 − 2x log x + 2x + C

Concepts to recall

  • (a cos x + b)/(c cos x + d): split off a constant first, leaving 1/(c cos x + d).
  • Weierstrass substitution t = tan(x/2): sin x = 2t/(1 + t2), cos x = (1 − t2)/(1 + t2), dx = 2dt/(1 + t2).
  • ∫dt/(1 + a2t2) = (1/a) tan−1(at).
  • Integration by parts: ∫uv dx = u∫v dx − ∫(u′∫v dx)dx.

Marking note Marks: 1 each for (i), (ii), (iii)(a), (iii)(b), (iii)(c). Here Σ(x − x̄)2 = 14 as well, so byx = −1 too (r = −1: the points are exactly collinear).

Concepts to recall

  • Actual (not marginal) revenue from the nth unit = R(n) − R(n − 1). Marginal revenue R′(n) is only an approximation.
  • Regression coefficients: byx = rσy/σx, bxy = rσx/σy; same sign as r; r2 = bxybyx; r is the GM, not the AM.
  • bxy = Σ(x − x̄)(y − ȳ)/Σ(y − ȳ)2: the denominator is for the variable you are regressing on.
SECTION C – 15 MARKSISC 2025 Mathematics (860), Q20
Question 20[2]
(i) Find the regression line of best fit from the following data: Σx = 24, Σy = 44, Σxy = 306, Σx2 = 164, Σy2 = 576, n = 4.
OR
(ii) Two lines of regression are given as 4x + 3y + 7 = 0 and 3x + 4y + 8 = 0. Identify the line of regression of x on y.

Solution to the first alternative

  1. x̄ = 24/4 = 6, ȳ = 44/4 = 11. byx = (nΣxy − ΣxΣy)/(nΣx2 − (Σx)2) = (4 · 306 − 24 · 44)/(4 · 164 − 576) = 168/80 = 2·1.
    [1]
  2. Line of regression of y on x: y − 11 = 2·1(x − 6), i.e. y = 2·1x − 1·6.
    [1]
Answer
y = 2·1x − 1·6 (that is, 21x − 10y − 16 = 0)
Marking note “Line of best fit” is the least-squares line of y on x. The line of x on y, bxy = 168/368 = 21/46 giving x = (21y + 45)/46, may also be given for completeness (r = √(2·1 × 21/46) ≈ 0·98).

Solution to the OR alternative

  1. Trial 1: take 4x + 3y + 7 = 0 as x on y: bxy = −3/4; then 3x + 4y + 8 = 0 is y on x: byx = −3/4. Product = 9/16 < 1: admissible (r2 = 9/16, r = −3/4).
    [1]
  2. Trial 2 (the other way round): byx = −4/3 and bxy = −4/3, product 16/9 > 1, impossible since r2 ≤ 1. So the line of regression of x on y is 4x + 3y + 7 = 0.
    [1]
Answer
4x + 3y + 7 = 0 is the regression line of x on y.

Concepts to recall

  • Regression line of y on x: y − ȳ = byx(x − x̄); it always passes through (x̄, ȳ).
  • byx = (nΣxy − ΣxΣy)/(nΣx2 − (Σx)2).
  • Each regression coefficient comes from its own line: from x on y take x = …y (coefficient of y after solving for x); from y on x take y = …x.
  • Test for the assignment: bxybyx = r2 must be ≤ 1.
SECTION C – 15 MARKSISC 2025 Mathematics (860), Q21
Question 21[4]
(i) A utensil manufacturer produces ‘x’ dinner sets per week and sells each set at ₹ p, where x = (600 − p)/8. The cost of production of ‘x’ sets is ₹ x2 + 78x + 2000. (a) Write the revenue function. [1] (b) Write the profit function. [1] (c) Calculate the number of dinner sets to be produced and sold per week to ensure maximum profit. [2]
OR
(ii) The Average Cost of producing ‘x’ units of a commodity is given by AC = x2/200 − x/50 − 30 + 5000/x. (a) Find the Cost function. [1] (b) Find the Marginal Cost function. [1] (c) Find the Marginal Average Cost function. [1] (d) Verify that d/dx(AC) = (MC − AC)/x. [1]

Solution to the first alternative

  1. (a) p = 600 − 8x, so revenue R(x) = px = 600x − 8x2.
    [1]
  2. (b) Profit P(x) = R(x) − C(x) = 600x − 8x2 − x2 − 78x − 2000 = −9x2 + 522x − 2000.
    [1]
  3. (c) P′(x) = −18x + 522 = 0 ⇒ x = 29.
    [1]
  4. P″(x) = −18 < 0, so profit is maximum at x = 29 (maximum profit = ₹ 5569).
    [1]
Answer
(a) R = 600x − 8x2; (b) P = −9x2 + 522x − 2000; (c) 29 dinner sets (maximum profit ₹ 5569).

Solution to the OR alternative

  1. (a) C(x) = x · AC = x3/200 − x2/50 − 30x + 5000.
    [1]
  2. (b) MC = dC/dx = 3x2/200 − x/25 − 30.
    [1]
  3. (c) Marginal Average Cost = d(AC)/dx = x/100 − 1/50 − 5000/x2.
    [1]
  4. (d) MC − AC = (3x2/200 − x2/200) + (−x/25 + x/50) + (−30 + 30) − 5000/x = x2/100 − x/50 − 5000/x. Divide by x: x/100 − 1/50 − 5000/x2 = d(AC)/dx. Verified.
    [1]
Answer
(a) C = x3/200 − x2/50 − 30x + 5000; (b) MC = 3x2/200 − x/25 − 30; (c) MAC = x/100 − 1/50 − 5000/x2; (d) verified.

Concepts to recall

  • Revenue = price × quantity; express p in terms of x from the demand relation. Profit = revenue − cost.
  • Maximum of a profit function: P′(x) = 0 and P″(x) < 0.
  • Cost C(x) = x × AC; MC = dC/dx; marginal average cost = d(AC)/dx.
  • Since C = x·AC, MC = AC + x d(AC)/dx, so d(AC)/dx = (MC − AC)/x: the result in (d) is a general identity.
SECTION C – 15 MARKSISC 2025 Mathematics (860), Q22
Question 22[4]
Two different types of books have to be stacked in the shelf of a library. The first type of book weighs 1 kg and has a thickness of 6 cm. The second type of book weighs 1·5 kg and has a thickness of 4 cm. The shelf is 96 cm long and can support a maximum weight of 21 kg. How should both the types of books be placed in the shelf to include the maximum number of books? Formulate a Linear Programming Problem and solve it graphically.
  1. Let there be x books of the first type and y of the second. Maximise Z = x + y (number of books).
    [½]
  2. Constraints: length 6x + 4y ≤ 96, i.e. 3x + 2y ≤ 48; weight x + 1·5y ≤ 21, i.e. 2x + 3y ≤ 42; x, y ≥ 0.
    [1]
  3. Draw the lines 3x + 2y = 48 (through (16, 0), (0, 24)) and 2x + 3y = 42 (through (21, 0), (0, 14)). They meet where 9x + 6y = 144 and 4x + 6y = 84, i.e. 5x = 60: P(12, 6). The feasible region is OAPC with corners O(0, 0), A(16, 0), P(12, 6), C(0, 14).
    [1½]
  4. Z at the corners: O 0; A 16; P 12 + 6 = 18; C 14.
    [½]
  5. Maximum Z = 18 at P(12, 6): 12 books of the first type and 6 of the second (length 72 + 24 = 96 cm, weight 12 + 9 = 21 kg: both limits just used).
    [½]
Answer
12 books of the first type and 6 of the second: maximum number of books = 18.
Marking note The corner (12, 6) is integer-valued, so no rounding argument is needed.

Concepts to recall

  • LPP steps: define variables, write the objective and constraints (with x, y ≥ 0), draw the feasible region, evaluate Z at every corner, choose the optimum.
  • A bounded feasible region always has its optimum at a corner point (corner-point theorem).
  • Convert units consistently: here cm for thickness, kg for weight; 1·5y may be cleared by × 2.
