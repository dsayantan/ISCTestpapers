What to revise

  • A 6-mark question with an OR in every 2024–2026 paper (Q12, Q13 or Q14); specimen 2027 splits it into a 2-mark and a one-mark question: homogeneous (x2dy + (xy + y2)dx = 0, x dy/dx = y − x tan(y/x)), linear in y or in x ((x + 5y2)dy/dx = y, x(x − 1)dy/dx − y = …), separable with a given point.

ONE-MARK QUESTIONS (7)ISC Specimen 2027 Mathematics, Q1(xix)
Question 1(xix) · Specimen 2027[1]
If the solution of the differential equation dy/dx = (ax + 3)/(2y + 5) represents a circle, then find the value of a.
  1. Separate the variables and integrate: (2y + 5) dy = (ax + 3) dx gives y2 + 5y = ax2/2 + 3x + c, i.e. ax2/2 − y2 + 3x − 5y + c = 0.
    [½]
  2. A circle has equal coefficients of x2 and y2 (and no xy term): a/2 = −1, so a = −2. The curve is x2 + y2 − 3x + 5y − c = 0.
    [½]
Answer
a = −2
Marking note Whether the circle is real also depends on c (radius squared = 9/4 + 25/4 + c must be positive); the question only asks for the value of a.

Concepts to recall

  • Variable-separable equation: write f(y)dy = g(x)dx and integrate both sides.
  • General second-degree equation represents a circle iff the coefficients of x2 and y2 are equal (same sign) and there is no xy term.
ONE-MARK QUESTIONS (7)ISC 2026 Mathematics (860), Q1(x)
Question 1(x) · Board 2026[1]
The solution of dy/dx − y = 1, y(0) = 1 is given by:
(a)y = −ex + 1
(b)y = −e−x−1
(c)y = −1 + ex
(d)y = 2ex − 1
  1. Integrating factor = e∫−1 dx = e−x. Then ye−x = ∫e−x dx = −e−x + C, so y = −1 + Cex.
    [½]
  2. y(0) = 1 gives 1 = −1 + C, C = 2. So y = 2ex − 1. (Check: y′ − y = 2ex − 2ex + 1 = 1.)
    [½]
Answer
(d) y = 2ex − 1

Concepts to recall

  • Linear equation dy/dx + Py = Q: IF = e∫Pdx, solution y·IF = ∫Q·IF dx + C.
  • With options given, substituting the initial condition x = 0, y = 1 eliminates (a), (b), (c) at once.
ONE-MARK QUESTIONS (7)ISC Specimen 2026 Mathematics, Q1(ii)
Question 1(ii) · Specimen 2026[1]
If m and n are respectively the order and degree of the differential equation ddx(dydx)3 = 0, then the value of (m − n) is:
(a)0
(b)1
(c)2
(d)3
  1. Differentiate: 3(dy/dx)2·(d2y/dx2) = 0. The highest derivative is d2y/dx2, so the order m = 2.
    [½]
  2. Its power is 1 (the equation is a polynomial in the derivatives), so the degree n = 1. Hence m − n = 2 − 1 = 1.
    [½]
Answer
(b) 1
Common slip Reading the cube as the degree (n = 3) and the order as 1, which gives m − n = −2, not an option.

Concepts to recall

  • Order = order of the highest derivative; degree = power of that highest derivative once the equation is a polynomial in the derivatives.
  • The cube on (dy/dx) is a lower derivative: it does not make the degree 3. Expand the outer d/dx first.

Question 1(vi) · Board 2025 Imp.[1]
The integrating factor of the differential equation (1 − x2) dy/dx + xy = ax is:
(a)√1 − x2
(b)−1/√1 − x2
(c)1/√1 − x2
(d)−√1 − x2
  1. Standard form: dy/dx + [x/(1 − x2)] y = ax/(1 − x2), so P = x/(1 − x2).
    [½]
  2. ∫ P dx = −½ log|1 − x2|, so I.F. = e∫Pdx = (1 − x2)−1/2 = 1/√1 − x2.
    [½]
Answer
(c) 1/√1 − x2
Common slip Reading P = x (without dividing by 1 − x2) gives ex2/2, which is not an option.

Concepts to recall

  • Linear equation dy/dx + Py = Q: I.F. = e∫Pdx.
  • First divide by the coefficient of dy/dx to reach standard form.
ONE-MARK QUESTIONS (7)ISC 2025 Mathematics (860), Q1(ii)
Question 1(ii) · Board 2025[1]
Which of the following is a homogenous differential equation?
(a)(4x2 + 6y + 5) dy − (3y2 + 2x + 4) dx = 0
(b)(xy) dx − (x3 + y3) dy = 0
(c)(x3 + 2y2) dx + 2xy dy = 0
(d)y2 dx + (x2 − xy − y2) dy = 0
  1. A first-order equation Mdx + Ndy = 0 is homogeneous when M and N are homogeneous functions of the same degree.
    [½]
  2. (a) mixes degrees 2, 1, 0; (b) has xy of degree 2 but x3 + y3 of degree 3; (c) has x3 (3) with 2y2 (2) in the same bracket. In (d) y2 and x2 − xy − y2 are both of degree 2: homogeneous.
    [½]
Answer
(d) y2 dx + (x2 − xy − y2) dy = 0

Concepts to recall

  • Homogeneous function of degree n: f(λx, λy) = λnf(x, y).
  • Such an equation is solved by y = vx, dy/dx = v + xdv/dx.
ONE-MARK QUESTIONS (7)CISCE Specimen 2025 Mathematics, Q1(iv)
Question 1(iv) · Specimen 2025[1]
Assertion: Degree of the differential equation a(dy/dx)2 + b(dx/dy) = c is 3.
Reason: If each term involving derivatives of a differential equation is a polynomial (or can be expressed as a polynomial) then the highest exponent of the highest order derivative is called the degree of the differential equation.
(a)Both Assertion and Reason are true and Reason is the correct explanation for Assertion.
(b)Both Assertion and Reason are true but Reason is not the correct explanation for Assertion.
(c)Assertion is true and Reason is false.
(d)Assertion is false and Reason is true.
  1. dx/dy = 1/(dy/dx), so the equation can be expressed as a polynomial in y′ : multiply by y′ = dy/dx to get a(y′)3 + b = cy′.
    [½]
  2. Highest order derivative is y′ (order 1) with highest exponent 3: degree = 3, so the Assertion is true. The Reason is exactly the definition used to reach it: Reason true and explains the Assertion.
    [½]
Answer
(a) Both Assertion and Reason are true and Reason is the correct explanation for Assertion.
Common slip Saying the equation “has dx/dy so the degree is not defined”.
Marking note CISCE’s printed key gives (d) “Assertion false”. That cannot be right: after multiplying by dy/dx the equation is a(y′)3 + b = cy′, order 1 degree 3, exactly as the Assertion says. (a) is the answer worked out here; if the examiner’s key is followed, (d) is what it prints.

Concepts to recall

  • Degree = power of the highest order derivative once the equation is a polynomial in the derivatives (clear fractions and radicals first).
  • dx/dy = 1/(dy/dx): an inverse derivative is not an obstacle, it is cleared by multiplying through.
ONE-MARK QUESTIONS (7)ISC 2024 Mathematics (860), Q1(ii)
Question 1(ii) · Board 2024[1]
The order and the degree of the differential equation 1 + (dydx)2 = d2ydx2 are:
(a)2 and 32
(b)2 and 3
(c)3 and 4
(d)2 and 1
  1. Highest derivative is d2y/dx2, so the order is 2.
    [½]
  2. The equation is a polynomial in the derivatives: y″ = 1 + (y′)2. The power of y″ is 1, so the degree is 1.
    [½]
Answer
(d) 2 and 1
Common slip Giving degree 2 from the squared first derivative.

Concepts to recall

  • Order = order of the highest derivative; degree = its power once the equation is a polynomial in the derivatives (free of radicals and fractions of derivatives).
  • The square of dy/dx does not change the degree, because it is not the highest derivative.
TWO-MARK QUESTIONS (3)ISC Specimen 2027 Mathematics, Q4
Question 4 · Specimen 2027[2]
Solve the following differential equation: dx/dy = x/y + f(x/y) / f′(x/y)
  1. The right side is a function of x/y: a homogeneous equation in which x is the dependent variable. Put x = vy, so dx/dy = v + y dv/dy.
    [½]
  2. v + y dv/dy = v + f(v)/f′(v), so y dv/dy = f(v)/f′(v).
    [½]
  3. Separate the variables: f′(v)/f(v) dv = dy/y. Integrate: log|f(v)| = log y + log c.
    [½]
  4. f(v) = cy, i.e. f(x/y) = cy.
    [½]
Answer
f(x/y) = cy

Concepts to recall

  • Homogeneous equation dx/dy = F(x/y): put x = vy and separate the variables.
  • ∫ f′(v)/f(v) dv = log|f(v)| (the numerator is the derivative of the denominator).
  • The arbitrary constant is written as log c so that two logs combine into a product.
TWO-MARK QUESTIONS (3)ISC Specimen 2026 Mathematics, Q4
Question 4 · Specimen 2026[2]
Show that the general solution of the differential equation dydx = y cot 2x is log y = ½ log|sin 2x| + C.
  1. Separate the variables: dy/y = cot 2x dx.
    [½]
  2. Integrate: ∫ dy/y = log y (taking y > 0).
    [½]
  3. ∫ cot 2x dx: put t = sin 2x, dt = 2 cos 2x dx, so = ½ ∫ dt/t = ½ log|sin 2x|.
    [½]
  4. Hence log y = ½ log|sin 2x| + C. Shown.
    [½]
Answer
log y = ½ log|sin 2x| + C

Concepts to recall

  • Variables separable: dy/dx = f(x)g(y) ⇒ dy/g(y) = f(x) dx.
  • ∫ cot(ax) dx = (1/a) log|sin ax| + C: do not forget the 1/a from the chain rule.

FOUR-MARK QUESTIONS (1)ISC Specimen 2026 Mathematics, Q9
Question 9 · Specimen 2026[4]
(i) Solve the differential equation: x dydx = y − x tan(y/x).
OR
(ii) Solve the following differential equation: (1 + x2) dydx + 2xy = 4x2.

Solution to the first alternative

  1. Divide by x: dy/dx = y/x − tan(y/x), a function of y/x: homogeneous. Put y = vx, dy/dx = v + x dv/dx.
    [1]
  2. v + x dv/dx = v − tan v ⇒ x dv/dx = −tan v ⇒ cot v dv = −dx/x.
    [1]
  3. Integrate: log|sin v| = −log|x| + log c ⇒ sin v = c/x.
    [1]
  4. Replace v = y/x: x sin(y/x) = c.
    [1]
Answer
x sin(y/x) = c

Solution to the OR alternative

  1. Divide by (1 + x2): dy/dx + [2x/(1 + x2)]y = 4x2/(1 + x2): linear, with P = 2x/(1 + x2), Q = 4x2/(1 + x2).
    [1]
  2. I.F. = e∫P dx = elog(1 + x2) = 1 + x2.
    [1]
  3. y(1 + x2) = ∫ [4x2/(1 + x2)](1 + x2) dx = ∫ 4x2 dx = 4x3/3 + c.
    [1]
  4. y = (4x3/3 + c)/(1 + x2).
    [1]
Answer
y(1 + x2) = 4x3/3 + c

Concepts to recall

  • Homogeneous equation dy/dx = f(y/x): substitute y = vx to separate the variables.
  • ∫ cot v dv = log|sin v|; write the constant as log c so the logs combine.
  • Linear equation dy/dx + Py = Q: integrating factor I.F. = e∫Pdx, solution y·I.F. = ∫ Q·I.F. dx + c.
  • Here the left side is d/dx[y(1 + x2)], which is why the I.F. is 1 + x2.
SIX-MARK QUESTIONS (5)ISC 2026 Mathematics (860), Q14
Question 14 · Board 2026[6]
(i) Solve the following differential equation: x2dy + (xy + y2)dx = 0
OR
(ii) Find the particular solution for the following differential equation: √(1 − y2) dx = (sin−1y − x) dy, given that y(0) = 0

Solution to the first alternative

  1. dy/dx = −(xy + y2)/x2, which is a function of y/x: a homogeneous equation.
    [1]
  2. Put y = vx, dy/dx = v + x dv/dx: v + x dv/dx = −(v + v2).
    [1]
  3. x dv/dx = −v2 − 2v = −v(v + 2), so dv/[v(v + 2)] = −dx/x.
    [1]
  4. 1/[v(v + 2)] = (1/2)[1/v − 1/(v + 2)]. Integrating: (1/2) log|v/(v + 2)| = −log|x| + log c1.
    [2]
  5. v/(v + 2) = C/x2. With v = y/x: y/(y + 2x) = C/x2, i.e. x2y = C(y + 2x).
    [1]
Answer
x2y = C(y + 2x)

Solution to the OR alternative

  1. Write as dx/dy + x/√(1 − y2) = sin−1y/√(1 − y2): linear in x with P = 1/√(1 − y2).
    [1]
  2. IF = e∫dy/√(1−y2) = esin−1y.
    [1]
  3. xesin−1y = ∫ sin−1y · esin−1y/√(1 − y2) dy. Put t = sin−1y, dt = dy/√(1 − y2): ∫ tet dt = (t − 1)et + C.
    [2]
  4. General solution: x = sin−1y − 1 + Ce−sin−1y.
    [1]
  5. y(0) = 0 means x = 0 when y = 0: 0 = 0 − 1 + C, so C = 1. Particular solution: x = sin−1y − 1 + e−sin−1y.
    [1]
Answer
x = sin−1y − 1 + e−sin−1y

Concepts to recall

  • Homogeneous equation dy/dx = F(y/x): substitute y = vx and separate variables.
  • Partial fractions: 1/[v(v + 2)] = (1/2)(1/v − 1/(v + 2)).
  • Always resubstitute v = y/x at the end; the constant may be written in any equivalent form.
  • If the equation is linear in x (dx/dy + Px = Q, P, Q functions of y), use IF = e∫Pdy.
  • ∫ tet dt = (t − 1)et + C (by parts).
  • Use the condition y(0) = 0 as the pair (x, y) = (0, 0).
SIX-MARK QUESTIONS (5)ISC 2025 Improvement Mathematics (860), Q12
Question 12 · Board 2025 Imp.[6]
(i) Solve the differential equation: x(x − 1) dy/dx − y = x2(x − 1)2. Find the particular solution satisfying the condition y = 0 when x = 0.
OR
(ii) Find the particular solution of the differential equation (x + y) dy + (x − y) dx = 0, given that y = 1 when x = 1.

Solution to the first alternative

  1. Standard form: dy/dx − [1/(x(x − 1))] y = x(x − 1). Linear, with P = −1/(x(x − 1)) and Q = x(x − 1).
    [1]
  2. 1/(x(x − 1)) = 1/(x − 1) − 1/x, so ∫P dx = −log|(x − 1)/x| and I.F. = x/(x − 1).
    [2]
  3. Solution: y · x/(x − 1) = ∫ x(x − 1) · x/(x − 1) dx = ∫ x2 dx = x3/3 + C.
    [1½]
  4. General solution: y = (x − 1)(x3/3 + C)/x. At x = 0, y = 0: the left side yx/(x − 1) = 0 so 0 = 0 + C, C = 0. (y must stay finite at 0, which forces C = 0.)
    [1]
  5. Particular solution: y = x2(x − 1)/3.
    [½]
Answer
General: yx/(x − 1) = x3/3 + C; particular: y = x2(x − 1)/3.
Marking note Verification: y = (x3 − x2)/3 gives x(x − 1)y′ − y = x2(x − 1)2. ✓

Solution to the OR alternative

  1. dy/dx = (y − x)/(x + y): homogeneous of degree 1. Put y = vx, dy/dx = v + x dv/dx.
    [1]
  2. v + x dv/dx = (v − 1)/(v + 1), so x dv/dx = −(v2 + 1)/(v + 1).
    [1½]
  3. Separate: (v + 1)/(v2 + 1) dv = −dx/x. Integrate: ½ log(v2 + 1) + tan−1v = −log x + c.
    [1½]
  4. Replace v = y/x: ½ log(x2 + y2) + tan−1(y/x) = c (since log x + ½ log(v2 + 1) = ½ log(x2 + y2)).
    [1]
  5. x = 1, y = 1: c = ½ log 2 + π/4. Particular solution: ½ log(x2 + y2) + tan−1(y/x) = ½ log 2 + π/4.
    [1]
Answer
½ log(x2 + y2) + tan−1(y/x) = ½ log 2 + π/4
Marking note Equivalent forms are accepted, e.g. log√(x2 + y2) + tan−1(y/x) = (π/4 + ½ log 2).

Concepts to recall

  • Linear equation dy/dx + Py = Q: I.F. = e∫P, solution y(I.F.) = ∫ Q(I.F.) dx + C.
  • Partial fractions: 1/(x(x − 1)) = 1/(x − 1) − 1/x; elog u = u.
  • Because x = 0 makes the coefficient of dy/dx vanish, the initial condition is applied to the cleared form yx = (x − 1)(…), or by requiring y finite.
  • Homogeneous equation dy/dx = f(y/x): substitute y = vx and separate variables.
  • ∫(v + 1)/(v2 + 1) dv = ½ log(v2 + 1) + tan−1v.
  • Always apply the initial condition last, after returning to x, y.
SIX-MARK QUESTIONS (5)ISC 2025 Mathematics (860), Q12
Question 12 · Board 2025[6]
(i) Solve the differential equation (x + 5y2) dy/dx = y, when x = 2 and y = 1.
OR
(ii) Find the particular solution of the differential equation (x2 − 2y2) dx + 2xy dy = 0, when x = 1 and y = 1.

Solution to the first alternative

  1. Rewrite with x as the dependent variable: dx/dy = (x + 5y2)/y, i.e. dx/dy − (1/y)x = 5y, linear in x.
    [2]
  2. Integrating factor = e−∫dy/y = e−log y = 1/y.
    [1]
  3. x · (1/y) = ∫5y · (1/y) dy = 5y + c, so x = 5y2 + cy.
    [1]
  4. x = 2, y = 1: 2 = 5 + c, c = −3.
    [1]
  5. Particular solution: x = 5y2 − 3y.
    [1]
Answer
x = 5y2 − 3y

Solution to the OR alternative

  1. dy/dx = (2y2 − x2)/(2xy): right side is homogeneous of degree 0.
    [1]
  2. Put y = vx, dy/dx = v + x dv/dx: v + x dv/dx = (2v2 − 1)/(2v).
    [1]
  3. x dv/dx = (2v2 − 1)/(2v) − v = −1/(2v).
    [1]
  4. Separate: 2v dv = −dx/x. Integrate: v2 = −log|x| + c, i.e. y2/x2 = −log|x| + c.
    [2]
  5. x = 1, y = 1: 1 = 0 + c, c = 1. So y2 = x2(1 − log x).
    [1]
Answer
y2 = x2(1 − log x)

Concepts to recall

  • If dy/dx is awkward, try dx/dy + Px = Q with P, Q functions of y; the integrating factor is e∫Pdy and the solution x·IF = ∫Q·IF dy.
  • The equation (x + 5y2) dy = y dx is not linear in y but is linear in x.
  • Use the initial condition at the end to fix c.
  • Homogeneous equation dy/dx = f(y/x): substitute y = vx and separate variables.
  • A “particular solution” means the arbitrary constant is fixed by the given point.
  • ∫2v dv = v2; ∫dx/x = log|x|.
SIX-MARK QUESTIONS (5)CISCE Specimen 2025 Mathematics, Q12
Question 12 · Specimen 2025[6]
(i) Solve the differential equation: (x dy − y dx) y sin(y/x) = (y dx + x dy) x cos(y/x). Find the particular solution satisfying the condition that y = π when x = 1.
  1. Divide both sides by x2y cos(y/x): [(x dy − y dx)/x2] tan(y/x) = (y dx + x dy)/(xy).
    [1½]
  2. Recognise the two differentials: (x dy − y dx)/x2 = d(y/x) and y dx + x dy = d(xy). So tan(y/x) d(y/x) = d(xy)/(xy): variables separated.
    [1½]
  3. Integrate: log|sec(y/x)| = log|xy| + log|c|, so sec(y/x) = c(xy).
    [1½]
  4. y = π at x = 1: sec π = −1 = c(1·π) ⇒ c = −1/π. Particular solution: sec(y/x) = −xy/π, i.e. xy = −π sec(y/x).
    [1½]
Answer
sec(y/x) = −xy/π (general solution sec(y/x) = c·xy)

Concepts to recall

  • Spot the exact differentials d(y/x) = (x dy − y dx)/x2 and d(xy) = x dy + y dx.
  • Alternative: the equation is homogeneous in x, y; put y = vx and separate variables (the key’s Method II) to get the same result.
  • ∫ tan u du = log|sec u| + c.
SIX-MARK QUESTIONS (5)ISC 2024 Mathematics (860), Q13
Question 13 · Board 2024[6]
(i) Solve the following differential equation: 2y ex/y dx + (y − 2x ex/y) dy = 0, given x = 0 and y = 1.
OR
(ii) Solve the following differential equation: x(x2 − 1) dydx = 1, y = 0, given x = 2.

Solution to the first alternative

  1. Homogeneous equation: dxdy = 2x ex/y − y2y ex/y, a function of x/y.
    [1]
  2. Put x = vy: dx/dy = v + y dv/dy. Then v + y dv/dy = (2vev − 1)/(2ev) = v − 1/(2ev).
    [1½]
  3. So y dv/dy = −1/(2ev), i.e. 2ev dv = −dy/y (variables separated).
    [1]
  4. Integrate: 2ev = −log|y| + C, i.e. 2ex/y + log|y| = C.
    [1]
  5. x = 0, y = 1: 2e0 + log 1 = C ⇒ C = 2.
    [½]
  6. Particular solution: 2ex/y + log y = 2.
    [1]
Answer
2ex/y + log y = 2

Solution to the OR alternative

  1. Separate variables: dy = dx / [x(x2 − 1)] = dx / [x(x − 1)(x + 1)].
    [1]
  2. Partial fractions: 1/[x(x − 1)(x + 1)] = −1/x + (1/2)/(x − 1) + (1/2)/(x + 1) (A = −1, B = C = 1/2).
    [2]
  3. Integrate: y = −log|x| + ½ log|x − 1| + ½ log|x + 1| + C = ½ log|x2 − 1| − log|x| + C.
    [1]
  4. x = 2, y = 0: 0 = ½ log 3 − log 2 + C ⇒ C = log 2 − ½ log 3.
    [1]
  5. y = ½ log[4(x2 − 1)/(3x2)].
    [1]
Answer
y = ½ log 4(x2 − 1)3x2  (for x > 1)

Concepts to recall

  • The terms are homogeneous (degree 1), and x/y appears in the exponent: write dx/dy and substitute x = vy (not y = vx).
  • Then separate variables and integrate; use the initial condition to fix C.
  • Variables separable: dy = f(x) dx; integrate with partial fractions when the denominator factorises.
  • Partial fractions: 1/[x(x − 1)(x + 1)] = A/x + B/(x − 1) + C/(x + 1); find A, B, C by substituting x = 0, 1, −1.
