Question 1(i) · Specimen 2027[1]
A relation R is defined on ℤ as aRb if and only if a2 − 7ab + 6b2 = 0. Then R is:
(a)reflexive and symmetric
(b)transitive but not reflexive
(c)symmetric but not reflexive
(d)reflexive but not symmetric
  1. Reflexive: for every a ∈ ℤ, a2 − 7a2 + 6a2 = 0, so (a, a) ∈ R.
    [½]
  2. Not symmetric: (6, 1) ∈ R as 36 − 42 + 6 = 0, but (1, 6) ∉ R as 1 − 42 + 216 = 175 ≠ 0. Hence R is reflexive but not symmetric.
    [½]
Answer
(d) reflexive but not symmetric
Marking note R is not transitive either (36 R 6 and 6 R 1, but 36 R 1 would need 36 = 1 or 36 = 6), which is why (b) cannot be chosen.

Concepts to recall

  • The three tests: reflexive (a, a) ∈ R; symmetric (a, b) ∈ R ⇒ (b, a) ∈ R; transitive.
  • One counter-example is enough to disprove symmetry. Factorising helps: a2 − 7ab + 6b2 = (a − b)(a − 6b), so aRb means a = b or a = 6b.

Observe the given graph.
Assertion: The curves given above can be considered as f(x) and f−1(x).
Reason: The curves are reflections of each other across the line x = y.
(a)Both Assertion and Reason are true, and Reason is the correct explanation of Assertion.
(b)Both Assertion and Reason are true, but Reason is not the correct explanation of Assertion.
(c)Assertion is true and Reason is false.
(d)Assertion is false and Reason is true.
  1. The two curves are mirror images in the dashed line y = x (they cross it at (−1, −1), (0, 0) and (1, 1)): the Reason is true.
    [½]

ONE-MARK QUESTIONS (17)ISC 2026 Mathematics (860), Q1(ix)
Question 1(ix) · Board 2026[1]
If set A contains four elements and set B contains five elements, then the number of one-one and onto mapping from A → B is:
(a)120
(b)0
(c)720
(d)20
  1. A one-one function from A to B needs at least as many elements in B as in A, which is true here, but an onto function needs every element of B to be an image.
    [½]
  2. Four elements can have at most four distinct images, so the range has at most 4 elements and cannot equal B (5 elements). Hence no bijection exists: the number is 0.
    [½]
Answer
(b) 0
Common slip Choosing 120 = 5P4, which counts one-one maps only.

Concepts to recall

  • A bijection between finite sets exists only if the sets have the same number of elements; then the count is n!.
  • The number of one-one maps from an m-set to an n-set (m ≤ n) is nPm = 120 here, a tempting wrong answer.
ONE-MARK QUESTIONS (17)ISC 2026 Mathematics (860), Q1(xv)
Question 1(xv) · Board 2026[1]
A relation R on the set A = {a, b, c} is defined by R = {(a, b), (b, a)}. Is the relation R symmetric? Justify.
  1. R is symmetric if (x, y) ∈ R ⇒ (y, x) ∈ R. Here (a, b) ∈ R and its reverse (b, a) ∈ R; (b, a) ∈ R and its reverse (a, b) ∈ R.
    [½]
  2. Every pair has its reverse in R, so R is symmetric (it is not reflexive, as (a, a) ∉ R, but that is not asked).
    [½]
Answer
Yes, R is symmetric.

Concepts to recall

  • Symmetric: (x, y) ∈ R ⇒ (y, x) ∈ R. Reflexive: (x, x) ∈ R for all x. Transitive: (x, y), (y, z) ∈ R ⇒ (x, z) ∈ R.
  • For a relation given as a list, check each listed pair against its reverse; a missing element elsewhere in A does not matter for symmetry.
ONE-MARK QUESTIONS (17)ISC Specimen 2026 Mathematics, Q1(ix)
Question 1(ix) · Specimen 2026[1]
Statement 1: If a relation R on a set A satisfies R = R−1, then R is symmetric.
Statement 2: For a relation R to be symmetric, it is necessary that R = R−1.
(a)Statement 1 is true and Statement 2 is false.
(b)Statement 2 is true and Statement 1 is false.
(c)Both the statements are true.
(d)Both the statements are false.
  1. R−1 = {(b, a) : (a, b) ∈ R}. If R = R−1, then (a, b) ∈ R ⇒ (b, a) ∈ R−1 = R, which is exactly symmetry: Statement 1 is true.
    [½]
  2. Conversely, if R is symmetric then R−1 ⊆ R, and applying the same to R−1 gives R ⊆ R−1, so R = R−1 is necessary: Statement 2 is true. Both are true: R is symmetric ⇔ R = R−1.
    [½]
Answer
(c) Both the statements are true.

Concepts to recall

  • R is symmetric ⇔ R = R−1 (the inverse relation just reverses every pair).
  • “Necessary” means: symmetry cannot hold without it. “Sufficient” means: it is enough by itself. Here the condition is both.
ONE-MARK QUESTIONS (17)ISC Specimen 2026 Mathematics, Q1(xiii)
Question 1(xiii) · Specimen 2026[1]
If a relation R on the set {a, b, c} is defined by R = {(b, b)}, then classify the relation.
  1. Reflexive needs (a, a), (b, b) and (c, c) all in R; (a, a) and (c, c) are missing, so R is not reflexive.
    [½]
  2. (b, b) reversed is (b, b) ∈ R: symmetric. (b, b) and (b, b) give (b, b) ∈ R: transitive.
    [½]
Answer
R is symmetric and transitive but not reflexive (so it is not an equivalence relation).

Concepts to recall

  • Reflexive: (a, a) ∈ R for every element of the set. Symmetric: (a, b) ∈ R ⇒ (b, a) ∈ R. Transitive: (a, b), (b, c) ∈ R ⇒ (a, c) ∈ R.
  • Reflexivity is judged against the whole set, here three elements, not just against the pairs present in R.
ONE-MARK QUESTIONS (17)ISC Specimen 2026 Mathematics, Q1(xiv)
Question 1(xiv) · Specimen 2026[1]
The given function f : ℝ → ℝ is many-one. Give reason.
  1. From the graph, the curve meets the x-axis at three different points, x1, x2 and the origin.
    [½]
  2. Three different inputs have the same image: f(x1) = f(x2) = f(0) = 0 with x1 ≠ x2 ≠ 0. A function is one-one only if different inputs give different outputs, so f is many-one.
    [½]
Answer
Many-one: the horizontal line y = 0 cuts the graph at three points, so one image (0) has three pre-images.

Concepts to recall

  • One-one ⇔ every horizontal line cuts the graph at most once (horizontal-line test). Many-one ⇔ some horizontal line cuts it at least twice.
  • Many-one has nothing to do with onto: the range may or may not be all of ℝ.
ONE-MARK QUESTIONS (17)ISC 2025 Improvement Mathematics (860), Q1(x)
Question 1(x) · Board 2025 Imp.[1]
Consider the graph of f(x), f: ℝ → ℝ (two branches, as for y = 1/x). Statement 1: The function is one-one. Statement 2: The function is onto.
(a)Statement 1 is true and Statement 2 is false.
(b)Statement 2 is true and Statement 1 is false.
(c)Both the statements are true.
(d)Both the statements are false.
  1. Any horizontal line cuts the graph at most once (each value is taken by only one x): the function is one-one. Statement 1 true.
    [½]
  2. The graph never meets the x-axis, so 0 ∈ codomain ℝ has no pre-image; the range is ℝ − {0} ≠ ℝ. Not onto: Statement 2 false.
    [½]
Answer
(a) Statement 1 is true and Statement 2 is false.

Concepts to recall

  • Horizontal line test: one-one if every horizontal line meets the graph at most once; onto if every horizontal line (every y in the codomain) meets it at least once.
  • Onto means range = codomain.
ONE-MARK QUESTIONS (17)ISC 2025 Improvement Mathematics (860), Q1(xiii)
Question 1(xiii) · Board 2025 Imp.[1]
If R is a relation from {11, 12, 13} to {8, 10, 12} defined by y = x − 3, find the range of R−1.
  1. x = 11 gives y = 8 ∈ B; x = 12 gives 9 ∉ B; x = 13 gives 10 ∈ B. So R = {(11, 8), (13, 10)}, and R−1 = {(8, 11), (10, 13)}.
    [½]
  2. Range of R−1 = set of second elements = domain of R = {11, 13}.
    [½]
Answer
{11, 13}
Common slip Including 12 (whose image 9 is not in {8, 10, 12}) or writing the range as {8, 10}.

Concepts to recall

  • A relation from A to B is a set of ordered pairs (a, b) with a ∈ A, b ∈ B; the pair is kept only if y = x − 3 lies in the second set.
  • R−1 = {(b, a) : (a, b) ∈ R}, so domain(R−1) = range(R) and range(R−1) = domain(R).
ONE-MARK QUESTIONS (17)ISC 2025 Mathematics (860), Q1(ix)
Question 1(ix) · Board 2025[1]
Assertion: If Set A has m elements, Set B has n elements and n < m, then the number of one-one function(s) from A → B is zero.
Reason: A function f: A → B is defined only if all elements in Set A have an image in Set B.
(a)Both Assertion and Reason are true and Reason is the correct explanation for Assertion.
(b)Both Assertion and Reason are true but Reason is not the correct explanation for Assertion.
(c)Assertion is true and Reason is false.
(d)Assertion is false and Reason is true.
  1. One-one means different elements of A have different images, which needs at least m distinct elements in B. With n < m two elements of A must share an image, so no one-one function exists: Assertion true.
    [½]
  2. The Reason is a true statement about the definition of a function, but it says nothing about distinct images, so it does not explain the Assertion. (b).
    [½]
Answer
(b) Both Assertion and Reason are true but Reason is not the correct explanation for Assertion.

Concepts to recall

  • Number of one-one functions from A to B (m ≤ n): n!/(n − m)!; zero if m > n (pigeonhole principle).
  • Function: every element of the domain has exactly one image.
  • Assertion–Reason: decide each statement on its own first, then ask whether the Reason is why the Assertion holds.

Question 1(xii) · Board 2025[1]
Write the smallest equivalence relation from the set A to A, where A = {1, 2, 3}.
  1. An equivalence relation must be reflexive, so it must contain (1, 1), (2, 2), (3, 3).
    [½]
  2. This set is already symmetric and transitive, so nothing more is needed: R = {(1, 1), (2, 2), (3, 3)}, the identity relation.
    [½]
Answer
R = {(1, 1), (2, 2), (3, 3)}

Concepts to recall

  • Equivalence relation = reflexive + symmetric + transitive.

ONE-MARK QUESTIONS (17)CISCE Specimen 2025 Mathematics, Q1(ix)
Question 1(ix) · Specimen 2025[1]
Statement 1: The intersection of two equivalence relations is always an equivalence relation.
Statement 2: The union of two equivalence relations is always an equivalence relation.
Which one of the following is correct?
(a)Statement 1 implies Statement 2.
(b)Statement 2 implies Statement 1.
(c)Statement 1 is true only if Statement 2 is true.
(d)Statement 1 and 2 are independent of each other.
  1. Statement 1 is true: R ∩ S is reflexive (it contains every (a, a)), symmetric and transitive because R and S both are.
    [½]
  2. Statement 2 is false: with R = {(1,1),(2,2),(3,3),(1,2),(2,1)} and S = {(1,1),(2,2),(3,3),(2,3),(3,2)}, R ∪ S has (1,2), (2,3) but not (1,3): not transitive. Statement 1 is true while Statement 2 is false, so “Statement 2 implies Statement 1” holds (a false statement implies anything) and the other implications fail.
    [½]
Answer
(b) Statement 2 implies Statement 1.
Common slip Choosing (c): “Statement 1 true only if Statement 2 true” would make Statement 1 depend on a false statement.
Marking note CISCE’s printed key is (c). By the logic above, Statement 1 is true while Statement 2 is false, so (c) (S1 ⇒ S2) is false; (b) is the logically correct option and is the answer worked here. The key’s (c) is flagged as an error in the specimen key. (Option (d), “independent”, is also arguable for two statements with fixed truth values, so the item is ambiguous; (b) is the one the logic of the options supports.)

Concepts to recall

  • Intersection of equivalence relations is an equivalence relation; the union need not be transitive.
  • p ⇒ q is false only when p is true and q is false: true ⇒ false (option a, c) fails; false ⇒ true (option b) holds.

Question 1(xiii) · Specimen 2025[1]
If a relation R on the set {a, b, c} is defined by R = {(b, b)}, then classify the relation.
  1. Not reflexive: (a, a) and (c, c) ∉ R.
    [½]
  2. Symmetric: the only pair (b, b) is its own reverse. Transitive: no pair (x, y), (y, z) other than (b, b), (b, b) ⇒ (b, b) ∈ R.
    [½]
Answer
R is symmetric and transitive but not reflexive.

Concepts to recall

  • Reflexive: (x, x) ∈ R for every x in the set; symmetric: (x, y) ∈ R ⇒ (y, x) ∈ R; transitive: (x, y), (y, z) ∈ R ⇒ (x, z) ∈ R.
  • A relation with few pairs is often symmetric and transitive “vacuously”.

Question 1(xiv) · Specimen 2025[1]
The given function f: R → R is not ‘onto’ function. Give reason.
  1. A function is onto if every real number (every line y = k parallel to the x-axis) is the value of f for some x.
    [½]
  2. The graph has a lowest point (the minimum of the dip left of the origin); a horizontal line y = k drawn below it cuts the graph nowhere, so such a k has no pre-image: the range ≠ R.

Answer
Range is not the whole of R: a horizontal line below the lowest point of the graph meets it nowhere, so f is not onto.

Question 1(i) · Board 2024[1]
Let L be the set of all straight lines in a plane. The relation R on L defined as ‘perpendicular to’ is:
(a)Symmetric and Transitive
(b)Transitive
(c)Symmetric
(d)Equivalence
  1. Reflexive? A line is not perpendicular to itself, so R is not reflexive.
    [½]
  2. Symmetric: if l1 ⊥ l2 then l2 ⊥ l1. Transitive? If l1 ⊥ l2 and l2 ⊥ l3 then l1 ∥ l3, not ⊥; so it is not transitive.

TWO-MARK QUESTIONS (2)ISC 2026 Mathematics (860), Q3
Question 3 · Board 2026[2]
(i) Let f(x) = 4 − (x − 7)3 be an invertible function, then find f−1(x).
OR
(ii) Find the range of the function f(x) = 13 − 2 sin x.

Solution to the first alternative

  1. Put y = f(x) = 4 − (x − 7)3. Then (x − 7)3 = 4 − y.
    [1]
  2. x − 7 = (4 − y)1/3, so x = 7 + (4 − y)1/3. Interchanging the names: f−1(x) = 7 + (4 − x)1/3.
    [1]
Answer
f−1(x) = 7 + (4 − x)1/3

Solution to the OR alternative

  1. −1 ≤ sin x ≤ 1 ⇒ −2 ≤ −2 sin x ≤ 2 ⇒ 1 ≤ 3 − 2 sin x ≤ 5. The denominator is always positive, so f is defined for all real x.
    [1]
  2. Taking reciprocals (all positive) reverses the inequalities: 1/5 ≤ f(x) ≤ 1, and both ends are attained (sin x = 1 and −1). Range = [1/5, 1].
    [1]
Answer
Range = [1/5, 1]

Concepts to recall

  • To find an inverse: write y = f(x), solve for x in terms of y, then swap the letters.
  • Cube roots are defined for negative numbers too, so (4 − x)1/3 exists for every real x: f is a bijection ℝ → ℝ.
  • Check: f(f−1(x)) = 4 − (4 − x) = x.
  • Range of a function built from sin x: first bound the inner expression using −1 ≤ sin x ≤ 1.
  • Reciprocal of a positive quantity in [m, M] lies in [1/M, 1/m].
TWO-MARK QUESTIONS (2)ISC 2024 Mathematics (860), Q2
Question 2 · Board 2024[2]
(i) Let f : R − {−1/3} → R − {0} be defined as f(x) = 53x + 1 is invertible. Find f−1(x).
OR
(ii) If f : R → R is defined by f(x) = 2x − 74, show that f(x) is one-one and onto.

Solution to the first alternative

  1. Put y = f(x) = 5/(3x + 1). Then 3x + 1 = 5/y.
    [1]
  2. x = (5 − y)/(3y), so f−1(x) = 5 − x3x, x ∈ R − {0}.
    [1]
Answer
f−1(x) = (5 − x)/(3x)

Solution to the OR alternative

  1. One-one: f(x1) = f(x2) ⇒ (2x1 − 7)/4 = (2x2 − 7)/4 ⇒ x1 = x2.
    [1]
  2. Onto: let y ∈ R (co-domain). Solving (2x − 7)/4 = y gives x = (4y + 7)/2, a real number, and f((4y + 7)/2) = (4y + 7 − 7)/4 = y. Every y has a pre-image, so f is onto.
    [1]
Answer
f is one-one and onto (a bijection).

Concepts to recall

  • To find the inverse: write y = f(x), solve for x in terms of y, then rename y as x.
  • f is invertible iff it is one-one and onto; the problem tells us it is.
FIVE-MARK QUESTIONS (1)ISC Specimen 2027 Mathematics, Q16
Question 16 · Specimen 2027[5]
Also draws on: the inverse of a quadratic-in-root function; domain and range of the branches.
The graph of f(x) = x − 6√x + 1 is shown below. (i) State the natural domain of f(x). [1] (ii) Does f(x) have an inverse function? Explain your answer. [1] (iii) Let g(x) = x − 6√x + 1, 0 ≤ x ≤ 9. Find g−1(x) and verify (g ∘ g−1)(4) = 4. [1] (iv) Let h(x) = x − 6√x + 1, x ≥ 9. Find h−1(x) and verify (h ∘ h−1)(16) = 16. [1] (v) Find the value of x such that g−1(x) = h−1(x). [1]
  1. (i) √x needs x ≥ 0, so the natural domain is [0, ∞).
    [1]
  2. (ii) No. A horizontal line such as y = 1 meets the graph twice (f(0) = 1 and f(36) = 36 − 36 + 1 = 1): f fails the horizontal line test, so it is not one-one and has no inverse on [0, ∞).
    [1]
  3. (iii) Let y = x − 6√x + 1, i.e. (√x)2 − 6√x + (1 − y) = 0, so √x = 3 ± √(y + 8). On 0 ≤ x ≤ 9, √x ∈ [0, 3], so take the minus sign: g−1(x) = (3 − √(x + 8))2. Then (g ∘ g−1)(x) = (3 − √(x + 8))2 − 6(3 − √(x + 8)) + 1 = 9 − 6√(x + 8) + x + 8 − 18 + 6√(x + 8) + 1 = x (CISCE’s key then reads off 4 at x = 4; see the note).
    [1]
  4. (iv) On x ≥ 9, √x ≥ 3: take the plus sign, h−1(x) = (3 + √(x + 8))2. (h ∘ h−1)(x) = 9 + 6√(x + 8) + x + 8 − 18 − 6√(x + 8) + 1 = x. At x = 16: h−1(16) = (3 + √24)2, and (h ∘ h−1)(16) = 16. (Here √24 > 3 so √h−1 = 3 + √24 is valid.)
    [1]
  5. (v) g−1(x) = h−1(x) ⇒ (3 − √(x + 8))2 = (3 + √(x + 8))2 ⇒ 12√(x + 8) = 0 ⇒ x = −8 (the vertex value, f(9) = −8).
    [1]
Answer
(i) [0, ∞); (ii) no, not one-one; (iii) g−1(x) = (3 − √(x + 8))2 on [−8, 1]; (iv) h−1(x) = (3 + √(x + 8))2 on [−8, ∞); (v) x = −8
Common slip Choosing the wrong sign of ±√(y + 8): for g (x ≤ 9) it must be minus, for h (x ≥ 9) plus.

Concepts to recall

  • A function has an inverse iff it is one-one and onto (horizontal line test); restrict the domain to a branch where it is monotonic to get an inverse.
  • To find an inverse: write y = f(x), solve for x, swap; the branch (± sign) is chosen from the restricted domain.
  • Range of the branch = domain of the inverse: g maps [0, 9] onto [−8, 1]; h maps [9, ∞) onto [−8, ∞).
  • (f ∘ f−1)(x) = x holds for x in the range of f only.
