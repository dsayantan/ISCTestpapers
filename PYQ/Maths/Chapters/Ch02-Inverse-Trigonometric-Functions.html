What to revise

  • Principal values and simplification: cosec(sin−1(−½)) − sec(cos−1(−½)), sec−1(−√2), tan−1(2 sin(2 cos−1(√3/2))).
  • Equations: sin−1x + sin−1(1 − x) = cos−1x is the 4-mark question of both specimen 2025 and 2026; also 2 tan−1(1/3) + sec−1(5√2/7) = tan−1(…), 4 sin−1x + cos−1x = π.

ONE-MARK QUESTIONS (6)ISC Specimen 2027 Mathematics, Q1(ii)
Question 1(ii) · Specimen 2027[1]
If θ = sin−1x + cos−1x − tan−1x, x ≥ 0, then the smallest interval in which θ lies is:
(a)π/2 ≤ θ ≤ 3π/4
(b)0 < θ < π
(c)−π/4 ≤ θ ≤ 0
(d)π/4 ≤ θ ≤ π/2
  1. sin−1x and cos−1x need −1 ≤ x ≤ 1, so with x ≥ 0 we have 0 ≤ x ≤ 1. Then sin−1x + cos−1x = π/2, so θ = π/2 − tan−1x.
    [½]
  2. For 0 ≤ x ≤ 1, 0 ≤ tan−1x ≤ π/4, hence π/2 − π/4 ≤ θ ≤ π/2, i.e. π/4 ≤ θ ≤ π/2.
    [½]
Answer
(d) π/4 ≤ θ ≤ π/2

Concepts to recall

  • sin−1x + cos−1x = π/2 for −1 ≤ x ≤ 1.
  • The domain restriction is part of the question: it cuts x to [0, 1], and tan−1 is increasing, so its range is [0, π/4].
ONE-MARK QUESTIONS (6)ISC 2026 Mathematics (860), Q1(vi)
Question 1(vi) · Board 2026[1]
Statement 1: If 0 < x < π/2 then the value of tan−1(cot x) = π/2 − x
Statement 2: tan−1(tan x) = x, ∀ x ∈ ℝ
(a)Statement 1 is true and Statement 2 is false.
(b)Statement 2 is true and Statement 1 is false.
(c)Both the statements are true.
(d)Both the statements are false.
  1. Statement 1: cot x = tan(π/2 − x), and for 0 < x < π/2 we have 0 < π/2 − x < π/2, inside (−π/2, π/2). So tan−1(cot x) = π/2 − x: true.
    [½]
  2. Statement 2: tan−1(tan x) = x only for −π/2 < x < π/2. For example x = π gives tan−1(0) = 0 ≠ π: false.
    [½]
Answer
(a) Statement 1 is true and Statement 2 is false.

Concepts to recall

  • tan−1(tan x) = x only when x ∈ (−π/2, π/2) (the principal-value interval).
  • Convert to a co-function first, then check that the angle lies in the principal interval.

Find the principal value of sec−1(−√2).
  1. Let sec−1(−√2) = θ with θ ∈ [0, π], θ ≠ π/2. Then sec θ = −√2, cos θ = −1/√2.
    [½]
  2. In [0, π] the angle with cos θ = −1/√2 is θ = π − π/4 = 3π/4.
    [½]
Answer
3π/4

ONE-MARK QUESTIONS (6)ISC Specimen 2026 Mathematics, Q1(x)
Question 1(x) · Specimen 2026[1]
Assertion: The equality tan(cot−1x) = cot(tan−1x) is true for all x ∈ ℝ.
Reason: The identity tan−1x + cot−1x = π/2 is true for all x ∈ ℝ.
(a)Both Assertion and Reason are true and Reason is the correct explanation for Assertion.
(b)Both Assertion and Reason are true but Reason is not the correct explanation for Assertion.
(c)Assertion is true and Reason is false.
(d)Assertion is false and Reason is true.
  1. The Reason is a standard identity valid on all of ℝ: cot−1x = π/2 − tan−1x. It is true.
    [½]
  2. Then tan(cot−1x) = tan(π/2 − tan−1x) = cot(tan−1x), using tan(π/2 − θ) = cot θ. So the Reason directly gives the Assertion: option (a).
    [½]
Answer
(a) Both Assertion and Reason are true and Reason is the correct explanation for Assertion.
Marking note CISCE’s key is (a), followed here. Strictly, at x = 0 both sides are undefined (tan(π/2) and cot 0), so the equality is meant for every x where the two sides exist; this does not change the intended answer: write (a), as the key does.

Concepts to recall

  • tan−1x + cot−1x = π/2 for every real x (unlike sin−1 + cos−1, which needs |x| ≤ 1).
  • Complementary angles: tan(π/2 − θ) = cot θ.

Question 1(iii) · Specimen 2025[1]
The trigonometric equation tan−1 x = 3 tan−1 a has solution for
(a)|a| ≤ 1√3
(b)|a| > 1√3
(c)|a| < 1√3
(d)all real value of a.
  1. The left side is a principal value, so tan−1x ∈ (−π/2, π/2); the right side must lie in the same open interval: |3 tan−1a| < π/2.
    [½]
  2. |tan−1a| < π/6 ⇒ |a| < tan(π/6) = 1/√3. At |a| = 1/√3 the right side is ±π/2, which tan−1x never reaches, so equality is excluded.
    [½]
Answer
(c) |a| < 1√3

Concepts to recall

  • Range of tan−1: the open interval (−π/2, π/2).
  • An equation “principal value = something” has a solution only if “something” lies in the range.

TWO-MARK QUESTIONS (5)ISC Specimen 2027 Mathematics, Q6
Question 6 · Specimen 2027[2]
(i) Parag is working on a school project on right-angled triangles. He draws a right-angled triangle PQR with ∠R = 90°. The sides opposite angles P, Q, R are p, q, r respectively. Evaluate the expression: tan−1(p/(q + r)) + tan−1(q/(r + p)).
OR
(ii) The equation given below has equal roots: ax2 + sin−1(x2 − 2x + 2) + cos−1(x2 − 2x + 2) = 0. What is the value of ‘a’?

Solution to the first alternative

  1. Since ∠R = 90°, p2 + q2 = r2. Use tan−1a + tan−1b = tan−1[(a + b)/(1 − ab)] (here ab < 1).
    [½]
  2. Numerator: p/(q + r) + q/(r + p) = [p(r + p) + q(q + r)] / [(q + r)(r + p)] = (pr + p2 + q2 + qr)/[(q + r)(r + p)] = (pr + r2 + qr)/[(q + r)(r + p)].
    [½]
  3. Denominator: 1 − pq/[(q + r)(r + p)] = [(q + r)(r + p) − pq] / [(q + r)(r + p)] = (qr + pr + r2)/[(q + r)(r + p)].
    [½]
  4. The two are equal, so the argument is 1 and the sum = tan−11 = π/4.
    [½]
Answer
π/4

Solution to the OR alternative

  1. sin−1u + cos−1u = π/2, so the equation reduces to ax2 + π/2 = 0, valid only when −1 ≤ u ≤ 1, where u = x2 − 2x + 2.
    [½]
  2. u = (x − 1)2 + 1 ≥ 1, so the domain needs u ≤ 1, i.e. (x − 1)2 = 0: x = 1 is the only admissible root (the equal roots).
    [1]
  3. Substitute x = 1: a + π/2 = 0, so a = −π/2.
    [½]
Answer
a = −π/2
Marking note “Equal roots” is read as: the domain of the inverse functions admits only the single value x = 1. (The quadratic ax2 + π/2 itself would have roots ±1 for a = −π/2, but x = −1 gives u = 5, outside [−1, 1], and is rejected.)

Concepts to recall

  • tan−1a + tan−1b = tan−1[(a + b)/(1 − ab)] when ab < 1.
  • Pythagoras for the right-angled triangle: p2 + q2 = r2 turns the two expressions into the same polynomial.
  • Cross-check with a 3-4-5 triangle: tan−1(3/9) + tan−1(4/8) = tan−1(1/3) + tan−1(1/2) = π/4.
  • sin−1u + cos−1u = π/2 for −1 ≤ u ≤ 1 only: the domain restriction is the whole point.
  • Complete the square: x2 − 2x + 2 = (x − 1)2 + 1 has minimum value 1 at x = 1.

Question 6 · Specimen 2026[2]
A music streaming app uses the function f(x) = tan−1(x/10) to assign a mood score based on the number of hours a user listens to music per week. Let the listening times of two users, A and B, be 6 and 8 hours. Compute the combined mood score of user A and user B, that is, f(6) + f(8).
  1. f(6) + f(8) = tan−1(6/10) + tan−1(8/10) = tan−1(3/5) + tan−1(4/5).
    [½]
  2. The formula tan−1a + tan−1b = tan−1[(a + b)/(1 − ab)] holds when ab < 1. Here ab = 12/25 < 1.
    [½]
  3. = tan−1[(3/5 + 4/5)/(1 − 12/25)] = tan−1[(7/5)/(13/25)] = tan−1(35/13).
    [1]
Answer
Combined score = tan−1(35/13) ≈ 1·22 rad (about 69·6°)
Marking note Not simplified further: 35/13 is not a standard value, so tan−1(35/13) is the expected form.

Concepts to recall

  • tan−1a + tan−1b = tan−1[(a + b)/(1 − ab)] for ab < 1; for ab > 1 (both positive) add π.

TWO-MARK QUESTIONS (5)ISC 2025 Mathematics (860), Q3
Question 3 · Board 2025[2]
Find the value of tan−1x − cot−1x, if (tan−1x)2 − (cot−1x)2 = 5π/8.
  1. Put a = tan−1x, b = cot−1x. Then a2 − b2 = (a − b)(a + b) and a + b = π/2.
    [1]
  2. (π/2)(a − b) = 5π/8, so a − b = (5π/8) ÷ (π/2) = 5/4.
    [1]
Answer
tan−1x − cot−1x = 5/4
Marking note Taken as printed (5π/8, not 5π2/8). The answer 5/4 is attainable: a = (5/4 + π/2)/2 ≈ 1·41 lies in (−π/2, π/2), i.e. x = tan(1·41) ≈ 6·2. Had the right side been 5π2/8, a − b would be 5π/4 > π/2, which is impossible; the printed reading is the sensible one.

Concepts to recall

  • tan−1x + cot−1x = π/2 for every real x.
  • Difference of squares turns a square equation into a linear one in a − b.

Question 6 · Specimen 2025[2]
Find the value of: tan−1(x/y) + tan−1((y − x)/(y + x))
  1. Divide numerator and denominator of the second fraction by y: (y − x)/(y + x) = (1 − x/y)/(1 + x/y).
    [½]
  2. This is (1 − t)/(1 + t) with t = x/y, i.e. tan(π/4 − θ) for t = tanθ: tan−1[(1 − t)/(1 + t)] = tan−11 − tan−1t = π/4 − tan−1(x/y).
    [1]
  3. Sum = tan−1(x/y) + π/4 − tan−1(x/y) = π/4.
    [½]
Answer
π/4
Marking note The result π/4 needs x/y > −1; for x/y < −1 the sum is π/4 − π = −3π/4.

Concepts to recall

  • tan−1A − tan−1B = tan−1[(A − B)/(1 + AB)] for AB > −1; here A = 1, B = x/y.
  • Valid for x/y > −1 (the principal value of the difference lies in (−π/2, π/2)); this is the intended case.
FOUR-MARK QUESTIONS (4)ISC 2026 Mathematics (860), Q8
Question 8 · Board 2026[4]
(i) If tan−1( (√(1+x2) − √(1−x2)) / (√(1+x2) + √(1−x2)) ) = α, prove that sin 2α = x2.
OR
(ii) Solve for x: 2tan−1(1/3) + sec−1(5√2/7) = tan−1x

Solution to the first alternative

  1. Put x2 = cos 2θ with 0 ≤ 2θ ≤ π/2 (possible since 0 ≤ x2 ≤ 1 for the roots to exist).
    [1]
  2. √(1 + cos 2θ) = √2 cos θ and √(1 − cos 2θ) = √2 sin θ (both cos θ, sin θ ≥ 0 for θ ∈ [0, π/4]). The fraction becomes (cos θ − sin θ)/(cos θ + sin θ).
    [1]
  3. Divide by cos θ: (1 − tan θ)/(1 + tan θ) = tan(π/4 − θ). So α = tan−1[tan(π/4 − θ)] = π/4 − θ, as π/4 − θ ∈ [0, π/4] lies in the principal range.
    [1]
  4. 2α = π/2 − 2θ, so sin 2α = sin(π/2 − 2θ) = cos 2θ = x2. Hence proved.
    [1]
Answer
sin 2α = x2 (proved)

Solution to the OR alternative

  1. 2tan−1(1/3) = tan−1[ (2/3)/(1 − 1/9) ] = tan−1(3/4).
    [1]
  2. Let sec−1(5√2/7) = φ. Then sec φ = 5√2/7, tan φ = √(sec2φ − 1) = √(50/49 − 1) = 1/7 (φ is acute). So sec−1(5√2/7) = tan−1(1/7).
    [1]
  3. tan−1(3/4) + tan−1(1/7) = tan−1[ (3/4 + 1/7)/(1 − 3/28) ] = tan−1[ (25/28)/(25/28) ] = tan−11 (the product 3/28 < 1, so the formula applies).
    [1]
  4. Hence tan−1x = tan−11, so x = 1.
    [1]
Answer
x = 1

Concepts to recall

  • Substitution x2 = cos 2θ removes both roots: 1 + cos 2θ = 2cos2θ, 1 − cos 2θ = 2sin2θ.
  • (1 − tan θ)/(1 + tan θ) = tan(π/4 − θ).
  • Cancelling tan−1 with tan needs the angle inside (−π/2, π/2); say so.
  • 2tan−1a = tan−1[2a/(1 − a2)] for |a| < 1.
  • sec−1u = tan−1√(u2 − 1) for u ≥ 1.
  • tan−1a + tan−1b = tan−1[(a + b)/(1 − ab)] when ab < 1.
FOUR-MARK QUESTIONS (4)ISC Specimen 2026 Mathematics, Q7
Question 7 · Specimen 2026[4]
Solve: sin−1(x) + sin−1(1 − x) = cos−1x.
  1. Use cos−1x = π/2 − sin−1x: sin−1(1 − x) = π/2 − 2 sin−1x.
    [1]
  2. Let θ = sin−1x (so sin θ = x). Take the sine of both sides: 1 − x = sin(π/2 − 2θ) = cos 2θ = 1 − 2 sin2θ = 1 − 2x2.
    [1]
  3. 2x2 − x = 0 ⇒ x(2x − 1) = 0 ⇒ x = 0 or x = 1/2.
    [1]
  4. Check (squaring-type steps can add roots): x = 0: 0 + π/2 = π/2 = cos−10 ✓. x = 1/2: π/6 + π/6 = π/3 = cos−1(1/2) ✓. Both satisfy the equation.
    [1]
Answer
x = 0 or x = 1/2

Concepts to recall

  • cos−1x = π/2 − sin−1x for |x| ≤ 1; cos 2θ = 1 − 2 sin2θ.
  • Taking the sine of both sides of an inverse-trig equation can introduce extra roots, so substitute the answers back.
  • Domain: sin−1x needs |x| ≤ 1 and sin−1(1 − x) needs 0 ≤ x ≤ 2, so x ∈ [0, 1] (both roots lie in it).

Question 7 · Specimen 2025[4]
Solve: sin−1(x) + sin−1(1 − x) = cos−1x.
  1. Domain: −1 ≤ x ≤ 1 and −1 ≤ 1 − x ≤ 1, so 0 ≤ x ≤ 1. Use cos−1x = π/2 − sin−1x.
    [1]
  2. sin−1(1 − x) = π/2 − 2 sin−1x. Take sine of both sides: 1 − x = sin(π/2 − 2 sin−1x) = cos(2 sin−1x).
    [1]
  3. Put θ = sin−1x: cos 2θ = 1 − 2 sin2θ = 1 − 2x2. So 1 − x = 1 − 2x2 ⇒ 2x2 − x = 0 ⇒ x(2x − 1) = 0.
    [1]
  4. x = 0 or x = 1/2. Check: x = 0: 0 + π/2 = π/2 = cos−10 ✓. x = 1/2: π/6 + π/6 = π/3 = cos−1(1/2) ✓. Both accepted.
    [1]
Answer
x = 0 or x = 1/2

  • sin−1x + cos−1x = π/2 for −1 ≤ x ≤ 1.
  • cos 2θ = 1 − 2 sin2θ: turn the inverse-trig equation into a polynomial.

FOUR-MARK QUESTIONS (4)ISC 2024 Mathematics (860), Q8
Question 8 · Board 2024[4]
(i) Solve for x: sin−1(x2) + cos−1 x = π6
OR
(ii) If sin−1x + sin−1y + sin−1z = π, show that x2 − y2 − z2 + 2yz√(1 − x2) = 0.

Solution to the first alternative

  1. Write sin−1(x/2) = π/6 − cos−1x and take sine: x/2 = sin(π/6) cos(cos−1x) − cos(π/6) sin(cos−1x).
    [1½]
  2. cos(cos−1x) = x, sin(cos−1x) = √(1 − x2). So x/2 = x/2 − (√3/2)√(1 − x2), giving √(1 − x2) = 0 and x = ±1.
    [1½]
  3. Check: x = 1 gives π/6 + 0 = π/6 (valid); x = −1 gives −π/6 + π = 5π/6 ≠ π/6 (rejected).
    [1]
Answer
x = 1
Marking note Full marks for x = 1 with the rejection of −1 shown; a candidate who stops at ±1 loses the last mark.

Solution to the OR alternative

  1. Let sin−1x = A, sin−1y = B, sin−1z = C, so A + B + C = π and B + C = π − A.
    [1]
  2. Take cosine: cos(B + C) = −cos A, i.e. cosB cosC − sinB sinC = −cosA.
    [1]
  3. cos B = √(1 − y2), cos C = √(1 − z2), cos A = √(1 − x2): √(1−y2)√(1−z2) = yz − √(1−x2).
    [1]
  4. Square: (1 − y2)(1 − z2) = y2z2 − 2yz√(1−x2) + 1 − x2. Expanding: 1 − y2 − z2 + y2z2 = y2z2 + 1 − x2 − 2yz√(1−x2), so x2 − y2 − z2 + 2yz√(1−x2) = 0.
    [1]
Answer
Proved.

Concepts to recall

  • sin(A − B) = sinA cosB − cosA sinB.
  • sin(cos−1x) = √(1 − x2) because the angle lies in [0, π].
  • Taking a sine can introduce extra roots; always verify in the original equation.
  • Substitute angles A, B, C so that sine is x, y, z and the radicals are the cosines.
  • cos(π − A) = −cos A.
  • The radical √(1−x2) is the target, so use the cosine form (not the sine form) of B + C.
SIX-MARK QUESTIONS (2)ISC 2025 Improvement Mathematics (860), Q14
Question 14 · Board 2025 Imp.[6]
Consider the function y = sin−1(2x√1 − x2), x ∈ [−1/√2, 1/√2].
(i) Find the range of y if x = 0, 1/2 and −1/2. [1]   (ii) Prove: 2 sin−1x = sin−1(2x√1 − x2). [1]
(iii) Evaluate: tan−1(2 cos(2 sin−1½)). [2]   (iv) If 4 sin−1x + cos−1x = π, calculate the value of x. [2]
  1. (i)
  2. x = 0: y = sin−10 = 0. x = 1/2: 2(½)(√3/2) = √3/2, so y = sin−1(√3/2) = π/3. x = −1/2: y = sin−1(−√3/2) = −π/3. Values taken: 0, π/3, −π/3.
    [1]
  3. (ii) Let x = sin θ, θ ∈ [−π/4, π/4] (since |x| ≤ 1/√2). Then 2x√1 − x2 = 2 sin θ cos θ = sin 2θ. As 2θ ∈ [−π/2, π/2] (the principal range), sin−1(sin 2θ) = 2θ = 2 sin−1x. Proved.
    [1]
  4. (iii) sin−1½ = π/6, so 2 sin−1½ = π/3 and cos(π/3) = ½.
    [1]
  5. 2 cos(π/3) = 1, and tan−1(1) = π/4.
    [1]
  6. (iv) cos−1x = π/2 − sin−1x, so 4 sin−1x + π/2 − sin−1x = π, i.e. 3 sin−1x = π/2.
    [1]
  7. sin−1x = π/6, so x = sin(π/6) = 1/2.
    [1]
Answer
(i) 0, π/3, −π/3; (ii) proved; (iii) π/4; (iv) x = 1/2.
Marking note In part (i) "range" is read as the values of y for those three inputs. Part (ii) holds only on the stated interval; outside it the right side equals π − 2 sin−1x or −π − 2 sin−1x.

Concepts to recall

  • Principal value ranges: sin−1: [−π/2, π/2]; cos−1: [0, π]; tan−1: (−π/2, π/2).
  • sin−1(sin u) = u only if u ∈ [−π/2, π/2]: the restriction |x| ≤ 1/√2 is exactly what keeps 2θ in this range.
  • sin−1x + cos−1x = π/2; substitution x = sin θ turns √1 − x2 into cos θ.

Question 13 · Board 2025[6]
Observe the two graphs, Graph 1 and Graph 2 given (redrawn below) and answer the questions that follow. (i) Which one of the graphs represents y = sin−1x? [1] (ii) Write the domain and range of y = sin−1x. [1] (iii) Prove that sin−1(1/√5) + sin−1(2/√5) = π/2. [2] (iv) Find the value of tan−1[2 sin(2 cos−1(√3/2))]. [2]
  1. (i) Graph 2. sin−1x is the mirror image of sin x (on [−π/2, π/2]) in the line y = x; sin x flattens at its ends (Graph 1), so its inverse becomes vertical at x = ±1 (Graph 2).
    [1]
  2. (ii) Domain [−1, 1]; range [−π/2, π/2].
    [1]
  3. (iii) Let α = sin−1(1/√5). Then sin α = 1/√5 and cos α = √(1 − 1/5) = 2/√5, so α = cos−1(2/√5).
    [1]
  4. LHS = cos−1(2/√5) + sin−1(2/√5) = π/2, since sin−1t + cos−1t = π/2 for t ∈ [−1, 1]. Hence proved.
    [1]
  5. (iv) cos−1(√3/2) = π/6, so 2 cos−1(√3/2) = π/3 and sin(π/3) = √3/2.
    [1]
  6. 2 · √3/2 = √3, and tan−1(√3) = π/3.
    [1]
Answer
(i) Graph 2; (ii) domain [−1, 1], range [−π/2, π/2]; (iii) proved; (iv) π/3.

Concepts to recall

  • Principal branches: sin−1: [−1, 1] → [−π/2, π/2]; cos−1: [−1, 1] → [0, π]; tan−1: ℜ → (−π/2, π/2).
  • The graph of an inverse function is the reflection of the original in the line y = x: flat ends become vertical ends.
  • sin−1x + cos−1x = π/2; evaluate nested expressions from the inside out.
