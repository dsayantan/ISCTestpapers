What to revise

  • Properties without expanding: factorise using row/column operations: 3 × 3 determinants that equal (a − b)(b − c)(c − a)(a + b + c), vanish when x + y + z = 0, or equal the permuted form of specimen 2027 Q13. Show each valid operation.

  • One-markers: |−4A| for order 3, |adj A|, the determinant of the cofactor matrix, when a matrix is singular, when a 2-equation system has a unique solution, area of a triangle as a determinant.
  • Habit: multiplying a row by k multiplies the determinant by k; for order n, |kA| = kn|A|.

Question 1(iii) · Specimen 2027[1]
Let A be the area of a triangle having vertices (x1, y1), (x2, y2) and (x3, y3). Which of the following is correct?
(a)x1y11x2y21x3y31 = +A
(b)x1y11x2y21x3y31 = ±2A
(c)x1y11x2y21x3y31 = ±A/2
(d)x1y11x2y21x3y31 = A2
  1. The area of the triangle is A = ½ |Δ|, where Δ is the determinant of the coordinates with a column of 1s.
    [½]
  2. The determinant may be positive or negative (it depends on the order of the vertices), so Δ = ±2A.
    [½]
Answer
(b) x1y11x2y21x3y31 = ±2A

Concepts to recall

  • Area of a triangle = ½ × (absolute value of the 3 × 3 determinant of the vertices with a column of 1s).
  • The area is never negative, which is why the ± appears when the determinant itself is written equal to a multiple of A.

Question 1(i) · Board 2026[1]
If A is a square matrix of order 3 and its determinant is |A| = −3, then the value of |−4A| is:
(a)202
(b)192
(c)−212
(d)−192
  1. For a square matrix of order n, |kA| = kn|A|. Here n = 3 and k = −4.
    [½]
  2. |−4A| = (−4)3|A| = (−64)(−3) = 192.
    [½]
Answer
(b) 192
Common slip Writing |−4A| = −4|A| = 12.

Concepts to recall

  • |kA| = kn|A| for a matrix of order n (every one of the n rows gets the factor k).
  • Do not confuse it with the scalar multiple of the matrix elements: the determinant picks up k3, not k.
ONE-MARK QUESTIONS (12)ISC 2026 Mathematics (860), Q1(xi)
Question 1(xi) · Board 2026[1]
Assertion: The system of three linear equations in three unknown variables can be written in the matrix form as AX = B. It has a unique solution X = A−1B.
Reason: Matrix A is non-singular.
(a)Both Assertion and Reason are true and Reason is the correct explanation for Assertion.
(b)Both Assertion and Reason are true but Reason is not the correct explanation for Assertion.
(c)Assertion is true and Reason is false.
(d)Assertion is false and Reason is true.
  1. AX = B has the unique solution X = A−1B exactly when A−1 exists, i.e. when |A| ≠ 0, i.e. A is non-singular.
    [½]
  2. So the Reason (A non-singular) is the condition under which the Assertion holds: both are true and the Reason explains the Assertion.
    [½]
Answer
(a) Both Assertion and Reason are true and Reason is the correct explanation for Assertion.

Concepts to recall

  • A−1 exists ⇔ |A| ≠ 0 (A non-singular). Then AX = B has the unique solution X = A−1B.
  • If |A| = 0 the system is either inconsistent (adj A · B ≠ O) or has infinitely many solutions.

Question 1(xiii) · Board 2026[1]
Solve for x: 1−252x−1042x = 86.
  1. Expand along the first row: 1(2x2 + 4) + 2(4x − 0) + 5(8 − 0) = 2x2 + 8x + 44.
    [½]
  2. 2x2 + 8x + 44 = 86 ⇒ x2 + 4x − 21 = 0 ⇒ (x + 7)(x − 3) = 0, so x = 3 or x = −7.
    [½]
Answer
x = 3 or x = −7
Common slip Sign slip on the middle term: the cofactor of −2 carries a minus, giving +2·(4x).

Concepts to recall

  • Expansion of a 3 × 3 determinant along any row/column: Σ (element × its cofactor), signs + − + / − + − / + − +.

ONE-MARK QUESTIONS (12)ISC Specimen 2026 Mathematics, Q1(iv)
Question 1(iv) · Specimen 2026[1]
Consider Δ = |2a 2b 2c ; 2e f g ; 2i j k|.
Assertion: The value of Δ = 4 × |a b c ; e f g ; i j k|.
Reason: If all elements of one row or one column of a determinant are multiplied by a scalar k, then the value of the determinant is multiplied by k.
(a)Both Assertion and Reason are true, and Reason is the correct explanation for Assertion.
(b)Both Assertion and Reason are true, but Reason is not the correct explanation for Assertion.
(c)Assertion is true and Reason is false.
(d)Assertion is false and Reason is true.
  1. Reason: multiplying every element of one row (or one column) by k multiplies the determinant by k: a standard property, so the Reason is true.
    [½]
  2. In Δ only the first row (2a, 2b, 2c) carries the factor 2; the other rows are unchanged. So Δ = 2 × |a b c; e f g; i j k|, not 4 ×. The Assertion is false.
    [½]
Answer
(d) Assertion is false and Reason is true.
Common slip Counting a 2 against each of the three entries of the row and writing 22, 23 or 4.

Concepts to recall

  • Taking a factor out of one row gives one factor; the factor 23 = 8 arises only when every row is doubled, i.e. |2A| = 8|A| for order 3.
  • Assertion–Reason: test each statement separately first; only then ask whether the Reason explains the Assertion.
ONE-MARK QUESTIONS (12)ISC Specimen 2026 Mathematics, Q1(xii)
Question 1(xii) · Specimen 2026[1]
The value of the determinant of a matrix A of order 3 is 3. If C is the matrix of cofactors of the matrix A, then what is the value of the determinant of C2?
  1. C is the cofactor matrix, so C = (adj A)′ and |C| = |adj A| = |A|n−1 = 32 = 9.
    [½]
  2. |C2| = |C||C| = 9 × 9 = 81.
    [½]
Answer
|C2| = 81
Common slip Using |A|n = 27 for |adj A|, which gives 729.

Concepts to recall

  • |adj A| = |A|n−1 for a matrix of order n; the cofactor matrix is the transpose of adj A and has the same determinant.
  • |AB| = |A||B|, so |C2| = |C|2.

Question 1(i) · Board 2025 Imp.[1]
Find the value of μ if the following system of equations is consistent: 2x + 3y − 8 = 0,  7x − 5y + 3 = 0,  4x − 6y + μ = 0.
(a)4
(b)6
(c)8
(d)2
  1. Solve the first two equations: 2x + 3y = 8 and 7x − 5y = −3. Eliminating y: 31x = 31, so x = 1 and y = 2.
    [½]
  2. Three lines are consistent only if the common point also satisfies the third: 4(1) − 6(2) + μ = 0, so μ = 8.
    [½]
Answer
(c) 8

Concepts to recall

  • Three equations in two unknowns are consistent when the solution of two of them satisfies the third (equivalently, the 3 × 3 determinant of coefficients is 0).
  • Check by determinant: |2 3 −8; 7 −5 3; 4 −6 μ| = 0 gives μ = 8.
ONE-MARK QUESTIONS (12)ISC 2025 Improvement Mathematics (860), Q1(xi)
Question 1(xi) · Board 2025 Imp.[1]
The sum 2xyzpqrabc + xyzstu2a2b2c is equal to which one of the following?
(a)3x3y3z2p + s2q + t2r + u4a4b4c
(b)2x2y2z2p + s2q + t2r + u2a2b2c
(c)xyzp + sq + tr + u2a2b2c
(d)2x2y2zp + sq + tr + u4a4b4c
  1. A factor 2 can be taken into one row of a determinant: 2D1 is D1 with its third row multiplied by 2, i.e. rows (x, y, z), (p, q, r), (2a, 2b, 2c).
    [½]
  2. Now the two determinants agree in rows 1 and 3, so they add by adding the second rows: (p + s, q + t, r + u). This is option (c).
    [½]
Answer
(c) xyzp + sq + tr + u2a2b2c
Common slip Multiplying every row by 2 gives 8D, not 2D (options (a), (b) and (d) make that error).

Concepts to recall

  • Property: if the elements of one row are written as sums, the determinant splits into the sum of two determinants; conversely two determinants that differ in only one row add by adding that row.
  • A scalar multiplier k multiplies one row (or column) only, not the whole determinant: k·D = D with one row multiplied by k.

Question 1(xiv) · Board 2025 Imp.[1]
For what value of a is the matrix A = [(1, −2, 3), (1, 2, 1), (a, 2, −3)] not invertible?
  1. A is not invertible when |A| = 0. |A| = 1(−6 − 2) + 2(−3 − a) + 3(2 − 2a) = −8 − 6 − 2a + 6 − 6a = −8 − 8a.
    [½]
  2. −8 − 8a = 0, so a = −1.
    [½]
Answer
a = −1
Common slip Sign error on the middle term (−(−2)M12 = +2M12).

Concepts to recall

  • A square matrix is invertible (non-singular) exactly when |A| ≠ 0.
  • Expand along the first row: |A| = a11M11 − a12M12 + a13M13, watching the sign of the middle term.

Question 1(vi) · Board 2025[1]
The existence of unique solution of the system of equations x + y = λ and 5x + ky = 2 depends on:
(a)λ only
(b)λ/k = 1
(c)both k and λ
(d)k only
  1. Coefficient determinant: |A| = 115k = k − 5.
    [½]
  2. A unique solution exists iff |A| ≠ 0, i.e. k ≠ 5. The constants λ and 2 do not enter this test: it depends on k only.
    [½]
Answer
(d) k only

Concepts to recall

  • For AX = B with a square A: |A| ≠ 0 ⇔ a unique solution; |A| = 0 ⇒ none or infinitely many (decided by (adj A)B).

Question 1(vi) · Specimen 2025[1]
If abcmnpxyz = k, then what is the value of 6a2b2c3mnp3xyz ?
(a)k6
(b)2k
(c)3k
(d)6k
  1. Take the common factor 3 out of the first column (6a, 3m, 3x): the determinant becomes 3 × the one with first row (2a, 2b, 2c) and rows 2, 3 = (m, n, p), (x, y, z).
    [½]

  • A common factor of a single row or column may be taken out of a determinant.

TWO-MARK QUESTIONS (2)ISC 2026 Mathematics (860), Q2
Question 2 · Board 2026[2]
Using properties of determinant, show that: b − cc − aa − bc − aa − bb − c2(a − b)2(b − c)2(c − a) = 0
  1. Let Δ be the determinant. Apply C1 → C1 + C2 + C3 (adding columns does not change the value).
    [1]
  2. New C1: row 1 = (b − c) + (c − a) + (a − b) = 0; row 2 = (c − a) + (a − b) + (b − c) = 0; row 3 = 2[(a − b) + (b − c) + (c − a)] = 0. A determinant with a whole column of zeros is 0, so Δ = 0. Hence shown.
    [1]
Answer
Δ = 0 (shown)
Marking note Row 3 is not a multiple of row 1, so “two proportional rows” is not available; the column-sum route is the intended one. The row route R3 → R3 + 2R1 + 2R2 (which gives a zero row, since R1 + R2 = −R3/2) is equally acceptable.

Concepts to recall

  • C1 → C1 + C2 + C3 leaves the value unchanged (adding multiples of other columns).
  • A determinant with a zero row or zero column equals 0.
  • Spot the pattern: each row has three terms that sum to zero ((b−c) + (c−a) + (a−b) = 0), the cue for adding the columns.

Question 3 · Board 2024[2]
Find the value of the determinant given below, without expanding it at any stage.
βγ1α(β + γ)γα1β(γ + α)αβ1γ(α + β)
  1. Apply C1 → C1 + C3. The first column becomes βγ + αβ + αγ, γα + βγ + βα, αβ + γα + γβ: each entry equals αβ + βγ + γα = s.
    [1]
  2. Now C1 = (s, s, s)T = s × C2, two proportional columns, so the determinant is 0.
    [1]
Answer
0

Concepts to recall

  • Operation Ci → Ci + kCj leaves a determinant unchanged.
  • A determinant with two identical or proportional rows or columns is 0.
  • Look for a common symmetric sum (αβ + βγ + γα) that appears when two columns are added.
THREE-MARK QUESTIONS (1)ISC Specimen 2027 Mathematics, Q13
Question 13 · Specimen 2027[3]
(i) If x, y, z are distinct non-zero real numbers, prove that Δ = xx2yzyy2zxzz2xy = y2z2x2y3z3x3111. Hence or otherwise evaluate Δ in its simplest form if xy + yz + zx = 1.
  1. Proof. Multiply R1, R2, R3 by x, y, z and divide by xyz: Δ = (1/xyz) x2x3xyzy2y3xyzz2z3xyz. Take xyz out of C3: Δ = x2x31y2y31z2z31.
    [½]
  2. Interchange rows and columns (|M| = |M′|): Δ = x2y2z2x3y3z3111.
    [½]
  3. Move the columns cyclically (C1 → C2 → C3 → C1), which is two interchanges and so leaves the sign unchanged: Δ = y2z2x2y3z3x3111. Hence proved.
    [½]
  4. Evaluation. From Δ = x2x31y2y31z2z31 apply R1 → R1 − R2, R2 → R2 − R3 and take out (x − y) and (y − z): Δ = (x − y)(y − z) x + yx2 + xy + y20y + zy2 + yz + z20z2z31.
    [½]
  5. R2 → R2 − R1 gives (z − x, (z − x)(x + y + z), 0); take out (z − x): Δ = (x − y)(y − z)(z − x) x + yx2 + xy + y201x + y + z0z2z31.
    [½]
  6. Expand along C3: the determinant = (x + y)(x + y + z) − (x2 + xy + y2) = xy + yz + zx = 1. So Δ = (x − y)(y − z)(z − x).
    [½]
Answer
Δ = (x − y)(y − z)(z − x)(xy + yz + zx) = (x − y)(y − z)(z − x)
Common slip Multiplying the rows by x, y, z without dividing by xyz, which multiplies Δ by xyz. Do R1 → R1 − R2 before R2 → R2 − R3, so that the old R2 is used.

Concepts to recall

  • Row-operation rules: multiplying a row by k multiplies the determinant by k (so divide by k to compensate); Ri → Ri − Rj leaves it unchanged; interchanging two rows or columns flips the sign.
  • |M| = |M′|: rows and columns may be swapped. A cyclic shift of three columns is an even permutation, so no sign change.
  • Differences of powers factorise: x2 − y2 = (x − y)(x + y), x3 − y3 = (x − y)(x2 + xy + y2).

Question 7 · Board 2026[4]
Vinayak runs a bakery shop. He sells three items: Sandwiches (₹x per unit), Fruit juices (₹y per unit) and Cookies (₹z per unit). The sales revenue over three days are 37, 26 and 37 respectively. The entire information is given below as matrix equation.
231123311xyz = 372637
Consider A = 231123311 and |A| = 17. Find the price per unit for each item using matrix method.
  1. The system is AX = B with |A| = 17 ≠ 0, so A−1 exists and X = A−1B = (1/|A|)(adj A)B.
    [½]
  2. Cofactors: C11 = 2·1 − 3·1 = −1; C12 = −(1·1 − 3·3) = 8; C13 = 1·1 − 2·3 = −5; C21 = −(3·1 − 1·1) = −2; C22 = 2·1 − 1·3 = −1; C23 = −(2·1 − 3·3) = 7; C31 = 3·3 − 1·2 = 7; C32 = −(2·3 − 1·1) = −5; C33 = 2·2 − 3·1 = 1.
    [1]
  3. adj A = (cofactor matrix)′ = −1−278−1−5−571, so A−1 = (1/17) adj A.
    [1]
  4. X = (1/17)−1−278−1−5−571372637 = (1/17)−37 − 52 + 259296 − 26 − 185−185 + 182 + 37 = (1/17)1708534 = 1052
    [1]
  5. So x = 10, y = 5, z = 2: a sandwich costs ₹10, a fruit juice ₹5 and a cookie ₹2. (Check: 2·10 + 3·5 + 2 = 37; 10 + 10 + 6 = 26; 30 + 5 + 2 = 37.)
    [½]
Answer
Sandwich ₹10, fruit juice ₹5, cookie ₹2 per unit.
Common slip Forgetting to transpose the cofactor matrix gives wrong prices that still look plausible.

Concepts to recall

  • Matrix method: AX = B ⇒ X = A−1B when |A| ≠ 0, with A−1 = adj A / |A|.
  • adj A is the transpose of the cofactor matrix; cofactor Cij = (−1)i+j × minor.
  • Always verify by substituting back in the three equations: it catches any cofactor slip.
FOUR-MARK QUESTIONS (3)ISC 2025 Improvement Mathematics (860), Q7
Question 7 · Board 2025 Imp.[4]
Using the properties of determinants, prove that 111abca3b3c3 = (a − b)(b − c)(c − a)(a + b + c)
  1. Apply C1 → C1 − C2, then C2 → C2 − C3: LHS = 001a − bb − cca3 − b3b3 − c3c3
    [1]
  2. Take (a − b) out of C1 and (b − c) out of C2, using a3 − b3 = (a − b)(a2 + ab + b2) and similarly for b, c: LHS = (a − b)(b − c) 00111ca2 + ab + b2b2 + bc + c2c3
    [1]
  3. Expand along R1 (only the third entry, 1, is non-zero; its cofactor has sign +): determinant = (b2 + bc + c2) − (a2 + ab + b2) = bc + c2 − a2 − ab.
    [1]
  4. bc + c2 − a2 − ab = (c − a)(c + a) + b(c − a) = (c − a)(a + b + c). Hence LHS = (a − b)(b − c)(c − a)(a + b + c) = RHS. Proved.
    [1]
Answer
LHS = (a − b)(b − c)(c − a)(a + b + c) = RHS (proved).
Marking note The 2 × 2 minor of the (1, 3) entry is rows 2, 3 and columns 1, 2: with the common factors removed it is (b2+bc+c2) − (a2+ab+b2) as shown. Award full marks for any valid route (e.g. R2, R3 operations).

Concepts to recall

  • Value of a determinant is unchanged by Ci → Ci − kCj (i ≠ j); the operations are done one after the other, each on the current columns.
  • A common factor of a whole column can be taken outside the determinant.
  • Expanding along a row or column with two zeros reduces the work to one 2 × 2 minor. Identity: x3 − y3 = (x − y)(x2 + xy + y2).
FOUR-MARK QUESTIONS (3)ISC 2025 Mathematics (860), Q7
Question 7 · Board 2025[4]
If x + y + z = 0 then show that 111xyzx3y3z3 = 0, using properties of determinant.
  1. Let Δ be the determinant. Apply C2 → C2 − C1, C3 → C3 − C1:
    Δ = 100xy − xz − xx3y3 − x3z3 − x3
    [1]
  2. Take (y − x) out of C2 and (z − x) out of C3, using a3 − b3 = (a − b)(a2 + ab + b2):
    Δ = (y − x)(z − x) 100x11x3x2 + xy + y2x2 + xz + z2
    [1]
  3. Expand along R1: Δ = (y − x)(z − x)[(x2 + xz + z2) − (x2 + xy + y2)] = (y − x)(z − x)[(z − y)(z + y) + x(z − y)]
    [1]
  4. = (y − x)(z − x)(z − y)(x + y + z) = 0, because x + y + z = 0. Hence proved.
    [1]
Answer
Δ = (y − x)(z − x)(z − y)(x + y + z) = 0.
Common slip Expanding the original determinant and using x3 + y3 + z3 = 3xyz only: the expansion does not contain that sum, so that route is not a proof.

Concepts to recall

  • Column operation Cj → Cj − Ci leaves a determinant unchanged; a common factor of a column may be taken outside.
  • Expanding along a row that is (1, 0, 0) reduces a 3×3 determinant to one 2×2 minor.
  • The factor (x + y + z) appearing is what lets the given condition kill the whole determinant.

Question 20 · Specimen 2027[5]

A ball is thrown vertically downwards from the top of a cliff, and its position is tracked from when it is first thrown until it hits the ground (at which point it may be assumed that the ball comes instantaneously to rest). The height of the ball above the ground after t seconds is given by the equation S(t) = at2 + bt + c, where a, b and c are real constants and the height S is measured in metres. It is observed that after 1 second the ball is 285 m above the ground; after 2 seconds its height is 260 m and after 4 seconds it is 180 m. Set up and solve a matrix equation to find the height of the cliff.
  1. S(1) = 285: a + b + c = 285; S(2) = 260: 4a + 2b + c = 260; S(4) = 180: 16a + 4b + c = 180. In matrix form AX = B: 1114211641abc = 285260180.

    [1]

    [1]
