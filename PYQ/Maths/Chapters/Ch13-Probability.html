Question 1(xv) · Specimen 2027[1]
If P(A) = m, P(B | Ā) = 3m, P(B | A) = 6m, then what will be P(A | B)?
(a)2m/(1 + m)
(b)4m/(1 + m)
(c)7m/(1 + m)
(d)9m/(1 + m)
  1. P(B ∩ A) = P(A)P(B | A) = 6m2; P(B ∩ Ā) = P(Ā)P(B | Ā) = (1 − m)(3m) = 3m − 3m2.
    [½]
  2. P(B) = 6m2 + 3m − 3m2 = 3m + 3m2. P(A | B) = 6m2/(3m + 3m2) = 2m/(1 + m).
    [½]
Answer
(a) 2m/(1 + m)

Concepts to recall

  • Bayes’ theorem: P(A | B) = P(A)P(B | A) / [P(A)P(B | A) + P(Ā)P(B | Ā)].
  • Remember P(Ā) = 1 − P(A) = 1 − m.

Question 1(iii) · Board 2026[1]
If events A and B are mutually exclusive, such that P(A) = 1/5 and P(B) = 2/3, then the value of P(A ∪ B) is:
(a)11/15
(b)3/15
(c)14/15
(d)13/15
  1. Mutually exclusive: P(A ∩ B) = 0, so P(A ∪ B) = P(A) + P(B) − P(A ∩ B) = P(A) + P(B).
    [½]
  2. = 1/5 + 2/3 = 3/15 + 10/15 = 13/15.
    [½]
Answer
(d) 13/15

Concepts to recall

  • Addition theorem: P(A ∪ B) = P(A) + P(B) − P(A ∩ B).
  • Mutually exclusive events cannot occur together: P(A ∩ B) = 0 (not P(A)P(B), which is for independent events).
ONE-MARK QUESTIONS (16)ISC Specimen 2026 Mathematics, Q1(v)
Question 1(v) · Specimen 2026[1]
Five numbers x1, x2, x3, x4, x5 are randomly selected from the numbers 1, 2, 3, …, 18 and arranged in increasing order such that x1 < x2 < x3 < x4 < x5. What is the probability that x2 = 7 and x4 = 11?
(a)26/51
(b)3/104
(c)1/68
(d)1/34
  1. Number of ways to choose 5 numbers from 18: 18C5 = 8568 (the increasing order is then forced).
    [½]
  2. x2 = 7 and x4 = 11: x1 from {1…6} (6 ways), x3 from {8, 9, 10} (3 ways), x5 from {12…18} (7 ways): 6 × 3 × 7 = 126. Probability = 126/8568 = 1/68.
    [½]
Answer
(c) 1/68

Concepts to recall

  • Choosing 5 numbers and sorting them: the sample space is a combination, 18C5, not a permutation.
  • Fixing the 2nd and 4th smallest splits the rest into three independent gaps: below 7, between 7 and 11, above 11.
ONE-MARK QUESTIONS (16)ISC Specimen 2026 Mathematics, Q1(xi)
Question 1(xi) · Specimen 2026[1]
Given two events A and B such that P(A | B) = 0·25 and P(A ∩ B) = 0·12. The value P(A′ ∩ B) is:
(a)0·36
(b)0·48
(c)0·88
(d)0·036
  1. P(A | B) = P(A ∩ B)/P(B) ⇒ P(B) = 0·12/0·25 = 0·48.
    [½]
  2. B splits into (A ∩ B) and (A′ ∩ B): P(A′ ∩ B) = P(B) − P(A ∩ B) = 0·48 − 0·12 = 0·36.
    [½]
Answer
(a) 0·36
Common slip Choosing 0·48, which is P(B) itself.

Concepts to recall

  • Conditional probability: P(A | B) = P(A ∩ B)/P(B).
  • P(A′ ∩ B) = P(B) − P(A ∩ B), because B = (A ∩ B) ∪ (A′ ∩ B), a disjoint union.

Question 1(xv) · Specimen 2026[1]
There are three machines and 2 of them are faulty. They are tested one by one in a random order till both the faulty machines are identified. What is the probability that only two tests are needed to identify the faulty machines?
  1. Two tests are needed when the first machine tested is faulty: whether the second is good (the third is then faulty) or faulty (both found), the pair is known after two tests. [If the first is good, the other two must both be faulty after a single test.]
    [½]
  2. P = (2/3)(1/2) + (2/3)(1/2) = 1/3 + 1/3 = 2/3.
    [½]
Answer
2/3
Marking note CISCE’s key adds the two branches “first faulty, second good” and “both faulty”, each with probability 1/3; the sum equals P(first machine faulty) = 2/3.

Concepts to recall

  • Multiply along a branch of the tree and add the branches that lead to the event.
  • Think about what the tests reveal: with 2 faulty out of 3, one good machine found means the other two are faulty without any further test.

Question 1(ix) · Board 2025 Imp.[1]
If P(A) = 3/10, P(B) = 2/5 and P(A ∪ B) = 3/5, then the value of P(A|B) + P(B|A) is:
(a)1/12
(b)7/12
(c)1/10
(d)1/3
  1. P(A ∩ B) = P(A) + P(B) − P(A ∪ B) = 3/10 + 4/10 − 6/10 = 1/10.
    [½]
  2. P(A|B) = (1/10)/(2/5) = 1/4; P(B|A) = (1/10)/(3/10) = 1/3; sum = 1/4 + 1/3 = 7/12.
    [½]
Answer
(b) 7/12

Concepts to recall

  • Addition law: P(A ∪ B) = P(A) + P(B) − P(A ∩ B).
  • Conditional probability: P(A|B) = P(A ∩ B)/P(B); note the denominator is the event that is given.

Question 1(xii) · Board 2025 Imp.[1]
In a class of 50 students, 25 study English, 10 study History and 10 study both the subjects. Find the probability that a randomly selected student studies either English or History.
  1. n(E ∪ H) = n(E) + n(H) − n(E ∩ H) = 25 + 10 − 10 = 25.
    [½]
  2. P = 25/50 = 1/2.
    [½]
Answer
1/2
Common slip Adding 25 + 10 = 35 counts the 10 students who study both twice.

  • P(E ∪ H) = P(E) + P(H) − P(E ∩ H) = 1/2 + 1/5 − 1/5 = 1/2.

Question 1(xv) · Board 2025 Imp.[1]
Consider two events A and B. The probability that at least one of A or B occurs is 0·6. If the probability of both A and B occurring is 0·3, calculate P(A′) + P(B′).
  1. P(A ∪ B) = P(A) + P(B) − P(A ∩ B), so P(A) + P(B) = 0·6 + 0·3 = 0·9.
    [½]
  2. P(A′) + P(B′) = 2 − [P(A) + P(B)] = 2 − 0·9 = 1·1.
    [½]
Answer
1·1
Marking note P(A) and P(B) individually cannot be found from the data, and need not be.

Concepts to recall

  • P(A′) = 1 − P(A).
  • The sum P(A) + P(B) is not needed separately: only the total 0·9 matters. "At least one" = union.
ONE-MARK QUESTIONS (16)ISC 2025 Mathematics (860), Q1(v)
Question 1(v) · Board 2025[1]
Assertion: Consider the two events A and B such that n(A) = n(B) and P(A|B) = P(B|A).
Reason: The events A and B are mutually exclusive.
(a)Both Assertion and Reason are true and Reason is the correct explanation for Assertion.
(b)Both Assertion and Reason are true but Reason is not the correct explanation for Assertion.
(c)Assertion is true and Reason is false.
(d)Assertion is false and Reason is true.
  1. P(A|B) = n(A∩B)/n(B) and P(B|A) = n(A∩B)/n(A). Since n(A) = n(B) the two are equal: the Assertion is true.
    [½]
  2. The Reason is a separate claim that nothing in the question guarantees (A and B may overlap), so it is false. Assertion true, Reason false.
    [½]
Answer
(c) Assertion is true and Reason is false.
Marking note In the (unlikely) case that A and B were exclusive both conditional probabilities would be 0 and the Assertion would still hold, but exclusivity is not the reason the two are equal; the equal sizes are. Option (c) is the intended key.

Concepts to recall

  • Conditional probability: P(A|B) = P(A∩B)/P(B).
  • Mutually exclusive events have P(A∩B) = 0; they need not be the ones given here.
  • Assertion–Reason: decide each statement on its own first, then ask whether the Reason is why the Assertion holds.

Question 1(xiv) · Board 2025[1]
Three critics review a book. Odds in favour of the book are 5:2, 4:3 and 3:4 respectively for the three critics. Find the probability that all critics are in favour of the book.
  1. Odds in favour a : b mean P(favour) = a/(a + b): the probabilities are 5/7, 4/7, 3/7.
    [½]
  2. The critics decide independently, so P(all favour) = (5/7)(4/7)(3/7) = 60/343.
    [½]
Answer
P = 60/343
Common slip Multiplying the odds (5/2)(4/3)(3/4) instead of the probabilities.

Question 1(xi) · Specimen 2025[1]
Given two events A and B such that (A/B) = 0·25 and P(A ∩ B) = 0·12. The value of P(A ∩ B′) is:
(a)0·36
(b)0·48
(c)0·88
(d)0·036
  1. P(A ∩ B′) = P(A) − P(A ∩ B). The conditional probability fixes P(A): P(B/A) = P(A ∩ B)/P(A) ⇒ P(A) = 0·12/0·25 = 0·48.
    [½]
  2. P(A ∩ B′) = 0·48 − 0·12 = 0·36.
    [½]
Answer
(a) 0·36
Marking note The paper prints the conditional as “(A/B)” with no P. Read as P(A/B) = 0·25 it gives P(B) = 0·48 but P(A ∩ B′) cannot be found, and no option matches. CISCE’s key is (a) 0·36, which follows from P(B/A) = 0·25 as worked here.

Concepts to recall

  • P(A ∩ B′) = P(A) − P(A ∩ B) (the part of A outside B).
  • P(B/A) = P(A ∩ B)/P(A); P(A/B) = P(A ∩ B)/P(B).

Question 1(xv) · Specimen 2025[1]
There are three machines and 2 of them are faulty. They are tested one by one in a random order till both the faulty machines are identified. What is the probability that only two tests are needed to identify the faulty machines?
  1. Two tests are needed exactly when the first machine tested is faulty: whatever the second result (good, or faulty), the faulty pair is then known (if the second is good, the third is faulty). If the first is good, one test is enough.
    [½]
  2. P = P(first faulty and second good) + P(first faulty and second faulty) = (2/3)(1/2) + (2/3)(1/2) = 2/3.
    [½]
Answer
2/3
Common slip Counting only “faulty, faulty” (1/3).

Concepts to recall

  • Multiplication rule: P(E1 ∩ E2) = P(E1)P(E2/E1); add the disjoint cases.
  • Identification stops when the remaining machine can be inferred.

Teena is practising for an upcoming Rifle Shooting tournament. The probability of her shooting the target in the 1st, 2nd, 3rd and 4th shots are 0·4, 0·3, 0·2 and 0·1 respectively. Find the probability of at least one shot of Teena hitting the target.
  1. P(no hit) = (1 − 0·4)(1 − 0·3)(1 − 0·2)(1 − 0·1) = 0·6 × 0·7 × 0·8 × 0·9 = 0·3024 (shots are independent).

TWO-MARK QUESTIONS (3)ISC Specimen 2027 Mathematics, Q3
Question 3 · Specimen 2027[2]
In a school, for a period of 8 working days, it is equally likely that Tanishka is present or absent on any given day. What is the probability that she is present in school for at least 5 consecutive working days?
  1. Each day has 2 equally likely outcomes, so the total number of outcomes = 28 = 256.
    [½]
  2. Favourable: Case 1 the first five days are P (PPPPP _ _ _): the other 3 days are free, 23 = 8 ways.
    [½]
  3. Case 2 a run of five starting on day 2, 3 or 4 is preceded by an absence (APPPPP__, _APPPPP_, __APPPPP): 2 free days each, 3 × 22 = 12 ways. Favourable = 8 + 12 = 20.
    [½]
  4. P = 20/256 = 5/64.
    [½]
Answer
5/64
Common slip Counting 4 positions × 23 = 32 for the run, which counts the same sequence more than once (e.g. PPPPPP__ is counted twice).

Concepts to recall

  • Classical probability: P = favourable outcomes / total outcomes, with 2n equally likely present/absent sequences for n days.
  • To avoid double counting a long run, count each sequence by where its first run of five begins: either at day 1, or at day 2–4 immediately after an A.
  • The words “at least” include runs of 6, 7 and 8 days; they are inside the free positions.
TWO-MARK QUESTIONS (3)ISC 2026 Mathematics (860), Q5
Question 5 · Board 2026[2]
A die marked 1, 2, 3 in red and 4, 5, 6 in green is thrown. Let A be the event ‘Number appearing is odd’ and B be the event ‘Number appearing is green’.
Prove that the events A and B are not independent.
  1. Sample space S = {1, 2, 3, 4, 5, 6}. A = {1, 3, 5}, B = {4, 5, 6}, A ∩ B = {5}. So P(A) = 3/6 = 1/2, P(B) = 3/6 = 1/2, P(A ∩ B) = 1/6.
    [1]
  2. P(A)·P(B) = 1/4 ≠ 1/6 = P(A ∩ B). Independence requires P(A ∩ B) = P(A)P(B), so A and B are not independent.
    [1]
Answer
P(A ∩ B) = 1/6 ≠ P(A)P(B) = 1/4, hence not independent.

Concepts to recall

  • Events A, B are independent ⇔ P(A ∩ B) = P(A)·P(B).
  • List the favourable outcomes of A, B and A ∩ B explicitly for a die: it is quick and avoids slips.

FOUR-MARK QUESTIONS (6)ISC 2026 Mathematics (860), Q10
Question 10 · Board 2026[4]
(i) A sports store owner conducts a game ‘weekend-surprise’ every Friday for his customers. He fills two bags with cricket balls of red and white colours. The first bag has 4 white and 4 red balls while the second bag contains 3 white and 5 red balls. The rules of the game are: the customer will be blind folded; two balls have to be transferred from the first bag to the second bag one after another without replacement, and then one ball has to be drawn out from the second bag; the colours of the three balls (two balls transferred from the first bag and one ball drawn from the second bag) are considered; if all the three balls are of the same colour, the customer wins a surprise gift. What is the probability that a customer can win the surprise gift?
OR
(ii) Children of a society practise building human pyramids for 16 days to participate in the pyramid building competition during the Janmashtami festival. During practice sessions, the number of pyramids successfully formed in a day are X = 0, 1, 2, 3, 4. The data of the practice sessions is given in the following table:
Pyramids made (X)01234
No. of days146x1
(a) Find the number of days on which the children made 3 pyramids. [1]
(b) Form a probability distribution table for the number of pyramids made per day. Verify if it is a valid probability distribution table. [2]
(c) Calculate the average number of pyramids formed. [1]

Solution to the first alternative

  1. The gift is won only if the two transferred balls are of the same colour (WW or RR) and the ball drawn from bag 2 is also of that colour.
  2. P(WW) = (4/8)(3/7) = 3/14. Then bag 2 has 5 white + 5 red = 10 balls, so P(white | WW) = 5/10 = 1/2.
    [1½]
  3. P(RR) = (4/8)(3/7) = 3/14. Then bag 2 has 3 white + 7 red = 10 balls, so P(red | RR) = 7/10.
    [1½]
  4. P(win) = (3/14)(1/2) + (3/14)(7/10) = 3/28 + 3/20 = (15 + 21)/140 = 36/140 = 9/35.
    [1]
Answer
P(win) = 9/35

Solution to the OR alternative

  1. (a) The days add up to 16: 1 + 4 + 6 + x + 1 = 16, so x = 4 days.
    [1]
  2. (b) P(X) = days/16:
    X01234
    P(X)1/164/166/164/161/16
    [1]
  3. Valid: every P(X) lies between 0 and 1, and ΣP(X) = (1 + 4 + 6 + 4 + 1)/16 = 16/16 = 1.
    [1]
  4. (c) Mean = ΣXP(X) = (0·1 + 1·4 + 2·6 + 3·4 + 4·1)/16 = 32/16 = 2 pyramids per day.
    [1]
Answer
(a) 4 days; (b) valid table, ΣP = 1; (c) E(X) = 2

Concepts to recall

  • Total probability: P(E) = Σ P(Ai) P(E | Ai) over the mutually exclusive ways the transfer can go.
  • Without replacement: the second draw’s probability uses one fewer ball (4/8 then 3/7).
  • After the transfer, bag 2 always holds 8 + 2 = 10 balls; recount each colour for each case.
  • A valid probability distribution has 0 ≤ pi ≤ 1 and Σpi = 1.
  • Relative frequency = probability: divide each count by the total (16 days).
  • Mean E(X) = Σxipi.
FOUR-MARK QUESTIONS (6)ISC Specimen 2026 Mathematics, Q10
Question 10 · Specimen 2026[4]
(i) Three friends go to a restaurant to have pizza. They decide who will pay by tossing a coin. Each of them tosses a coin and if one person gets a different result (heads or tails) than the other two, that person pays. If all three get the same result they toss again until they get a different result. (a) What is the probability that all three get the same result in one round of tossing? (b) What is the probability that they get a different result in one round? (c) What is the probability that they need exactly four rounds of tossing to determine who pays?
OR
(ii) A school offers students the choice of three modes for attending classes: Mode A, offline (in-person), 40% of students; Mode B, online (live virtual classes), 35%; Mode C, recorded lectures, 25%. After a feedback survey, 20% of students from Mode A reported the class as “Excellent”, 30% from Mode B and 50% from Mode C. A student is selected at random from the entire group and is found to have rated the class “Excellent”. (a) Represent the data in terms of probability; define the events clearly. (b) Using Bayes’ theorem, find the probability that the student attended the recorded lectures (Mode C), given “Excellent”. (c) Interpret your result. Which mode has the highest likelihood of being chosen if a student says “Excellent”?

Solution to the first alternative

  1. (a) P(HHH) + P(TTT) = (1/2)3 + (1/2)3 = 1/8 + 1/8 = 1/4.
    [1]
  2. (b) P(different result) = 1 − 1/4 = 3/4.
    [1]
  3. (c) Exactly four rounds means the first three rounds all give the same result and the fourth gives a different one. Rounds are independent.
    [1]

A primary school teacher wants to teach the concept of ‘larger number’ to the students of Class II. To teach this concept, he conducts an activity in his class. He asks the children to select two numbers from a set of numbers given as 2, 3, 4, 5 one after the other without replacement. All the outcomes of this activity are tabulated in the form of ordered pairs given below:
2345
2(2,2)(2,3)(2,4)
3(3,2)(3,3)(3,5)
4(4,2)(4,4)(4,5)
5(5,3)(5,4)(5,5)
(i) Complete the table given above. (ii) Find the total number of ordered pairs having one larger number. (iii) Let the random variable X denote the larger of two numbers in the ordered pair. Now, complete the probability distribution table for X (X = 3, 4, 5). (iv) Find the value of P(X < 5). (v) Calculate the expected value of the probability distribution.
  1. (i) The four blank cells are (2,5), (3,4), (4,3) and (5,2). The table now shows all 4 × 4 = 16 ordered pairs.
    [1]
  2. (ii) “Having one larger number” means the two numbers are different, which also is what drawing without replacement gives. The four pairs (2,2), (3,3), (4,4), (5,5) are excluded: 16 − 4 = 12 ordered pairs.
    [1]
  3. (iii) The 12 pairs are equally likely. X = 3: (2,3), (3,2) → 2/12. X = 4: (2,4), (4,2), (3,4), (4,3) → 4/12. X = 5: (2,5), (5,2), (3,5), (5,3), (4,5), (5,4) → 6/12.
    X345
    P(X = x)1/61/31/2
    The probabilities add to 1 (2 + 4 + 6 = 12).
    [2]
  4. (iv) P(X < 5) = P(X = 3) + P(X = 4) = 1/6 + 1/3 = 1/2.
    [1]
  5. (v) E(X) = 3(1/6) + 4(1/3) + 5(1/2) = 1/2 + 4/3 + 5/2 = 13/3.
    [1]
Answer
(i) (2,5), (3,4), (4,3), (5,2); (ii) 12; (iii) 1/6, 1/3, 1/2; (iv) 1/2; (v) E(X) = 13/3
Marking note The printed table includes the pairs (2,2), (3,3), (4,4), (5,5), which cannot occur when drawing without replacement, and the distribution asked for has X = 3, 4, 5 only (so no 2). The consistent reading, used here, is that the 12 pairs with different numbers form the sample space. If a candidate took all 16 pairs the probabilities would be 1/16, 3/16, 5/16, 7/16 for X = 2, 3, 4, 5 and E(X) would be 33/8; but then P(X = 2) is missing from the table.

Concepts to recall

  • Random variable: list its values, find P for each (favourable ordered pairs / total), check ΣP = 1.
  • Expected value E(X) = Σ xi P(xi).
  • P(X < 5) = P(X = 3) + P(X = 4), or 1 − P(X = 5).
