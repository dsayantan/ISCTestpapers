Straight lines against planes

Each slide is labelled. Entries by kind: straight lines 8, planes 4, lines and planes together 7, direction-cosine / other 0. A line is given by a point and a direction; a plane by a point and a normal, so the angle between a line and a plane uses the complement (sin θ = |b·n|/(|b||n|)).

What to revise

  • Straight lines against planes. Lines: direction cosines and ratios, vector and Cartesian form, shortest distance between skew lines, intersection point, line through a point parallel to another line. Planes: equation through three points, with intercepts, through a point normal to a vector, angle between planes, distance of a point or between parallel planes. Mixed: line parallel to a plane, plane containing a line, angle between a line and a plane. The labels at the top of each slide say which of the three it is.
  • 4-mark question (17): a case study with a tower, balloons or a stage and a plane or two lines.
  • Habit: convert between vector and Cartesian forms; a line is parallel to a plane when its direction is perpendicular to the normal.

Question 1(xii) · Specimen 2027[1]
3-D geometry: Straight lines.
The point of intersection of the lines (x − 1)/2 = (y − 2)/3 = (3 − z)/(−4) and (x − 1)/5 = (2 − y)/(−2) = (z − 3)/1 is:
(a)(1, 2, −3)
(b)(−1, 2, 3)
(c)(1, −2, 3)
(d)(1, 2, 3)
  1. Rewrite the lines in standard form: first (x − 1)/2 = (y − 2)/3 = (z − 3)/4 (since (3 − z)/(−4) = (z − 3)/4); second (x − 1)/5 = (y − 2)/2 = (z − 3)/1.
    [½]
  2. Both lines pass through (1, 2, 3) and their direction ratios (2, 3, 4) and (5, 2, 1) are not proportional, so they are not the same line: they meet only at (1, 2, 3).
    [½]
Answer
(d) (1, 2, 3)

Concepts to recall

  • Standard form of a line: (x − x1)/a = (y − y1)/b = (z − z1)/c; flip signs so that every numerator is (variable − constant).
  • Two non-parallel lines through a common point meet only at that point.

Question 15(iii) · Board 2026[1]
3-D geometry: Straight lines.
The direction cosines of the line passing through the points P(2, 3, 5) and Q(−1, 2, 4) are:
(a)(3/√11, 1/√11, 1/√11)
(b)(1/√11, 1/√11, 1/√11)
(c)(3/√11, −1/√11, −1/√11)
(d)(−3/√11, 1/√11, −1/√11)
  1. Direction ratios of PQ: (−1 − 2, 2 − 3, 4 − 5) = (−3, −1, −1); the same line has ratios (3, 1, 1) (QP). √(9 + 1 + 1) = √11.
    [½]
  2. Direction cosines (3/√11, 1/√11, 1/√11). (Reversing the direction changes all three signs, and only option (a) has a consistent set.)
    [½]
Answer
(a) (3/√11, 1/√11, 1/√11)

Concepts to recall

  • Direction ratios of the line through (x1, y1, z1), (x2, y2, z2) are the coordinate differences; direction cosines = ratios/√(Σratios2).
  • Reversing the sense of a line negates all three direction cosines together; mixed signs (options c, d) cannot be right.

Question 15(ii) · Specimen 2026[1]
3-D geometry: Lines and planes. Also draws on: the plane is given by position vectors of three points (Ch 10).
A plane passes through three points A, B and C with position vectors î + ĵ, ĵ + k̂ and k̂ + î respectively. The equation of the line passing through the point P with position vector î + 2ĵ + 2k̂ and normal to the plane is:
(a)r = (î + 2ĵ + 2k̂) + λ(î + ĵ + k̂), λ ∈ ℝ
(b)r = (î + ĵ + k̂) + λ(î + 2ĵ + 2k̂), λ ∈ ℝ
(c)r · (î − ĵ − k̂) = î + 2ĵ + 2k̂
(d)x − 1 = y = z
  1. AB = (ĵ + k̂) − (î + ĵ) = −î + k̂, AC = (k̂ + î) − (î + ĵ) = −ĵ + k̂. A normal to the plane: n = AB × AC = |î ĵ k̂; −1 0 1; 0 −1 1| = (0 + 1)î − (−1 − 0)ĵ + (1 − 0)k̂ = î + ĵ + k̂.
    [½]
  2. The line through P(1, 2, 2) parallel to n: r = (î + 2ĵ + 2k̂) + λ(î + ĵ + k̂): option (a). (Cartesian: x − 1 = y − 2 = z − 2.)
    [½]
Answer
(a) r = (î + 2ĵ + 2k̂) + λ(î + ĵ + k̂), λ ∈ ℝ
Common slip Using the plane’s equation (option c) or the direction (1, 2, 2) of P itself (option b).

Concepts to recall

  • A normal to the plane through three points is AB × AC. A line normal to the plane has direction vector along this normal.
  • Line through a point a with direction b: r = a + λb. Option (c) is a plane, and (b), (d) pass through the wrong point.

Question 15(iii) · Specimen 2026[1]
3-D geometry: Straight lines.
If the direction cosines of a line are ⟨1/c, 1/c, 1/c⟩, then:
(a)c > 0
(b)0 < c < 1
(c)c = ±√3
(d)c > 2
  1. Direction cosines satisfy l2 + m2 + n2 = 1: 1/c2 + 1/c2 + 1/c2 = 1.
    [½]
  2. 3/c2 = 1 ⇒ c2 = 3 ⇒ c = ±√3 (both signs give a valid line, in opposite senses).
    [½]
Answer
(c) c = ±√3

Concepts to recall

  • l2 + m2 + n2 = 1 for direction cosines (cosines of the angles with the three axes).
  • Reversing a line’s direction changes the signs of all three direction cosines, so both ±√3 are acceptable.

The distance of the plane through (1, 1, 1) and perpendicular to the line (x − 1)/3 = (y − 1)/0 = (z − 1)/4 from the origin is
(a)34
(b)43
(c)75
(d)1
  1. The line direction (3, 0, 4) is the normal to the plane: 3(x − 1) + 0(y − 1) + 4(z − 1) = 0, i.e. 3x + 4z = 7.
    [½]

(c) 75

TWO-MARK QUESTIONS (3)ISC Specimen 2027 Mathematics, Q2
Question 2 · Specimen 2027[2]
3-D geometry: Lines and planes.
A straight line Lθ has vector equation r = 5i + λ(5i + sin θ j + cos θ k) and a plane πP has equation x = p, p ∈ ℝ. Show that the angle between Lθ and πP is independent of both θ and p.
  1. Direction of the line d = 5i + sin θ j + cos θ k. The plane x = p is r·i = p, so its normal is n = i.
    [½]
  2. d·n = 5; |d| = √(25 + sin2θ + cos2θ) = √26; |n| = 1.
    [½]
  3. If φ is the angle between the line and the plane, sin φ = |d·n| / (|d||n|) = 5/√26.
    [½]
  4. So φ = sin−1(5/√26), a constant: θ has cancelled (sin2θ + cos2θ = 1) and p never entered. Hence proved.
    [½]
Answer
φ = sin−1(5/√26), independent of θ and p
Common slip Using cos φ = |d·n|/(|d||n|), which gives the angle with the normal, not with the plane.
Marking note CISCE’s key writes the angle as “θ” and equates sin θ with 5/√26, clashing with the θ of the line; here the angle is called φ. Award both marks for a correct result sin φ = 5/√26 however the angle is named.

Concepts to recall

  • Angle φ between a line (direction d) and a plane (normal n): sin φ = |d·n| / (|d||n|) (cosine would give the angle with the normal).
  • The plane x = p has normal i; the value of p only positions the plane and does not change its orientation.
  • sin2θ + cos2θ = 1 removes θ from |d|.
TWO-MARK QUESTIONS (3)ISC 2025 Improvement Mathematics (860), Q16
Question 16 · Board 2025 Imp.[2]
3-D geometry: Straight lines.
(i) Find the shortest distance between the lines: r = (i+2j+3k) + λ(2i+3j+4k),  r = (2i+4j+5k) + μ(4i+6j+8k).
OR
(ii) Find the equation of the straight line passing through (1, 2, 1) and parallel to the line joining the points (1, 4, 6) and (5, 4, 4).

Solution to the first alternative

  1. The direction vectors (2, 3, 4) and (4, 6, 8) are proportional, so the lines are parallel. Take b = 2i+3j+4k, a2 − a1 = i+2j+2k.
    [½]
  2. (a2 − a1) × b = |i j k; 1 2 2; 2 3 4| = (8 − 6)i − (4 − 4)j + (3 − 4)k = 2i−k, magnitude √5.
    [1]
  3. Distance = √5/√29 = √(5/29) = √145/29 ≈ 0·415 units.
    [½]
Answer
√5/√29 = √145/29 units
Common slip Applying the skew-lines formula gives 0/0: first test whether the directions are proportional.

Solution to the OR alternative

  1. Direction of the line joining the points = (5 − 1, 4 − 4, 4 − 6) = (4, 0, −2), proportional to (2, 0, −1).
    [1]
  2. Required line: r = i+2j+k + λ(2i−k), or (x − 1)/2 = (y − 2)/0 = (z − 1)/(−1).
    [1]
Answer
r = i+2j+k + λ(2i−k)

Concepts to recall

  • Parallel lines r = a1 + λb, r = a2 + μb: distance = |(a2 − a1) × b|/|b|.
  • Skew lines use |(a2 − a1)·(b1 × b2)|/|b1 × b2|; here b1 × b2 = 0, so the parallel formula is needed.
  • Line through a parallel to b: r = a + λb; direction ratios of the line joining two points = difference of coordinates.
  • Any non-zero multiple of the direction vector is acceptable, e.g. 4i − 2k.
TWO-MARK QUESTIONS (3)ISC 2025 Mathematics (860), Q16
Question 16 · Board 2025[2]
3-D geometry: Planes.
(i) Find the equation of the plane passing through the points (2, 2, −1), (3, 4, 2) and (7, 0, 6).
OR
(ii) Find the equation of the plane passing through the points (2, 3, 1), (4, −5, 3) and parallel to x-axis.

Solution to the first alternative

  1. Take A(2, 2, −1), B(3, 4, 2), C(7, 0, 6): AB = (1, 2, 3), AC = (5, −2, 7).
    [½]
  2. Normal n = AB × AC = (14 + 6, 15 − 7, −2 − 10) = (20, 8, −12) ∝ (5, 2, −3).
    [1]
  3. Plane: 5(x − 2) + 2(y − 2) − 3(z + 1) = 0, i.e. 5x + 2y − 3z = 17 (check: B gives 15 + 8 − 6 = 17, C gives 35 + 0 − 18 = 17).
    [½]
Answer
5x + 2y − 3z = 17

Solution to the OR alternative

  1. Direction in the plane along the two points: AB = (2, −8, 2); the plane is parallel to the x-axis, so i = (1, 0, 0) also lies along it.
    [½]
  2. Normal n = AB × i = (0, 2, 8) ∝ (0, 1, 4).
    [1]
  3. Plane: 0(x − 2) + 1(y − 3) + 4(z − 1) = 0, i.e. y + 4z = 7. (Check: (4, −5, 3): −5 + 12 = 7.)
    [½]
Answer
y + 4z = 7

Concepts to recall

  • Plane through three points: normal = cross product of two edge vectors; then n·(r − a) = 0.
  • Always verify by substituting the other two points.
  • A plane parallel to the x-axis has no x in its equation: its normal is perpendicular to i, so a = 0.
  • Plane parallel to a given line: the normal is perpendicular to the line’s direction.
THREE-MARK QUESTIONS (1)ISC Specimen 2027 Mathematics, Q12
Question 12 · Specimen 2027[3]
3-D geometry: Planes.
(i) A vector n of magnitude 8 units is inclined to the x-axis at 45°, y-axis at 60° and at an acute angle with the z-axis. A plane through the point (√2, −1, 1) is normal to n. Find the equation of the plane in vector form.
OR
(ii) The planes π1 and π2 have equations 2x + 6y − 2z = 5 and 3x + 9y + pz = −51/2 respectively. (a) Verify that the point P(2, ½, 1) lies on the plane π1. [1] (b) Determine the value of p if π2 is parallel to π1. [1] (c) A line through P normal to π1 meets π2 at the point Q. Find the coordinates of Q. [1]

Solution to the first alternative

  1. Direction cosines: l = cos 45° = 1/√2, m = cos 60° = ½, n = cos γ. From l2 + m2 + n2 = 1: n2 = 1 − ½ − ¼ = ¼, so n = ½ (γ is acute, reject −½).
    [1]
  2. n = 8(li + mj + nk) = 8(i/√2 + j/2 + k/2) = 4√2 i + 4j + 4k.
    [1]
  3. Plane through a = √2 i − j + k normal to n: r·n = a·n = (√2)(4√2) + (−1)(4) + (1)(4) = 8, so r·(4√2 i + 4j + 4k) = 8, i.e. r·(√2 i + j + k) = 2.
    [1]
Answer
r·(√2 i + j + k) = 2 [equivalently r·(4√2 i + 4j + 4k) = 8]
Common slip Keeping both roots ±½ for the direction cosine n, which gives two vectors.

Solution to the OR alternative

  1. (a) LHS of π1 at P: 2(2) + 6(½) − 2(1) = 4 + 3 − 2 = 5 = RHS, so P lies on π1.
    [1]
  2. (b) Parallel planes have proportional coefficients: 3/2 = 9/6 = p/(−2), so p = −3.
    [1]
  3. (c) The normal to π1 has direction (2, 6, −2) ∝ (1, 3, −1). The line through P: (x − 2)/1 = (y − ½)/3 = (z − 1)/(−1) = λ, so a general point is (2 + λ, ½ + 3λ, 1 − λ). It lies on π2: 3(2 + λ) + 9(½ + 3λ) − 3(1 − λ) = −51/2 ⇒ 33λ + 15/2 = −51/2 ⇒ λ = −1. Q = (1, −5/2, 2).
    [1]
Answer
(a) verified; (b) p = −3; (c) Q(1, −5/2, 2)
Marking note Check: Q = (1, −5/2, 2): 3(1) + 9(−5/2) − 3(2) = 3 − 22·5 − 6 = −25·5 = −51/2 ✓, and PQ = (−1, −3, 1) ∝ (1, 3, −1), the normal.

Concepts to recall

  • Direction cosines satisfy l2 + m2 + n2 = 1; the vector of magnitude |n| is |n| × (li + mj + nk).
  • Vector equation of a plane through a point with position vector a and normal n: (r − a)·n = 0, i.e. r·n = a·n.
  • “Acute angle with the z-axis” picks the positive root for the third direction cosine.
  • A point lies on a plane if its coordinates satisfy the equation.
  • Planes a1x + b1y + c1z = d1 and a2x + b2y + c2z = d2 are parallel iff a1/a2 = b1/b2 = c1/c2.
  • The line through a point normal to a plane has the plane’s normal as its direction ratios.
FOUR-MARK QUESTIONS (4)ISC 2026 Mathematics (860), Q17
Question 17 · Board 2026[4]
3-D geometry: Straight lines.
(i) The paths traced by two hot air balloons are: (x − 1)/2 = (y − b)/3 = (z − 3)/4 and (x − 4)/5 = (y − 1)/2 = z/1. Find the value of ‘b’ to be avoided so that the two hot air balloons do not collide.
OR
(ii) A school is preparing the stage for its annual day function. They want to place a hanging mic and a hanging light on the stage. They decide to position the mic at the point (3, 2, 1) such that it is equidistant from a plain backdrop and the hanging light as shown below (mic midway between the backdrop and the light, on a line perpendicular to the backdrop). The equation of the surface of the plain backdrop is 2x − y + z + 1 = 0.
(a) Find the distance between the mic and the plain backdrop. [1]
(b) Calculate the coordinates of the hanging light’s position. [3]

Solution to the first alternative

  1. The balloons collide only if the two lines intersect, i.e. if they are coplanar (not parallel). So the value of b to be avoided is the one that makes the lines intersect.
    [1]
  2. a1 = (1, b, 3), d1 = (2, 3, 4); a2 = (4, 1, 0), d2 = (5, 2, 1). a2 − a1 = (3, 1 − b, −3).
    [1]
  3. The lines intersect iff [a2 − a1, d1, d2] = 0: 31 − b−3234521 = 3(3 − 8) − (1 − b)(2 − 20) − 3(4 − 15) = −15 + 18(1 − b) + 33 = 36 − 18b.
    [1]
  4. 36 − 18b = 0 ⇒ b = 2. For b = 2 the paths meet (collision); so b = 2 must be avoided. (For any other b the lines are skew since d1 ∦ d2.)
    [1]
Answer
b = 2 is to be avoided.

Solution to the OR alternative

  1. (a) Distance of (3, 2, 1) from 2x − y + z + 1 = 0: |2·3 − 2 + 1 + 1|/√(4 + 1 + 1) = 6/√6 = √6 units.
    [1]
  2. (b) The mic–light line is perpendicular to the backdrop, so it has direction (2, −1, 1), the normal. Line through the mic: (3 + 2λ, 2 − λ, 1 + λ).
    [1]
  3. The light is at distance √6 from the mic (the mic is equidistant from backdrop and light): |λ|·√6 = √6, so λ = ±1. λ = −1 gives (1, 3, 0), which satisfies 2 − 3 + 0 + 1 = 0: that is the foot on the backdrop. So the light is the other end.
    [1]
  4. λ = +1: the light is at (5, 1, 2). Check: mic is the midpoint of (1, 3, 0) and (5, 1, 2) = (3, 2, 1) ✓.
    [1]
Answer
(a) √6 units; (b) the light is at (5, 1, 2)
Marking note This is not the “image of the point in the plane” (that would be (−1, 4, −1), on the backdrop’s far side); the figure shows the light on the mic’s side of the backdrop, on the opposite side from the backdrop, giving (5, 1, 2).

Concepts to recall

  • Two lines r = a1 + λd1, r = a2 + μd2 intersect ⇔ shortest distance = 0 ⇔ [a2 − a1, d1, d2] = 0 (and not parallel).
  • Read the data off the symmetric form carefully: (x − 4)/5 = (y − 1)/2 = z/1 passes through (4, 1, 0).
  • Skew lines never meet: that is the “do not collide” case.
  • Distance of (x1, y1, z1) from ax + by + cz + d = 0: |ax1 + by1 + cz1 + d|/√(a2 + b2 + c2).
  • A line perpendicular to a plane has the plane’s normal (a, b, c) as its direction.
  • Midpoint formula: the mic is the midpoint of the foot of the perpendicular and the light, so light = 2(mic) − foot.
FOUR-MARK QUESTIONS (4)ISC Specimen 2026 Mathematics, Q17
Question 17 · Specimen 2026[4]
3-D geometry: Straight lines.
(i) Given that B and C lie on the line (x + 3)/5 = (y − 1)/2 = (z + 4)/3, BC = 5 units and A is the point (0, 2, 3), find the area of ΔABC.
OR
(ii) Find the equation of the plane containing the line x/(−2) = (y − 1)/3 = (1 − z)/1 and the point (−1, 0, 2).

Solution to the first alternative

  1. Let D be the foot of the perpendicular from A to the line. A general point of the line: D(5λ − 3, 2λ + 1, 3λ − 4); the line has direction ratios ⟨5, 2, 3⟩.
    [1]
  2. AD = ⟨5λ − 3, 2λ − 1, 3λ − 7⟩ and AD ⊥ line: 5(5λ − 3) + 2(2λ − 1) + 3(3λ − 7) = 0 ⇒ 38λ − 38 = 0 ⇒ λ = 1.
    [1]
  3. D = (2, 3, −1) and AD = √[(2 − 0)2 + (3 − 2)2 + (−1 − 3)2] = √(4 + 1 + 16) = √21.
    [1]
  4. Area of ΔABC = ½ × BC × AD = ½ × 5 × √21 = (5/2)√21 ≈ 11·46 square units.
    [1]
Answer
Area = (5/2)√21 square units

Solution to the OR alternative

  1. Rewrite the line as x/(−2) = (y − 1)/3 = (z − 1)/(−1): it passes through P(0, 1, 1) with direction ratios ⟨−2, 3, −1⟩.
    [1]
  2. The plane contains P and the point Q(−1, 0, 2): vector PQ = (−1, −1, 1). A normal is the cross product of the two vectors in the plane: n = ⟨−2, 3, −1⟩ × ⟨−1, −1, 1⟩ = (3 − 1, 1 + 2, 2 + 3) = (2, 3, 5).
    [1½]
  3. Plane through Q(−1, 0, 2): 2(x + 1) + 3(y − 0) + 5(z − 2) = 0 ⇒ 2x + 3y + 5z − 8 = 0.
    [1]
  4. Check: P gives 0 + 3 + 5 − 8 = 0 ✓; direction · normal = −4 + 9 − 5 = 0 ✓.
    [½]
Answer
2x + 3y + 5z = 8
Common slip Reading the direction of the z-part as +1 instead of −1.

Concepts to recall

  • The area of a triangle with base BC on a line is ½ × BC × (perpendicular distance of A from that line).
  • Foot of the perpendicular to a line: write a general point of the line in λ and impose (vector to it) · (direction) = 0.
  • A plane through a line and an external point contains the direction of the line and the vector from a point of the line to that point; their cross product is the normal.
  • Rewrite (1 − z)/1 as (z − 1)/(−1): the sign of the direction ratio flips when z is written the other way round.
  • Equivalent determinant form: |x+1 y z−2; −2 3 −1; −1 −1 1| = 0.

(ii) Find the equation of the plane containing the line x/(−2) = (y − 1)/3 = (1 − z)/1 and the point (−1, 0, 2).

Solution to the first alternative

  1. Direction of the line d = i − j + 4k; normal of the plane n = i + 5j + k.
    [½]
  2. d · n = 1 − 5 + 4 = 0: the line is perpendicular to the normal, hence parallel to the plane (or in it).
    [1]
  3. The point (2, −2, 3) of the line gives a · n = 2 − 10 + 3 = −5 ≠ 5, so the line is not in the plane: it is a parallel line. Distance of that point from the plane: |a·n − 5|/|n| = |−5 − 5|/√27 = 10/√27.
    [1½]
  4. Distance = 10/(3√3) = 10√3/9 units ≈ 1·92 units.
    [1]
Answer
Parallel; distance = 10/(3√3) = 10√3/9 units
Marking note CISCE’s key ends “10/√27 = 10/3√3 units”, with no bracket round the denominator; it is 10/(3√3) = 10√3/9 ≈ 1·92 (not 10/3 × √3), and the key is correct.

Solution to the OR alternative

  1. Rewrite the line: (1 − z)/1 = (z − 1)/(−1), so the line is x/(−2) = (y − 1)/3 = (z − 1)/(−1): it passes through P(0, 1, 1) with direction d = (−2, 3, −1).
    [1]
  2. Plane through Q(−1, 0, 2): a(x + 1) + by + c(z − 2) = 0. It contains P: a(1) + b(1) + c(−1) = 0 ⇒ a + b − c = 0. Its normal is ⟂ d: −2a + 3b − c = 0.
    [1]
  3. Solve: a/(−1 + 3) = b/(2 + 1) = c/(3 + 2), i.e. (a, b, c) ∝ (2, 3, 5).
    [1]
  4. Plane: 2(x + 1) + 3y + 5(z − 2) = 0, i.e. 2x + 3y + 5z − 8 = 0. (Check: P gives 3 + 5 − 8 = 0 ✓.)
    [1]
Answer
2x + 3y + 5z − 8 = 0

Concepts to recall

  • Line ∥ plane ⇔ d · n = 0 (and the line is not contained in the plane).
  • Distance from a point with position vector a to the plane r·n = d: |a·n − d|/|n|.
  • For a line parallel to a plane, every point of the line is the same distance from it.
  • A plane containing a line and a point: its normal is perpendicular to the line’s direction and to the join of the point to a point of the line.
  • Normal = cross product of the two directions; here (−2, 3, −1) × (1, 1, −1) = (−2, −3, −5) ∝ (2, 3, 5).
  • Symmetric form with (1 − z): flip the sign of both numerator and denominator to read the direction ratios correctly.

Question 15 · Board 2025 Imp.[5]
3-D geometry: Lines and planes. Also draws on: part (i) is the section formula for position vectors (Ch 10); part (ii) is on planes.
(i) Consider the figure shown (lines AC and BD meet at P with AP = 2, PB = 1, PC = 3, PD = 4; A, B, C, D have position vectors a, b, c, d). Statement 1: the position vector of P is (2c + 3a)/5. Statement 2: the position vector of P is (4d + b)/5. Choose: (a) Statement 1 true, 2 false; (b) Statement 2 true, 1 false; (c) both true; (d) both false. [1]
(ii) Two solar panels A and B are placed parallel to each other on a terrace. The equation of the surface of panel A is 2x + 2y − z + 9 = 0. (a) The direction cosines of the plane are: (1) (−2/3, −2/3, 1/3); (2) (2/3, −2/3, −1/3); (3) (2/3, 2/3, 1/3); (4) (−2/3, −2/3, −1/3). [1] (b) A fly is sitting on panel A. The position of the fly is (2, m, 3). Find m. [1] (c) Find the equation of panel B if the point (3, 2, −4) lies on it. [1] (d) Find the distance between the panels. [1]
  1. (i) P divides AC with AP : PC = 2 : 3, so p = (3a + 2c)/5, which is Statement 1: true. P divides BD with BP : PD = 1 : 4, so p = (4b + 1·d)/5 = (4b + d)/5. Statement 2, (4d + b)/5, has the weights interchanged: false. Answer (a).
    [1]
  2. (ii)(a) Write the plane as −2x − 2y + z = 9 (constant on the right made positive; √(4 + 4 + 1) = 3). Direction cosines of the normal: (−2/3, −2/3, 1/3), option (1).
    [1]
  3. (b) The fly lies on A: 2(2) + 2m − 3 + 9 = 0, so 2m = −10 and m = −5.
    [1]
  4. (c) Panel B is parallel to A: 2x + 2y − z + k = 0. Through (3, 2, −4): 6 + 4 + 4 + k = 0, k = −14. B: 2x + 2y − z − 14 = 0.
    [1]
  5. (d) Distance between parallel planes = |d1 − d2|/√(a2 + b2 + c2) = |9 − (−14)|/3 = 23/3 units.
    [1]
Answer
(i) (a); (ii) (a) option (1); (b) m = −5; (c) 2x + 2y − z − 14 = 0; (d) 23/3 units.
Marking note (ii)(a): the direction cosines of the plane’s normal (2, 2, −1)/3 itself are not among the options, so the option with the constant term made positive is the intended one.

Concepts to recall

  • Section formula (internal, ratio m : n): position vector = (n·first + m·second)/(m + n); the weights are crossed: the nearer end gets the larger weight.
  • Direction cosines of a plane = those of its normal, (a, b, c)/√(a2 + b2 + c2) after making the constant term sign-correct (normal form lx + my + nz = p, p > 0).

FIVE-MARK QUESTIONS (2)ISC 2025 Mathematics (860), Q15
Question 15 · Board 2025[5]
3-D geometry: Lines and planes. Also draws on: part (i) is a vector identity (Ch 10) and part (iii) shows three points are collinear.
In subparts (i) and (ii) choose the correct options and in subparts (iii) and (iv) answer the questions as instructed.
(i) Assertion: (a + b)2 + (b − a)2 = 2(a2 + b2). Reason: Dot product of any two vectors is commutative. (a) Both true, Reason is the correct explanation; (b) both true, Reason not the explanation; (c) Assertion true, Reason false; (d) Assertion false, Reason true. [1]
(ii) The angle between the two planes x + y + 2z = 9 and 2x − y + z = 15 is: (a) π/2 (b) π/3 (c) π (d) 3π/4. [1]
(iii) Show that points P(−2, 3, 5), Q(1, 2, 3) and R(7, 0, −1) are collinear. [1]
(iv) Two honeybees fly parallel to each other along straight lines. The equation of the path of one is r = (î + 2ĵ + 3k̂) + λ(2î + 3ĵ + 4k̂). (a) Write the above equation in cartesian form. [1] (b) Find the equation of the path of the other honeybee passing through the point (2, 4, 5). [1]
  1. (i) Answer (a). (a + b)·(a + b) = a2 + 2a·b + b2 and (b − a)·(b − a) = b2 − 2a·b + a2: the middle terms cancel only because a·b = b·a. Sum = 2(a2 + b2). The Assertion is true and the Reason is why.
    [1]
  2. (ii) Answer (b). Normals n1 = (1, 1, 2), n2 = (2, −1, 1): cos θ = |n1·n2|/(|n1||n2|) = |2 − 1 + 2|/(√6 √6) = 3/6 = 1/2, so θ = π/3.
    [1]
  3. (iii) PQ = (1 + 2, 2 − 3, 3 − 5) = (3, −1, −2); QR = (7 − 1, 0 − 2, −1 − 3) = (6, −2, −4) = 2PQ. The vectors are parallel and share the point Q, so P, Q, R are collinear.
    [1]
  4. (iv)(a) The line passes through (1, 2, 3) with direction ratios 2, 3, 4: (x − 1)/2 = (y − 2)/3 = (z − 3)/4.
    [1]
  5. (b) Parallel lines have the same direction ratios: (x − 2)/2 = (y − 4)/3 = (z − 5)/4, i.e. r = (2î + 4ĵ + 5k̂) + μ(2î + 3ĵ + 4k̂).
    [1]
Answer
(i) (a); (ii) (b) π/3; (iii) collinear; (iv) (a) (x−1)/2 = (y−2)/3 = (z−3)/4; (b) (x−2)/2 = (y−4)/3 = (z−5)/4.
Marking note Marks: 1 for each of (i), (ii), (iii), (iv)(a) and (iv)(b). The vector form for (iv)(b) with any parameter name is accepted.

Concepts to recall

  • Parallelogram law: |a + b|2 + |a − b|2 = 2(|a|2 + |b|2); it uses a·b = b·a.
  • Angle between planes = angle between their normals: cos θ = |n1·n2|/(|n1||n2|).
  • Collinearity: two displacement vectors from a common point are parallel. Line through (x1, y1, z1) with direction (a, b, c): (x − x1)/a = (y − y1)/b = (z − z1)/c.
