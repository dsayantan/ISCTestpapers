Papers 2024–2026 and specimens 2025, 2026 ask Section A (65) and then Section B or Section C (15); Section B is the counted choice, so every paper’s counted marks add to 80. Where a question offers an OR alternative from another chapter, the alternative sits in its own chapter and is not counted. 1 OR alternative(s) in this chapter come from questions whose main part is in another chapter.

What to revise

  • The most-asked chapter: an integral in almost every question number of Section A. Methods in rotation: by parts (x2 cos x, x tan−1x, ln x), partial fractions, substitution, and standard forms completing the square.
  • Definite integrals by properties (6 marks): ∫02π, ∫ x/(1 + sin x), ∫0π/2 log tan x dx, even/odd functions, ∫ab f(a + b − x). Greatest-integer and modulus integrands are cut at the break points.
  • One-markers: ∫(cot x − cosec2x)ex dx = exf(x), ∫|x + 3|, ∫−11 x3 cos x dx = 0, and a step-error question on a worked anti-derivative (specimen 2027).
  • Habit: constant of integration in every indefinite answer; check limits after a substitution.

Question 1(ix) · Specimen 2027[1]
Shown below is a solved anti-differentiation problem to obtain f(x):
df/dx = 1/(x(log x)2) such that f(e) = −1. Taking the anti-derivative: f(x) = ∫ dx/(x(log x)2) + C.
Step 1 ⇒ f(x) = ∫ d(log x)/(log x)2 + C
Step 2 ⇒ f(x) = −1/log x + C
Given f(e) = −1 ⇒ f(e) = −1 + C ⇒ C = 0
Step 3 f(x) = −1/log x
In which step is there an error (if any) in the solution?
(a)Step 1
(b)Step 2
(c)Step 3
(d)No error
  1. Step 1: put t = log x, dt = dx/x, so dx/(x(log x)2) = dt/t2: correct. Step 2: ∫t−2 dt = −1/t: correct.
    [½]
  2. f(e) = −1/log e + C = −1 + C = −1 gives C = 0, and Step 3 follows. Check: d/dx(−1/log x) = 1/(x(log x)2). There is no error.
    [½]
Answer
(d) No error
Common slip Looking for a slip that is not there: the working is correct line by line.

Concepts to recall

  • ∫ f′(x)/[f(x)]n dx by the substitution t = f(x); here t = log x and dt = dx/x.
  • To check a worked solution, differentiate the final answer and test the initial condition.

Question 1(x) · Specimen 2027[1]
On solving ∫ −3/√(1 − x2) dx, Anil’s answer was 3 cos−1x + c and Jaspreet’s answer was −3 ∫ dx/√(1 − x2) = −3 sin−1x + c. Whose answer was correct?
(a)Only Anil’s answer was correct.
(b)Only Jaspreet’s answer was correct.
(c)Both of them were correct.
(d)Neither of them was correct.
  1. d/dx (3 cos−1x) = −3/√(1 − x2) and d/dx (−3 sin−1x) = −3/√(1 − x2): both differentiate to the integrand.
    [½]
  2. They differ only by a constant: cos−1x = π/2 − sin−1x, so 3 cos−1x = 3π/2 − 3 sin−1x, absorbed into c. Both are correct.
    [½]
Answer
(c) Both of them were correct.

Concepts to recall

  • sin−1x + cos−1x = π/2, so the two inverse functions have antiderivative forms that differ by a constant.
  • Two antiderivatives of the same function always differ by a constant; the arbitrary constant c hides it.

Question 1(xvii) · Specimen 2027[1]
Assertion: ∫−11 x3 cos x dx = 0
Reason: If f(x) is a continuous function defined on [0, a], then ∫0a f(x) dx = ∫0a f(a − x) dx
(a)Both Assertion and Reason are true, and Reason is the correct explanation of Assertion.
(b)Both Assertion and Reason are true, but Reason is not the correct explanation of Assertion.
(c)Assertion is true and Reason is false.
(d)Assertion is false and Reason is true.
  1. f(x) = x3 cos x has f(−x) = −x3 cos x = −f(x): an odd function, so ∫−11 f dx = 0. The Assertion is true.
    [½]
  2. The Reason is the “King” property of definite integrals and is true, but the vanishing of the integral comes from the odd-function property ∫−aa f = 0, not from this property. Reason is true but not the explanation.
    [½]
Answer
(b) Both Assertion and Reason are true, but Reason is not the correct explanation of Assertion.

Concepts to recall

  • ∫−aa f(x) dx = 0 when f is odd and = 2∫0a f dx when f is even.
  • King’s property ∫0a f(x) dx = ∫0a f(a − x) dx is a separate true statement; it does not apply to limits −1 to 1.

TWO-MARK QUESTIONS (8)ISC Specimen 2026 Mathematics, Q5
Question 5 · Specimen 2026[2]
(i) If ∫x5 cos(x6) dx = k sin(x6) + C, find the value of ‘k’.
OR
(ii) Evaluate: ∫50√x√(5 − x) + √x dx

Solution to the first alternative

  1. Put t = x6, so dt = 6x5 dx and x5 dx = dt/6.
    [½]
  2. ∫ cos t · (dt/6) = (1/6) sin t + C = (1/6) sin(x6) + C.
    [1]
  3. Comparing with k sin(x6) + C: k = 1/6.
    [½]
Answer
k = 1/6

Solution to the OR alternative

  1. Let I = ∫05 √x/[√(5 − x) + √x] dx. Using ∫0a f(x) dx = ∫0a f(a − x) dx: I = ∫05 √(5 − x)/[√x + √(5 − x)] dx.
    [1]
  2. Add the two forms: 2I = ∫05 [√x + √(5 − x)]/[√(5 − x) + √x] dx = ∫05 1 dx = 5.
    [½]
  3. I = 5/2.
    [½]
Answer
5/2

Concepts to recall

  • Substitution: when the integrand contains g′(x) times a function of g(x), put t = g(x). Here g = x6, g′ = 6x5.
  • Differentiate the answer to check: (1/6)cos(x6)·6x5 = x5 cos(x6).
  • King’s property: ∫0a f(x) dx = ∫0a f(a − x) dx. Use it when swapping x ↔ a − x exchanges the two terms of the denominator.
  • Result to remember: ∫0a f(x)/[f(x) + f(a − x)] dx = a/2.

Question 5 · Specimen 2025[2]
(i) Evaluate: ∫2x3 − 1x4 + x dx
OR
(ii) Evaluate: ∫ex cosec x (1 − cot x) dx

Solution to the first alternative

  1. Divide numerator and denominator by x2: integrand = (2x − 1/x2)/(x2 + 1/x).
    [1]
  2. Put t = x2 + 1/x, dt = (2x − 1/x2) dx: ∫ dt/t = log|t| + c = loge|x2 + 1/x| + c.
    [1]
Answer
loge |x² + 1/x| + c = loge |(x³ + 1)/x| + c
Marking note The key divides “by x” but then writes the quotient that dividing by x2 gives; the division by x2 is the correct reading and the result is the same.

Solution to the OR alternative

  1. Expand: ex(cosec x − cosec x cot x) = ex[f(x) + f′(x)] with f(x) = cosec x, since f′(x) = −cosec x cot x.
    [1]
  2. Use ∫ ex[f(x) + f′(x)] dx = exf(x) + c: result ex cosec x + c.
    [1]
Answer
ex cosec x + c

Concepts to recall

  • Recognise “derivative of the denominator in the numerator”: ∫ f′/f dx = log|f| + c.
  • To expose it, divide top and bottom by a power of x (here x2), not by x.
  • ∫ ex[f(x) + f′(x)] dx = exf(x) + c.
  • d/dx cosec x = −cosec x cot x.

Question 9 · Board 2025 Imp.[4]
(i) Evaluate: ∫x tan−1x dx
OR
(ii) Evaluate: ∫cos xsin2x + 4 sin x + 5 dx

Solution to the first alternative

  1. Integrate by parts with tan−1x as the first function: ∫x tan−1x dx = (x2/2) tan−1x − ∫ (x2/2) · 1/(1 + x2) dx.
    [1½]
  2. x2/(1 + x2) = 1 − 1/(1 + x2), so ∫ = ½(x − tan−1x).
    [1]
  3. Result: (x2/2) tan−1x − x/2 + ½ tan−1x + C = ½(x2 + 1) tan−1x − x/2 + C.
    [1½]
Answer
½(x2 + 1) tan−1x − x/2 + C

Solution to the OR alternative

  1. Put t = sin x, dt = cos x dx: integral = ∫ dt/(t2 + 4t + 5).
    [1½]
  2. Complete the square: t2 + 4t + 5 = (t + 2)2 + 1, so integral = ∫ dt/[(t + 2)2 + 1].
    [1]
  3. = tan−1(t + 2) + C = tan−1(sin x + 2) + C.
    [1½]
Answer
tan−1(sin x + 2) + C
Common slip Forgetting to substitute back t = sin x at the end.

Concepts to recall

  • By parts: ∫ u v dx = u∫v dx − ∫ (u′ ∫v dx) dx. ILATE: choose the inverse trigonometric function as u.
  • Improper fraction trick: x2/(1 + x2) = 1 − 1/(1 + x2).
  • Check: d/dx of the answer = x tan−1x + ½ − ½ = x tan−1x (the 1/2 terms cancel).
  • Substitute t = sin x whenever cos x dx is present and the rest is a function of sin x.
  • Quadratic with no real roots in the denominator: complete the square and use ∫ du/(u2 + 1) = tan−1u.

Question 8 · Board 2025[4]
(i) Evaluate: ∫cos x3 cos x − 5 dx
OR
(ii) Evaluate: ∫(log x)2 dx

Solution to the first alternative

  1. Write cos x = (1/3)(3 cos x − 5) + 5/3, so the integrand is 1/3 + (5/3)/(3 cos x − 5).
    [1]
  2. Let t = tan(x/2): cos x = (1 − t2)/(1 + t2), dx = 2dt/(1 + t2), and 3 cos x − 5 = −(2 + 8t2)/(1 + t2).
    [1]
  3. ∫dx/(3 cos x − 5) = ∫−2dt/(2 + 8t2) = −∫dt/(1 + 4t2) = −½ tan−1(2t).
    [1]
  4. Hence the integral = x/3 − (5/6) tan−1(2 tan(x/2)) + C.
    [1]
Answer
x/3 − (5/6) tan−1(2 tan (x/2)) + C

Solution to the OR alternative

  1. Integrate by parts with u = (log x)2, dv = dx: ∫(log x)2dx = x(log x)2 − ∫x · 2 log x · (1/x) dx
    [1]
  2. = x(log x)2 − 2∫log x dx
    [1]
  3. ∫log x dx = x log x − x (by parts again, with u = log x)
    [1]
  4. Therefore the integral = x(log x)2 − 2x log x + 2x + C.
    [1]
Answer
x(log x)2 − 2x log x + 2x + C
