What to revise

  • Types and properties: a matrix both symmetric and skew-symmetric, AB − BA for symmetric A, B, An for a scalar or diagonal matrix, (A2)−1 = (A−1)2, AB = O with A non-singular.
  • Word problems in matrix form: three shopkeepers and three kinds of bag (Board 2025 Q5), index numbers of three commodities (2025 Improvement Q6): write the data as a matrix and multiply.
  • Conceptual: why (A + B)(A − B) ≠ A2 − B2 (specimen 2027).
  • Habit: matrices do not commute; state the order of every product.

ONE-MARK QUESTIONS (13)ISC Specimen 2027 Mathematics, Q1(xviii)
Question 1(xviii) · Specimen 2027[1]
Using the properties of matrices, explain why the following concept is incorrect: Since (a + b)(a − b) = a2 − b2, therefore (A + B)(A − B) = A2 − B2 also must be true if A and B are matrices.
  1. Expand: (A + B)(A − B) = A2 − AB + BA − B2.
    [½]
  2. Matrix multiplication is not commutative (AB ≠ BA in general), so −AB + BA ≠ O and (A + B)(A − B) ≠ A2 − B2. Hence the concept is incorrect.
    [½]
Answer
Matrix multiplication is non-commutative (AB ≠ BA), so (A + B)(A − B) = A2 − AB + BA − B2 ≠ A2 − B2 in general.
Marking note A counter-example: A = [[1, 1], [0, 1]], B = [[1, 0], [1, 1]] give AB ≠ BA and (A + B)(A − B) ≠ A2 − B2 (checked in the verifier).

Concepts to recall

  • Matrix multiplication is associative and distributive but not commutative: AB ≠ BA in general.
  • Number identities that use ab = ba (such as (a + b)(a − b) = a2 − b2) hold for matrices only when AB = BA.

ONE-MARK QUESTIONS (13)ISC Specimen 2026 Mathematics, Q1(i)
Question 1(i) · Specimen 2026[1]
If A and B are square matrices of order 3, A is a non-singular matrix and AB = O, then the matrix B is:
(a)unit matrix
(b)scalar matrix
(c)non-singular matrix
(d)null matrix
  1. A is non-singular, so |A| ≠ 0 and A−1 exists.
    [½]
  2. Pre-multiply AB = O by A−1: A−1(AB) = A−1O ⇒ (A−1A)B = O ⇒ IB = O ⇒ B = O, the null matrix.
    [½]
Answer
(d) null matrix
Common slip Saying “AB = O means A = O or B = O”: that is false in general (two non-zero singular matrices can multiply to O).

Concepts to recall

  • A non-singular matrix has an inverse, so it can be cancelled from the left: AB = O ⇒ B = O.
  • For singular matrices AB = O does not force A = O or B = O; the non-singular hypothesis is what settles it.
ONE-MARK QUESTIONS (13)ISC Specimen 2026 Mathematics, Q1(vi)
Question 1(vi) · Specimen 2026[1]
If A = [a 0 0; 0 a 0; 0 0 a], then An equals:
(a)[an 0 0; 0 an 0; 0 0 an]
(b)[a 0 0; 0 an 0; 0 0 a]
(c)[an 0 0; 0 a 0; 0 0 an]
(d)[na 0 0; 0 na 0; 0 0 an]
  1. A = aI with I the unit matrix of order 3, so A2 = a2I2 = a2I.
    [½]
  2. By induction An = anI: every diagonal entry becomes an and the off-diagonal entries stay 0 (option a).
    [½]
Answer
(a) [an 0 0; 0 an 0; 0 0 an]

Concepts to recall

  • A scalar matrix aI commutes with everything and (aI)n = anIn = anI.
  • The powers of a diagonal matrix are the powers of its diagonal entries.
ONE-MARK QUESTIONS (13)ISC 2025 Improvement Mathematics (860), Q1(v)
Question 1(v) · Board 2025 Imp.[1]
Also draws on: det A = 0 for a skew-symmetric matrix of odd order is also a determinant property (Ch 4).
Assertion: If A is a skew-symmetric matrix of order 3 × 3, then det(A) = 0. Reason: If A is a square matrix, then det(A) = det(A′).
(a)Both Assertion and Reason are true and Reason is the correct explanation of Assertion.
(b)Both Assertion and Reason are true but Reason is not the correct explanation of Assertion.
(c)Assertion is true and Reason is false.
(d)Assertion is false and Reason is true.
  1. A′ = −A, so det(A) = det(A′) = det(−A) = (−1)3 det(A) = −det(A), giving det(A) = 0: the Assertion is true.
    [½]
  2. The Reason is a true general property, but it is only one step of the argument; it alone says nothing about the value 0 (the key step is det(−A) = (−1)3det A for order 3). So the Reason is true but not the full explanation.
    [½]
Answer
(b) Both Assertion and Reason are true but Reason is not the correct explanation of Assertion.
Marking note A reader who treats det(A) = det(A′) as the explanation would choose (a); the standard textbook reading, followed here, is that the Reason is not sufficient by itself.

Concepts to recall

  • A skew-symmetric matrix of odd order always has determinant 0; of even order it need not be zero (a perfect square).
  • det(A′) = det(A) for every square matrix; det(kA) = kn det(A) for order n.
ONE-MARK QUESTIONS (13)ISC 2025 Improvement Mathematics (860), Q1(vii)
Question 1(vii) · Board 2025 Imp.[1]
Statement 1: Every scalar matrix is a diagonal matrix. Statement 2: Every diagonal matrix is an identity matrix.
(a)Statement 1 is true and Statement 2 is false.
(b)Statement 2 is true and Statement 1 is false.
(c)Both the statements are true.
(d)Both the statements are false.
  1. A scalar matrix has all diagonal entries equal and all others zero: it is a special diagonal matrix. Statement 1 is true.
    [½]
  2. diag(2, 3, 5) is a diagonal matrix but is not an identity matrix (indeed not even scalar). Statement 2 is false.
    [½]
Answer
(a) Statement 1 is true and Statement 2 is false.

Concepts to recall

  • Hierarchy: identity ⊂ scalar ⊂ diagonal ⊂ square matrices.
  • Diagonal: aij = 0 for i ≠ j. Scalar: also aii all equal. Identity: scalar with entries 1.

Question 1(i) · Board 2025[1]
If A = 0a00, then A16 is:
(a)Unit matrix
(b)Null matrix
(c)Diagonal matrix
(d)Skew matrix
  1. A2 = 0a000a00 = 0000 = O
    [½]
  2. So A16 = (A2)8 = O8 = O, the null matrix.
    [½]
Answer
(b) Null matrix
Common slip Assuming a ≠ 0 keeps the matrix alive: it does not, because the (1,1) and (2,2) entries multiply to zero.

Concepts to recall

  • A matrix with Ak = O for some k is nilpotent; every higher power is also O.
  • Always try A2 first when a high power is asked: a pattern appears at once.
ONE-MARK QUESTIONS (13)ISC 2025 Mathematics (860), Q1(xi)
Question 1(xi) · Board 2025[1]
Statement 1: If ‘A’ is an invertible matrix, then (A2)−1 = (A−1)2.
Statement 2: If ‘A’ is an invertible matrix, then |A−1| = |A|−1.
(a)Statement 1 is true and Statement 2 is false.
(b)Statement 2 is true and Statement 1 is false.
(c)Both the statements are true.
(d)Both the statements are false.
  1. Statement 1: (A2)−1 = (AA)−1 = A−1A−1 = (A−1)2 (reversal law (AB)−1 = B−1A−1): true.
    [½]
  2. Statement 2: |A||A−1| = |AA−1| = |I| = 1, so |A−1| = 1/|A|: true. Both are true.
    [½]
Answer
(c) Both the statements are true.

Concepts to recall

  • Reversal law of inverses: (AB)−1 = B−1A−1.
  • |AB| = |A||B| and |I| = 1 give |A−1| = 1/|A|.
ONE-MARK QUESTIONS (13)ISC 2025 Mathematics (860), Q1(xiii)
Question 1(xiii) · Board 2025[1]
For what value of x, is A = 01−2−103x−30 a skew symmetric matrix?
  1. Skew symmetric: aij = −aji, so the diagonal is 0 (it is) and a31 = −a13.
    [½]
  2. a13 = −2, hence x = a31 = 2. (Check: a12 = 1 = −a21 and a23 = 3 = −a32 already hold.)
    [½]
Answer
x = 2

Concepts to recall

  • Skew symmetric: A′ = −A, i.e. aij = −aji; every diagonal entry is 0.
  • Only the unknown’s mirror entry has to be compared; the others serve as a check.
ONE-MARK QUESTIONS (13)CISCE Specimen 2025 Mathematics, Q1(i)
Question 1(i) · Specimen 2025[1]
A matrix which is both symmetric and skew symmetric matrix is a / an:
(a)triangular matrix
(b)identity matrix
(c)diagonal matrix
(d)null matrix
  1. Symmetric: A′ = A. Skew symmetric: A′ = −A. Both together give A = −A, so 2A = O.
    [½]
  2. Hence A = O, every entry is zero: the matrix is a null (zero) matrix.
    [½]
Answer
(d) null matrix
Common slip Choosing “diagonal”: a diagonal matrix is symmetric, but diag(1, 2) is not skew symmetric.

Concepts to recall

  • Symmetric: aij = aji; skew symmetric: aij = −aji, so every diagonal entry of a skew matrix is 0.
  • A zero matrix is the only matrix that is both; the identity is symmetric but not skew.

Question 1(x) · Specimen 2025[1]
In a third order matrix aij denotes the element of the ith row and the jth column. A = [aij] with aij = 0 for i = j, 1 for i > j, −1 for i < j.
Assertion: Matrix A is not invertible.
Reason: Determinant A = 0.
(a)Both Assertion and Reason are true and Reason is the correct explanation for Assertion.
(b)Both Assertion and Reason are true but Reason is not the correct explanation for Assertion.
(c)Assertion is true and Reason is false.
(d)Assertion is false and Reason is true.
  1. A = 0−1−110−1110 has A′ = −A: it is skew symmetric of odd order 3, so |A| = |A′| = |−A| = (−1)3|A| ⇒ |A| = 0 (direct expansion also gives 0): Reason is true.
    [½]
  2. A square matrix is invertible iff |A| ≠ 0. Since |A| = 0, A is not invertible: Assertion true, and the Reason is exactly why.
    [½]
Answer
(a) Both Assertion and Reason are true and Reason is the correct explanation for Assertion.

Concepts to recall

  • Skew symmetric matrix of odd order: |A| = 0.
  • A⁻¹ exists ⇔ |A| ≠ 0 (A is non-singular).
ONE-MARK QUESTIONS (13)ISC 2024 Mathematics (860), Q1(vii)
Question 1(vii) · Board 2024[1]
Assertion: Let the matrices A = −32−54 and B = 4−25−3 be such that A100B = BA100.
Reason: AB = BA implies AnB = BAn for all positive integers n.
(a)Both Assertion and Reason are true and Reason is the correct explanation for Assertion.
(b)Both Assertion and Reason are true but Reason is not the correct explanation for Assertion.
(c)Assertion is true and Reason is false.
(d)Assertion is false and Reason is true.
  1. Reason: if AB = BA then AnB = An−1(AB) = An−1BA = … = BAn (move B across one A at a time). True.
    [½]
  2. Assertion: AB = −200−2 = BA (both products equal −2I), so by the Reason A100B = BA100. True, and the Reason is exactly why.
    [½]
Answer
(a) Both Assertion and Reason are true and Reason is the correct explanation for Assertion.
Marking note Here AB = BA = −2I; verified in the checker.

Concepts to recall

  • Matrix multiplication is not commutative in general; commuting matrices commute with each other’s powers.
  • Always compute AB and BA for the given matrices before judging the Assertion.
ONE-MARK QUESTIONS (13)ISC 2024 Mathematics (860), Q1(x)
Question 1(x) · Board 2024[1]
If A and B are symmetric matrices of the same order, then AB − BA is:
(a)Skew − symmetric matrix
(b)Symmetric matrix
(c)Diagonal matrix
(d)Identity matrix
  1. (AB − BA)′ = (AB)′ − (BA)′ = B′A′ − A′B′ = BA − AB (as A′ = A, B′ = B).
    [½]
  2. = −(AB − BA), so AB − BA is skew-symmetric.
    [½]
Answer
(a) Skew-symmetric matrix

Concepts to recall

  • Reversal law of transpose: (PQ)′ = Q′P′.
  • Skew-symmetric: M′ = −M. Note AB + BA would be the symmetric one.
TWO-MARK QUESTIONS (2)ISC 2025 Improvement Mathematics (860), Q6
Question 6 · Board 2025 Imp.[2]
In a market survey, three commodities A, B and C were studied. Each commodity had three varieties. To find the index number of A, B and C, fixed weights were assigned to the three varieties of each commodity. Table: A: varieties I, II, III = 1, 2, 3, total weight P; B: 2, 4, 5, total weight Q; C: 3, 5, 6, total weight R.
(i) Represent the above information in matrix form.
(ii) Find the value of P, Q and R if the weights assigned to A, B and C are 2 kg, 3 kg and 1 kg respectively.
  1. (i) 123245356w1w2w3 = PQR (rows: A, B, C; columns: varieties I, II, III).
    [1]
  2. (ii) With the weights 2, 3, 1: 123245356231 = 2 + 6 + 34 + 12 + 56 + 15 + 6 = 112127. So P = 11 kg, Q = 21 kg, R = 27 kg.
    [1]
Answer
P = 11 kg, Q = 21 kg, R = 27 kg
Marking note The wording "weights assigned to A, B and C" is loose (the weights belong to the three varieties). The matrix is symmetric, so reading 2, 3, 1 as weights of A, B, C or of the three varieties gives the same P, Q, R = 11, 21, 27.

Concepts to recall

  • A table of rows and columns is a matrix; a total weight is a row of the matrix times the column of weights (a matrix product).
  • Row-by-column multiplication: (3 × 3)(3 × 1) = (3 × 1).
TWO-MARK QUESTIONS (2)ISC 2025 Mathematics (860), Q5
Question 5 · Board 2025[2]
Three shopkeepers Gaurav, Rizwan and Jacob use carry bags made of polythene, handmade paper and newspaper. The number of polythene bags, handmade bags and newspaper bags used by Gaurav, Rizwan and Jacob are (20, 30, 40), (30, 40, 20) and (40, 20, 30) respectively. One polythene bag costs ₹ 1, one handmade bag is for ₹ 5 and one newspaper bag costs ₹ 2. Gaurav, Rizwan and Jacob spend ₹ A, ₹ B and ₹ C respectively on these bags. Using the concepts of matrices and determinants: (i) Represent the above information in matrix form. (ii) Find the values of ₹ A, ₹ B and ₹ C.
  1. (i) (Number of bags) × (cost per bag) = (amount spent):
    203040304020402030152 = ABC
    [1]
  2. (ii) A = 20(1) + 30(5) + 40(2) = 250; B = 30(1) + 40(5) + 20(2) = 270; C = 40(1) + 20(5) + 30(2) = 200.
    [1]
Answer
(i) as above; (ii) A = ₹ 250, B = ₹ 270, C = ₹ 200.

Concepts to recall

  • Row of the first matrix = what one shopkeeper buys; column of the second = the unit prices. Their product is the total spend.
  • Matrix product (3×3)(3×1) is a 3×1 column: one amount per shopkeeper.
THREE-MARK QUESTIONS (1)ISC Specimen 2027 Mathematics, Q13 (OR alternative)
Question 13 · Specimen 2027 (OR)[3]
OR alternative of Question 13; not counted in the paper’s 80 marks.
(ii) A school is organising its Annual Day function and plans to decorate every chair with a ribbon and every table with a cover. There are 150 chairs and 20 tables, all of which need decorations. Company A charges ₹12 per chair ribbon and ₹180 per table cover. Company B charges ₹10 per chair ribbon and ₹200 per table cover. By setting up one matrix equation that includes both companies, compare the overall prices that would be charged by the two companies.
  1. Quantities Q = [150   20] (chairs, tables). Prices P with a column per company: P = 1210180200 (row 1 chair ribbon, row 2 table cover; column 1 Company A, column 2 Company B).
    [1½]
  2. Total cost C = QP = [150 × 12 + 20 × 180   150 × 10 + 20 × 200] = [1800 + 3600   1500 + 4000] = [5400   5500].
    [1]
  3. Company A charges ₹5400 and Company B ₹5500: Company A is cheaper by ₹100.
    [½]
Answer
C = [5400   5500]: Company A (₹5400) is ₹100 cheaper than Company B (₹5500)
Marking note Q P in the other order (P Q) is not defined, which is why the matrices are arranged as above.

Concepts to recall

  • A product QP is defined when the columns of Q equal the rows of P; a 1 × 2 times a 2 × 2 gives a 1 × 2 row, one entry per company.
  • Put the quantities in a row and each company’s prices in a column so that row × column gives “quantity × price” summed.
