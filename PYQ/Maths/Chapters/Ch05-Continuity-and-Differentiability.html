What to revise

  • Second-order identities (4 marks, nearly every paper): y = 3 cos(log x) + 4 sin(log x); x = tan((1/a) log y); x = sin t, y = sin pt; y = x3 log(1/x); y = (A + Bx)e−2x. Differentiate twice and substitute.
  • Techniques: implicit and logarithmic differentiation (xy = yx, xy = ex−y), derivatives of inverse trigonometric functions after a substitution, x = ey + ey + ….
  • Continuity: find k (or p, q) for continuity at a point, read continuity and differentiability off a graph, and discuss f(x) = |x − 1| + |x − 4|.
  • Habit: left-hand and right-hand limits, then the value, written out in that order.

Question 1(ii) · Board 2026[1]
Consider the function ‘f’ given by f(x) = log x, x > 0, then the function ‘f’ is:
(a)differentiable and continuous at x = 1.
(b)differentiable but not continuous at x = 1.
(c)continuous but not differentiable at x = 1.
(d)neither differentiable nor continuous at x = 1.
  1. log x is defined for every x > 0, so limx→1 log x = log 1 = 0 = f(1): continuous at x = 1.
    [½]
  2. f′(x) = 1/x exists for all x > 0, in particular f′(1) = 1: differentiable at x = 1.
    [½]
Answer
(a) differentiable and continuous at x = 1.

Concepts to recall

  • Every elementary function (polynomial, log, exponential, trigonometric) is continuous and differentiable throughout its domain.
  • Differentiable ⇒ continuous. The converse fails only at sharp corners such as |x|.

Question 1(iv) · Board 2026[1]
Assertion: f(x) = { 1 + x, x ≤ 2 ; 5 − x, x > 2 } at x = 2 is not differentiable.
Reason: A function is said to be differentiable at x = a if Left hand derivative is equal to Right hand derivative i.e., Lf′(a) = Rf′(a).
(a)Both Assertion and Reason are true and Reason is the correct explanation for Assertion.
(b)Both Assertion and Reason are true but Reason is not the correct explanation for Assertion.
(c)Assertion is true and Reason is false.
(d)Assertion is false and Reason is true.
  1. Left derivative at 2: f(x) = 1 + x gives Lf′(2) = 1. Right derivative at 2: f(x) = 5 − x gives Rf′(2) = −1. (Both pieces equal 3 at x = 2, so f is continuous, but there is a corner.)
    [½]
  2. Lf′(2) ≠ Rf′(2), so f is not differentiable at 2: the Assertion is true. The Reason is the definition of differentiability, true, and it is exactly why the Assertion holds.
    [½]
Answer
(a) Both Assertion and Reason are true and Reason is the correct explanation for Assertion.

Concepts to recall

  • Differentiable at a ⇔ Lf′(a) = Rf′(a) (finite).
  • Assertion–Reason: first test each statement, then ask whether the Reason explains the Assertion.

Question 1(iii) · Specimen 2026[1]
The derivative of xy = c2 with respect to x is:
(a)dy/dx = (2c − y)/x
(b)dy/dx = c2/x2
(c)dy/dx = −y/x
(d)dy/dx = y/x
  1. Differentiate both sides with respect to x; c is a constant, so (c2)′ = 0. Product rule on the left: x(dy/dx) + y·1 = 0.
    [½]
  2. x(dy/dx) = −y ⇒ dy/dx = −y/x.
    [½]
Answer
(c) dy/dx = −y/x
Common slip Differentiating c2 as 2c (option a).

Question 1(vii) · Specimen 2026[1]
Observe the following graphs (a), (b), (c) and (d), each representing a different type of function.
Statement 1: A function which is continuous at a point may not be differentiable at that point.
Statement 2: Graph (c) is an example of a function that is continuous but not differentiable at the origin.
(a)Statement 1 is true and Statement 2 is false.
(b)Statement 2 is true and Statement 1 is false.
(c)Both the statements are true.
(d)Both the statements are false.
  1. Statement 1 is true: continuity does not imply differentiability. Example: f(x) = |x| is continuous at 0, but Lf′(0) = −1 ≠ Rf′(0) = 1. Graph (a), with its sharp corner at the origin, shows exactly this.
    [½]
  2. Statement 2 is false: graph (c) is a smooth wave-like curve with no corner or break anywhere (it dips just below the origin and does not pass through it), so it is differentiable at x = 0 and cannot be an example of a function that is not differentiable there. (Graphs (b) and (d) have jumps, so they are not even continuous.)
    [½]
Answer
(a) Statement 1 is true and Statement 2 is false.
Marking note The graphs are redrawn from the question; (a) is the corner-at-the-origin graph.

Concepts to recall

  • Differentiable ⇒ continuous, but continuous ⇏ differentiable. The standard failure is a sharp corner (or cusp, or vertical tangent).
  • Reading a graph: a corner = unequal left and right slopes; a gap/jump = not continuous; a smooth unbroken curve = differentiable.

The derivative of tan−1[(cos x − sin x)/(cos x + sin x)] with respect to x, where x ∈ (0, π/2), is:

(d)−1

Question 1(iv) · Board 2024[1]
The graph of the function f is shown below. Of the following options, at what values of x is the function f NOT differentiable?
(a)At x = 0 and x = 2
(b)At x = 1 and x = 3
(c)At x = −1 and x = 1
(d)At x = −1·5 and x = 1·5
  1. At x = 0 the left branch ends at the open dot (0, −1) while f(0) = 0: f is not even continuous there, hence not differentiable.
    [½]
  2. At x = 2 the lower semicircle meets the upper semicircle with a vertical tangent (slope infinite), so the derivative does not exist. At 1, 3, −1, ±1·5 the curve is smooth.

TWO-MARK QUESTIONS (6)ISC Specimen 2027 Mathematics, Q5
Question 5 · Specimen 2027[2]
(i) Determine the values of constants p and q such that the function f(x) = {p sin x + q∀x ≤ 0x2 + 2x + 1∀x > 0 is differentiable at x = 0.
OR
(ii) Observe the graph given below: (a) State the value(s) of x where the function has removable discontinuity. [1] (b) State the value(s) of x where the graph of the function is not differentiable. [1]

Solution to the first alternative

  1. Differentiable ⇒ continuous. LHL = limx→0⁻ (p sin x + q) = q, RHL = limx→0⁺ (x2 + 2x + 1) = 1 and f(0) = q. Equating, q = 1.
    [1]
  2. LHD = d/dx(p sin x + q) at 0 = p cos 0 = p; RHD = d/dx(x2 + 2x + 1) at 0 = 2. Equating, p = 2.
    [1]
Answer
p = 2, q = 1

Solution to the OR alternative

  1. (a) At x = −2 the two sides join smoothly (LHL = RHL) but there is an open circle: f(−2) is missing. So the removable discontinuity is at x = −2.
    [1]
  2. (b) The graph is discontinuous at x = −2 (hole), at x = 0 (left limit about 2·6, but f(0) ≈ 2·1) and at x = 2 (jump from −6 to about 0·5). A function that is discontinuous at a point is not differentiable there: x = −2, 0 and 2.
    [1]
Answer
(a) x = −2; (b) x = −2, 0, 2

Concepts to recall

  • Differentiable at a ⇒ continuous at a, and LHD = RHD there.
  • Two unknown constants need two conditions: continuity gives q, equal derivatives give p.
  • For a piecewise function whose pieces are differentiable, the one-sided derivatives at the join are the derivatives of the pieces evaluated at the join.
  • Removable discontinuity: limx→a f(x) exists but f(a) is missing or different (an open circle with the curve continuing through).
  • A jump discontinuity has unequal left and right limits.
  • Differentiable ⇒ continuous, so every point of discontinuity is a point of non-differentiability (corners and cusps add more).

Question 10 · Specimen 2027[3]
If x = 3z + 1 and y = f(x), then prove that 9 d2y/dx2 = d2y/dz2.
  1. dx/dz = 3. By the chain rule dy/dz = (dy/dx)(dx/dz) = 3 dy/dx.

    [1]

    [1]

THREE-MARK QUESTIONS (2)ISC Specimen 2027 Mathematics, Q11
Question 11 · Specimen 2027[3]
Also draws on: part (ii) judges a local maximum from f'(x) (Ch 6).
(i) Find the derivative of the function f(x) = log[(√(1 + x2) + x)/(√(1 + x2) − x)] + tan−1(2x/(1 − x2)) with respect to x. [2] (ii) An analyst claims that the function f(x) has a local maximum at some point x = c. Evaluate this claim using the expression for f′(x). [1]
  1. (i) Multiply the numerator and denominator inside the log by (√(1 + x2) + x): the denominator becomes (1 + x2) − x2 = 1, so the log term = log(√(1 + x2) + x)2 = 2 log(√(1 + x2) + x). Also tan−1(2x/(1 − x2)) = 2 tan−1x (up to a constant). So f(x) = 2 log(√(1 + x2) + x) + 2 tan−1x.
    [1]
  2. f′(x) = 2 · [x/√(1 + x2) + 1] / (√(1 + x2) + x) + 2/(1 + x2) = 2/√(1 + x2) + 2/(1 + x2), because x/√(1 + x2) + 1 = (x + √(1 + x2))/√(1 + x2).
    [1]
  3. (ii) Both terms of f′(x) are positive for every real x, so f′(x) > 0 and never zero. A local maximum needs f′(c) = 0 with a sign change from + to −. f is strictly increasing, so the claim is incorrect.
    [1]
Answer
(i) f′(x) = 2/√(1 + x2) + 2/(1 + x2); (ii) the claim is false: f′(x) > 0 for all x
Marking note The term tan−1(2x/(1 − x2)) equals 2 tan−1x only for |x| < 1; for |x| > 1 it equals 2 tan−1x ∓ π and it is undefined at x = ±1, so strictly f is defined for x ≠ ±1. The derivative is the same constant-free expression in every interval, so the answer (and part (ii), where f′ > 0 on each interval of the domain) is unaffected. CISCE’s key ignores this.

Concepts to recall

  • Simplify before differentiating: rationalise the quotient inside the logarithm; tan−1(2x/(1 − x2)) = 2 tan−1x.
  • d/dx log(√(1 + x2) + x) = 1/√(1 + x2).
  • A local maximum of a differentiable function requires f′ = 0 and a sign change from positive to negative; a strictly positive derivative rules it out.

Concepts to recall

  • Simplify first: log(1/x) = −log x makes the differentiation shorter.
  • Product rule: (uv)′ = u′v + uv′, with (log x)′ = 1/x.
  • For “prove that … = 0”, substitute y′ and y″ and show the log terms cancel.

Question 8 · Specimen 2026[4]
If y = (A + Bx)e−2x, prove that d2ydx2 + 4dydx + 4y = 0.
  1. Differentiate (product rule): dy/dx = Be−2x + (A + Bx)(−2e−2x) = Be−2x − 2y.
    [1]
  2. So dy/dx + 2y = Be−2x ……(1).
    [1]
  3. Differentiate (1) again: d2y/dx2 + 2 dy/dx = −2Be−2x = −2(dy/dx + 2y), using (1).
    [1]
  4. d2y/dx2 + 2 dy/dx + 2 dy/dx + 4y = 0 ⇒ d2y/dx2 + 4 dy/dx + 4y = 0. Proved.
    [1]
Answer
Proved: d2y/dx2 + 4 dy/dx + 4y = 0

Concepts to recall

  • Two arbitrary constants (A, B) ⇒ the differential equation is of order 2: differentiate twice and eliminate both.
  • Trick: keep the term Be−2x as one block (equation (1)); it appears again after the second differentiation and can then be eliminated in one step.
  • This is the auxiliary equation (m + 2)2 = 0, a repeated root −2.

(i) If x = sin t, y = sin pt, prove that (1 − x2) d2y/dx2 − x dy/dx + p2y = 0.
  1. dx/dt = cos t, dy/dt = p cos pt, so dy/dx = p cos pt/cos t. Since cos t = √1 − x2: √1 − x2 y1 = p cos pt.
    [1]
  2. Differentiate again w.r.t. x: √1 − x2 y2 − [x/√1 − x2] y1 = −p2 sin pt · (dt/dx) = −p2y/√1 − x2 (as dt/dx = 1/cos t).
    [2]
  3. Multiply by √1 − x2: (1 − x2)y2 − xy1 = −p2y, i.e. (1 − x2) d2y/dx2 − x dy/dx + p2y = 0. Proved.
    [1]
Answer
(1 − x2) y2 − xy1 + p2y = 0 (proved).

Concepts to recall

  • Parametric derivative dy/dx = (dy/dt)/(dx/dt); for the second derivative differentiate again with the chain rule, d/dx = (dt/dx) d/dt.
  • Replace cos t by √1 − x2 (valid for cos t > 0): a standard trick in "prove the differential equation" questions.
  • Derivative of √1 − x2 is −x/√1 − x2.

(i) If x = tan((1/a) log y) then show that (1 + x2) d2y/dx2 + (2x − a) dy/dx = 0.

    [1]

    [1]
  3. Differentiate again: (1 + x2) y2 + 2x y1 = a y1.
    [1]
  4. Hence (1 + x2) y2 + (2x − a) y1 = 0. Hence proved.
    [1]

(1 + x2) d2y/dx2 + (2x − a) dy/dx = 0

Concepts to recall

  • To prove a relation involving y″, first get a first-order relation free of fractions, then differentiate it again (product rule on the left side).

(ii) If y = (x + √(a2 + x2))m, prove that (a2 + x2) d2y/dx2 + x dy/dx − m2y = 0.

If y = 3 cos(log x) + 4 sin(log x), show that x2 d2ydx2 + x dydx + y = 0.

    [½]
  4. Hence x2 d2y/dx2 + x dy/dx + y = 0.
    [½]
