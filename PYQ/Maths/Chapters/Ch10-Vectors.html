What to revise

  • Dot and cross products: |a − 2b|, projection of b on a, a unit vector or a vector of given magnitude perpendicular to two vectors, area of a parallelogram or triangle from a × b.
  • Short proofs (2 marks): a × b = a × c implies b = c or a ∥ (b − c); conditions on |a × b| and a · b; collinearity of three points by vectors; specimen 2027 Q8 on the nearest point on a road.
  • Habit: state the formula (a · b = |a||b| cos θ, |a × b| = |a||b| sin θ) before substituting.

Question 1(xi) · Specimen 2027[1]
If a = 2i + 3j − k, b = −i + 2j − 4k, c = i + j + k (vectors), then (a × b)·(a × c) is:
(a)60
(b)64
(c)74
(d)−74
  1. a × b = ijk23−1−12−4 = (−12 + 2)i − (−8 − 1)j + (4 + 3)k = −10i + 9j + 7k.
    [½]
  2. a × c = ijk23−1111 = (3 + 1)i − (2 + 1)j + (2 − 3)k = 4i − 3j − k.
  3. Dot product = (−10)(4) + (9)(−3) + (7)(−1) = −40 − 27 − 7 = −74.
    [½]
Answer
(d) −74
Marking note Cross-check: a·a = 14, b·c = −3, a·c = 4, b·a = 8, so the identity gives 14(−3) − 4(8) = −74, the same.

Concepts to recall

  • Cross product by the determinant with i, j, k in the first row; the middle term carries a minus sign.
  • Cross-check by the identity (a × b)·(a × c) = (a·a)(b·c) − (a·c)(b·a).

Question 15(i) · Board 2026[1]
A scalar is multiplied by a unit vector, then the resultant is:
Statement 1: A vector with the magnitude of the scalar.
Statement 2: A vector with unit magnitude.
(a)Statement 1 is true and Statement 2 is false.
(b)Statement 2 is true and Statement 1 is false.
(c)Both the statements are true.
(d)Both the statements are false.
  1. If λ is a scalar and n̂ a unit vector, |λn̂| = |λ||n̂| = |λ|, so the product is a vector whose magnitude is that of the scalar: Statement 1 is true.
    [½]
  2. The magnitude is |λ|, not 1 (unless λ = ±1), so Statement 2 is false.
    [½]
Answer
(a) Statement 1 is true and Statement 2 is false.
Marking note Statement 1 is read as “magnitude equal to the magnitude (modulus) of the scalar”, which is the intended meaning.

Concepts to recall

  • |λa| = |λ||a|: multiplying by a scalar scales the length and keeps the line of action (reverses the sense if λ < 0).
  • A unit vector has magnitude 1; a unit vector in the direction of a is a/|a|.

ONE-MARK QUESTIONS (13)ISC Specimen 2026 Mathematics, Q15(i)
Question 15(i) · Specimen 2026[1]
Consider the following statements and choose the correct option:
Statement 1: If a and b represent two adjacent sides of a parallelogram, then the diagonals are represented by a + b and a − b.
Statement 2: If a and b represent two diagonals of a parallelogram, then the adjacent sides are represented by 2(a + b) and 2(a − b).
(a)Statement 1 is true and Statement 2 is false.
(b)Statement 2 is true and Statement 1 is false.
(c)Both the statements are true.
(d)Both the statements are false.
  1. Statement 1: with adjacent sides a and b from a common vertex, the diagonals are a + b (triangle law) and a − b (the other diagonal). True.
    [½]
  2. Statement 2: the diagonals bisect each other, so if the diagonals are a and b the sides are (a + b)/2 and (a − b)/2, not 2(a + b) and 2(a − b), which are four times too long. False.
    [½]
Answer
(a) Statement 1 is true and Statement 2 is false.

Concepts to recall

  • Parallelogram: diagonals = sum and difference of the adjacent sides; conversely sides = half the sum and half the difference of the diagonals.
  • Quick check with a rhombus or a square: the diagonals are longer than the sides, but only by a factor √2 in a square, never 2(a + b) of them.

Question 15(iv) · Specimen 2026[1]
If a and b are unit vectors enclosing an angle θ and |a + b| < 1, then find the values between which θ lies.
  1. |a + b|2 = |a|2 + |b|2 + 2a·b = 1 + 1 + 2 cos θ = 2 + 2 cos θ. Condition: 2 + 2 cos θ < 1 ⇒ cos θ < −1/2.
    [½]
  2. With 0 ≤ θ ≤ π, cos θ < −1/2 ⇒ 2π/3 < θ ≤ π.
    [½]
Answer
θ ∈ (2π/3, π]

Concepts to recall

  • |a + b|2 = |a|2 + |b|2 + 2a·b.
  • The angle between two vectors lies in [0, π]; cos θ is decreasing there, so cos θ < −1/2 ⇒ θ > 2π/3.

If a is a unit vector perpendicular to b and (a + 2b) · (3a − b) = −5, find |b|.
  1. |a| = 1 and a·b = 0. Expand: 3|a|2 − a·b + 6b·a − 2|b|2 = 3 + 5(a·b) − 2|b|2 = 3 − 2|b|2.
    [½]
  2. 3 − 2|b|2 = −5 ⇒ |b|2 = 4 ⇒ |b| = 2.
    [½]
Answer
|b| = 2
Common slip Writing (a + 2b)·(3a − b) = 3|a|2 − 2|b|2 and forgetting the cross terms (they vanish here, but only because a·b = 0).

Concepts to recall

  • Perpendicular vectors: a·b = 0; unit vector: |a|2 = 1; the dot product is distributive and commutative.

TWO-MARK QUESTIONS (6)ISC Specimen 2027 Mathematics, Q7
Question 7 · Specimen 2027[2]
(i) Find the vector projection of B = 6i + 3j + 2k on A = i − 2j − 2k and the scalar component of B on A.
OR
(ii) If the position vectors of three points A, B, C are respectively i + j + k, 2i + 3j − 4k and 7i + 4j + 9k, find the unit vector perpendicular to the plane of triangle ABC.

Solution to the first alternative

  1. B·A = 6(1) + 3(−2) + 2(−2) = 6 − 6 − 4 = −4; |A|2 = 1 + 4 + 4 = 9, |A| = 3.
    [½]
  2. Vector projection of B on A = [(B·A)/|A|2] A = −(4/9)(i − 2j − 2k).
    [1]
  3. Scalar component of B on A = (B·A)/|A| = −4/3.
    [½]
Answer
Vector projection = −(4/9)(i − 2j − 2k) = (−4i + 8j + 8k)/9; scalar component = −4/3
Common slip Dividing by |A| instead of |A|2 in the vector projection.

Solution to the OR alternative

  1. AB = (2 − 1, 3 − 1, −4 − 1) = i + 2j − 5k; AC = (7 − 1, 4 − 1, 9 − 1) = 6i + 3j + 8k.
    [½]
  2. AB × AC = ijk12−5638 = (16 + 15)i − (8 + 30)j + (3 − 12)k = 31i − 38j − 9k.
    [1]
  3. |AB × AC| = √(961 + 1444 + 81) = √2486. Unit vector = ±(31i − 38j − 9k)/√2486.
    [½]
Answer
±(31i − 38j − 9k)/√2486
Marking note CISCE’s key prints the unit vector with the + sign only; the opposite vector is equally perpendicular to the plane, so accept either (or ±).

Concepts to recall

  • Scalar component (projection length) of B on A = B·A / |A|.
  • Vector projection = (scalar component) × (unit vector along A) = (B·A/|A|2) A.
  • A negative dot product means the angle between the vectors is obtuse, so the projection points against A.
  • AB × AC is perpendicular to both AB and AC, hence to the plane ABC; its magnitude is twice the area of the triangle.
  • Unit vector = vector / magnitude; both ± directions are perpendicular to the plane.
  • Position vectors: AB = (position of B) − (position of A).
TWO-MARK QUESTIONS (6)ISC Specimen 2027 Mathematics, Q8
Question 8 · Specimen 2027[2]
Three landmarks of Dehradun are joined by straight roads. Clock tower of Dehradun is considered as the ‘origin’. IMA (I) is 3 km east and 9 km north of Clock Tower and Rajpur (R) is 5 km east and 5 km south of IMA. A bus stop (S) is situated two thirds of the way along the road from Clock Tower to IMA. Considering i as a 1 km vector pointing east and j as a 1 km vector pointing north: (i) Find the position vector of the bus stop (S) relative to the Clock Tower. [1] (ii) Prove that the bus stop (S) is the closest point to Rajpur (R) on the Clock Tower to IMA (I) road. [1]
  1. (i) OI = 3i + 9j; OR = OI + (5i − 5j) = 8i + 4j. S is ⅔ of the way from O to I: OS = ⅔(3i + 9j) = 2i + 6j.
    [1]
  2. (ii) RS = OS − OR = (2 − 8)i + (6 − 4)j = −6i + 2j.
    [½]
  3. OS·RS = (2)(−6) + (6)(2) = −12 + 12 = 0, so RS ⊥ OS (S lies on OI). The perpendicular from R to the road meets it at S, and the perpendicular distance is the shortest: S is the nearest point of the road to R.
    [½]
Answer
(i) OS = 2i + 6j; (ii) RS·OS = 0, so S is the foot of the perpendicular from R to the road
Marking note S has to lie on the road itself (the segment OI): it does, being ⅔ of the way along it. The perpendicular distance is |RS| = √40 km.

Concepts to recall

  • Position vector of the point dividing OI in the ratio 2 : 1 is ⅔ OI (section formula).
  • The nearest point on a line to an external point is the foot of the perpendicular from that point to the line: the vector joining them is perpendicular to the line’s direction.
  • Two vectors are perpendicular if and only if their dot product is zero.
TWO-MARK QUESTIONS (6)ISC 2026 Mathematics (860), Q16
Question 16 · Board 2026[2]
(i) Three drone cameras A, B and C are recording a hockey match. Their positions with respect to a control tower O are given by the following coordinates: A(1, 4, 6), B(3, 4, 5) and C(5, 4, 4). Using vector method, show that the drone cameras A, B and C are moving in a straight path while recording the match.
OR
(ii) If a and b are mutually perpendicular vectors, |a + b| = 13 and |a| = 5, then find the value of |b|.

Solution to the first alternative

  1. Position vectors: OA = î + 4ĵ + 6k̂, OB = 3î + 4ĵ + 5k̂, OC = 5î + 4ĵ + 4k̂. AB = OB − OA = 2î − k̂.
    [½]
  2. BC = OC − OB = 2î − k̂.
    [½]
  3. AB = BC: the two vectors are parallel and share the point B, so A, B, C lie on one straight line (B is the midpoint of AC).
    [1]
Answer
AB = BC = 2î − k̂, so A, B, C are collinear.

Solution to the OR alternative

  1. |a + b|2 = |a|2 + |b|2 + 2a·b, and a·b = 0 because a ⊥ b.
    [1]
  2. 169 = 25 + |b|2 ⇒ |b|2 = 144 ⇒ |b| = 12.
    [1]
Answer
|b| = 12

Concepts to recall

  • Three points are collinear ⇔ AB = λBC for some scalar λ (parallel vectors with a common point).
  • Alternative test: AB × AC = 0.
  • Vector from P to Q = position vector of Q − position vector of P.
  • |a + b|2 = |a|2 + |b|2 + 2a·b.
  • Perpendicular vectors have a·b = 0 (Pythagoras: 5, 12, 13).
TWO-MARK QUESTIONS (6)ISC Specimen 2026 Mathematics, Q16
Question 16 · Specimen 2026[2]
(i) A building is to be constructed in the form of a triangular pyramid ABCD as shown in the figure. Let the angular points be A(0, 1, 2), B(3, 0, 1), C(4, 3, 6) and D(2, 3, 2) and let G be the point of intersection of the medians of ΔBCD. Using the above information: (a) What will be the length of the vector AG? (b) Find the area of ΔABC.
OR
(ii) What are the values of x for which the angle between the vectors 2x2î + 3xĵ + k̂ and î − 2ĵ + x2k̂ is obtuse?

Solution to the first alternative

  1. (a) G is the centroid of ΔBCD: G = ((3 + 4 + 2)/3, (0 + 3 + 3)/3, (1 + 6 + 2)/3) = (3, 2, 3). AG = (3 − 0)î + (2 − 1)ĵ + (3 − 2)k̂ = 3î + ĵ + k̂, |AG| = √(9 + 1 + 1) = √11 units.
    [1]
  2. (b) AB = (3, −1, −1), AC = (4, 2, 4). AB × AC = |î ĵ k̂; 3 −1 −1; 4 2 4| = (−4 + 2)î − (12 + 4)ĵ + (6 + 4)k̂ = −2î − 16ĵ + 10k̂, magnitude √(4 + 256 + 100) = √360 = 6√10. Area = ½ × 6√10 = 3√10 square units.
    [1]
Answer
(a) |AG| = √11 units; (b) area of ΔABC = 3√10 square units

Solution to the OR alternative

  1. The angle is obtuse when cos θ < 0, i.e. when a·b < 0 (both vectors are non-zero: the first has k̂ component 1 and the second has î component 1).
    [½]
  2. a·b = 2x2(1) + 3x(−2) + (1)(x2) = 3x2 − 6x.
    [½]
  3. 3x(x − 2) < 0 ⇒ 0 < x < 2 (the product is negative between the roots).
    [1]
Answer
x ∈ (0, 2)
Marking note The vectors are never antiparallel for 0 < x < 2 (that would need 3x and 2x2 to have opposite signs), so every such x gives an obtuse angle, not a straight one.

Concepts to recall

  • The point where the medians meet is the centroid, the mean of the three vertices: G = (b + c + d)/3.
  • Area of a triangle with adjacent sides u, v = ½|u × v|.
  • Obtuse ⇔ cos θ < 0 ⇔ a·b < 0 (if the vectors are not antiparallel; antiparallel would give θ = π, a straight angle).
  • A quadratic x(x − 2) < 0 holds strictly between its roots.
TWO-MARK QUESTIONS (6)CISCE Specimen 2025 Mathematics, Q16
Question 16 · Specimen 2025[2]
(i) Find a vector of magnitude 9 units and perpendicular to the vectors a = 4i − j + k and b = −2i + j − 2k.
OR
(ii) What are the values of x for which the angle between the vectors 2x2i + 3xj + k and i − 2j + x2k is obtuse?

Solution to the first alternative

  1. A vector perpendicular to both is a × b = ijk4−11−21−2 = i(2 − 1) − j(−8 + 2) + k(4 − 2) = i + 6j + 2k, with |a × b| = √(1 + 36 + 4) = √41.
    [1]
  2. Required vector = 9 (a × b)/|a × b| = (9/√41)(i + 6j + 2k).
    [1]
Answer
(9/√41)(i + 6j + 2k) (the negative of this also qualifies)

Solution to the OR alternative

  1. The angle is obtuse ⇔ cos θ < 0 ⇔ a·b < 0 (the magnitudes are positive). a·b = 2x2 − 6x + x2 = 3x2 − 6x.
    [1]
  2. 3x(x − 2) < 0 ⇒ 0 < x < 2. (The vectors are never exactly opposite, so no value needs to be removed.)
    [1]
Answer
0 < x < 2, i.e. x ∈ (0, 2)

Concepts to recall

  • a × b is perpendicular to both a and b; divide by its magnitude for a unit vector, multiply by 9.
  • Two answers exist, ±: accept either.
  • Angle θ between a and b: cos θ = a·b/(|a||b|). Obtuse ⇔ a·b < 0 (and not antiparallel).
  • Solve the quadratic inequality by roots and sign.
TWO-MARK QUESTIONS (6)ISC 2024 Mathematics (860), Q16
Question 16 · Board 2024[2]
(i) If a × b = a × c where a, b and c are non-zero vectors, then prove that either b = c or a and (b − c) are parallel.
OR
(ii) If a and b are two non-zero vectors such that |a × b| = a·b, find the angle between a and b.

Solution to the first alternative

  1. a × b − a × c = 0 ⇒ a × (b − c) = 0 (distributive law).
    [1]
  2. The cross product of two vectors is zero iff one is the zero vector or they are parallel. a ≠ 0, so either b − c = 0, i.e. b = c, or a ∥ (b − c).
    [1]
Answer
Proved.

Solution to the OR alternative

  1. |a × b| = |a||b| sinθ and a·b = |a||b| cosθ, so |a||b| sinθ = |a||b| cosθ.
    [1]
  2. As |a||b| ≠ 0, tanθ = 1 and 0 ≤ θ ≤ π gives θ = π/4 (45°).
    [1]
Answer
θ = π/4

Concepts to recall

  • a × b = 0 ⇔ a = 0 or b = 0 or a ∥ b; so you cannot “cancel” a as in ordinary algebra.
  • The cross product is distributive over addition.
  • |a × b| = |a||b| sinθ, a·b = |a||b| cosθ; dividing gives tanθ.
  • tanθ = 1 ⇒ θ = π/4 (the other solution 5π/4 is outside [0, π]).

Question 17 · Board 2025 Imp.[4]
Consider the two vectors a = 2i − 3j + 4k and b = 5i + qj − k.
(i) Calculate ‘q’ if both the vectors are perpendicular to each other. [1] (ii) Find the unit vector perpendicular to both a and b if q = 4. [2] (iii) Find the projection of a on b if q = 1. [1]
  1. (i) a·b = 10 − 3q − 4 = 0, so q = 2.
    [1]
  2. (ii) With q = 4: a × b = |i j k; 2 −3 4; 5 4 −1| = (3 − 16)i − (−2 − 20)j + (8 + 15)k = −13i + 22j + 23k.
    [1]
  3. |a × b| = √(169 + 484 + 529) = √1182. Unit vector = ±(−13i + 22j + 23k)/√1182.
    [1]
  4. (iii) With q = 1: a·b = 10 − 3 − 4 = 3, |b| = √(25 + 1 + 1) = 3√3. Projection = a·b/|b| = 3/(3√3) = 1/√3 = √3/3.
    [1]
Answer
(i) q = 2; (ii) ±(−13i + 22j + 23k)/√1182; (iii) 1/√3.
Marking note Accept the positive unit vector alone; the ± is shown for completeness.

Concepts to recall

  • Perpendicular vectors: a·b = 0.
  • A vector perpendicular to both is a × b; divide by its magnitude for the unit vector (either sign is correct).
  • Projection of a on b (a scalar) = a·b/|b|; the vector projection would also carry the direction b/|b|.

Question 17 · Board 2025[4]
Consider the position vectors of A, B and C as OA = 2î − 2ĵ + k̂, OB = î + 2ĵ − 2k̂ and OC = 2î − ĵ + 4k̂. (i) Calculate AB and BC. [1] (ii) Find the projection of AB on BC. [1] (iii) Find the area of the triangle ABC whose sides are AB and BC. [2]
  1. (i) AB = OB − OA = (1 − 2, 2 + 2, −2 − 1) = −î + 4ĵ − 3k̂; BC = OC − OB = (2 − 1, −1 − 2, 4 + 2) = î − 3ĵ + 6k̂.
    [1]
  2. (ii) Projection of AB on BC = AB·BC/|BC| = (−1 − 12 − 18)/√(1 + 9 + 36) = −31/√46 (about −4·57).
    [1]
  3. (iii) AB × BC = îĵk̂−14−31−36 = (24 − 9)î − (−6 + 3)ĵ + (3 − 4)k̂ = 15î + 3ĵ − k̂.
    [1]
  4. Area = ½|AB × BC| = ½√(225 + 9 + 1) = √235/2 sq. units (about 7·66).
    [1]
Answer
(i) −î + 4ĵ − 3k̂, î − 3ĵ + 6k̂; (ii) −31/√46; (iii) √235/2 sq. units.
Common slip Reporting the projection as 31/√46: the sign matters, since AB makes an obtuse angle with BC.

Concepts to recall

  • AB = (position vector of B) − (position vector of A): head minus tail.
  • Projection of a on b = a·b/|b| (a scalar, may be negative); the projection vector would be (a·b/|b|2)b.
