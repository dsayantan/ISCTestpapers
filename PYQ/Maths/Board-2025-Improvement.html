Question 1(i)[1]
Find the value of μ if the following system of equations is consistent: 2x + 3y − 8 = 0,  7x − 5y + 3 = 0,  4x − 6y + μ = 0.
(a)4
(b)6
(c)8
(d)2
  1. Solve the first two equations: 2x + 3y = 8 and 7x − 5y = −3. Eliminating y: 31x = 31, so x = 1 and y = 2.
    [½]
  2. Three lines are consistent only if the common point also satisfies the third: 4(1) − 6(2) + μ = 0, so μ = 8.
    [½]
Answer
(c) 8

Concepts to recall

  • Three equations in two unknowns are consistent when the solution of two of them satisfies the third (equivalently, the 3 × 3 determinant of coefficients is 0).
  • Check by determinant: |2 3 −8; 7 −5 3; 4 −6 μ| = 0 gives μ = 8.

Question 1(ii)[1]
If x = a cos θ, y = a sin θ, then dy/dx at θ = π/2 will be:
(a)−1
(b)Not defined
(c)1/a
(d)0
  1. dx/dθ = −a sin θ, dy/dθ = a cos θ, so dy/dx = −cot θ.
    [½]
  2. At θ = π/2: −cot(π/2) = 0.
    [½]
Answer
(d) 0
Common slip Putting θ = π/2 into tan θ instead of −cot θ gives "not defined".

Consider the graph of the derivative of f(x) shown. Assertion: f(x) is a quadratic function. Reason: The derivative of every quadratic function is linear.
(a)Both Assertion and Reason are true and Reason is the correct explanation of Assertion.
(b)Both Assertion and Reason are true but Reason is not the correct explanation of Assertion.

Question 1(v)[1]
Assertion: If A is a skew-symmetric matrix of order 3 × 3, then det(A) = 0. Reason: If A is a square matrix, then det(A) = det(A′).
(a)Both Assertion and Reason are true and Reason is the correct explanation of Assertion.
(b)Both Assertion and Reason are true but Reason is not the correct explanation of Assertion.
(c)Assertion is true and Reason is false.
(d)Assertion is false and Reason is true.
  1. A′ = −A, so det(A) = det(A′) = det(−A) = (−1)3 det(A) = −det(A), giving det(A) = 0: the Assertion is true.
    [½]
  2. The Reason is a true general property, but it is only one step of the argument; it alone says nothing about the value 0 (the key step is det(−A) = (−1)3det A for order 3). So the Reason is true but not the full explanation.
    [½]
Answer
(b) Both Assertion and Reason are true but Reason is not the correct explanation of Assertion.
Marking note A reader who treats det(A) = det(A′) as the explanation would choose (a); the standard textbook reading, followed here, is that the Reason is not sufficient by itself.

Concepts to recall

  • A skew-symmetric matrix of odd order always has determinant 0; of even order it need not be zero (a perfect square).
  • det(A′) = det(A) for every square matrix; det(kA) = kn det(A) for order n.

The derivative of tan−1[(cos x − sin x)/(cos x + sin x)] with respect to x, where x ∈ (0, π/2), is:

Question 1(ix)[1]
If P(A) = 3/10, P(B) = 2/5 and P(A ∪ B) = 3/5, then the value of P(A|B) + P(B|A) is:
(a)1/12
(b)7/12
(c)1/10
(d)1/3
  1. P(A ∩ B) = P(A) + P(B) − P(A ∪ B) = 3/10 + 4/10 − 6/10 = 1/10.
    [½]
  2. P(A|B) = (1/10)/(2/5) = 1/4; P(B|A) = (1/10)/(3/10) = 1/3; sum = 1/4 + 1/3 = 7/12.

(b) 7/12

Question 1(x)[1]
Consider the graph of f(x), f: ℝ → ℝ (two branches, as for y = 1/x). Statement 1: The function is one-one. Statement 2: The function is onto.
(a)Statement 1 is true and Statement 2 is false.
(b)Statement 2 is true and Statement 1 is false.
(c)Both the statements are true.
(d)Both the statements are false.
  1. Any horizontal line cuts the graph at most once (each value is taken by only one x): the function is one-one. Statement 1 true.
    [½]
  2. The graph never meets the x-axis, so 0 ∈ codomain ℝ has no pre-image; the range is ℝ − {0} ≠ ℝ. Not onto: Statement 2 false.
    [½]
Answer
(a) Statement 1 is true and Statement 2 is false.

Concepts to recall

  • Horizontal line test: one-one if every horizontal line meets the graph at most once; onto if every horizontal line (every y in the codomain) meets it at least once.
  • Onto means range = codomain.

Question 1(xi)[1]
The sum 2xyzpqrabc + xyzstu2a2b2c is equal to which one of the following?
(a)3x3y3z2p + s2q + t2r + u4a4b4c
(b)2x2y2z2p + s2q + t2r + u2a2b2c
(c)xyzp + sq + tr + u2a2b2c
(d)2x2y2zp + sq + tr + u4a4b4c
  1. A factor 2 can be taken into one row of a determinant: 2D1 is D1 with its third row multiplied by 2, i.e. rows (x, y, z), (p, q, r), (2a, 2b, 2c).
    [½]
  2. Now the two determinants agree in rows 1 and 3, so they add by adding the second rows: (p + s, q + t, r + u). This is option (c).
    [½]
Answer
(c) xyzp + sq + tr + u2a2b2c
Common slip Multiplying every row by 2 gives 8D, not 2D (options (a), (b) and (d) make that error).

Concepts to recall

  • Property: if the elements of one row are written as sums, the determinant splits into the sum of two determinants; conversely two determinants that differ in only one row add by adding that row.
  • A scalar multiplier k multiplies one row (or column) only, not the whole determinant: k·D = D with one row multiplied by k.

Question 1(xiii)[1]
If R is a relation from {11, 12, 13} to {8, 10, 12} defined by y = x − 3, find the range of R−1.
  1. x = 11 gives y = 8 ∈ B; x = 12 gives 9 ∉ B; x = 13 gives 10 ∈ B. So R = {(11, 8), (13, 10)}, and R−1 = {(8, 11), (10, 13)}.
    [½]
  2. Range of R−1 = set of second elements = domain of R = {11, 13}.
    [½]
Answer
{11, 13}
Common slip Including 12 (whose image 9 is not in {8, 10, 12}) or writing the range as {8, 10}.

Concepts to recall

  • R−1 = {(b, a) : (a, b) ∈ R}, so domain(R−1) = range(R) and range(R−1) = domain(R).

Using the properties of determinants, prove that 111abca3b3c3 = (a − b)(b − c)(c − a)(a + b + c)

Question 8[4]
(i) If x = sin t, y = sin pt, prove that (1 − x2) d2y/dx2 − x dy/dx + p2y = 0.
OR
(ii) In a particular forest, the population density (P) of wild animals (in thousands of animals per sq. km) at a distance ‘r’ km from the centre of the forest is approximately given by P = 10 + 20r − 10r2.
(a) What is the population density in the centre of the forest? (b) Calculate the rate of change of population density. (c) For what value of ‘r’ is the population density maximum? (d) Prove that the population density of animals varies with distance from the centre.

    [1]
