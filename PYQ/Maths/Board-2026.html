If A is a square matrix of order 3 and its determinant is |A| = −3, then the value of |−4A| is:
(a)202
(b)192
(c)−212
(d)−192
  1. For a square matrix of order n, |kA| = kn|A|. Here n = 3 and k = −4.
    [½]
  2. |−4A| = (−4)3|A| = (−64)(−3) = 192.
    [½]
Answer
(b) 192
Common slip Writing |−4A| = −4|A| = 12.

Concepts to recall

  • |kA| = kn|A| for a matrix of order n (every one of the n rows gets the factor k).
  • Do not confuse it with the scalar multiple of the matrix elements: the determinant picks up k3, not k.

Question 1(ii)[1]
Consider the function ‘f’ given by f(x) = log x, x > 0, then the function ‘f’ is:
(a)differentiable and continuous at x = 1.
(b)differentiable but not continuous at x = 1.
(c)continuous but not differentiable at x = 1.
(d)neither differentiable nor continuous at x = 1.
  1. log x is defined for every x > 0, so limx→1 log x = log 1 = 0 = f(1): continuous at x = 1.
    [½]
  2. f′(x) = 1/x exists for all x > 0, in particular f′(1) = 1: differentiable at x = 1.
    [½]
Answer
(a) differentiable and continuous at x = 1.

Concepts to recall

  • Every elementary function (polynomial, log, exponential, trigonometric) is continuous and differentiable throughout its domain.
  • Differentiable ⇒ continuous. The converse fails only at sharp corners such as |x|.

Question 1(iii)[1]
If events A and B are mutually exclusive, such that P(A) = 1/5 and P(B) = 2/3, then the value of P(A ∪ B) is:
(a)11/15
(b)3/15
(c)14/15
(d)13/15
  1. Mutually exclusive: P(A ∩ B) = 0, so P(A ∪ B) = P(A) + P(B) − P(A ∩ B) = P(A) + P(B).
    [½]
  2. = 1/5 + 2/3 = 3/15 + 10/15 = 13/15.
    [½]
Answer
(d) 13/15

Concepts to recall

  • Addition theorem: P(A ∪ B) = P(A) + P(B) − P(A ∩ B).
  • Mutually exclusive events cannot occur together: P(A ∩ B) = 0 (not P(A)P(B), which is for independent events).

Question 1(viii)[1]
Observe the graph given below and answer the question that follows.
Statement 1: f(x) increases in (−∞, −1) and (1, ∞)
Statement 2: f(x) decreases in (−∞, 0) and (1, ∞)
Which one of the following is correct?
(a)Statement 1 is true and Statement 2 is false.
(b)Statement 2 is true and Statement 1 is false.
(c)Both the statements are true.
(d)Both the statements are false.
  1. Read the graph (y = |x2 − 1|): it falls on (−∞, −1), rises on (−1, 0), falls on (0, 1) and rises on (1, ∞).
    [½]
  2. Statement 1 claims f increases on (−∞, −1): it decreases there, so Statement 1 is false. Statement 2 claims it decreases on (−∞, 0) and (1, ∞): it increases on (−1, 0) and on (1, ∞), so Statement 2 is false. Both are false.
    [½]

(d) Both the statements are false.

Concepts to recall

  • Increasing: the graph rises as x increases (f′ > 0); decreasing: it falls (f′ < 0). Read left to right.
  • A statement about a union of intervals is true only if it holds on every interval in it.

Question 1(ix)[1]
If set A contains four elements and set B contains five elements, then the number of one-one and onto mapping from A → B is:
(a)120
(b)0
(c)720
(d)20
  1. A one-one function from A to B needs at least as many elements in B as in A, which is true here, but an onto function needs every element of B to be an image.
    [½]
  2. Four elements can have at most four distinct images, so the range has at most 4 elements and cannot equal B (5 elements). Hence no bijection exists: the number is 0.
    [½]
Answer
(b) 0
Common slip Choosing 120 = 5P4, which counts one-one maps only.

Concepts to recall

  • A bijection between finite sets exists only if the sets have the same number of elements; then the count is n!.
  • The number of one-one maps from an m-set to an n-set (m ≤ n) is nPm = 120 here, a tempting wrong answer.

Question 1(xi)[1]
Assertion: The system of three linear equations in three unknown variables can be written in the matrix form as AX = B. It has a unique solution X = A−1B.
Reason: Matrix A is non-singular.
(a)Both Assertion and Reason are true and Reason is the correct explanation for Assertion.
(b)Both Assertion and Reason are true but Reason is not the correct explanation for Assertion.
(c)Assertion is true and Reason is false.
(d)Assertion is false and Reason is true.
  1. AX = B has the unique solution X = A−1B exactly when A−1 exists, i.e. when |A| ≠ 0, i.e. A is non-singular.
    [½]
  2. So the Reason (A non-singular) is the condition under which the Assertion holds: both are true and the Reason explains the Assertion.
    [½]
Answer
(a) Both Assertion and Reason are true and Reason is the correct explanation for Assertion.

  • A−1 exists ⇔ |A| ≠ 0 (A non-singular). Then AX = B has the unique solution X = A−1B.

Question 1(xv)[1]
A relation R on the set A = {a, b, c} is defined by R = {(a, b), (b, a)}. Is the relation R symmetric? Justify.
  1. R is symmetric if (x, y) ∈ R ⇒ (y, x) ∈ R. Here (a, b) ∈ R and its reverse (b, a) ∈ R; (b, a) ∈ R and its reverse (a, b) ∈ R.
    [½]
  2. Every pair has its reverse in R, so R is symmetric (it is not reflexive, as (a, a) ∉ R, but that is not asked).
    [½]
Answer
Yes, R is symmetric.

Concepts to recall

  • Symmetric: (x, y) ∈ R ⇒ (y, x) ∈ R. Reflexive: (x, x) ∈ R for all x. Transitive: (x, y), (y, z) ∈ R ⇒ (x, z) ∈ R.
  • For a relation given as a list, check each listed pair against its reverse; a missing element elsewhere in A does not matter for symmetry.

Question 2[2]
Using properties of determinant, show that: b − cc − aa − bc − aa − bb − c2(a − b)2(b − c)2(c − a) = 0

    [1]
  2. New C1: row 1 = (b − c) + (c − a) + (a − b) = 0; row 2 = (c − a) + (a − b) + (b − c) = 0; row 3 = 2[(a − b) + (b − c) + (c − a)] = 0. A determinant with a whole column of zeros is 0, so Δ = 0. Hence shown.
    [1]

Δ = 0 (shown)

Question 3[2]
(i) Let f(x) = 4 − (x − 7)3 be an invertible function, then find f−1(x).
OR
(ii) Find the range of the function f(x) = 13 − 2 sin x.

Solution to the first alternative

  1. Put y = f(x) = 4 − (x − 7)3. Then (x − 7)3 = 4 − y.
    [1]
  2. x − 7 = (4 − y)1/3, so x = 7 + (4 − y)1/3. Interchanging the names: f−1(x) = 7 + (4 − x)1/3.
    [1]
Answer
f−1(x) = 7 + (4 − x)1/3

Solution to the OR alternative

  1. −1 ≤ sin x ≤ 1 ⇒ −2 ≤ −2 sin x ≤ 2 ⇒ 1 ≤ 3 − 2 sin x ≤ 5. The denominator is always positive, so f is defined for all real x.
    [1]
  2. Taking reciprocals (all positive) reverses the inequalities: 1/5 ≤ f(x) ≤ 1, and both ends are attained (sin x = 1 and −1). Range = [1/5, 1].
    [1]
Answer
Range = [1/5, 1]

Concepts to recall

  • To find an inverse: write y = f(x), solve for x in terms of y, then swap the letters.
  • Cube roots are defined for negative numbers too, so (4 − x)1/3 exists for every real x: f is a bijection ℝ → ℝ.
  • Check: f(f−1(x)) = 4 − (4 − x) = x.
  • Range of a function built from sin x: first bound the inner expression using −1 ≤ sin x ≤ 1.
  • Reciprocal of a positive quantity in [m, M] lies in [1/M, 1/m].

Question 5[2]
A die marked 1, 2, 3 in red and 4, 5, 6 in green is thrown. Let A be the event ‘Number appearing is odd’ and B be the event ‘Number appearing is green’.
Prove that the events A and B are not independent.
  1. Sample space S = {1, 2, 3, 4, 5, 6}. A = {1, 3, 5}, B = {4, 5, 6}, A ∩ B = {5}. So P(A) = 3/6 = 1/2, P(B) = 3/6 = 1/2, P(A ∩ B) = 1/6.
    [1]
  2. P(A)·P(B) = 1/4 ≠ 1/6 = P(A ∩ B). Independence requires P(A ∩ B) = P(A)P(B), so A and B are not independent.
    [1]
Answer
P(A ∩ B) = 1/6 ≠ P(A)P(B) = 1/4, hence not independent.

Concepts to recall

  • Events A, B are independent ⇔ P(A ∩ B) = P(A)·P(B).

Question 6[2]
(i) The surface of a spherical balloon is increasing at the rate of 4 cm2/sec. Find the rate of change of volume when its radius is 12 cm.
OR
(ii) Find the equation of the normal at (1, 2) to the curve x2 = 4y.

Solution to the first alternative

  1. S = 4πr2 ⇒ dS/dt = 8πr dr/dt = 4, so dr/dt = 1/(2πr).
    [1]
  2. V = (4/3)πr3 ⇒ dV/dt = 4πr2 dr/dt = 4πr2/(2πr) = 2r. At r = 12: dV/dt = 24 cm3/sec.
    [1]
Answer
dV/dt = 24 cm3/s

Solution to the OR alternative

  1. Misprint: the point (1, 2) does not lie on x2 = 4y (1 ≠ 8). The point meant is (2, 1) (coordinates written the other way round), and that reading is solved here.
  2. 2x = 4 dy/dx ⇒ dy/dx = x/2; slope of tangent at (2, 1) is 1.
    [½]
  3. Slope of normal = −1/(slope of tangent) = −1.
    [½]
  4. Normal: y − 1 = −1(x − 2), i.e. x + y − 3 = 0.
    [1]
Answer
x + y = 3 (at the point (2, 1))
Marking note As printed, (1, 2) is not on the curve. If the intended point was (1, 1/4) the normal is 8x + 4y − 9 = 0 (slope of normal −2). Award full marks for a correct method on any consistent reading, and credit a candidate who points out that the point is not on the curve.

Concepts to recall

  • Related rates: write the formula connecting the quantities, differentiate with respect to t using the chain rule, then substitute the instant’s value.
  • Sphere: S = 4πr2, V = (4/3)πr3; note dV/dt = (r/2)(dS/dt) always.
  • Slope of tangent = dy/dx at the point; slope of normal = −1/(dy/dx).
  • Equation of normal at (x1, y1): y − y1 = −(x − x1)/(dy/dx). Always check that the given point lies on the curve.

(i) If tan−1( (√(1+x2) − √(1−x2)) / (√(1+x2) + √(1−x2)) ) = α, prove that sin 2α = x2.
